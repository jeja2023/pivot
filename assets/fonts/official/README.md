# 截图公文标准的字体配置

严格公文导出使用用户指定的原字体：

| 用途 | 字体 | 默认文件名 |
| --- | --- | --- |
| 标题 | 方正小标宋_GBK | 方正小标宋_GBK.TTF |
| 正文、主送、落款、附件说明 | 方正仿宋_GBK | 方正仿宋_GBK.TTF |
| 一级层级、附件标识 | 方正黑体_GBK | 方正黑体_GBK.TTF |
| 二级层级 | 方正楷体_GBK | 方正楷体_GBK.TTF |
| 页码 | 宋体 | simsun.ttc |
| 阿拉伯数字和西文 | Times New Roman | times.ttf |

字体文件不随本仓库分发。Windows 服务优先读取本目录/`PIVOT_PDF_FONT_DIR`，并可使用 `C:\Windows\Fonts` 中已安装的字体。本次验收机器已安装全部六种原字体。

其他服务器需要把有授权且允许嵌入的上述字体安装或挂载到字体目录，可沿用 `PIVOT_PDF_FONT_DIR` 指定目录。加载器会校验字体内部族名与嵌入标记；不接受仅改文件名的替代字体。缺失或禁止嵌入时，严格公文 DOCX/PDF 导出会明确失败，不会用 Noto、系统仿宋或其他字体冒充截图格式。

DOCX 写入准确的中西文字体名，PDF 嵌入对应字形子集。接收 DOCX 的电脑也应安装相应字体；不同电脑缺字体时 Word 可能自行替代，应用无法把该替代结果标为合规。PDF 已嵌入字形，可用于固定版式流转。
