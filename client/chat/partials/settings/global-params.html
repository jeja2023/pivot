全局参数

运行时调整并发、上下文、采样、上传、图片与检索参数，字段名和说明已统一为中文，无需修改配置文件或重启服务。

请求队列

控制聊天请求与模型端点的并发、排队和超时，优先保证服务稳定。

max_concurrent_ai_requests
max_ai_queue_size
ai_queue_timeout_ms
model_endpoint_default_concurrency
model_endpoint_queue_size
model_endpoint_queue_timeout_ms

上下文预算

控制默认上下文窗口、输出预留和附件注入预算，影响所有未单独配置的模型。

model_context_window_tokens
memory_threshold
context_reserved_output_tokens
attachment_context_max_chars

采样参数

统一聊天和 OpenAI 兼容接口的默认采样行为，便于整体调参。

sampling_temperature
sampling_top_p
sampling_presence_penalty
sampling_frequency_penalty

上传附件

控制聊天附件、知识库文件和图片输入的大小及图片数量，避免单次请求过重。

upload_attachment_max_bytes
knowledge_upload_max_bytes
image_upload_max_bytes
image_context_max_bytes
max_attachments_per_message
max_images_per_message

知识库检索

控制 RAG 召回、切片和上下文预算，尽量在信息量和上下文占用之间保持平衡。

rag_top_k_max
rag_candidate_limit_max
rag_chunk_size_max
rag_context_budget_percent
knowledge_extract_max_chars
rag_index_max_concurrent

智能体后台

控制智能体任务、工作流和记忆压缩并发，适合按服务器资源做整体调度。

agent_max_concurrent_runs
agent_dag_node_concurrency
memory_compression_max_concurrent
chat_auto_agent_enabled（兼容键）

安全与终端隐身

开启后服务端将对普通 Web 浏览器和外部扫描完全隐身（直接掐断连接，显示 ERR_EMPTY_RESPONSE），只有官方 Pivot 桌面客户端可连接访问。

stealth_mode_enabled · 开启后外部访问将直接物理断开连接
远程客户端连接时填入 desktop-config.json 或连接配置窗口中
