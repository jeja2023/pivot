# Pivot v0.3.0 需求规格说明书 (SRS)

> **文档版本**：1.0  
> **适用版本**：Pivot v0.3.0  
> **目标用户**：架构师、研发工程师、产品经理、质量保障工程师

---

## 1. 业务目标

解决复杂业务场景下工作流配置门槛高、任务分解缺乏灵活性、模型流式输出体验割裂、缺少可视化成果沉淀空间及智能体交付缺乏量化评测手段的核心痛点。

## 2. 功能需求规格

### 2.1 工作流模板库 (FR-01)
- **FR-01-1 模板商城浏览**：支持按分类、难度、标签检索与分页查询。
- **FR-01-2 动态变量配置**：支持 string, number, select, connection_id, model_id, boolean 等类型，支持正则与范围校验。
- **FR-01-3 变量替换与实例化**：解析 `{{var.name}}` 占位符，自动生成初始工作流与初始发布版本。
- **FR-01-4 模板评分与反馈**：支持 1-5 星评分与使用心得评论，自动加权更新平均分。

### 2.2 实时流式输出系统 (FR-02)
- **FR-02-1 SSE 事件流推送**：支持 started, thinking, tool_call, output, completed, error, progress 等 7 类事件。
- **FR-02-2 思考链可视化**：前端支持折叠式思考过程面板与步骤耗时感知。
- **FR-02-3 断线缓冲与重连**：服务端保留事件序号，客户端支持基于 Last-Event-ID 的恢复重放。

### 2.3 评测与质量保障体系 (FR-03)
- **FR-03-1 自动化评测流水线**：支持批量运行测试用例并收集实际输出与指标。
- **FR-03-2 五维加权评分模型**：准确性、成本、延迟、可靠性与综合评分计算。
- **FR-03-3 回归质检与对比**：对比目标版本与历史基准版本指标，检测性能退化。

### 2.4 工具推荐系统 (FR-04)
- **FR-04-1 协同过滤推荐**：基于用户使用行为计算工具关联度矩阵与 Top-N 推荐。
- **FR-04-2 转移概率预测**：马尔可夫链分析上游工具调用后的下一跳工具推荐。

### 2.5 增强规划引擎 (FR-05)
- **FR-05-1 动态任务分解**：递归将高层目标分解为子任务 DAG，支持最大深度与最大任务数限制。
- **FR-05-2 自适应拓扑调整**：在执行中根据节点输出动态修改拓扑并审计记录。

### 2.6 Artifacts 交互空间 (FR-06)
- **FR-06-1 多模态沙箱渲染**：HTML、React、Vue、Markdown、Code、SVG 隔离预览。
- **FR-06-2 多版本管理**：修改保留历史版本快照，支持原子回滚。
- **FR-06-3 安全分享与讨论**：公开链接过期控制、线程化讨论批注。

### 2.7 编排 DSL 规范 (FR-07)
- **FR-07-1 声明式语法解析**：词法与 AST 解析验证，环路检测。
- **FR-07-2 拓扑并行调度**：按依赖层级调度多智能体协作执行。
