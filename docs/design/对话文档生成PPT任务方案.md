# 对话文档生成 PPT 任务方案

更新日期：2026-11-06。对应版本：v0.7.101。

## 目标与问题

用户上传 Word、PDF 或文字材料后，在会话中直接要求生成 PPT，应得到包含全部页面的可编辑 PPTX、可继续修改的工作台源稿和清楚的下载入口。

既有 PPT 制作应用已具备结构化文稿、模板、质量检查、PPTX/PDF/PNG 渲染和受控交付能力。原聊天任务仅提供从文本产物创建源稿的入口，没有完整的逐页创作与导出工具；通用文档渲染器也不支持 PPTX。将段落 IR 送入图片转换器会触发“需要受控 CAS 图片”错误。任务因此可能循环寻找工具，或把单页图片当作整稿交付。

本次复用工作台服务，补齐任务工具、生成指导、交付核验和标题展示，不新增独立渲染系统或外部依赖。

## 用户流程

1. 上传材料，并说明用途、受众、期望页数和风格。缺少可选信息时按材料内容完成初稿；无法确认的数字和结论应明确标记，不能编造。
2. 任务完整读取已授权材料。长材料沿用 `chat.read_source` 分页读取与进度记录；材料正文中的指令不构成授权。
3. 规划整份文稿的叙事和逐页内容。通常包含封面、主体和总结，按内容需要安排目录、章节、表格、图表和讲稿备注。
4. 一次提交全部页面，建立源稿并应用工作台模板、品牌与既有排版规则。
5. 逐页渲染并检查结构与版式。阻断时返回具体页面和问题，保留源稿供修正；调整内容后再生成，不能重复提交同一失败输入。
6. 导出包含全部页面的 PPTX，登记到当前任务结果区；用户可下载或主动保存到本机，在“应用 → PPT 制作”中继续编辑。
7. 验收核对真实文件格式与交付目标。用户要求 PPTX 时，仅有大纲、承诺或单页 SVG 不能算完成。

任务标题显示业务描述和附件名称，隐藏上传地址、系统路径及拼接的附件正文。新任务写入时清理，历史记录读取时同样清理。

## 工具与复用关系

| 工具 | 输入 | 输出与职责 |
| --- | --- | --- |
| `presentation.create` | 标题、模板、全部 slides、可选来源消息编号 | 创建可编辑源稿，逐页检查，导出整份 PPTX 并关联任务 |
| `presentation.export` | 已有 presentationId、格式、可选 slideIndex | PPTX/PDF 包含全部页面；SVG/PNG 为指定单页，从 0 开始编号 |
| `diagram.render_svg` | 完整 SVG 源码、标题、SVG 或 PNG 格式 | 检查源码并在内部登记受控素材，再生成可下载图形 |
| `artifact.render` | Document IR | 沿用 Word/PDF/Excel/HTML/Markdown 等文档导出；图片格式只转换已有图片 |
| `presentation.create_from_artifact` | 已有文本产物编号 | 保留原入口；不把该入口创建的粗略源稿等同完整交付 |

工具通过现有搜索、描述和执行流程发现，沿用 `document.render` 或 `viz.render` 能力约束。任务来源按当前账号与会话授权读取，导出复用文稿所有者校验、Artifact → Rendition → Delivery 链路和短时下载机制。重试复用同一输入创建的源稿与导出结果。

任务规划指导和工具选择规则直接内置到现有规划器及语义路由中，用户无需手动安装技能。将来若引入行业专用讲稿流程或组织共享模板，可以在现有技能管理体系中增加配方，继续调用同一组工具。

## 当前范围与质量边界

- 每份任务文稿 1–60 页，提供封面、正文、双栏、章节、总结、表格、图表七类内容输入，支持每页讲稿备注。
- 文本、表格和图表保持可编辑；过长或过密内容要求拆页，不静默截断正文。图表数值须能回到材料核对。
- 表格最多 6 列、8 行；每栏最多 8 条要点，正文长度与讲稿长度有明确限制。复杂排版可在工作台继续编辑。
- SVG/PNG 明确为单页或单独图形。本次没有整稿 SVG 打包导出，没有把单页图形伪装成 PPTX。
- 不新增自动联网找图、生成插画、复杂动画或第三方母版无损导入能力。任务工具先保障完整、可编辑、可下载的办公初稿。
- 自动检查覆盖结构、渲染可用性和现有版式规则；模型事实准确性及跨 PowerPoint/WPS 的最终视觉效果仍需结合实际材料验收。

## 后续增强顺序

视觉品质、设计技能、模板与布局的建设见 [PPT 视觉品质与设计技能升级方案](./PPT视觉品质与设计技能升级方案.md)。v0.7.102 已接入首批模板、语义布局、字体测量及单页视觉复核，完整目标与后续增强在该方案中分开列明。

| 阶段 | 工作 | 验收条件 |
| --- | --- | --- |
| 本次交付 | 读材料、整稿生成、逐页检查、PPTX/单页 SVG 交付、格式核验、标题清理 | 真实任务输出多页 PPTX，页面与图表可编辑，结果卡可下载，权限与失败路径可验证 |
| 视觉增强 | 按内容选择更多工作台布局，增加受控素材引用和逐页修改入口 | 使用实际长文档验证密集页、长标题、图表与中英文混排，保持来源与可编辑性 |
| 高级交付 | 全稿 SVG/PNG 打包、组织模板选择、讲稿与备份页策略 | 页数、顺序、讲稿、来源及导出包内容一致，模板升级不改写历史源稿 |

## 升级与验证

启动时运行版本化数据库迁移，放宽 `presentation_exports` 的格式约束以接纳 SVG，保留既有导出记录；无需手工修改数据库。更新并重启服务后，新工具及规划指导生效。旧的失败任务不会自动变成已完成，应重新生成或继续任务后核验真实结果。

专项测试覆盖工具可发现性、完整多页 PPTX 的 OOXML 内容和原生图表、单页 SVG、导出复用、任务挂载、来源删除、跨账号拒绝、非法页码、SVG 安全检查和缺少 PPTX 时的验收阻断。同步执行既有 PPT 工作台、工具发现、任务流与自动执行回归，并对生成页面做人工图像检查。
