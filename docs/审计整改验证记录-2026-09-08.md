# Pivot 审计整改与验证记录

更新时间：2026-09-08

## 范围

本记录以 `.tmp/审计结论.md` 的 140 条线索为整改输入，记录当前代码、迁移和门禁的落地状态。

经需求确认，本轮不处理以下两项：

- 暗色主题未完整接线；
- `stealthSecret` 的业务分发与交互方式。

## 已落地的核心整改

- 数据库 MCP：只读 SQL 规则、行数上限、共享连接白名单、IPv6/DNS SSRF 防护、统一工具治理与审计路径已收口；PostgreSQL/MySQL 增加会话级只读保护。
- 鉴权与凭据：访问令牌版本撤销、刷新令牌家族重放检测与设备绑定、API Key 作用域/有效期、密码强度与异步 bcrypt、IP 与账号双维度登录限流均已实施。
- RAG：索引采用暂存后原子切换；嵌入失败不再伪造“就绪”；查询向量缓存、批量落库、并行候选召回、图谱融合、字符偏移引用和上下文裁剪保留引用尾部均已实现。
- Agent：非幂等恢复需重新审批、终态副作用统一执行、步骤唯一性、审批去重、重试指数退避与持久化调度、队列真实状态统计已实现；DAG 工具 checkpoint key 固定为运行、节点与规范输入摘要，不再随重试 attempt 改变；运行元数据由可重试 CAS 补丁更新，避免审批、聊天回写等并发更新互相覆盖。
- 运行可靠性：健康检查真实探测数据库，SSE 有连接上限、取消和有界背压；首响应超时、流无进展超时和用户取消共用流控制器并保留诊断错误码；优雅关闭会先通知并释放 SSE 客户端、停止受跟踪的沙箱/能力工作进程、收口空闲与存量 HTTP 连接，再刷新写队列和关闭连接池；存储 GC 已增加磁盘孤儿文件对账。
- 桌面与交付：特权配置窗口隔离、敏感 JSON 原子写入、默认拒绝渲染页系统权限；远程桌面安装包不再携带本地 Agent Chromium 运行时，本地档位才临时注入并自检该运行时，且会裁剪 Chromium 安装/提权/PWA/WebGPU 辅助文件与未选语言；better-sqlite3 和 KaTeX 字体已完成精简/完整性校验。Docker 默认裁去未启用 MySQL、SQL Server、MongoDB 驱动的依赖闭包，桌面包默认保留三类驱动，只有显式设置 `PIVOT_DESKTOP_DB_CONNECTORS` 时才裁剪；正式 Windows 发布包强制 HTTPS 更新源、代码签名发布者和签名凭据。远程客户端的 `local_database` 授权桥仍只支持本机 SQLite 文件，未将驱动裁剪误认为本机数据库直连协议。
- 前端性能与安全：业务脚本使用 `defer`；聊天 CSS 由模块源生成单一受校验 bundle，已删除无引用的会话标签、旧提示词库、法规旧布局和数据分析旧面板选择器并以契约测试防回流；大型隐藏工作区改为同源按需模板；个人、应用、Agent、工作流、知识库、工具库和设置的导航统一经 `workspaces.navigation`/`implementations` 模块 API，不再由调用点直接依赖 legacy 兼容命名空间；代码高亮限集合并缓存；Markdown 仅在安全 DOM 插入点消毒一次；ECharts 选项禁用字符串 formatter。
- 工程治理：PG 迁移必须提供 `upPg` 或显式基线，架构边界、失效异步白名单、依赖 overrides、第三方许可、死导出、生产直接 SQL 和 legacy 全局别名均已接入阻断门禁。大文件基线会随缩小自动要求收紧；文档 IR 与技能域共享的摘要工具已解耦；Agent Runtime 已移除无边界平铺导出，只提供按领域分组 API，运行元数据采用可重试 CAS 补丁避免并发写丢失。

## 新增运行与发布注意事项

- `.env.example` 现在明确最小启动集，且不再提供可直接使用的 PostgreSQL 密码。
- 生产启动会校验 `DATABASE_URL` 的 PostgreSQL 协议和 URL 格式，并拒绝 `JWT_SECRET` 与 `DATA_ENCRYPTION_KEY` 复用；不会因存量 PostgreSQL 密码复杂度不足阻断启动。
- 现有环境可以继续使用当前 PostgreSQL 密码；如运维有轮换要求，再按数据库自身策略更新账户和 `.env`。程序不会代替运维修改数据库账户。
- `npm run clean:workspace` 只做预览；`npm run clean:workspace -- --yes` 才会清理 `.tmp`、`.codex-tmp` 与限定测试产物，且保护浏览器/运行时/发布构建输入目录。
- 根目录 `config.json` 固定为开发机本地地址与独立 Electron session 分区。正式客户端必须使用未纳入 Git 的 `PIVOT_DISTRIBUTION_CONFIG`，Windows 更新发布还必须提供 HTTPS 更新源、签名发布者和代码签名凭据；构建中断后会在下次启动时自动恢复临时修改的构建输入。
