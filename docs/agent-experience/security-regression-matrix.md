# Agent Security Regression Matrix

每一行均须给出可执行测试证据；`npm run check:regression-matrix` 会校验测试文件和测试标题仍然存在。这里的证据代表已覆盖的行为路径，不把参数归一化测试伪装成完整故障演练。

| Area | Regression | Evidence |
| --- | --- | --- |
| Chat task execution | 真实工具状态、增量回放、账号隔离、审批参数绑定与并发决定、文件就绪和下载、迟到响应隔离 | `tests/chat-task-feed.test.js#轻量任务进度按账号和有效来源会话隔离，并且隐藏模型事件后游标仍前进`<br>`tests/chat-task-controls-http.test.js#任务进度、审批续期、重复决定和暂停接口保留鉴权、归属及参数绑定`<br>`tests/chat-task-feed.test.js#实际关联产物可读取正确字节，过期后不再显示可下载，缺失核验不冒充通过`<br>`tests/e2e/chat-task-execution.spec.js#多任务卡补充与暂停绑定指定任务，历史翻页和迟到响应不串会话` |
| Natural conversation | 请求/答案幂等、同任务接续、最新能力撤回、长附件完整读取、作用域隔离、学习关闭栅栏与发布竞争 | `tests/chat-conversation-product.test.js#并发请求、租约失效和内容冲突均保持用户消息幂等`<br>`tests/chat-conversation-product.test.js#助手答案落库后进程中断，重试从消息唯一关联恢复且不会产生两份答案`<br>`tests/chat-conversation-product.test.js#运行中改为只规划立即暂停并收回能力，旧调度快照不能再写文件`<br>`tests/chat-conversation-product.test.js#首轮长附件按页读取真实消息，遗漏资料阻断完成，删除来源后不能继续读取`<br>`tests/chat-conversation-product.test.js#关闭学习推进写入栅栏、立即阻止自动发布，并与正在发布的作业串行化` |
