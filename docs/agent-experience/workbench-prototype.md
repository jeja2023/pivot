# Agent Workbench Prototype

```text
Agent 工作台
├─ 快速设置：称呼 / 语言 / 详略 / 常见工作
├─ 统一收件箱：运行 / 审批 / 失败 / 预算 / 工具异常 / 发布 / 提醒
├─ 持续目标：定时 / Webhook / 文件 / 数据库 / 暂停 / 恢复 / 熔断
├─ 个人档案：字段版本 / 恢复 / 并发冲突
├─ 记忆治理：分类 / 来源 / 使用原因 / 保留期 / 批量删除
├─ 反馈与质量：评分 / 修正 / 工具信号 / 管理员指标
└─ 能力发布：Skill/工作流 diff / 验证 / 评测 / 灰度 / 回滚
```

Every destructive or external action has a visible risk, expiry, approval state, and audit source. The same server APIs serve Web, Electron and future mobile clients.
