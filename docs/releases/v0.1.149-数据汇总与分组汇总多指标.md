# Pivot v0.1.149 发布记录：数据汇总与分组汇总多指标

## 发布概要

本版本将工作流中的整体统计与按维度统计拆分为两个清晰节点。数据汇总用于不分组的总体计算；数据分组汇总用于按一个或多个字段分组后的多指标计算。用户可以在同一次配置中返回记录数、总额、平均值等多个命名结果。

## 新增能力

- 新增 data.aggregate 数据汇总工具和常用工作流节点。
- 数据汇总对全部输入行生成一条汇总结果，不需要配置分组字段。
- 数据分组汇总保留原有多字段分组能力，并支持每个分组同时输出多个统计指标。
- 参数向导使用表格式可视编辑器配置统计方式、指标字段和结果名称；可从上游节点的实际字段候选中选择，也可手动输入。

## 使用边界

| 目标 | 选择节点 | 示例 |
| --- | --- | --- |
| 只要总体结果 | 数据汇总 | 订单总数、总金额、平均金额 |
| 要比较各维度结果 | 数据分组汇总 | 按部门统计订单数、总金额、平均金额 |

计数不要求选择指标字段。求和、平均值、最小值和最大值必须选择数值字段；编辑器和服务端都会在配置错误时阻止执行。输入行数、返回分组数和单次指标数均保留安全上限。

## 兼容性

历史工作流继续使用 valueField 与 aggregation 时，不需要迁移即可运行。原有输出字段 value、count、group、groupBy 和 groupByFields 仍会保留；新模式只是在结果行中增加以“结果名称”为键的统计字段。因此，已发布工作流的下游变量引用不会因为本次升级失效。

## 工具目录与治理

数据汇总已加入工具库、聊天工具目录、运行记录标签、工具策略页和单步测试样例。它和分组汇总一样，仍在既有 MCP Schema、会话工具白名单、工作流治理、审计和输入输出限制之内运行；本次改造没有扩大工具权限。

## 验证

- 数据汇总的计数、求和和平均值多指标计算通过回归测试。
- 分组汇总的多指标计算、旧版单指标兼容和缺少数值字段的拒绝路径通过回归测试。
- 节点预设、参数向导、编辑期校验、工具目录和中文展示相关回归测试通过。
