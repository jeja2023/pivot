# v0.7.53 扫描件引用与 WebDAV 同步保护

发布日期：2026-10-28

## 改动

- 扫描 PDF 的新 OCR 结果保存识别文字块与页面坐标，按文档、所有者、原文件哈希和页码隔离。引用高亮先验证权限、版本和文件哈希；仅当引用文字唯一匹配、坐标有效且渲染比例一致时使用 OCR 坐标，其他情况回退页码。高亮为 OCR 返回的文字块范围，可能包含同块中的相邻文字。
- WebDAV 删除同步默认为关闭，可由管理员在来源配置中显式启用；扫描不完整、下载失败或命中数量/深度限制时不归档。大比例缺失采用既有清单预览、限时一次性审批和重新扫描校验。WebDAV 源端 ACL 不会被继承，Pivot 继续严格按所有者和系统管理员隔离。

## 验证与部署

新增 PostgreSQL 迁移 `202610280004_knowledge_ocr_location`，依赖 v0.7.49–v0.7.50 的既有迁移。既有 OCR 缓存没有坐标，需重新识别才可能生成扫描件高亮；旧缓存本身不会自动更新。

测试使用真实生成的空白 PDF 和模拟 OCR 文字框，覆盖坐标范围、重复文本、跨用户/哈希缓存隔离；WebDAV 使用模拟服务。尚未在用户实际 OCR 服务和 WebDAV 产品上验证坐标格式、删除清单、网络权限或生产性能。

真实业务黄金集、容量压测和备份恢复演练未执行：目前没有独立生产测试环境。多种具体企业平台连接器与源端 ACL 对接仍需要目标产品和测试环境；不得将本版本视为这些验收已完成。
