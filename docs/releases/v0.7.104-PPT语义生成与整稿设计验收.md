# v0.7.104 PPT 语义生成与整稿设计验收

日期：2026-11-06。

## 功能升级

- 新主题从模型自由坐标生成改为语义页面协议，布局引擎负责槽位、几何与字号，聊天和工作台共用编译服务；保留已有 IR 协议兼容。
- 依据真实字体容量完整拆页，报告计划页数与实际页数，保留讲稿和来源；无法容纳的单条长要点或数据页给出明确错误，不静默截断。
- 新增“整稿视觉复核”“优化整稿排版”，后台任务提供进度、停止、刷新后查询及原稿变化检查。没有视觉模型、未检查完、请求取消或失败都不能视为整稿通过。
- 排版优化只生成建议，用户确认后应用，可撤销；至多两轮候选评估，保留事实、来源、讲稿、锁定对象和已批准页面。
- 改善长标题末行孤字；真实 PPTX 交付前核对页数、正文、表格和原生图表，内容缺失时阻断交付。
- 增加同材料八页新旧设计对照，覆盖封面、目录、章节、结论与证据、比较、图表、行动与总结，提供三套新主题的完整可编辑样稿。
- 系统监控对话质量页优化：将“查看任务核验失败明细”按钮移动至卡片标题行右侧；失败明细弹窗重构为全局统一对话框布局规范，数据表格增加序号列，分页使用全局统一分页控件，右上角关闭按钮统一为红色边框样式。
- 修复模型配置添加/编辑弹窗尺寸，解决高密度配置项在常见屏幕高度下产生垂直滚动条的问题。
- 修复对话路由并发槽测试中知识检索环节的 Mock 流式适配，保障并发控制回归用例在真实 CI 环境下的确定性。

## 使用

在“应用 → PPT 制作”选用咨询式简报、政企正式或培训讲解主题，按原流程上传材料、确认大纲并生成。若为保持可读字号而拆页，完成提示会显示实际页数。

AI 助手中的“优化整稿排版”不需要视觉模型，先生成建议，点击“应用排版优化建议”后才改变文稿；“整稿视觉复核”需要当前账号可用且支持图像输入的模型。任务在后台执行，可查看页数进度或停止。文稿变化后旧结果会明确标注，不能直接应用旧建议。

Agent 可通过 `presentation.review_deck` 的 `start/status/cancel` 操作启动、查询或取消整稿检查。新任务只登记工作，不代表检查通过；与当前 Agent 关联的任务在父任务停止后不再继续调用模型。

## 范围与部署

本地验收已生成原商务蓝与三套新主题的八页原生 PPTX、逐页预览和同材料对照；源材料中的金额、责任安排、讲稿及引用均保留。自动测试覆盖真实文件缺字和图表数值被改动时的阻断，检查任务取消、旧版本失效、账号隔离、父任务停止，以及浏览器中的建议确认、刷新恢复与导出流程。

视觉模型调用协议使用受控测试模型验证，未调用生产视觉模型。样稿中的金额和安排为明确标记的验收示例，不是实际业务数据。

验证结果：77 项相关单元与 PostgreSQL 集成回归通过；3 项真实应用浏览器用例通过，覆盖创建、保存恢复、下载及整稿检查流程。ESLint、类型检查和 `npm run check` 通过。全仓增量规范检查仍提示工作区既有监控弹窗中的内联样式及颜色，本轮未改动这些文件。

复用现有文稿、权限、任务和受控导出体系，本版没有新增数据库迁移。更新并重启服务、刷新页面后生效。后台检查任务最长十五分钟；服务重启后可读取已有结果，未完成的旧检查请先停止再重新启动，或待其过期后重建。

文件内容核验不等于 PowerPoint/WPS 的独立视觉验收。自动联网配图、复杂母版无损导入及自主内容改写仍在后续范围；重要事实与目标软件的字体效果应结合真实材料核对。

设计依据与完整阶段规划见 [PPT视觉品质与设计技能升级方案](../design/PPT视觉品质与设计技能升级方案.md)。
