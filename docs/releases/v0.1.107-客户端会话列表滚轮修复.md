# v0.1.107 发布记录：客户端会话列表滚轮修复

发布日期：2026-09-09

## 修复内容

- Electron 桌面运行时对会话列表注册非被动滚轮处理：滚轮移动直接更新列表的 `scrollTop`，避免特定 Windows 精度触控板或无边框窗口组合下默认 overflow 滚动失效。
- 浏览器模式继续采用浏览器原生滚动，桌面端只在列表确有溢出内容时接管滚轮。
- 会话列表保持隐藏滚动条和纯滚动触底分页，不新增按钮或固定底栏。

## 验证

- 浏览器 E2E 模拟桌面运行时，使用真实鼠标滚轮验证列表位置变化及触底自动分页；
- `npm run check` 与 `npm run lint` 通过。
