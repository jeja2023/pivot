# v0.5.3 任务建议卡操作语义收敛

发布日期：2026-10-19

回答区任务建议卡收敛为两个用户可理解的动作：

```text
可将此请求转为受控任务
先生成计划并审阅，不会立即执行。

[生成执行计划]  [暂不需要]
```

- **生成执行计划**：创建并打开任务草案，供用户审阅、编辑和确认；不会直接创建 Agent Run。
- **暂不需要**：关闭当前建议；当前会话内同类建议不会再次出现。

移除“继续对话”和 `×`，因为用户关闭建议后本来就可以继续输入；“暂不需要”更准确表达用户是在拒绝本次任务化建议，而不是关闭会话或误以为该操作可逆地隐藏整段回答。

执行计划生成、草案确认和实际执行仍维持三段分离：

```text
普通回答 → 生成执行计划 → 确认计划并开始执行
```

已执行 `npm run check`，包含前端安全、架构、全局变量、迁移和 E2E 脚手架门禁。
