# v0.7.158 SVG 声明式动画与代码保存弹窗修复

日期：2026-11-13。启用源码版本 v0.7.158，归档 SVG 动画预览和代码文件保存输入修复。

## 使用变化

- SVG 代码块不再因使用声明式动画而直接报“不支持的动态元素”。支持受限的 `animate`、`animateTransform`、`animateMotion`、内部路径 `mpath`、安全 `set`，以及既有安全 CSS 关键帧动画，可展示旋转、位移、路径运动和透明度变化。
- 预览和放大继续使用隔离图片文档，下载及本机保存保留受支持的动画。SVG 节点不进入聊天主文档；禁止脚本、外链和危险属性改写，保留资源及结构限制。
- 修复 Electron“保存到本机”调用原生 `prompt()` 报不支持的问题。文件名和多个授权目录的选择复用项目输入弹窗，支持取消；完成后继续核对账号、原始内容和目录授权，再进入原有受控产物交付链。
- 手机或普通浏览器缺少桌面授权能力时，引导使用“下载 SVG”或“下载文件”，不会先创建本机交付产物。

## 升级与兼容

本次没有新增依赖、数据库迁移、桌面 IPC 或必填配置。包版本、锁文件、README、设计基线、使用帮助及发布文档同步至 v0.7.158。

按当前容器交付方式，重新构建并部署主镜像后刷新客户端页面，即可加载新的预览、输入弹窗与服务端 SVG 校验。不需要为本次 `prompt()` 修复单独安装新版桌面客户端；“保存到本机”仍要求既有桌面交付能力及有效目录授权。

本版本不更改现有 0.7.76 客户端的更新地址、通道、证书或验签规则，也不自动替换生产下载目录。通用静态图片转换入口仍默认拒绝 SMIL 动画。

## 实际验证

功能阶段通过项目隔离 PostgreSQL 测试入口运行六个相关测试文件，共 30 项通过，无失败或跳过；证据保留执行时源码 v0.7.157 身份：

- 动画规则及格式校验：允许的声明式动画可保存；危险属性、事件触发、外部资源、脚本、命名空间改写和扩展名伪装被拒绝。
- 真实受控接口：按原有账号权限创建动画 SVG、签发下载许可并取回文件，保留动画及 MIME/文件名校验。
- 浏览器预览：两个时刻画面不同，下载和本机保存保留动画；覆盖源码切换、放大、桌面及 390px 窄屏布局。
- 输入与生命周期：原生 `prompt()` 不可用时仍可保存，取消及无效目录不创建交付，多目录选择有效，账号变化和迟到回调不继续保存旧内容。
