# v0.2.1 数据分析验收补齐与 SQLite 导入修复

发布日期：2026-10-11

## 修复内容

数据分析页面原本在界面和导入服务中均声明支持 SQLite，但上传中间件沿用了通用附件白名单，实际会在文件到达导入服务前拒绝 `.sqlite`。本版本改为数据分析路由使用独立的受限上传器：仅接受 CSV、XLS/XLSX、SQLite/SQLite3/DB；SQLite 文件还必须匹配 `SQLite format 3` 文件头。通用聊天附件与知识库上传范围没有扩大。

SQLite 导入后仍由 `better-sqlite3` 以只读、`query_only` 模式打开，选表、字段和最大行数仍由数据分析服务的既有边界控制；上传类型放行不等于允许数据库写入或任意文件读取。

## 新增浏览器验收

- XLSX 与 SQLite 真实文件上传，确认数据集名称与两行记录正确显示；
- 全量语义分析任务在页面中创建、取消、重试，页面刷新后仍能从所属数据集恢复同一任务；
- 本地受控假模型以 1.5 秒延迟制造可取消窗口，不访问外部模型端点。

服务层回归继续覆盖 SQLite 到 Parquet、字段权限、异步查询、图表、治理、仪表盘与刷新告警。

## 容量基准
