# v0.1.202 知识库统计摘要与样式预加载修复

发布日期：2026-10-10

## 问题

知识库工作台加载 `/api/rag/summary` 时，如果存在 1 个索引失败文档，响应会合法返回 `error: 1`。旧版前端把任意 truthy 的 `data.error` 都当作接口错误，因此控制台显示“知识库统计摘要加载失败：Error: 1”，并清空统计卡片。

同时，应用首屏在空闲时预加载 Agent 工作区 CSS，但用户未必在几秒内进入 Agent 工作区，Chromium 会提示该 preload 未及时使用。

## 修复

- RAG JSON 请求只把字符串错误和结构化错误对象视为错误；统计响应中的数值错误计数继续作为业务指标使用。
- 统计摘要渲染逻辑不再以 `summary.error` 数值作为失败条件，失败文档数量仍在“失败”指标中展示。
- Agent 工作区样式不再在 `pivot:app-shown` 时无条件预加载；用户悬停、聚焦或真正打开自动化工作区时仍按需预热，工作区样式门控和加载失败重试保持不变。

## 验证

- 前端安全/渲染契约测试已补充数值 `error` 字段回归断言。
- JavaScript 语法检查、前端资源检查和 `npm run check` 全量工程门禁通过。
