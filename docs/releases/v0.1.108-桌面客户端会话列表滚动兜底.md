# v0.1.108 发布记录：桌面客户端会话列表滚动兜底

发布日期：2026-09-09

## 问题范围

桌面客户端可以配置为加载远程 Pivot 服务。服务端前端已更新但客户端仍使用旧版桌面运行时时，单独更新网页 CSS 无法修复 Electron 内的滚动链，表现为会话条目持续堆积却无法向下滚动。

## 修复内容

- 在 Electron preload 中为 `#session-list` 注入仅限桌面端的高度链与独立 `overflow-y: auto`，并隐藏视觉滚动条；
- 在捕获阶段监听会话列表内的非被动滚轮事件，直接且受边界约束地更新 `scrollTop`；
- 仅在会话列表实际溢出并发生位置变化时阻止默认事件，因此不干预应用内其它区域及列表顶部、底部以外的滚动；
- 保持服务端聊天页原有的正常滚动逻辑，桌面端多一层独立保险，而非依赖 CSS 分包或远程资源加载顺序。

## 升级说明

该修复在桌面客户端的 preload 中，必须更新并重启桌面客户端才能生效。仅刷新远程服务页面或重启服务端不会替换已安装客户端中的 preload 文件。

## 验证

- 桌面 preload 契约测试验证滚动容器样式、隐藏滚动条、捕获阶段非被动滚轮监听、边界 `scrollTop` 更新和事件拦截；
- 保留浏览器 E2E 对会话列表真实鼠标滚轮和触底自动分页的验证；
- `npm run check`、`npm run lint` 通过后方可发布。
