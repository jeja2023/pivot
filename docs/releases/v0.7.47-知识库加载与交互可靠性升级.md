# v0.7.47 知识库加载与交互可靠性升级

发布日期：2026-10-28

## 问题与改进

- 检索模型摘要过去依赖设置脚本的加载时序，可能一直停留在加载状态。现在独立请求摘要所需设置，请求失败时给出明确提示；重新进入可重试，且知识库入口不再同时加载完整设置页并重复请求。
- 文档处理期间原先反复刷新整个文档列表、筛选项和统计信息，造成提示闪烁和勾选丢失。现在仅轮询文档列表，按文档 ID 复用表格行及勾选、启用控件，不变的单元格和分页不重建；处理中的启用操作保持锁定。
- 当轮询检测到文档状态或当前页成员变化时，重新获取统计摘要、质量诊断和图谱摘要。统计请求与文档请求均有顺序保护，慢响应不会覆盖较新的数据；统计失败继续显示部分不可用及重试入口。
- 专题库请求和各专题的标签请求分别校验请求顺序与当前用户，标签缓存按用户隔离并在 60 秒后过期。创建标签、整理文档、上传或删除文档后主动失效；切换专题立即刷新文档，不等待旧标签请求。
- 样式及脚本继续按需加载并在页面会话内复用；每次打开仍重新获取当前页文档，确保数据新鲜。

## 验证范围

- 浏览器回归覆盖模型请求失败恢复和请求次数、普通用户专题筛选与批量重建、后台轮询勾选及焦点、慢统计竞态、专题和标签请求乱序及标签缓存过期。
- 运行设置、知识库权限及工作区模块契约测试和修改文件 ESLint 检查。浏览器测试中的普通用户及文档数据使用接口模拟，生产账户与实际文档重建仍需在部署环境验收。

无需数据库迁移或新增配置。更新服务端资源并重新加载页面后生效。
