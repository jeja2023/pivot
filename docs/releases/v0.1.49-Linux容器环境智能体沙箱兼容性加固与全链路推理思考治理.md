## 🌟 核心更新概览

Pivot v0.1.49 重点聚焦于 **智能体（Agent）在 Linux 非特权容器及 CI 环境下的跨平台沙箱兼容性加固**、**Qwen3 等深度推理模型思考过程（Thinking / Reasoning Process）的全链路治理与极速模式机制**，以及 **项目架构治理指标的基线同步**。

本次更新彻底消除了在 Docker 非 root 用户（`node`）和 GitHub Actions CI 环境中因 `/sys/fs/cgroup` 不可写导致的 Skill 发布阻断异常，同时确立了企业生产环境下推理模型“默认极速、按需思考”的最佳实践体系，进一步提升了系统跨环境交付的健壮性与响应效率。

---

## 🚀 详细改进明细

### 1. Linux 非特权容器与 CI 智能体沙箱降级兼容性加固
- **cgroup 严格沙箱按需降级机制**：
  - 修复原本在 `agent-releases.js` 中硬编码 `strictIsolation: true` 导致在无法写入 `/sys/fs/cgroup` 的 Linux 非特权环境（如 Docker 镜像 `USER node`、GitHub Actions Runner、K8s Pod）下直接抛出 `AGENT_CGROUP_UNAVAILABLE` 并阻断发布验证的缺陷。
  - 重构 [agent-releases.js](file:///e:/pivot/server/services/agent-releases.js) 与 [agent-python.js](file:///e:/pivot/server/services/agent-python.js) 中的隔离配置，将硬编码改为尊重调用方传参及 `PIVOT_AGENT_STRICT_ISOLATION` 环境变量控制。
- **动态隔离环境探测与多级自愈**：
  - 在 [agent-os-isolation.js](file:///e:/pivot/server/services/agent-os-isolation.js) 中加入对环境变量 `PIVOT_AGENT_STRICT_ISOLATION` 与 `PIVOT_AGENT_CGROUP_ROOT` 的适配支持。在标准容器或 CI 环境下，自动平滑降级为基于进程组（`process-group`）与文件系统 Jail（`createWorkspaceJail`）的安全隔离机制，兼顾安全性与跨环境通用性。

### 2. 深度推理模型思考过程（Thinking Process）全链路治理
- **“默认极速、按需深度思考”架构确立**：
  - 针对生产环境接入的 Qwen3.6-35B、QwQ、DeepSeek-R1 等具备思考能力的大模型，全面梳理并打通了五层思考控制链路：
    1. **模型配置层**：`models` 表区分 `supports_reasoning`（具备推理能力）与 `chat_thinking_enabled`（对话保留思考过程，默认 0 关闭）；
    2. **流式聊天层**：未勾选开启思考时，自动下发 `chat_template_kwargs: { enable_thinking: false }`（硬指令）并在 Prompt 追加 `\n/no_think`（软指令）实施双保险阻断，首字延迟缩短 3~8 倍；
    3. **应用中心层**：公文起草、法规问答等工具型任务默认关闭思考，并在返回时通过 `stripThinkTags` 彻底剥离可能残留的 `<think>` 标签，确保输出纯净；
    4. **后台任务层**：全量数据分析、文档解析与长期记忆抽取严格禁用思考过程，防止思考文本破坏 JSON 结构或挤占 Token 输出预算；
    5. **代理补全层**：OpenAI 代码补全代理自动拦截思考块，避免思维链污染代码编辑器。
- **生产多模型路由实践落地**：
  - 支持在后台配置 `(极速版)` 与 `(深度思考版)` 两个同端点模型，让用户在界面下拉菜单中根据任务难度（日常公文 vs 高难数学/算法）自由无缝切换。

### 3. 架构治理指标基准同步
- **大文件管控基线更新**：
  - 在 [scripts/governance_baseline.json](file:///e:/pivot/scripts/governance_baseline.json) 中将全量语义分析模块 `semantic-analysis.js`（1014 行）纳入受控基线，严格执行大文件“只减不增”的长期治理规范。
