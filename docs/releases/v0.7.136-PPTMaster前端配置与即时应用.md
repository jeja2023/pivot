# v0.7.136：PPT Master前端配置与即时应用

日期：2026-11-09。

系统`admin`账号可在“设置 → 模型配置 → PPT Master制作服务”维护全站连接，启用或停用服务、填写服务根地址和访问密钥，先测试草稿再保存。保存立即进入实际服务调用，无需修改环境文件或重启Pivot。页面设置优先于环境默认值，停用后标准PPT创建、编辑、故事线和导出继续可用，不自动回退到旧连接。

配置整体复用项目数据密钥按独立用途加密保存。访问密钥只写入、不回显，留空保留，清除需明确选择；更换地址时必须重新提供新服务密钥，防止原密钥外发。测试连接只查询服务就绪、鉴权与协议，不创建制作任务，也不保存草稿。

保存通过修订比较防止并发覆盖，配置写入和PPT任务接纳使用同一数据库锁；有运行中或待确认的完整制作、原稿任务时会明确拒绝切换，结束任务后即可保存。调用端绑定当前连接和运行包身份，检查点不能跨连接混用。

运行请求复用安全HTTP客户端、DNS固定和敏感目标拦截，禁止跟随重定向。界面使用统一服务卡片和配置弹窗，支持窄屏；关闭后迟到的配置响应不能覆盖重新打开时的输入。

本轮更新Pivot主应用即可，独立PPT Master服务镜像和服务密钥可继续使用。部署位置见[独立服务说明](../deployment/PPTMaster独立服务部署与更新.md)，实际验证见[专项报告](../reports/PPTMaster前端配置与即时生效验证-20261109.md)。未部署生产。
