# v0.2.20 PDF工作应用产品级升级

发布日期：2026-10-13

## 概述

本版本将 PDF 工具从单项文件处理页升级为受控的文档处理工作区。升级聚焦结果完整性、页面可核验性、中文文档支持、批量语义、生命周期和业务分发。每一次处理都生成独立结果，不覆盖原文件。

## 处理正确性与安全

- 页面范围、页面顺序、文件数量、类型和总页数在服务端严格校验。无效页码、反向范围、缺页/重复页重排、未知操作和超出预算会给出中文错误提示，不再部分接受或静默回退。
- PDF 转图片按用户选择的原始页码输出；渲染不会再隐式限制为前三页。结果记录请求页数、实际处理页数和失败文件，输出不完整时不能标记成功。
- 结构处理不再将密码写入任务配置、任务详情、日志或导出结果。密码仅在短期加密存储中用于当前任务，完成、取消或过期后删除。当前版本明确不支持加密 PDF 的结构编辑，避免以不可靠方式绕过保护。
- 重试仅处理失败、待复核或已取消任务；已完成任务的“再次处理”会创建新的版本任务并保留原输出。路由会在执行动作前验证应用范围，不能通过 PDF 工具影响 OCR 等其他应用的任务。

## 工作区和功能扩展

- 新增能力接口、文件预检、任务详情、原页预览、完整状态筛选、批量结果和可操作动作。排队、处理中、部分完成、待复核、失败和已取消状态都提供对应的查看、下载、重试、取消或再次处理入口。
- 新增中文水印、页码、裁切、插入空白页、结构优化，以及图片转 PDF 的 A4、A3、北美信纸和适配方式选择。
- 可搜索 PDF 使用项目内受控 CJK 字体和不可见文本层；保留原始纸张点尺寸、渲染像素、旋转和裁切元数据，避免将预览像素误当成 PDF 物理尺寸。
- 单文件操作默认只处理一个输入；选择“批量分别处理”后，每个文件独立保存结果、成功/失败原因和下载项。合并与图片转 PDF 明确为组合多个输入的操作。

## 分发、保留与治理

- 已完成输出可发送到知识库或法规导入。法规导入默认标记为待审核材料，仍需人工确认文本、来源和效力，不会把普通 PDF 自动认定为有效法规。
- 输出保存 SHA-256、页数、质量摘要和到期时间。已被知识库或法规模块引用的输出会受到引用保护，不能被原任务删除或定期清理误删。
- 多输出下载会校验每一份文件都存在；任何输出缺失都会阻止生成不完整 ZIP 并提示重新处理。

## 数据库和部署

- 新增迁移 `202610130002_pdf_tool_product_upgrade`，扩展文档任务的配置版本、阶段、版本关系、取消/租约元数据，新增批量子项、短期凭据和输出引用表，并记录页面几何和输出质量信息。
- PostgreSQL 初始化快照、索引与数据字典已经同步。升级时按既有迁移机制自动执行；部署仍需配置 `DATA_ENCRYPTION_KEY`，以便加密短期密码凭据。
- OCR 继续通过独立 HTTP 服务运行。OCR 不可用时，合并、页面整理、水印、页码、裁切、图片转换和结构优化仍可使用；可搜索 PDF 会明确提示 OCR 或字体能力不可用。

## 用户使用说明

1. 在“应用 → PDF 工具”选择处理方式并上传文件。
2. 对需要页面范围的操作填写实际页码；重排必须填写全部页面且每页一次。
3. 在任务详情确认预检页数、处理计数、批量子项和输出文件；页面预览只展示受控资源。
4. 需要继续使用结果时，可下载、再次处理，或将某个输出发送至知识库/法规导入。
5. 重要材料仍应在下载后人工核验页数、方向、文本和业务内容。裁切只改变可见区域，不能替代真正脱敏；签署、PDF/A、原生正文编辑和复杂版式转换仍需使用经过专项验证的工具。
