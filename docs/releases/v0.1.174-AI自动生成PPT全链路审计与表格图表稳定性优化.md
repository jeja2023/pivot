# v0.1.174 发布记录：AI 自动生成 PPT 全链路审计与表格图表稳定性优化

发布日期：2026-09-24

## 发布摘要

本版本对 AI 自动生成 PPT 的大纲、页面结构、表格、图表、材料来源、Schema 校验、初稿保存与用户提示进行全链路审计。重点解决模型偶发返回不完整表格或图表时，整份演示被“表格至少需要一列”等技术错误阻断的问题。

## 优化内容

### 表格结构

- 表格列名为空时不再进入正式 PPT IR；该元素会被安全跳过；
- 对有效表格限制最大列数和行数，并将短行补齐为空单元格，确保每行与列定义一致；
- AI 页面生成提示词明确要求：只有能够提供完整列和行数据时才生成表格，否则使用普通文本表达。

### 图表数据

- 图表至少要求一个分类字段、一个数值字段和一行可解析数值；
- 缺少字段、数值不可解析或没有有效数据行时跳过图表，不中断整份演示；
- 未知图表类型归一化为柱状图；
- 没有可核实数据时，引导用户使用数据分析应用的“导入数据图表”功能，而不是让模型编造数值。

### 页面与来源安全边界

- 页面、元素和材料来源 ID 自动去重和规范化；
- 坐标、尺寸、旋转和常用文本样式约束在当前 16:9 或 4:3 画布以及 PPT IR 允许范围内；
- AI 初稿只接受文本、形状、表格和图表；外链图片与未知元素不会进入渲染链路；
- 页面与元素只保留当前请求材料中真实存在的来源引用，避免虚构来源造成校验失败；
- 所有归一化完成后仍由受控 PPT IR Schema 进行最终验证，不放宽素材、外链或边界安全策略。

### 用户体验

- 有问题的表格或图表不再阻断页面生成，初稿会保留其他可用内容；
- 如果发生安全降级，生成完成后会提示已处理的数据或元素数量；
- 用户可以直接在画布补充内容，或用带数据集绑定的图表替换模型跳过的图表。

## 验证记录

- 覆盖空表格、列行不匹配表格、空图表、非数值图表数据、未知图表类型、重复页面和元素 ID、越界坐标、非法样式、未知来源和不支持元素的组合故障矩阵；
- 通过 PPT 工作台专项测试、路径安全测试、导出渲染测试、全量 JavaScript 语法检查、死导出门禁、文本完整性和增量开发规范检查；
- 无新增数据库迁移或环境变量。

## 部署说明

- 远程模式必须部署本版本服务端与静态前端资源并重启 Pivot 服务；桌面客户端刷新页面后会加载新版界面；
- 若客户端仍显示 JSON 大纲确认框，说明其连接的服务端尚未部署到 v0.1.174，重新打包客户端本身不能替代远程服务更新；
- 离线桌面包内置服务的场景，应重新打包并分发该版本。
