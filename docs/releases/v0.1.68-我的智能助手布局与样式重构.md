# v0.1.68 发布记录：我的智能助手布局与样式重构

发布日期：2026-09-01

## 结果

“我的智能助手”从横向铺满的密集表单，调整为核心信息优先的个人工作台。所有原有字段、保存接口和记忆治理规则保持不变。

## 页面结构

| 区域 | 优化后的呈现 |
| --- | --- |
| 顶部 | 增加设置引导与账号范围提示，说明设置用途与修改边界。 |
| 身份与沟通 | 按称呼、角色、沟通语气、详略程度的实际使用频率排列，宽屏采用差异化字段比例。 |
| 工作方式 | 工作习惯、常用工具、常见任务改为统一高度的可读文本卡，支持按需纵向扩展。 |
| 高级偏好 | JSON 配置默认折叠，避免影响日常填写；展开后提供更大的编辑区域。 |
| 记忆与隐私 | 分成自动记忆、禁止保存类别、安全保障三块；敏感信息永久禁止的状态更加清晰。 |

## 体验与兼容

- 宽屏下减少不必要的横向拉伸，提升字段层级、留白和阅读密度。
- 在中等宽度时基础信息转为两列；在手机或窄屏时自动转为单列，操作按钮等宽显示。
- 深色模式同步适配卡片、表单、选中状态与引导信息。
- 不改变个人档案、记忆策略、快速设置或“打开记忆清单”的功能行为。

## 验证

- Harness 日常入口契约与中文界面测试 8/8 通过。
- `npm run check`、`npm run lint` 通过。
