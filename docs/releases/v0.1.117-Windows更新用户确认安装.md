# 智枢 Pivot v0.1.117 发布记录

## 1. 个人工作台帮助文档入口恢复

- **导轨底部入口**：在个人工作台左侧导航导轨底部（设置按钮上方）增设“帮助”项目，带帮助图标和明确文本，符合桌面端工具条习惯。
- **顶部操作区快捷图标**：在顶部标题栏操作区（搜索框右侧）增设圆角“帮助文档”图标按钮，便于大宽屏与移动窄屏快速直达。
- **用户信息弹窗联动**：在用户个人信息弹窗（点击头像唤出）的底部操作按钮中增加“使用帮助”入口，与“系统设置”并列。
- **无缝回退**：点击帮助后平滑加载 `/manual?embed=1` 帮助工作区，点击关闭自动恢复至工作台视图。

## 2. Windows 客户端更新改为用户确认安装

- 客户端继续在后台检查并下载已签名更新。
- 更新下载完成后显示“重启并安装”和“稍后”按钮。
- 默认 `installOnQuit=false`，用户选择“稍后”或退出客户端时不会自动覆盖安装。
- 只有用户明确点击“重启并安装”才调用 NSIS 静默覆盖安装。
- Windows 代码签名校验和正式构建验签保持强制启用。

## 3. 生产配置

```json
{
  "autoUpdate": {
    "enabled": true,
    "autoDownload": true,
    "installOnQuit": false,
    "checkOnStart": true,
    "checkIntervalMinutes": 30
  }
}
```

此配置表示“自动发现并下载，用户确认后安装”。
