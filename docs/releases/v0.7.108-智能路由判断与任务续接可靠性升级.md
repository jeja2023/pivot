# v0.7.108 智能路由判断与任务续接可靠性升级

日期：2026-11-06。上一版本：[v0.7.107](v0.7.107-PPT精修版式与Office断行一致性修复.md)。

本版汇总对话智能路由深度检查后的工程修复与可靠性升级，并修复全仓测试中的文档孤儿清理、记忆 HNSW 索引恢复两项失败。语义策略升级为 `chat-intent-v6`。真实模型效果及上游稳定性验收按用户要求暂停，未作为发布通过证据。

## 对话理解与用户限制

- 来源排除、偏好和工作目标分别处理。“不要联网，修复项目”先收紧来源，再继续判断工作；纯纠正、停止及撤销继续即时生效。
- 记忆快捷路径仅承载可确定的纯记忆指令，混合偏好与工作、词语讨论进入统一判断。
- 英文否定只约束对应动作与对象，不跨分句关闭后续明确请求的知识库或网页来源。
- 短附件的文本分析与文件交付分流，补齐中英文 PPT、Word、PDF 导出等表达；正文、引用和文件名中的操作词不构成新授权。
- 无历史、无资料、无真实业务数据及外部动作要求的独立文本草稿直接撰写；回答层使用占位符补充未知名称、日期和数值。

## 任务续接与交付

- 明确继续可绑定唯一的当前任务，时间口径及摘要／明细格式按字段更新；歧义、新主题或夹带新操作不能误走快捷路径。
- 时间、地区、对象和格式有结构化业务字段，避免旧口径与新要求无差别合并。安全限制及不能可靠拆分的复杂旧约束保守保留。
- 仍需能力、交付物、证据和验收要求贯穿任务交接、控制消息、契约规范化及工作状态；模型附属字段不能误撤销仍需查询能力。
- 用户明确禁止数据库、知识库或联网后，当前请求、任务目录、续接和实际执行共同过滤，历史任务不能恢复已撤销来源。
- 明确委托内的动作／能力矛盾可受控修复；规则不能自行引入桌面控制、代码执行等未被当前请求覆盖的能力。
- 可下载文件由文档渲染能力登记，原有下载、本机保存和审批链继续负责实际交付；不因下载报告申请不必要的本机写入权限。

## 协议、上下文与稳定性

- 严格 JSON Schema 按五类动作仅要求必要字段，直答分支排除写入与执行能力；兼容旧平铺 JSON，同时保留业务必填、类型和跨字段校验。
- 仅对供应方明确的结构化输出不兼容进行兼容调用；明确瞬时服务故障最多在原预算内重试一次，遵守可容纳的 `Retry-After`。认证、权限、输入错误、取消、熔断和截止不触发该重试。
- 上下文准备、排队、模型与学习建议共用总截止和取消信号；可选记忆、工具目录有独立子预算，迟到结果不能触发后续工作。
- 工具目录按实际可见集合标记完整度，优先保留显式选择并禁止引用被裁掉的名称；目录说明明确区分外部 MCP 与内置能力。
- 长请求保留中段限制片段并标记上下文完整度。被裁剪的任务先分页读全原文，业务工具执行前核对读取进度，审批不能跳过缺页保护。
- 内置知识检索与外部工具分别处理；诊断保存供应方动作、规范化修复、重试次数、Token 用量和上下文／排队／上游／总耗时，不向普通日志增加用户正文或凭据。

## 文档清理与记忆索引修复

| 问题 | 修复与保护 |
| --- | --- |
| 清理引用表缺失后查询回退到 `public` 同名表，可能误删文件 | 事务内固定并限定当前 Schema 的任务、导出及引用表；缺表就失败并保留文件，不跨 Schema 猜测引用 |
| 清理失败后扫描位置提前推进 | 仅在整批成功后推进游标，恢复后重试未确认的批次；继续执行任务锁、行锁、路径、文件身份和保留期检查 |
| 合法索引所有者无法恢复 HNSW 无效索引 | 所有者可修复自己的无效索引，无需提升为统计管理员；仍保护在用、在建、非本人无管理权限及跨表冲突的索引 |
| 索引构建影响连接后续请求 | 保留 advisory lock 与连接状态恢复，恢复原 `statement_timeout`，恢复失败的连接按错误释放 |
