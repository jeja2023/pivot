# Pivot v0.1.57 发布记录

**发布日期**：2026-08-27

---

## 概述

Pivot v0.1.57 聚焦于**会话消息流全屏两侧排布布局恢复、长会话虚拟滚动死循环频闪根因彻底修复、Agent 控制台数据表跨端字号截断防护与空白区域自适应消除、以及智能体工作流发布门禁交互闭环优化**。本次更新针对生产环境深度测试中暴露的视觉断层、渲染闪烁和门禁卡点进行了端到端的彻底重构与加固，保障高密度、长时间使用下的极致流畅与稳定体验。

---

## 主要更新内容

### 1. 会话界面消息记录恢复两侧全屏全宽展示

- **解除中央列宽约束**：
  - 移除了会话消息项 `.message-container > .message` 上强加的 `min(100%, 920px)` 居中定宽与 `margin-inline: auto` 限制，恢复为 `width: 100%; margin-inline: 0;`。
- **调整全局留白与内容气泡最大宽度**：
  - 外层容器内边距由 `28px clamp(20px, 5vw, 72px) 218px` 恢复为标准舒适间距 `20px 24px 218px`。
  - 消息气泡最大宽度放宽至 `min(92%, 960px)`，恢复助手消息靠最左、用户消息靠最右的两侧全屏自然延展排布。

### 2. 生产环境长会话持续死循环闪烁根因排查与彻底修复

- **增量 Keyed DOM 节点复用（Reconciliation）**：
  - 废除虚拟滚动每次窗口微调时调用 `setHtml(container, '')` 暴力全量清空容器的做法。
  - 依据唯一消息 Key 对视口内活跃 DOM 节点进行增量比对：视口内活跃节点 100% 保持在 DOM 中不销毁，仅平滑移除滑出视口的节点并挂载新进入节点，彻底杜绝白屏重绘。
- **程序化滚动保护（`isProgrammaticScroll`）与底部锚定解耦**：
  - 封装 `setProgrammaticScrollTop`，在虚拟滚动器调整滚动条或 `ResizeObserver` 捕获真实高度补偿位置时加锁互斥，切断「ResizeObserver → 调整 scrollTop → 触发原生 scroll 事件 → 调度重绘 → ResizeObserver」的高频事件死循环。
  - 当用户主动向上滑动超过 48px 时立即安全释放 `pinBottom` 锁定，消除与用户交互打架的问题。
- **消除 CSS 视口塌陷振荡与复用动画重放**：
  - 移除 `.message` 上的 `content-visibility: auto` 与 `contain-intrinsic-size`，消除因富文本/代码块动态高度进出视口时引起的浏览器内核级滚动高度突变（Layout Thrashing）。
  - 在 `.message-container.is-virtualized` 虚拟滚动模式下强制禁用 `.message-content` 入场淡入动画（`animation: none !important;`），防止滚动复用节点时透明度反复渐显引发频闪。

### 3. Agent 控制台数据表跨端字号截断防护

- **解决 Web 版类型列省略号截断**：
  - 针对 Web 浏览器强制 12px 最小中文字号策略导致 4 字符加粗徽标（62px~66px）超出 76px 列宽（扣除 padding 仅 60px 可用）而生成省略号的问题，将收件箱表格类型列宽度由 76px 增加至 96px，并挂载专用类名 `agent-inbox-type-col`。
  - 配置类型单元格 `text-overflow: clip; overflow: visible; padding: 4px 2px;`，并优化徽标内边距与居中对齐，杜绝截断。
- **连带加固任务运行列表类型列**：
  - 将任务列表第 4 列（类型）宽度由 86px 同步放宽至 96px，在 `.agent-run-type` 徽标上补充 `text-overflow: clip`，彻底消除不同操作系统与缩放 DPI 下的不一致表现。

### 4. 统一收件箱与持续目标页面底部空白消除

- **单卡片容器自适应撑满可用高度**：
  - 为 `.agent-cp-subview-pane:not([data-agent-cp-pane="quality"]) > .agent-cp-card` 配置 `flex: 1 1 auto; height: 100%; min-height: 0; display: flex; flex-direction: column;`，使收件箱、持续目标等单卡片视图纵向自然延伸至工作区底部，消除原本下方数百像素的空白灰色断层。
- **收件箱表格解除定高截断**：
  - 移除 `.agent-inbox-table-wrap` 原有的 `max-height: 400px;` 截断限制，改为自适应占满卡片主体（`flex: 1 1 auto; height: 100%; max-height: none; overflow: auto;`），表头保持吸顶固定，完整利用大屏纵向空间。
- **持续目标列表自适应弹性滚动**：
  - `.agent-goal-list` 调整为 `flex: 1 1 auto; min-height: 0; overflow-y: auto;`，空状态居中铺满展示，整体视觉规整协调。

### 5. 工作流发布固定评测集 409 门禁拦截修复与交互闭环

- **服务端支持跳过评测门禁**：
  - 后端路由 `POST /api/agents/workflows/:id/publish` 完善支持 `skipEvaluationGate: true`（或 `fixedEvaluationRequired: false`）参数，允许未配置专门评测集的工作流正常发布；全局错误中间件在 4xx 时透传 `code: err.code`。
- **前端门禁拦截智能弹窗确认**：
  - 当发布未通过评测集的工作流触发 409（`WORKFLOW_EVALUATION_GATE_FAILED`）时，系统自动拦截并弹出友好确认弹窗：*「该工作流尚未通过固定评测集（需通过率 ≥ 80%）。是否跳过评测门禁直接发布？」*，用户确认后一键完成发布。
- **画布工具栏增加快捷发布按钮**：
  - 在工作流画布顶部「发布」下拉菜单中新增 **「跳过门禁发布」** 快捷项，操作路径清晰直观。
