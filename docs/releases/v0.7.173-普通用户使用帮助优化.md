# Pivot v0.7.173 发布说明

2026-11-18 · 普通用户使用帮助优化

## 使用帮助

- 首页从登录和第一次对话开始，按用户目标指向应用、知识库、工具库、项目和自动化。审批、核验、下载和恢复说明放在对应操作旁。
- 根据普通用户界面校正导航及按钮名称。工作台顶部提供全局搜索，对话页提供会话搜索。附件菜单区分“选择文件”和“选择文件夹”，文档说明了所需模型能力。补齐公文“创建公文”、知识库“开始上传”、工具库“数据连接”下的本机授权入口及两种计划的提交步骤。
- 为数据分析、知识库和工作流补充三组示例。读者可以按给定输入操作，核对预期结果，并定位常见的设置或来源问题。[使用帮助](../../使用帮助.md)

## 更新方式

随 Pivot 主应用交付新的 `使用帮助.md` 后，用户重新打开“帮助”即可阅读。此项更新使用既有帮助页面和文档渲染方式，无新增数据库迁移、依赖或必填配置。源码版本为 v0.7.173，当前未构建或部署对应发行制品。

## 验证范围

以升版前的 v0.7.172 源码在本地隔离站点创建普通账号，经登录表单走查实际界面。验证了附件问答、知识库上传与检索、PPT 创建和导出、从数据图表生成汇报，以及 PDF 合并和下载。工作流试运行、发布和计划创建分别验证过，连贯复验因测试站点启动超时未完成。模型调用使用测试端点，本机助手配对及生产服务未实测。

三个新增示例均可在独立帮助页和站内嵌入模式渲染，帮助导航测试通过。
