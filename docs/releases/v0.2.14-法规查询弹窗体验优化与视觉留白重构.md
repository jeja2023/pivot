# v0.2.14 法规查询弹窗体验优化与视觉留白重构

发布日期：2026-10-12

## 概述

本版本重点针对法规查询应用中的核心交互弹窗（AI 智能问答弹窗、导入文档弹窗）进行全面的界面重构与视觉留白优化。彻底修复了 AI 问答弹窗头部排版异常挤压纵向折行的问题；将导入文档弹窗拓宽并重构为三列紧凑网格，实现主流视口下全内容免滚动呈现；同时全面优化弹窗遮罩与头部的垂直留白呼吸感，带来更专业、协调的高质感视觉体验。

---

## 详细变更内容

### 1. 法规 AI 智能问答弹窗头部重构与尺寸治理

- **根因修复与单行排版保护**：
  - 修复此前右侧模型选择器与范围选择器过宽导致的左侧标题容器（`.regulations-ai-header-main`）空间被严重挤压问题。
  - 消除标题“法规 AI 智能问答”逐字垂直拆行、“条文依据检索”胶囊标签被挤压为纵向单字排列、以及副标题多行折行导致的头部高度异常膨胀（膨胀至 140px）的严重排版缺陷。
  - 为 `.regulations-ai-title-row` 与 `.regulations-ai-header-badge` 配置 `white-space: nowrap` 与 `flex-shrink: 0` 保护，确保标题与胶囊徽标横向并列、永久单行展示。
  - 副标题添加单行文本省略（`text-overflow: ellipsis`）并配备原生 `title` 属性，在超长时优雅截断并支持悬停查看全称。
- **头部控件尺寸规范与合理分配**：
  - **模型选择器 (`#regulations-ai-model`)**：宽度规范为 `clamp(140px, 15vw, 190px)`，配合文本溢出省略，在充分展示当前模型名称的同时杜绝空间侵占。
  - **范围选择器 (`#regulations-ai-scope`)**：由于仅有“法规库”与“当前法规”两项，宽度规范为紧凑优雅的 `96px`（最小 `86px`）。
  - **关闭按钮**：统一规范为 `min-width: 64px; height: 32px` 的微质感红框按钮。
- **空状态卡片高度适配**：
  - 调整 `.regulations-ai-empty` 上下内边距为 `24px`，使空状态卡片与 4 个快捷推荐提问卡片在主流笔记本视口下均可完整居中呈现，彻底消除初始未提问状态下的垂直滚动条。

### 2. 导入文档弹窗加宽与多列网格重排（无滚动条呈现）

- **弹窗宽度合理扩容**：
  - 将导入文档弹窗宽度由原本局促的 `min(760px, calc(100vw - 32px))` 扩展为舒展大气的 `min(1040px, calc(100vw - 32px))`，使大屏幕利用率显著提升。
- **快速预设按钮单行排布**：
  - 快速预设按钮全部 6 项（法律、行政法规、司法解释、部门规章等）在顶部同一行完整排布，消除孤立掉行缺陷。
- **基础信息表单三列网格重构**：
  - 将包含标题、法规层级、分类、发布机构、适用范围、主题标签、版本标识、效力状态、生效日期在内的 9 项字段，由原本的双列（5 行）重构为 **3 列网格**（`repeat(3, minmax(0, 1fr))`，3 行）。
  - 纵向节省约 120px 垂直高度，字段排列井然有序。
- **摘要与文件分组双列对齐**：
  - 将原本各自独占一行的“官方来源地址”与“版本来源地址”整合为双列并排；
  - 将“文档文件”选择卡片与“完全重复文件”处理策略下拉框整合为双列并排；
  - 摘要输入框优化为紧凑的 `rows="2"`。
- **主流视口全内容免滚动呈现**：
  - 弹窗总高度压缩至 700px 以内，在主流 1080p 及 768p 屏幕下，所有表单项、提示文案以及底部的“预览条文”与“上传入库”按钮均可一次性完整呈现在视口内，无需滚动。
  - 配备 `@media (max-width: 880px)` 与 `@media (max-width: 600px)` 响应式平滑降级规则。

### 3. 弹窗顶部遮罩与头部留白（Whitespace）体验优化

- **外层遮罩层留白扩容**：
  - 将弹窗外部遮罩层容器 `.regulations-admin-panel` 内边距由 `20px` 调整为 `36px 24px`，确保所有法规弹窗在任何视口高度下，顶部与浏览器视口边缘始终保持至少 36px 以上的自然呼吸间距，杜绝弹窗顶死屏幕上沿。
- **弹窗居中与最大高度微调**：
  - 将 AI 问答弹窗高度限制调整为 `min(720px, calc(100vh - 72px))`，保持视口中优雅垂直居中。
- **头部内部留白呼吸感**：
  - 头部内边距优化为 `padding: 15px 24px !important; min-height: 66px !important;`。
  - 微质感图标规范为 `38px × 38px`，标题与操作项拥有更宽裕自然的上下留白，视觉重心稳健平衡。

### 4. 样式打包与工程质量保障

- **CSS 产物重新构建**：
  - 执行 `npm run build:chat-css` 重新打包压缩并同步输出 `client/chat/chat.workspace.apps.css`。
- **全量测试与规范校验**：
  - 全量执行并通过 25 项法规自动化集成与端到端浏览器测试（涵盖流式问答、模型隔离、批量操作、文档导入与解析等）。
  - 通过 `npm run check:standards:changed` 开发规范检查与 ESLint 校验。
