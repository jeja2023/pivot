# v0.7.133：PPT引擎一键离线发布与更新

日期：2026-11-08。

构建机运行`npm run release:ppt-master -- --checkout <固定上游仓库> --output <新发布目录>`，自动完成固定版本准备、镜像构建、完整包实际检查、`ppt-master.tar`导出、内容身份登记和发布签名。已有验收镜像可使用`--skip-build --image`。RSA发布私钥首次创建后复用，不进入离线包。

生产从已安装且受信任的Pivot镜像取出更新工具，首次登记可信公钥。以后通过`sudo python3 ppt-master-deploy/deploy_ppt_master.py <更新包目录>`完成验签、兼容核对、导入和切换；更新包不能自行替换生产信任根，也不执行自带的任意安装程序。

主镜像加入固定Docker客户端、许可、引擎锁、实际探针和可信更新工具。默认Compose仍不授予Docker权限，安装器显式增加协调进程的socket用户组、同路径任务目录和只读签名目录。生产公钥与清单采用PPT独立配置，其他Worker信任保留。

更新前拒绝正在制作或等待确认的任务；接纳与更新检查通过同一数据库事务锁串行。检查通过后重建主服务，实际核对引擎完整包、原稿协议和工作区双向读写。失败恢复原`.env`、Compose和应用容器镜像，提供显式回退；中断记录在下一次更新前先恢复。

离线执行支持正式签名绑定的完整镜像ID。发布同时登记镜像存储身份和Docker导出包配置内容身份，兼容containerd与传统镜像存储；生产只选择签名允许的完整身份执行，不使用可变标签或短ID。更新无需手工填写镜像摘要和签名。

当前面向本机Linux/amd64单活Docker部署；跨主机、远程Docker、多活和其他架构需要另行适配。上游提交或协议改变仍须先更新Pivot合同和适配并验收，不能直接替换任意最新版。

命令及首次接入见[操作说明](../deployment/PPT引擎一键离线更新.md)，实际验证与构建限制见[专项报告](../reports/PPT引擎一键部署与更新验证-20261108.md)。未部署生产。
