# v0.1.177 发布记录：演示大纲无格式标记层级预览

发布日期：2026-09-24

## 发布摘要

本版本移除 AI 创建 PPT 大纲确认页中原样显示的格式标记字符和列表符号。大纲仍保持连续层级结构，但用户看到的是正常的标题、章节、主题、目标说明和核心要点，而不是原始格式源码。

## 主要变更

- 大纲标题渲染为突出标题；
- 章节渲染为章节标题；
- 主题渲染为主题标题；
- 页面目标渲染为辅助说明；
- 核心要点渲染为普通分段文字；
- 移除原始格式符号、等宽源码字体和页面序号卡片；
- 去除“AI 创建演示文稿”弹窗右上角与右下角“取消”重复的关闭按钮；
- 保留章节、主题数量汇总、待确认项与提示信息；
- “生成页面”继续使用内部结构化大纲对象，不从展示内容反向解析。

## 验证记录

- 界面契约验证预览节点使用语义化容器，旧 JSON 编辑器、逐页表单和 Markdown 源码渲染函数均不存在；
- 通过 CSS 构建、PPT 工作台专项测试、语法检查、ESLint、文本完整性和增量开发规范检查；
- 无新增数据库迁移或环境变量。

## 部署说明

- 远程模式需部署 v0.1.177 静态资源并重启服务；
- 如客户端仍显示原始格式标记字符，说明当前连接的远程服务仍是旧版本，需要刷新缓存并确认服务端已完成升级。
