# v0.7.4 浏览器部署内语音识别

浏览器缺少 `zh-CN` 离线包时，语音输入和实时语音此前仍被拦截。Windows 客户端原生桥无法给普通浏览器提供识别能力。本版按用户确认的方案新增部署内服务器识别路径，浏览器无需安装中文离线包。

- 普通浏览器优先使用当前 Pivot 服务器本地识别；不可用时可尝试浏览器已具备的本地识别。桌面客户端优先使用系统原生引擎。
- 使用同源 AudioWorklet 采集和分段，内存中编码为单声道 16kHz PCM16 WAV。单段最长 20 秒，静音切句；实时语音仍使用当前文本模型回答和本地声音朗读。
- 新增登录后的能力查询与短录音识别接口，录音只发送当前部署服务器，不调用第三方音频服务。Linux/Docker 使用镜像内置 Vosk 中文模型，Windows 使用系统引擎。音频通过内存与进程 stdin 传递，不写录音文件，结果禁止缓存；临时语音不写入聊天和长期记忆。
- 服务器两并发、同用户一并发、每分钟最多 60 次；标准 WAV 校验、超时和断线取消均执行。停止录音立即释放麦克风，取消后不处理迟到结果。
- `PIVOT_SERVER_VOICE_ENABLED` 默认开启。Docker 构建阶段固定安装 Vosk 0.3.45 与中文模型 `vosk-model-small-cn-0.22`，下载摘要校验后加入镜像；运行时不联网下载。`PIVOT_SERVER_VOICE_MODEL_PATH` 支持管理员以只读挂载替换兼容中文模型。

Linux/Docker 部署需重建镜像并重建容器，单纯重启旧镜像不会安装识别运行库与模型。浏览器刷新加载前端；仍要求 HTTPS 或可信本地地址及麦克风权限，实时语音还需要可用文本模型和本地朗读声音。此路径无需更新浏览器扩展或安装桌面客户端。

```bash
docker compose build pivot
docker compose up -d --no-deps --force-recreate pivot
```

镜像构建阶段需要获取 Python 依赖和固定模型；内网环境可提前构建后导入镜像。运行识别只使用容器内文件，不要求服务器或浏览器访问模型下载站点。中文轻量模型降低部署资源占用，专业词和噪声环境的准确率需要真实业务验收。

检查、真实引擎验证与局限见 [验收报告](../reports/浏览器服务器语音识别验收报告_2026-10-19.md)。

验证完成：工程检查与 ESLint 通过；全量回归 1985 项、最终受影响回归 42 项、三条浏览器路径通过。真实音频工作线程与 HTTP 识别验证通过；Linux 容器在断网、只读、非 root 条件下经真实 HTTP 和 Vosk 引擎成功识别合成中文音频。未进行真人麦克风质量验收，也未直接更新远程部署。
