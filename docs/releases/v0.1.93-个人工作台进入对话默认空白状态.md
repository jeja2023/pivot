# v0.1.93 发布记录：个人工作台进入对话默认空白状态

- **版本号**：v0.1.93
- **适用范围**：Web 端、Electron 客户端、个人工作台、对话工作区

## 调整内容

此前从个人工作台点击“对话”会自动创建一个新的“新对话”，或者恢复上次选中的会话记录，导致用户尚未选择会话时就进入了具体对话。

现在的行为是：

- 点击个人工作台“对话”只打开对话工作区；
- 默认显示“请选择或新建对话”；
- 不创建数据库会话记录；
- 不自动恢复上次会话；
- 清除消息列表、上下文用量和未发送附件；
- 用户点击历史记录后才加载对应会话；
- 用户发送第一条消息时仍按现有逻辑自动创建会话。
