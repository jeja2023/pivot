# v0.7.10 系统监控分区与运行指标完善

系统设置中的“系统监控”重整为三个页签：

| 页签 | 内容 |
| --- | --- |
| 运行概览 | 服务健康、未恢复告警、HTTP 总量/5xx/P95、AI 并发、任务队列、运行压力及健康维护明细 |
| 服务与资源 | GPU 与并发保护、主机与进程资源、检索与向量服务、模型用量、模型端点 |
| 对话质量 | 最近 30 天执行统计、最近 24 小时路由诊断、质量异常复核与归档 |

概览去除今日 Token、今日消息、进程内存和系统负载等与详情重复的卡片。取消固定六面板网格及固定高度画布，桌面两列、移动端单列；允许设置区正常滚动，展示全部健康检查。仅告警历史保留有限高度滚动列表。

新增全局任务当前运行、排队、待人工确认、最早排队时长、最近 24 小时按完成时间统计的失败或部分完成。复用现有运行时探针展示本实例在途请求、事件循环 P99 与当前采样窗口、连接池繁忙/等待、待写入、异常队列和启动以来丢弃写入数量。不创建额外探针、连接池或任务调度器。

HTTP 指标为本实例启动以来的累计值，P95 为直方图估算；事件循环窗口随既有探针周期重置。对话、任务和告警为全局聚合。无延迟/比例样本、探针不可用、Windows 不支持的系统负载均明确表达；堆使用率改为已使用/真实堆上限。

未恢复告警包括未处理和已确认尚未恢复事件，最近事件展示状态和时间。进入概览、资源页不会查询对话执行统计；质量页停止自动刷新审核列表，手动“刷新指标”更新质量统计，审核列表仍使用原组件。

沿用管理员鉴权、8 秒监控缓存及请求合并。新增任务查询只返回聚合数据，不读取任务正文；任务聚合失败时返回不可用，其他指标保留。没有新增依赖或数据库迁移，不删除历史数据。

验证记录见 [验收报告](../reports/系统监控分区与指标优化验收报告_2026-10-19.md)。
