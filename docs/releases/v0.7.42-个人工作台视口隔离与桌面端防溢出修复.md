# v0.7.42 个人工作台视口隔离与桌面端防溢出修复

发布日期：2026-10-25。版本类型：前端工作区视口高度层叠隔离与桌面客户端防溢出修复。

---

## 1. 问题背景与现象

在 Pivot 桌面客户端（`pivot-desktop-runtime`）运行环境中，用户反馈：
> 「个人工作台页面，在操作跳转到其它页面后，再回到个人工作台页面后，个人工作台页面会变大溢出原来的画面」

### 视觉缺陷特征
- **左侧精简导轨头像裁切**：左侧导轨最底部的个人头像圆钮（直径 34px）被推挤到底部边界下方，仅露出顶部约 4px 的月牙边缘，其余 30px 全部被裁切到窗口可视区域外。
- **工作台卡片区域向下平移溢出**：第二行卡片（「继续工作」与「常用入口」）整体下移，卡片下边框被窗口下沿截断，底边距丢失。

### 缺陷根本原因
1. **桌面客户端窗口标题栏机制**：
   在 Electron/WebView2 等桌面客户端环境中，前端使用自定义的无边框拖拽标题栏（`.desktop-window-drag-region`，高度为 30px）。为腾出标题栏空间，根容器 `#app` 设定了 `margin-top: 30px; height: calc(100vh - 30px);`。
2. **样式按需懒加载的副作用**：
   应用启动进入个人工作台时，仅加载了基础的 `chat.shell.css`，此时 `#app` 正确受控于 `calc(100vh - 30px)`。
   当用户从工作台跳转到其它功能模块（例如：在「继续工作」中点击「测试导图」产物、进入「自动化」DAG 编排、或触发智能体运行）时，前端动态载入 `chat.workspace.agent.css` 样式包。
3. **全局层叠规则越界**：
   `chat.workspace.agent.css` 中包含来自 `workflow-product.css` 的全局规则：
   ```css
   body.is-main-workspace-full #app,
   body.is-main-workspace-full .chat-container {
       height: 100vh !important;
       max-height: 100vh !important;
       min-height: 100vh !important;
       overflow: hidden !important;
   }
   ```
   当用户返回个人工作台时，由于全屏工作区激活状态（`body.is-main-workspace-full`），该规则中的 `!important` 强行击穿了桌面客户端的 `calc(100vh - 30px)` 设定，把 `#app` 和内部的 `.chat-container` 硬性拉大为 `100vh`。
   容器叠加 `margin-top: 30px` 后总高度变为 **`100vh + 30px`**，整体向下溢出刚好 **30px**。

## 2. 核心改动与视口隔离体系

| 修改文件 | 核心改动 | 效果与目标 |
| :--- | :--- | :--- |
| [workflow-product.css](file:///e:/pivot/client/chat/styles/workspaces/agent/workflow-product.css) | 解除 `.chat-container` 的 `100vh` 写死规则，修改为 `height: 100% !important; max-height: 100% !important; min-height: 0 !important;`；针对桌面端明确约束 `#app` 严格继承 `calc(100vh - 30px) !important;` | 阻断工作流全屏规则对桌面标题栏基准高度的篡改 |
| [modals-forms.css](file:///e:/pivot/client/chat/styles/base/modals-forms.css) | 在 `body.pivot-desktop-runtime:not(.auth-active) #app` 规则中引入 `!important` 与 `max-height` 硬性保护 | 从全局基础样式层锁定桌面客户端 `#app` 视口高度，防御外部样式覆盖 |
| [chat-shell.css](file:///e:/pivot/client/chat/styles/base/chat-shell.css) | 为 `body.is-main-workspace-full .chat-container` 与 `.main-workspace-view` 补齐 `height: 100%; max-height: 100%; min-height: 0;` | 确保全屏模式下主工作区视图层级高度受限于容器内部 |
| [personal.css](file:///e:/pivot/client/chat/styles/workspaces/personal.css) | 显式声明 `.personal-workbench-shell`、`.personal-workbench-content` 及 `.personal-rail` 为 `height: 100%; max-height: 100%; box-sizing: border-box;`，并为 `.personal-workbench-scroll` 追加 `overflow-x: hidden;` | 个人工作台导轨与内容区域严格贴合可用高度，左下角头像圆钮与卡片下边框完整保留 |
| [scripts/build_chat_css.js](file:///e:/pivot/scripts/build_chat_css.js) | 执行编译打包，重新生成 [chat.shell.css](file:///e:/pivot/client/chat/chat.shell.css) 与 [chat.workspace.agent.css](file:///e:/pivot/client/chat/chat.workspace.agent.css) | 前端生产压缩包同步生效 |
