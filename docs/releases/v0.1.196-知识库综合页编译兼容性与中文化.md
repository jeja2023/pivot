# v0.1.196 知识库综合页编译兼容性与中文化

发布日期：2026-09-30

发布范围：知识库综合页编译输出兼容、来源校验诊断、运行状态中文化、生产自动编译身份加固与工作台交互。

---

## 1. 修复背景

部分本地 Qwen 模型会在受控 JSON 前后添加说明文字、使用 Markdown JSON 围栏或输出中文字段名，并常以输入资料编号（如 `S1`）标记来源。此前服务端只接受完整英文键名及 `documentId/versionId/blockId` 组合，因而会将有实际来源的候选页全部拒绝，界面只显示“模型输出未通过结构校验”。

---

## 2. 编译输出兼容与安全边界

- 支持从说明文字或 JSON 围栏中提取第一个完整 JSON 对象/数组；不会补全破损 JSON 或把普通文本猜测为候选页。
- 支持受控字段别名：英文/下划线字段、常见中文页面字段、中文事实字段与中文来源字段。
- 支持 `S1`、`S2` 等本轮输入资料编号；服务端只将其解析为本轮 manifest 内的确切文档版本和区块。
- 兼容页面级受控来源，将其收敛为“综合页正文”来源声明；无来源、越权来源、无效正文、HTML、外部链接与过长正文仍会被拒绝。
- 编译提示词改为明确的最简 `sourceId: "S1"` JSON 契约，降低本地模型填错完整内部 ID 的概率。

---

## 3. 诊断与生产可靠性

- 编译运行记录保存候选页数量、通过数量及拒绝分类；失败卡片显示“未识别 JSON”“来源未匹配”“正文不合规”等中文摘要，不暴露模型端点、凭据或原始输出。
- 工作台新增中文“编译前检查”，展示可用原始资料区块、自动模型与阻塞条件。
- 自动编译使用 Space 所有者的完整身份（包括所属部门）验证模型访问权限；修复部门限定模型在后台被空部门身份误判为不可访问的问题。
- 无已发布来源、模型不可访问或凭据异常时阻止入队，避免产生必然失败的编译任务。

---

## 4. 前端中文化

- 知识库综合页卡片、按钮、页面类型、页面状态、任务状态、任务阶段和触发原因均改为面向用户的中文文案。
- “新建 Wiki Space”“编译当前 Space”等混合术语改为“新建知识空间”“编译当前空间”；Markdown 保留为文件格式名称。
- 失败任务展示可行动原因和来源/结构校验摘要，避免只显示内部 `failed`、`generating_candidate` 等状态码；存在排队或编译任务时，工作台会低频自动刷新状态。

---

## 5. 验证

已通过：

- 端到端 PostgreSQL 隔离 schema 编译、审核、发布与来源失效测试；
- Qwen 常见输出形态：说明文字、JSON 围栏、中文字段与 `S1` 来源编号；
- 无来源/无模型阻止入队、自动编译部门身份、租约 Worker、取消、权限隔离与路由回归；
- PostgreSQL 迁移、配置注册、raw SQL、架构边界、死导出、安全 HTML 和开发规范门禁。

生产部署后，请先打开目标知识空间确认“编译前检查通过”，再手动执行一次编译。若仍失败，卡片会直接给出安全脱敏后的校验分类；运维人员可按运行 ID 查询服务端日志进一步定位模型响应异常。
