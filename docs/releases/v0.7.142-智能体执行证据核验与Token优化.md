# v0.7.142：智能体执行、证据核验与Token优化

日期：2026-11-09。承接[v0.7.141](v0.7.141-智能体任务与持续目标弹窗优化及空态精简.md)，本版整理智能体执行与效率优化，沿用现有权限、审批、审计、累计预算及数据兼容边界。

## 变更

1. 工具契约支持批量读取至多8个引用，在同一当前授权目录中预检并整批记忆；兼容单个引用、去重同名引用，拒绝冲突版本及不可见项。规划搜索只暴露自然语言查询和数量，完整目录API继续支持高级筛选。
2. MCP文本JSON在模型侧结构化展开，批量结果逐项保留关键小字段和错误；长文本裁剪明确标记不完整并保留受控原文引用。工作状态和语义压缩保留受控的早期业务事实，完整协议、持久记录和来源权限检查继续保留。
3. 记忆核验使用真实注入事件绑定的内容摘要，核验前后重查当前用户和范围，更正、停用或遗忘后不沿用旧事实。学习从服务端审计解析元工具包装下实际成功的只读业务调用；形成经验与确认启用、评测及撤销继续分开处理。
4. 批量子任务继承并收紧父任务资源及工具范围，分配余额时保留父任务收尾额度；部分创建失败保留已创建ID。父任务等待时持久回队并释放执行槽，恢复前检查直接子任务、控制消息、原始截止、取消和租约代次；完成回执同步进入核验证据。
5. 同Run安全回队读取现有持久检查点和观察；新Run续跑沿用原有资源账本及恢复入口。工具引用参数冲突在流式与JSON入口返回可修正反馈，不误触发协议降级；独立核验最多等待60秒，继续受任务截止和取消约束。
6. 任务事实摘要不重复展开已在工具消息中的成功搜索和契约全文，完全相同且已在当前请求中携带的目标去重。业务事实、错误、未知状态、硬约束、未决交付和原文引用保留，持久状态及审计不改写。
7. 核验增加脱敏且限长的`inputPreview`，复用现有脱敏规则，单字段裁剪并限制整体4000字符；过大参数明确省略。按执行顺序区分历史失败及后续版本修正，参数本身不能证明执行或交付成功，未解决错误继续保留缺口。
