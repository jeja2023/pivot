# v0.7.84 知识来源与工具链路优化

日期：2026-11-03。本版本记录工作区改动；更新版本号不表示已经构建、部署或完成生产验收。开发基线为 v0.7.83。

## 行为变化

- 会话显式选择的专题及标签可与任务范围求交并传递给 Agent；“这个专题”等短追问可继承同一会话此前选择，继续使用时核验当前访问。选择已清除、失效或无权访问时提示重新选择，不回退到全库。
- `rag.search` 为所选可信片段提供文档、版本、片段、引用、摘要及覆盖状态；长结果按完整片段压缩并保留来源清单。检索部分路径故障和无可靠命中使用不同状态，历史数据无法定位时不虚构位置。
- 严格知识回答校验拒答是否夹带内容及引用编号与来源键是否对应；会话输出前重新检查引用，涉及知识依据的 Agent 流式内容延后展示。任务验收复核知识来源，资料失效时不将文件已生成等同于来源和内容通过验收。
- Agent 任务详情可显示本次知识来源并打开可用引用；提示部分索引和截断。读取历史知识检索步骤时复核当前权限与片段，无法确认或旧格式缺少证据时隐藏历史结果并提示重新检索。
- 工具发现以业务别名辅助授权目录内排序，连续空搜索阈值使用 `PIVOT_AGENT_EMPTY_SEARCH_LIMIT`，默认 4，范围 2–12；达到阈值后等待用户选择工具。工具调用、策略阻断、网络拒绝和文件登记失败补充阶段与原因提示。

## 验证与限制

- 本轮链路单元测试 91 项及浏览器测试 2 项通过；浏览器使用真实 Chromium，任务来源按钮测试的引用服务为模拟接口。定向 ESLint、文本完整性、增量开发规范及差异空白检查通过。
- 此前隔离 PostgreSQL 链路集成测试 52 项通过；本轮新增任务详情跨用户和来源变更断言后，因未配置独立 `TEST_DATABASE_URL`，尚未复跑数据库组。运行方法及逐项状态见[实施进展与待验收](../reports/工具与知识库链路实施进展与待验收-20261103.md)。
