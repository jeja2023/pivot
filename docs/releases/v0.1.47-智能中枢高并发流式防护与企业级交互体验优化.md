## 🌟 核心更新概览

Pivot v0.1.47 重点针对 **高并发与流式代理下的 AI 信号量释放机制**、**PostgreSQL 全栈数据库兼容性**、**Agent 工作台企业级去 Emoji 与本地化体验** 以及 **核心路由防御性防护** 进行了深度优化与修复。

本次更新彻底解决了极端并发及异常断流场景下的 AI 信号量泄漏与队列死锁隐患，全面提升了系统的健壮性与稳定性，同时全量自动化单测套件（666 项用例）实现 100% 全绿通过。

---

## 🚀 详细改进明细

### 1. 高并发与流式代理 AI 信号量释放守护
- **请求/响应事件监听安全防护**：
  - 在 OpenAI 代码补全/聊天代理、主会话聊天路由及应用路由中，对 `req.once('aborted')`、`res.once('close')` 等生命周期监听添加函数类型防护，避免在特殊中间件环境或单元测试 Mock 对象下因缺乏 EventEmitter 方法抛出 `TypeError`。
- **上游流式断开与连接异常捕获**：
  - 为所有流式请求添加 `response.data.on('close')` 监听与异常兜底，确保客户端主动取消、网络意外断开或模型服务中断时，`aiSemaphore.active` 槽位 100% 可靠递减，杜绝请求堵塞在等待队列（5 分钟超时）的隐患。
- **代理流式结束 Promise 同步追踪**：
  - 增强 `createCompletionResponseProxy` 流式代理生命周期管理，加入 `streamFinished` 状态追踪，确保异步数据流在响应生命周期结束前完整释放。

### 2. PostgreSQL 长期记忆与数据库兼容性加固
- **严格布尔类型兼容性修复**：
  - 修复 `server/services/long-term-memory/index.js` 中插入 `sensitive` 字段时使用整数 `0` 导致 PostgreSQL 抛出 `42804: 字段 sensitive 的类型为 boolean, 但表达式的类型为 integer` 的语法异常，统一使用标准 SQL `FALSE` / `TRUE`。
- **长期记忆上下文构建最小预算优化**：
  - 优化 `buildLongTermMemoryContextMessage` 中的 Token 预算分配，将首条记忆与头尾结构标记的最小基础预算调整为 384 Tokens，确保在小窗口预算下至少能完整装配一条高置信度长期记忆。
- **旧数据库快照迁移 Preflight 加固**：
  - 在 `legacy-preflight.js` 预检兼容列中补齐 `users`、`sessions`、`messages`、`attachments`、`knowledge_docs` 等表的 `deleted_at` 基础字段，保障历史 SQLite 快照平滑无缝升级至最新架构。

### 3. 能力与管理路由防御性参数加固
- **可选链与默认值保护**：
  - 对 `/capabilities/packages` 等核心能力包路由中 `req.query` 的访问加入可选链防护（`req.query?.include_tools`），彻底杜绝无查询参数请求时的空指针异常。

### 4. Agent 工作台与用户交互体验升级
- **统一收件箱即时预载与纯净边框**：
  - 修复原本必须手动点击刷新按钮才能显示信箱数据的缺陷，切换至工作台即可自动拉取最新事项；移除表格列表行前的绿色竖线边框，保持企业级界面的整洁平整。
- **任务执行结果反馈去 Emoji 与矢量 SVG 规范**：
  - 任务结果反馈区域全面采用矢量 SVG 图标（`👍 有帮助` / `👌 部分有用` / `👎 需要修正`）替代 Emoji 表情，实现评分与评价胶囊双向智能联动。
- **执行过程全链路指标与标签中文化**：
  - 全面汉化执行过程中的工具名称、步骤状态、调用链追踪标签及指标数据（`Token 用量`、`响应延迟`、`计算开销`、`执行耗时`、`置信度`、`匹配得分` 等）。
- **聊天模式切换按钮对称美化**：
  - 优化输入框中「普通」/「Agent」切换胶囊按钮的左右对称内边距与居中对齐，消除右侧不对称留白。
