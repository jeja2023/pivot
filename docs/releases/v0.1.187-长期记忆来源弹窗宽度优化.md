# v0.1.187 长期记忆来源弹窗宽度优化

发布日期：2026-09-27

发布范围：设置工作区的长期记忆“来源”与“使用记录”内容弹窗。

## 变更内容

- 将来源弹窗的桌面最大宽度从 `820px` 增加到 `960px`。
- “来源”和“使用记录”共用该弹窗，因此会话标题、原始消息、证据摘录、使用原因、任务标识和排序信息都获得更大的可读空间。
- 弹窗由通用 `.model-modal` 样式提供的 `500px` 默认宽度曾在部分挂载位置覆盖来源规则。本版本改为使用 `#memory-source-modal .memory-source-modal` 精确选择器，保证实际渲染宽度正确。
- 小屏设备保持 `min(960px, calc(100vw - 32px))` 约束，弹窗不会超出视口；消息正文继续换行并在内容区内部滚动。

## 验收证据

- `tests/settings-page-contract.test.js` 验证精确来源弹窗规则与 `960px` 上限。
- Playwright 回归在首次打开设置页后创建长期记忆、点击“使用记录”，验证实际请求使用记录接口、弹窗正常打开且渲染宽度等于当前视口允许的最大宽度。
- `npm run build:chat-css` 已重新生成设置工作区样式包。

## 升级说明

无数据库迁移、无新增环境变量。部署新版服务端和静态资源后，刷新浏览器或重新打开客户端即可生效。
