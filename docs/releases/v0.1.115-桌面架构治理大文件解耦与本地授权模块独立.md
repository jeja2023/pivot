# 智枢 Pivot v0.1.115 发布记录

**发布版本**：v0.1.115  
**发布日期**：2026-09-10  
**关注领域**：桌面主进程架构治理、大文件职责解耦、本地设备授权与本地 MCP 执行模块独立化

---

## 核心重构与优化

### 1. 桌面主进程大文件治理与职责解耦

- **治理背景**：随着桌面客户端连接保护、窗口守护与更新机制的演进，主进程入口 `desktop/main.js` 增长至 1038 行，突破了项目架构治理规定的 1000 行大文件上限（`largeFileThreshold: 1000`）。
- **职责拆分与收敛**：依据高内聚低耦合原则，将原散落于主进程内部的本机设备资源授权、本机机密初始化、文件存储与本地 MCP 工具执行分发逻辑全量抽离，成立独立的 `desktop/local-authorizations.js` 模块。
- **行数大幅回落**：重构后 `desktop/main.js` 行数由 1038 行骤降至 798 行（精简 240 行），留出逾 200 行的安全裕量，彻底根治架构治理大文件告警。

### 2. 本地授权与 MCP 执行服务模块化（`desktop/local-authorizations.js`）

- **统一授权存储与状态流转**：封装 `LOCAL_AUTH_TYPES`、`readLocalAuthorizations`、`writeLocalAuthorizations` 以及本地环境密钥配置 `configureLocalAuthorizationEnvironment`，保证本机授权信息安全存储在用户私有数据区。
- **对话框交互与授权管理**：封装 SQLite 数据库文件、报表目录与本地浏览器的系统选择弹窗逻辑（`chooseLocalAuthorizationTarget`、`grantLocalAuthorization`、`revokeLocalAuthorization`），提供严格的输入校验与脱敏格式化。
- **MCP 本机工具执行收口**：收拢浏览器自动化（`runLocalBrowserTask`）与底层数据库/报表工具的本地执行管道，强化确认对话框与错误边界隔离。
- **依赖注入与可测试性**：通过 `createLocalAuthorizationManager` 工厂模式提供统一的实例接口，便于单元测试 mock 与后续桌面能力扩展。

### 3. 代码整洁度与规范收敛

- **无用依赖清理**：清理 `desktop/main.js` 中抽离后不再直接依赖的 `os`、`chooseLocalBrowserAuthorization`、`sanitizeLocalBrowserGrant` 等冗余引用，通过 ESLint 规范检验。
- **IPC 路由精简映射**：主进程中的 `pivot-local-auth:*` 与 `pivot-agent:*` 路由处理器统一委托至 `localAuthManager`，消除冗余代码与隐式全局状态耦合。
