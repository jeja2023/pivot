# Pivot v0.1.48 发布记录：应用中心大卡片对称居中重构与全栈运行防护对齐

**发布日期**：2026-08-26
**版本号**：v0.1.48
**发布主题**：应用中心大卡片对称居中重构与全栈运行防护对齐

---

## 🌟 核心更新概览

Pivot v0.1.48 重点聚焦于 **应用中心（App Center）视觉与交互体系的深度重构**、**数据分析全量语义分析报告全宽排版优化**、**报错提示去横幅化与 Toast 体系统一**，以及 **生产环境全栈数据库连接池与运行时保护参数的完整对齐**。

本次更新彻底消除了 5 个应用卡片在宽屏排布时的“右下角缺角”与空间失衡问题，卡片支持整卡点击直达；修复了全量语义分析报告被宽度挤压在左侧的缺陷；全面同步了高并发连接池与流式防护配置，使系统在交互质感与后台稳定性上均达到更高水准。

---

## 🚀 详细改进明细

### 1. 应用中心视觉重构与对称居中排布
- **自适应 Flex 居中对称布局**：
  - 将 5 个核心业务应用卡片重构为自适应 Flex 弹性居中排布（`display: flex; flex-wrap: wrap; justify-content: center;`）。在宽屏下呈现为 **上 3 张 + 下 2 张**，第二行两张卡片自动在中轴线上水平居中对齐，形成稳固和谐的对称视觉构图，彻底根除原 3 列网格导致的“右下角缺一个”与视觉倾斜问题。
- **工作区视口横纵双向绝对居中**：
  - 修复全屏工作区模式下基础面板（`.workspace-panel`）强制占满 100% 高度导致卡片整体贴顶并留下大面积空白的问题。贯通 Flex 纵向拉伸与居中链条，使卡片组无论窗口放大还是缩小，均严格稳坐于屏幕几何绝对正中心。
- **整卡直接点击与轻量化交互**：
  - 移除了卡片底部多余的「进入工作台 $\rightarrow$」操作栏，整张卡片任意区域均可直接点击直达对应应用工作台；优化了卡片尺寸（宽 336px、高 160px）与内边距，配合优雅的悬浮微动效，呈现出纯粹利落的现代化 App Tile 质感。
- **核心能力标签组（Feature Pills）**：
  - 为 5 个核心应用全面增补了精炼的业务特性标签组：
    - **公文写作**：`规范起草` · `红头版头` · `合规审校`
    - **数据分析**：`字段画像` · `数据透视` · `AI 图表洞察`
    - **法规查询**：`条文检索` · `版本追溯` · `依据问答`
    - **文字识别**：`双栏复核` · `表格提取` · `结构化导出`
    - **PDF 工具**：`页面重排` · `快速拆合` · `图文提取`

### 2. 报错提示去横幅化与 Toast 体系收敛
- **消除 DOM 横幅插入**：
  - 修复原本因 CSS 优先级覆盖导致应用中心顶部出现无内容条幅的问题，隐藏 `.apps-workbench-state`。
  - 将应用中心加载状态与错误提醒彻底收敛至系统级全局 Toast 弹窗（`showToast(message, 'error')`），保持页面流式结构的整洁统一。

### 3. 数据分析全量语义分析报告全宽排版优化
- **解除宽度限制并撑满右侧工作台**：
  - 修复全量任务语义分析报告因复用 `.message-content` 样式而继承了聊天气泡最大宽度（860px），导致在宽屏下被严重挤压在左侧一半空间的排版缺陷。
  - 显式配置 `.data-analysis-semantic-box` 与 `.data-analysis-semantic-report` 为 `width: 100%; max-width: none !important;`，解除其内部 Markdown 段落、表格、代码块、列表与引用等子元素的最大宽度约束，实现 100% 自适应舒展铺满。
- **暗黑模式完整适配**：
  - 补齐了全量任务控制框、进度条与分析报告在暗黑模式下的背景、边框与文字对比度。

### 4. 生产环境全栈防护配置与 .env 完整对齐
- **数据库连接池治理与慢查询主动熔断**：
  - 对齐 `PG_POOL_MAX=30`（扩容连接池，防并发鉴权与统计打满）、`PG_STATEMENT_TIMEOUT_MS=20000`（20s 慢查询提前熔断归还连接）、`PG_CONNECT_TIMEOUT_MS=5000` 与 `PG_IDLE_TIMEOUT_MS=30000`。
- **运行时全链路可观测性与保护参数**：
  - 对齐 `API_REQUEST_WATCHDOG_MS=20000`（GET 接口 20 秒悬挂 503 兜底保护）、`RUNTIME_DIAGNOSTICS_INTERVAL_MS=60000`（周期性记录事件循环延迟、连接池水位、在途请求与堆占用）、`RUNTIME_LOOP_DELAY_WARN_MS=500` 与 `RUNTIME_HEAP_WARN_RATIO=0.85`。
- **流式空闲断流守卫与线程池扩容**：
  - 对齐 `MODEL_STREAM_IDLE_TIMEOUT_MS=120000`（上游流式 120s 静默无数据主动释放槽位）与 `UV_THREADPOOL_SIZE=16`（解除 libuv 线程池文件 I/O 阻塞）。
