## 2. 知识图谱前端 UI 全面中文化

### 2.1 实体类型全量中文映射与别名容错
- 后端法规实体抽取逻辑打上的 `legal_doc`、`clause`、`obligation`、`right`、`penalty`、`subject` 等专业类型，此前在前端渲染层缺失中文字典，导致在统计概览栏（如原先出现的 `legal_doc 9`）、实体卡片、类型筛选下拉框与关系画布中暴露裸英文。
- 扩展 `GRAPH_TYPE_LABELS` 字典，将 `legal_doc` 映射为标准中文“**法规**”，在概览栏中与“概念 475”、“制度 305”、“部门 74”、“系统 24”实现统一的两字符对齐（`法规 9`）。
- 补齐 `clause: '条文'`、`obligation: '义务'`、`right: '权利'`、`penalty: '罚则'`、`subject: '主体'`、`standard: '标准'`、`term: '术语'`、`module: '模块'`、`service: '服务'` 等实体类型。
- 升级 `graphTypeLabel` 函数，加入大小写标准化、破折号/下划线规整及别名映射表（`legal`、`law`、`legal_document`、`regulation` 均归一化为“法规”），确保任何变体类型绝不回退至裸英文。

### 2.2 关系类型与连线配色全量中文化
- 扩展 `GRAPH_RELATION_LABELS` 与 `GRAPH_RELATION_ORDER`：
  - 法规关系：`applies_to: '适用'`、`references: '引用'`、`supersedes: '替代'`、`prohibits: '禁止'`、`requires: '要求'`、`regulates: '规范'`。
  - 系统关系：`calls: '调用'`、`integrates_with: '集成'`、`implements: '实现'`、`owned_by: '所属'` 等。
- 在 `rag-graph-layout.js` 的 `graphRelationTone` 中为所有新增关系配置对应的主题色调语义类（`is-belong`、`is-depend`、`is-affect`、`is-owner` 等），使关系连线色彩层次分明。

### 2.3 关系状态中文化与浮层提示净化
- 新增并导出 `graphStatusLabel` 方法，将 `active`（已确认）、`pending`（待确认）、`deleted`（已删除）、`disabled`（已禁用）、`draft`（草稿）、`stale`（已失效）等状态全量转化为标准中文。
- 优化 `buildGraphRelationTooltip` 浮层提示，彻底移除原先在中文后追加的英文括号 `（${row.relation_type}）`，状态显示由裸英文调整为规范中文。
- 关系控制器中的筛选与渲染层统一接入 `graphStatusLabel`。

## 3. 知识库 Wiki 综合页排版优化

### 3.1 正文与摘要 Markdown 格式符号清洗
- 知识库 Wiki 综合页面在聚合生成正文与摘要时，原先可能残留 Markdown 标题符（`#`）、粗体/斜体（`**`、`*`）、代码块标记（反引号）、引用符（`>`）、任务列表符号（`- [ ]`）及 HTML 标签。
- 引入正文与摘要深度清洗机制，剔除所有排版标记符号，段落保留自然空行与标点，使综合页面的正文呈现为整洁易读的出版物级版面。

### 3.2 弹窗高度自适应与底部大块空白治理
- 修复 Wiki 综合页弹窗（`.knowledge-wiki-modal`）固定设定 `height: 88vh` 导致的视觉缺陷。当聚合内容较少时，弹窗底部会空出一大块灰色空白区域。
- 将弹窗高度重构为内容自适应 `min(88vh, max-content)`，配合弹性布局与 `max-height: 88vh` 滚动保护，弹窗高度根据正文内容自适应闭合，消除多余空白。

  - 检索命中卡片与 AI 问答引用来源：标头统一配备规范的矢量图钉与法律书卷 SVG 图标。
- 增强视觉一致性与专业内网部署规范。
