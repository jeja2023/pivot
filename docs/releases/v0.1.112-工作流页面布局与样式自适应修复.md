# v0.1.112 发布记录：工作流页面布局与样式自适应修复

发布日期：2026-09-09

## 现象与根因

用户反馈在打开工作流详情页面时，左侧节点库面板与工作台布局出现明显样式异常：

1. **折叠按钮遮挡标题**：
   - 节点库面板左上角出现 `»` 切换按钮与标题重叠遮挡，导致标题文字被破坏呈现为 `[»] 点`。
   - 根因：在 `agent-dag-node-library.css` 中 `.pivot-node-library-toggle` 默认设置了 `display: flex;`，未正确受 HTML `hidden` 属性约束。在面板处于展开状态时，按钮依旧常驻显示在 `top: 10px; left: 10px; z-index: 8`，直接悬浮在 `z-index: 7` 的节点库头部标题文字上方。

2. **面板尺寸狭窄导致卡片文字垂直折裂**：
   - 节点库宽度硬编码为 188px，扣除内边距、边框、卡片内边距及图标后，文本可用宽度仅剩约 115px。
   - 节点描述文字（如“声明可填入、校验的执行期运行参数”、“借助大模型进行分析、生成或结构化内容”）被迫折叠成 3~4 行甚至 5 行极窄竖行，版面严重拥挤。

3. **视觉层级模糊与画布网格穿透**：
   - 浮动面板仅有浅灰色边框无立体投影，在网格背景上视觉层级不清。

4. **样式分包与动态挂载竞态保护不足**：
   - 工作流编排器通过 `openAgentDagWorkbench` 打开时，缺少像设置页一样的样式就绪等待窗口。当网络延迟或分包 CSS 未完成挂载时，容易触发初次渲染错位。

## 修复

1. **折叠切换按钮状态收敛**：
   - 明确规范 `.pivot-node-library-toggle` 默认 `display: none;` 及 `[hidden] { display: none !important; }`。
   - 仅在画布处于 `.is-library-collapsed` 时激活 `display: flex !important;`，彻底根除展开态重叠标题缺陷。

2. **节点库面板尺寸与文字排版自适应优化**：
   - 节点库面板宽度由 188px 拓宽至 240px，画布左内边距相应调整至 260px，确保节点卡片拥有约 170px 的充分文本宽度。
   - 节点标题与中文描述均可在 2 行内平整展示，并开启 `word-break: break-all;` 防破行。
   - 标题文案由单一的“节点”规范为“节点库”，意图表达更明确。

3. **视觉质感升级与层级隔离**：
   - 面板增加 `border-radius: 10px; backdrop-filter: blur(8px);` 及精细卡片投影 `box-shadow: 0 8px 24px -4px rgba(15, 23, 42, 0.1);`，浮动层与下方画布网格清晰分层。
   - 卡片图标尺寸与间距微调，悬停状态呈现轻柔位移与微光阴影。

4. **工作区入口样式就绪韧性加固**：
   - 在 `openAgentDagWorkbench` 与 `openAgentWorkbench` 入口中补充 `whenWorkspaceStylesLoaded` 守护窗口，确保 `chat.workspace.agent.css` 分包样式就绪后再挂载工作台，彻底阻断分包竞态。
