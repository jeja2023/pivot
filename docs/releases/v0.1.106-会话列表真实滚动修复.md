# v0.1.106 发布记录：会话列表真实滚动修复

发布日期：2026-09-09

## 修复内容

- 侧栏设为明确的全高、可收缩 flex 容器；会话列表设为 `flex: 1 1 0`、`min-height: 0` 和 `max-height: 100%`，使其在桌面端真正拥有独立的可滚动高度。
- 会话列表保留滚动到底部自动加载下一页的体验，不恢复额外的“加载更多”按钮。
- 恢复细窄滚动条与稳定滚动槽位，用户可以直观看到历史会话仍可继续向下浏览。

## 验证

- 触底后会话列表自动请求并追加下一页；
- `npm run check` 与 `npm run lint` 通过。
