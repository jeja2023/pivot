# v0.1.188 长期记忆按钮交互审计与合并建议弹窗化

发布日期：2026-09-27

发布范围：设置工作区的长期记忆工具栏、批量操作、任务维护、列表行操作、来源/使用记录弹窗、合并建议与检索评测。

## 审计结论

长期记忆页面的按钮分散在多个按需加载脚本中。此前部分事件在设置脚本注册时读取模块对象，首次打开设置页遇到脚本并发加载时可能缓存空 API；另有合并建议以内嵌面板展示，评测用例编辑的重置按钮受通用按钮样式影响，即使包含 `hidden` 属性也会显示在字段操作行。

本版本统一处理了这些问题，并为关键用户流程补充浏览器回归。

## 1. 全部长期记忆操作的动态入口

以下交互在用户实际点击时解析 `settings.memory` 模块，而不再依赖设置事件注册时的旧对象：

- 工具栏：刷新、启用/关闭、导出、合并建议、检索评测；
- 筛选与刷新：搜索、状态筛选、类型筛选；
- 批量操作：归档过期、恢复选中、禁用选中、删除选中；
- 抽取任务：重试失败、清理旧任务；
- 单条记忆：来源、使用记录、编辑、禁用、确认/恢复、删除；
- 评测：打开、关闭、刷新、运行、添加/更新、编辑、删除和取消编辑；
- 合并建议：打开、关闭和执行合并。

模块确实尚未就绪时，页面提示“长期记忆功能仍在加载，请稍后重试”，不再出现 `is not a function` 或静默无响应。

## 2. 合并建议改为独立弹窗

- “合并建议”不再把候选列表嵌入长期记忆页面。
- 新增独立模态框，桌面宽度最高 `900px`，移动端受 `calc(100vw - 32px)` 限制。
- 弹窗展示候选类型、相似度和两条记忆正文。点击“合并”后刷新列表，并重新加载当前建议。
- 合并窗口支持关闭按钮、点击遮罩关闭、窄屏单列布局和深色模式。

## 3. 检索评测的取消编辑按钮

截图中的“取消”并非多余的弹窗关闭操作，它用于取消“编辑已有评测用例”并恢复“添加用例”状态。

- 按钮改名为“取消编辑”，以明确语义。
- 从字段操作区移至表单标题行，只在编辑已有用例时显示。
- 增加专用 `[hidden]` 样式规则，避免通用按钮 `display` 样式覆盖原生隐藏属性；新增用例时该按钮不会显示或占位。

## 4. 来源与使用记录弹窗

- 来源和使用记录继续使用同一受控内容弹窗，但标题会按当前操作显示为“来源”或“使用记录”。
- 来源、使用记录、编辑和状态类操作均通过动态 API 调用，独立处理加载失败与关闭逻辑。
- 来源弹窗维持桌面最大 `960px`、小屏视口约束和内部内容滚动。
