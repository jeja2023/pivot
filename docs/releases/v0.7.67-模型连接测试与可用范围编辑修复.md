# v0.7.67 模型连接测试与可用范围编辑修复

发布日期：2026-10-29

## 更新内容

- 模型配置弹窗的测试、取消和保存按钮明确使用普通按钮类型；移除全局弹窗操作的重复事件绑定，并在测试或保存进行中阻止重复触发。测试连接不会保存配置或关闭弹窗。
- 将“保存范围”更名为“可用范围”。系统最高管理员可编辑自己拥有的个人模型和全局模型，在个人／全局间切换；全局模型可设置可见部门。普通用户和管理员不能借此将个人模型改为全局，也不能修改其他用户的个人模型。
- 将全局模型改为个人模型时，保留模型配置和加密密钥，在同一事务中清除该模型的系统默认及其他用户默认引用；全局模型收紧部门范围时，清除不再有权使用的用户默认引用。个人模型的部门列显示“仅本人”。
- 更新[使用帮助](../../使用帮助.md)中的测试和可用范围说明。

## 验证与限制

- 隔离 PostgreSQL 测试覆盖个人／全局双向切换、部门可见性、默认引用清理、密钥保留、非法范围及跨用户权限；模型配置浏览器测试覆盖测试成功和失败时不保存、单次保存及双向范围编辑。
- 工程检查和 lint 通过。未执行完整全量测试和生产环境验收；历史重复模型记录不会自动删除，需核对后按需手动处理。

## 更新方式

更新服务端并重新加载页面；桌面客户端使用对应版本构建。本次无需新增数据库迁移、必需环境变量或第三方依赖。
