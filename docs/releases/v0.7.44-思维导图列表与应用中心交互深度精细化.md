# Pivot v0.7.44 发布记录 —— 思维导图列表与应用中心交互深度精细化

**发布日期**：2026-10-26  
**版本号**：v0.7.44  
**涉及模块**：思维导图工作区（`apps.mindmaps`）、应用中心（`workspaces.apps`）、全局数据表格与弹窗交互体系

---

## 概述

v0.7.44 版本针对用户在实际使用思维导图和应用中心过程中反馈的视觉分散、按钮拥挤、弹窗冗余及表格列宽占用等体验痛点，开展了深入、系统的产品化精细重构：
1. **思维导图顶部操作栏单行化与收拢**：合并导入与辅助入口至“更多操作”下拉菜单，重写菜单项为严格左对齐，去除所有 Emoji 并换用精细 SVG 矢量线性图标。
2. **筛选功能整合为胶囊式分段组合栏（Segmented Filter Bar）**：将分散杂乱的归属范围、标题搜索、标签筛选与只看收藏整合为单体高质感胶囊组合栏，节省横向空间并提升操作流程度。
3. **全局统一数据表格规范落地**：数据表格增加序号列、完整四周边框、统一 38px 单元格行高、操作按钮防撑高，并移除无交互意义的图片预览列以释放长标题展示空间。
4. **新建与 AI 生成弹窗精益化**：移除重复的模板下拉框与多余装饰图元，移除右上角与右下角“取消”重复的关闭按钮。
5. **应用中心卡片去冗**：清除每个应用卡片底部的“进入工作台”区域，强化卡片作为整体可点击容器的高级质感。

---

## 详细改动清单

### 1. 思维导图工作区操作栏与筛选组合栏

- **单行水平对齐与按钮收拢**：
  - [client/chat/partials/workspaces/apps-mindmaps.html](file:///e:/pivot/client/chat/partials/workspaces/apps-mindmaps.html)：将“新建导图”、“AI 生成”作为主按钮保留，并将“导入导图文件 (XMind/MD/JSON)”、“数据转导图”、“数据层级映射”、“个人模板管理”统一归入“更多操作”下拉菜单。
  - [client/chat/styles/workspaces/apps/mindmaps.css](file:///e:/pivot/client/chat/styles/workspaces/apps/mindmaps.css)：修复下拉菜单项 `.mm-dropdown-item` 默认居中的问题，显式声明 `justify-content: flex-start !important` 和 `text-align: left !important`，各菜单项 SVG 图标尺寸固定（13px）并左侧基准线绝对对齐。
- **整合式胶囊筛选栏（.mm-filter-bar）**：
  - 弃用以往带有孤立文字标签（“搜索”、“范围”、“标签”）的分散控件排布；
  - 采用现代组合控件设计：`[ 范围下拉 ▾ | 🔍 标题搜索... | 🏷 标签筛选... | ⭐ 只看收藏 ]`，整体高度 32px，外轮廓圆角 6px，支持 `:focus-within` 聚焦环高亮；
  - 收藏状态切换块在勾选后呈现浅琥珀色背景与黄色星标，原生 Checkbox 无障碍属性与快捷键完全保留；
  - 刷新按钮与筛选栏右侧紧随排列，全行高度与视觉基线严密一致。

### 2. 数据表格规范化与结构精简

- **数据表格四边框与固定行高**：
  - 表格全面接入 `.table-container`、`.workspace-table-wrap`、`.mm-data-table`；
  - 表头背景采用 `var(--bg-side, #f8fafc)`，文字加粗并锁定 36px 黏性定位；
  - 单元格固定统一 38px 行高，完整细线边框分隔；
  - 单元格内操作按钮（“编辑/查看”、“收藏标签”、“删除”）高度限制在 22px，绝不撑高单元格行高。
- **列结构优化**：
  - 新增固定宽度 54px 的“序号”列，根据分页偏移自动连续编号；
  - 移除无实际点击大图预览功能的“预览”缩略图列，表头列数由 7 列精简为 6 列；
  - “名称”列最小宽度提升至 220px，支持超长标题自适应省略与原生 Tooltip；
  - 分页控件接入全局统一的 `renderWorkspacePagination` 逻辑，支持总条数展示与翻页联动。

### 3. 弹窗交互去重与视觉精简

- **新建思维导图弹窗**：
  - 移除弹窗内与上方卡片选择器重复的结构模板下拉框，以 4 种模板卡片（空白导图、工作计划、分析研判、会议纪要）作为核心选择器；
  - 移除导图名称输入框前多余的图元装饰，对齐输入框基准内边距；
  - 移除弹窗右上角红色关闭按钮，通过控制器传参 `{ hideClose: true }` 与 CSS 选择器 `.workspace-modal.mindmap-dialog:has(.mm-create-modal) .workspace-modal-close { display: none !important; }` 双层控制，避免与右下角“取消”按钮功能重复。
- **AI 生成思维导图弹窗**：
  - 移除分析推理模型选择下拉框前面的装饰图元，输入框与选择框间距、字号严整对齐；
  - 同步移除右上角重复的关闭按钮，统一由右下角“取消”按钮或 `Esc` 键退出。

### 4. 应用中心卡片极简重构

- **移除“进入工作台”区域**：
  - [client/chat/apps-workbench-core.js](file:///e:/pivot/client/chat/apps-workbench-core.js)：移除卡片渲染模板中的 `.app-card-footer` 及其“进入工作台”箭头操作栏；
  - [client/chat/styles/workspaces/apps/apps-grid.css](file:///e:/pivot/client/chat/styles/workspaces/apps/apps-grid.css)：将 `.app-card` 布局重设为 `justify-content: flex-start`，内边距优化为 `24px 26px`，整体高度更紧凑（`min-height: 168px`）；
  - 卡片整体为统一交互按钮，保持悬浮上浮（translateY(-4px)）、柔和投影加深及焦点环高亮交互。
