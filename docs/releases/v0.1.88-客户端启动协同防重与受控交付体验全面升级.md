# v0.1.88 发布记录：客户端启动协同防重与受控交付体验全面升级

## 版本概述

**发布日期**：2026-09-07  
**版本号**：v0.1.88  
**适用范围**：Pivot 全场景智能协同中枢系统（Web 端 / Windows & Linux 桌面客户端 / 集中控制面）

在 v0.1.87 完成受控交付目录授权弹窗视觉重构与多语言代码交付后，本版本重点解决**桌面客户端启动时注册本机交付设备产生的重复审计日志与并发网络冗余**，并对**受控交付状态监控、目录排重与删除撤销、多语言代码安全落盘及桌面客户端打包运行可靠性**完成全面收口与工程化治理。

---

## 核心更新特性

### 1. 注册本机交付设备双重日志根治与端侧启动协同锁

- **根因分析与并发收敛**：排查确认桌面客户端在 Electron 主进程启动时，受控交付控制器（`getDeliveryController().start()`）与本机 MCP 连接器（`getLocalMcpConnector().start()`）几乎在同一毫秒分别调用各自的 `ensureRegistered(deviceId)`，造成同时向服务端发起两组 Nonce 挑战与签名注册请求。
- **客户端启动协同单例锁**：
  - 在 [`desktop/delivery/executor.js`](file:///e:/pivot/desktop/delivery/executor.js) 中引入 `registeringPromise` 并发单例锁，并发调用自动复用正在进行的注册 Promise；
  - 在 [`desktop/delivery/controller.js`](file:///e:/pivot/desktop/delivery/controller.js) 导出 `ensureRegistered`；
  - 在 [`desktop/local-mcp-connector.js`](file:///e:/pivot/desktop/local-mcp-connector.js)、[`desktop/local-mcp-controller.js`](file:///e:/pivot/desktop/local-mcp-controller.js) 与 [`desktop/main.js`](file:///e:/pivot/desktop/main.js) 将连接器的设备注册统一委托给交付控制面，同时连接器内部具备并发锁；启动时两模块完全合并为**单次网络请求**与**单次公私钥挑战**。
- **服务端分类与幂等审计**：
  - 在 [`server/services/agent-local-devices.js`](file:///e:/pivot/server/services/agent-local-devices.js) 中精准区分操作类型：`created`（新设备注册）、`rotated`（密钥轮换）、`reactivated`（重新启用已撤销设备）、`reconnected`（相同公钥正常重连/并发调用）；
  - 在 [`server/routes/agent-delivery.js`](file:///e:/pivot/server/routes/agent-delivery.js) 中仅对 `created` 写入「注册本机交付设备」审计日志，`rotated` 写入「轮换本机交付设备密钥」，`reactivated` 写入「重新启用本机交付设备」；对 `reconnected`（正常设备重连）**不再生成冗余日志**，彻底消除日志刷屏。

### 2. 桌面受控交付目录授权弹窗现代化重构

- **彻底告别原生 Win32 弹窗**：替换原先调用操作系统 `dialog.showMessageBox` 弹出的粗糙系统消息框，设计并上线专属无边框 Electron 模态对话框（`desktop/delivery-grant.html` + `desktop/delivery-grant-preload.js`）。
- **统一 Pivot 品牌与视觉动效**：采用 Pivot Emerald 翠绿渐变主色调，配备入场 Pop-in 弹性动效的成功对勾徽章；增加专属已授权目录高亮胶囊卡片（`dir-pill`），并标明「受控写入」合规标识。
- **结构化格式标签芯片（Chips）展示**：将原先占满屏幕的多达 32 种格式长字符串重构为标签芯片排版，精选高频格式优先呈现，其余格式自动折叠为 `+N 种格式` 悬停提示气泡，直观整洁。
- **全链路深色模式与快捷交互**：完美适配深色模式（Dark Mode）；支持无边框标题栏拖拽与右上角快捷关闭；主按钮「确定」自动聚焦，支持 `Enter` 与 `Esc` 键极速确认关闭；左下角提供「查看交付状态」直达入口，并保留优雅降级容错机制。

### 3. 受控文件交付状态窗口极简交互与目录管理治理

- **顶栏标识精简收敛**：移除顶部标题栏中多余的「企业受控通道」小徽标，使对话框标题更加清爽聚焦。
- **运行状态展示去重与不换行保障**：重构第一张 KPI 卡片展示，彻底去除重复渲染的状态文字与标签，通过 `white-space: nowrap` 布局彻底解决「空闲待命」跨行折叠为两行的不良排版。
- **受控目录防重添加机制**：接入排重校验，当用户选择已授权目录时友好提示无需重复添加；并在本地持久化存储加载与保存时自动清理历史重复目录，确保列表中同路径目录永远唯一。
- **受控目录删除与授权撤销能力**：在受控输出目录列表中为每条记录增设「删除」操作按钮，并配置两步确认（防止误触），支持从服务端和本机无缝撤销目录写入授权。

### 4. 多语言代码资产安全受控交付全链路

- **全面扩展交付格式矩阵**：支持受控输出主流编程语言与配置文件（`py`、`js`、`ts`、`jsx`、`tsx`、`java`、`c`、`cpp`、`go`、`rs`、`sql`、`sh`、`json`、`yaml` 等）。
- **前端代码交付一键落盘**：新增 `client/chat/code-delivery.js`，在聊天与智能体代码产物中提供一键保存到本地受控目录的直观交互。
- **服务端防穿透与格式归一化**：在 `server/services/agent-path-safety.js` 与 `desktop/delivery/output-grants.js` 统一受控目录格式解析校验，提供向后兼容格式归一化，严守安全沙箱边界。

### 5. 客户端构建加固与运行环境稳定性保障

- **安装包构建与 Asar 运行加固**：排查并加固 electron-builder 打包配置与依赖打包清单，修复动态依赖与 Asar 完整性问题，消除客户端安装后打不开的异常风险。
- **自动更新完整性验证**：深入检验 `desktop/updater.js` 自动更新模块，确认更新检查间隔配置、首次失败 30 秒重试机制、窗口聚焦唤醒检查及平滑生命周期析构均具备高可用保障。
- **系统兼容性指引**：针对 Windows 7 64位等低版本系统提供兼容性诊断与运行要求说明（Node.js/Electron 内核平台基线与升级指引）。
