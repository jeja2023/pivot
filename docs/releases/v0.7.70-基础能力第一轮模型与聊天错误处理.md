# v0.7.70 基础能力第一轮：模型与聊天错误处理

日期：2026-10-30。此版本记录以 v0.7.69 为基线的第一轮修改。

## 更新内容

- 模型服务返回成功但没有可显示正文或图表时，聊天不再将空回复当作成功答案。用户消息保留，界面显示可重试的错误；相同请求标识重放时恢复该错误，不重复调用上游模型。
- 上游只返回 HTTP 429 而没有可识别正文时，显示限流和重试提示；明确的余额或额度不足仍优先采用相应提示。
- 建立基础能力执行方案，梳理模型、聊天、文件、知识库、工具、自动化与应用的入口、现有测试和未验收范围。

## 验证与边界

使用隔离 PostgreSQL、受控模型和浏览器完成聊天错误、请求重放、历史恢复及再次发送验证；相关聊天专项 177 项通过。该轮完整 Node 回归 2401 项通过、2 项外部依赖测试跳过；这些外部依赖在后续轮次的完整回归中实际运行并通过。

本轮没有连接真实模型供应商或生产业务数据。具体范围见[第一轮验证与修复](../reports/2026-10-30-基础能力第一轮验证与修复.md)和[基础能力执行方案](../reports/2026-10-30-Pivot基础能力做实执行方案.md)。

## 更新方式

更新主服务并刷新聊天页面。此轮无新增数据库迁移或必需环境变量。
