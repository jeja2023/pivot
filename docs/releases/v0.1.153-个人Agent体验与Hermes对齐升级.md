# Pivot v0.1.153 发布记录：个人 Agent 体验与 Hermes 对齐升级

## 发布概要

v0.1.153 完成《[Pivot达到Hermes个人Agent体验改造与落地方案](../../Pivot达到Hermes个人Agent体验改造与落地方案.md)》可由代码闭环的 P0～P2 项目。改造复用现有 Agent Run、会话、记忆、Skill、审批、Outbox、网络策略和审计边界；不会为个人体验创建第二套 Runtime 或绕过企业治理。

真实渠道/Provider 连通性、试点指标和人工评测仍须按 [发布证据](../agent-experience/personal-agent-beta-release-evidence.md) 执行。

## 工作流编排现阶段收口

- `workflow.iteration` 持久化每一项的输入摘要、固定工作流版本、调用实例与终态结果；中断恢复时仅复用输入未变化的已完成项，避免重复处理成功项。
- 触发器增加接收、派发、失败、水位与重放事件记录。所有者可查看脱敏诊断摘要，并把成功事件重放为新的运行；重放不修改原事件或覆盖原任务。
- 发布前可查看副作用、审批、网络、子工作流、模型/工具/凭据依赖和不可用工具的影响清单；发布可附说明，团队/组织发布可由同租户管理员通过或要求修改。
- 运行 Trace 关联工作流版本、子工作流调用路径与迭代项身份；历史运行详情的产物、审批和异常操作区统一复用 Agent 工作区 CSS，不再保留静态内联样式。

## 个人 Agent 主旅程

- 个人工作台新增“我的智能助手”卡片，集中展示档案、记忆、经验与待处理状态；未设置账号可直接进入 3 分钟快速设置。
- 聊天输入区增加显式“记住当前输入”和记忆管理入口；服务端验证来源会话、敏感规则和个人记忆策略。
- 自动学习生成的个人 Skill 会在后续任务中给出匹配理由和匹配词；停用/撤销后不再用于新 Run。
- 新增自然语言持续目标草案。每日、工作日、每周、固定间隔等受支持表达只会生成预览；用户确认绑定、15 分钟过期的 HMAC token 后才会创建目标。

## 双向渠道、能力与协作

- 新增 PostgreSQL Gateway 状态：一次性配对码、外部身份哈希、外部会话映射、入站 event 幂等和出站活跃时间。
- Gateway 先校验时间窗和 HMAC，再允许配对身份创建/接续 Pivot 会话与 Agent Run。撤销配对后立即拒绝新消息。
- 外部 conversation ID 只以摘要和 `outbound_target_encrypted` 保存；outbox 保留加密引用，投递适配器发送时才解封目标，避免明文落入运行追踪或投递记录。
- 个人能力目录只显示当前账号被授权的发布 Skill、内置工具与受控连接；不提供任意第三方自动安装。
- 新增最多 10 个子任务的并行委派，子任务继承或收窄主管任务的工具/审批边界，结构化结果最多允许一次修正并回传主管。
- 移动端审批按钮保持同一服务端授权路径，并保证触屏目标尺寸与误触保护。

## 受控多模态与项目上下文

- 网页检索、图片生成和 TTS 均采用管理员配置 Provider。工具只有在 Endpoint 配置后才会出现在目录中；每次调用要求任务级 Origin 白名单和人工审批。
- 图片/TTS 返回的媒体 URL 也必须在白名单；Provider 密钥仅经凭据引用或受控环境变量解析，不进入模型上下文、结果或日志。
- 聊天支持浏览器 Web Speech 的语音输入；录音由浏览器能力处理，服务端不会接收音频文件。
- 任务可选择已有授权知识库集合组成项目资料包。服务端创建 Run 时保存集合快照，`rag.search` 使用该范围并在每次检索执行当前 ACL，权限回收即时生效。
