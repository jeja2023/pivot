# v0.7.111 — BI 受控分批摄取与百万行版本登记

对应 v2.0 建设方案第 13.1、13.3、20—21 节的后台分批摄取要求。普通上传配置保持原上限，新的受控入口独立校验容量与完整性。

## 使用与合同

数据分析概览选择“后台分批导入 CSV”，提供带表头的 UTF-8 CSV、名称和事实/维度用途；可以额外填写预期行数。浏览器逐块计算 SHA-256，服务端按摘要和精确字节边界登记。未完成上传保留一天，可重新选择同一原文件继续；已确认分块不能被其他内容替换。

事实数据最多一百万行、维度数据最多两百万行，每文件最多 2 GiB、一百二十列；每块 8 MiB，最多二百五十六块。表头名称唯一，单条 CSV 记录受四 MiB 解析保护。单元格预览最多 256 字，完整值保存于数据文件；编码、十进制等保持字符串，避免导入时损失精度。

全部分块到齐后才接纳计算任务，执行与其他分析类型共用数据库槽位及配额。严格解析不跳过坏行；字段、声明行数、摘要或输出合同不符时整体失败。成功事务一次性登记个人数据集、analysis_dataset_versions、来源摘要与对象保留引用、任务成功和审计。取消与失败不会向数据集列表交付部分文件。
