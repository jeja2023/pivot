# Pivot v0.1.130 发布记录：网站嵌入代码节点

## 版本概览

- **版本号**：v0.1.130
- **发布日期**：2026-09-10
- **核心定位**：让工作流可以为其它网站生成可直接使用的 HTML iframe 嵌入代码。

## 新增能力

新增节点：`workflow.embed_code`，位于工作流“呈现与交付”节点组的高级节点中。

节点参数：

- 页面地址：同源路径或 HTTP/HTTPS 地址；
- 嵌入标题：写入 iframe 的无障碍标题；
- 固定宽度：非响应式模式下使用，范围 320～1600 像素；
- 嵌入高度：范围 180～1200 像素；
- 响应式宽度：开启后生成 `width="100%"`，适配外部网站容器。

## 生成代码示例

节点输出会生成类似以下代码：

```html
<iframe src="https://example.com/embed" title="外部页面" width="100%" height="500" loading="lazy" referrerpolicy="no-referrer" sandbox="allow-forms allow-modals allow-popups allow-presentation allow-scripts" style="border:0;max-width:100%;" allowfullscreen></iframe>
```

结果页面会以代码块展示生成内容，并提供目标页面预览入口。用户可以复制代码，粘贴到其它网站的 HTML 页面、CMS 自定义 HTML 区块或门户组件中。

## 使用限制与安全说明

- 该节点只生成代码，不会把页面发布到公网，也不会替用户创建外部可访问的工作流 URL；
- 目标地址必须在外部网站环境中可访问；使用内网地址、`localhost` 或 Pivot 登录态页面时，外部网站通常无法访问或无法保持登录状态；
- 目标站点如果设置了 `X-Frame-Options` 或 `Content-Security-Policy: frame-ancestors`，浏览器会拒绝 iframe 嵌入，此时需要调整目标站点策略或改用链接卡片；
- 生成代码使用 sandbox，默认不授予嵌入页面访问宿主页面 DOM 的权限；需要跨站登录、支付或复杂脚本通信时，应由目标站点管理员单独设计 postMessage 和授权策略；
- 页面地址仍拒绝 `javascript:`、`data:`、`file:`、协议相对地址以及包含用户名/密码的地址。
