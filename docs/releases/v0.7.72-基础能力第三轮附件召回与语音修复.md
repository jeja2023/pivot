# v0.7.72 基础能力第三轮：附件、召回与语音

日期：2026-10-30。

## 更新内容

- 文档附件解析失败时返回可操作的错误，不再作为空正文成功发送；用户输入和待发送附件保留，替换后可继续。解析大小超限返回 413，其他解析失败返回 422。
- DOCX 和 XLSX 校验必要的文档结构，普通 ZIP 伪装为 Office 文件会被拒绝；有效空白文档仍可解析。单文件类型不支持时显示准确提示。
- 知识库召回测试等待队列状态和调试历史写入，避免返回空状态或立即读取历史时发生竞态。
- Windows 本地语音识别对进程结果使用明确标记；附带的诊断信息不会污染结果解析，多条结果或失败进程仍被拒绝。

## 验证与边界

浏览器验证文本附件上传、解析、模型上下文、刷新预览及损坏文件替换恢复；同时验证思维导图、资金分析和工作流。PDF、PPT、连接器及 MCP 另有隔离专项测试。

该轮完整浏览器测试曾有一项真实音频识别失败，修复后单独复测通过；后续第四轮进一步调整测试时序并完成完整浏览器回归。真实 OCR 精度、目标 Office 软件及实际模型供应商仍需独立验收。详见[第三轮验证与修复](../reports/2026-10-30-基础能力第三轮验证与修复.md)。

## 更新方式

更新并重启主服务、刷新页面；如使用 Windows 本地语音识别，应同时更新服务端脚本和代码。此轮无新增数据库迁移或必需环境变量。
