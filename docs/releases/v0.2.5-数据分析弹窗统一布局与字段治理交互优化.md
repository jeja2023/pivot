# v0.2.5 数据分析弹窗统一布局与字段治理交互优化

发布日期：2026-10-11

## 概述

本版本针对数据分析应用中**字段治理**、**分析资产**与**仪表盘**页面的交互体验与界面规范进行系统性重构优化。全面统一所有弹窗的全局排版，移除重复冗余的右上角关闭按钮，规范表单标签、必填星号与按钮图标文字对齐，使整个数据分析应用的视觉语言和交互规范完全一致。

## 详细变更

### 1. 弹窗全局统一布局与靠左排版规范

- **弹窗标题与副标题靠左对齐**：为 `.data-analysis-dialog-modal`、`.data-analysis-modal-header`、`.data-analysis-modal-title-group` 显式设置靠左对齐与弹性盒起点对齐（`text-align: left !important; align-items: flex-start !important;`），根治基础 `.modal` 居中继承带来的错位问题；所有 12 个弹窗头部统一具备业务矢量图标、主标题（`<h3>`）与功能说明副标题（`<p>`）。
- **表单标签与内容严格靠左**：分组标题（`.data-analysis-subheading`）、表单标签（`.data-analysis-modal-form-grid label`）、输入框、下拉框、文本域及资产列表说明全部强制靠左排列；表单控件统一采用 34px 高度、7px 现代化圆角与轻量边框阴影。
- **必填红色星号位置与行内显示优化**：彻底解决此前 `<label>` 纵向 Flex 容器导致红色 `*` 被换行误排在标签文字下方的问题。为所有表单项的标签名称与必填星号添加 `<span class="data-analysis-label-title">` 容器，配合行内弹性盒与基线对齐，保证红色星号紧随标签文字右侧同行规整展示。

### 2. 弹窗操作按钮统一与去重

- **全面移除右上角重复关闭按钮**：在 `extra-panels.js` 与 `scalability.js` 中彻底移除字段治理、分析资产、仪表盘共 12 个弹窗头部的右上角关闭按钮，避免与弹窗右下角的“取消/完成”操作产生功能重复，同时在 CSS 中对 `.data-analysis-modal-close-btn` 配置 `display: none !important;` 作为全局防御。
- **规范右下角底部操作栏**：所有弹窗底部 `.data-analysis-modal-footer` 均统一放置右对齐的“取消”（次要按钮 `btn-secondary`）与“完成/保存/创建”（主要按钮 `btn-primary`），高度统一为 34px；支持点击底部按钮、点击遮罩或按 `Esc` 键退出弹窗。

### 3. 按钮名称与图标对齐及动态保护

- **按钮图标与文字垂直居中及间距规范**：为状态栏按钮（计算字段管理、业务指标口径、跨表关联模型、规模化数据管道）、仪表盘操作按钮（定时刷新计划、阈值告警规则、快照历史）及弹窗内操作按钮（预览计算、生成派生数据集）统一配置：
  - `display: inline-flex !important; align-items: center !important; justify-content: center !important; gap: 7px !important;`
  - SVG 图标配置 `flex-shrink: 0 !important; display: inline-block !important; vertical-align: middle !important; margin: 0 !important;`
  - 文字 `span` 配置 `line-height: 1 !important; vertical-align: middle !important;`
  彻底解决浏览器内联基线对齐导致的图标下沉、贴字和垂直不居中缺陷。
- **异步请求按钮保护（guardButton）**：优化 `core.js` 中的 `guardButton` 逻辑，在按钮处于加载执行状态时仅替换文字 `span` 内容，完整保留其 SVG 矢量图标结构与居中弹性盒布局，防止动态请求时图标被抹除导致界面跳动。
