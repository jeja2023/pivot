# Pivot v0.1.147 发布记录：聊天 @ 能力分页浏览

## 发布概要

本版本完善聊天 `@` 两级能力选择器：用户不必预先知道知识库或工具名称，进入某个类别后即可浏览完整的、受权限约束的能力列表。

## 交互变化

- 裸“@”仍只展示“知识库 / 工具”两个一级入口；
- 进入类别后默认显示候选列表、当前位置和总数，无需先输入关键词；
- 每页最多 6 条，使用上一页、下一页浏览全部可用知识库或工具，避免菜单无限增长；
- 搜索框作为可选过滤器，搜索结果也遵循同一分页规则。

## 安全边界

- 工具列表仅在用户进入工具类别时按需读取；
- 工具候选继续经过用户可见性、Capability 治理和当前聊天工具白名单过滤；
- `@` 选择只收窄本轮路由候选，不能直接授权、执行或绕过审批与网络预检。

## 验证

- 浏览器 E2E 覆盖 7 个可用工具时的“1–6 / 7”首页、分页到第 7 项、返回上一页、搜索与选择后路由覆盖；
- 聊天输入、自适应路由、RAG、MCP 与安全聊天专项回归通过；
- 完整 `npm run check` 通过。
