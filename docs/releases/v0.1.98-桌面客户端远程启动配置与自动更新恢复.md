# v0.1.98 发布记录：桌面客户端远程启动配置与自动更新恢复

## 背景

此前为避免将真实 stealthSecret 放入安装包，构建配置移除了 `config.json`。但桌面端没有远程配置时会回退到本地模式，导致新用户无法直接连接远程服务，也无法获得自动更新源。

## 本次修复

- 安装包重新携带不含 secret 的远程启动配置：
  - `remoteUrl`: `http://50.64.150.51:9006/`
  - 更新目录：`/downloads/`
  - 允许受控局域网 HTTP 更新
  - `allowedOrigins`: `http://50.64.150.51:9006`
- stealthSecret 不写入仓库配置或安装包。
- 如果服务端启用了隐身模式，客户端连接错误页提供“配置服务器”入口；用户输入密钥后保存到用户目录，后续升级继续复用。
- 版本提升至 v0.1.98，旧 v0.1.97 客户端可以通过已有同站更新源检测到该版本。

## 发布验收

- `npm run check`
- `npm run lint`
- `node --test tests/security-desktop-update.test.js`
- `node --test tests/security-boundaries.test.js`
- 打包后确认安装包 `resources/config.json` 存在，且内容不含 `stealthSecret`。
- 确认服务端 `downloads/latest.yml`、v0.1.98 安装包和 blockmap 已同步到远程 `/downloads/` 目录。
