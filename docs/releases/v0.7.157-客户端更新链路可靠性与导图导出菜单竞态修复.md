# v0.7.157 客户端更新链路可靠性与导图导出菜单竞态修复

日期：2026-11-13。启用源码版本 v0.7.157，整合导图导出菜单并发竞态修复与 Windows 桌面客户端更新、安装阶段诊断及错误摘要收敛改造。

## 导图导出菜单与并发下载竞态修复

- **阻止编程下载链接冒泡误关下拉菜单**：在 [`apps-workbench-mindmaps.js`](../../client/chat/apps-workbench-mindmaps.js) 中为临时 `<a download>` 注册 `click` 冒泡阻止（`stopPropagation`），避免后台自动下载完成触发 `link.click()` 时冒泡至 `document` 点击监听，将在打开状态的 `#xmind-export-menu` 提前关闭导致下一次格式按钮未命中。
- **按导出序号取消过期下载并复用进行中下载**：`download(job, sequence)` 绑定当前导出序号 `sequence`，在令牌、文件下载与读取 `blob()` 后均校验 `state.userId` 与 `state.exportSequence` 一致性；对同一任务且同一序号的进行中下载通过 `state.downloadInFlight` 复用单次请求，完成后清除以保留“下载文件”按钮手动重下能力。
- **同步切换导出菜单与显式传递按钮上下文**：`action(name, actionButton)` 优先同步处理 `export-menu`，点击委托显式传递当前触发按钮 `button`，避免共享 `state.actionButton` 在 `await` 扩展/弹窗子模块期间被其它点击覆盖。
- **浏览器测试去重与新增回归覆盖**：调整 [`mindmap-browser.test.js`](../../tests/mindmap-browser.test.js) 中的 `exportFile` 先注册 `waitForEvent('download')` 捕获自动下载完成事件（仅对 `json` 额外校验一次手动点击「下载文件」重下），避免 6 种格式并发 12 次下载触发 Chromium 单页连续下载限制；新增 [`mindmap-export-menu.test.js`](../../tests/mindmap-export-menu.test.js) 验证进行中下载复用、菜单不误关及下载完成后重下。

## Windows 客户端更新链路与安装诊断增强

- **安装器自检排除与阶段日志详情**：[`installer-process-guard.nsh`](../../desktop/installer-process-guard.nsh) 在原位进程核对中排除当前检查器/卸载器自身进程号，开启安装/卸载详情展示并写入 `%TEMP%\PivotInstaller-<PID>.log`，避免进度条停滞时缺少阶段可观测性。
- **签名查询超时与共享中文错误摘要**：[`updater.js`](../../desktop/updater.js) 为 PowerShell Authenticode 查询补充 30 秒超时；新增 [`desktop-update-errors.js`](../../client/common/desktop-update-errors.js) 收敛更新错误码与旧版原始错误文本为短中文提示，在更新器与 [`desktop-menu.js`](../../client/chat/desktop-menu.js) 中去重，并在进度达到 100% 时明确显示“正在校验更新...”。
- **独立更新会话与只读安装诊断**：沿用此前确认的独立 `electron-updater` 会话同源动态隐身签名绑定及本地模式无独立更新 URL 时的禁用保护；新增只读诊断脚本 [`collect_windows_installer_diagnostics.ps1`](../../scripts/collect_windows_installer_diagnostics.ps1) 与批处理 [`收集客户端安装诊断.bat`](../../scripts/bat/收集客户端安装诊断.bat)，以及部署排查文档（见[Docker 客户端下载配置](../Docker客户端下载配置.md)、[0.7.76 后续排查记录](../reports/windows-client-076-followup-20261113.md)）。
- **无新增依赖或结构迁移**：本次升版没有新增 npm 依赖、PostgreSQL 迁移或必填环境变量；0.7.76 等已安装旧二进制的签名策略仍受旧客户端自身校验约束，需按发布运维指引受控升级。
