# v0.7.46 思维导图大纲交互与节点文本居中及格式面板优化

## 概述

v0.7.46 版本对思维导图编辑器进行了深度的可用性细节打磨与体验优化。重点解决了大纲节点点击导致画布意外平移跳跃、节点内文字对齐偏左不居中、右侧格式检查器垂直间距过松、顶部工具栏存在重复功能按钮以及长文档标题显示被截断等关键体验问题，并对个人主题库与自定义主题包弹窗进行了全方位的结构与视觉升级。

---

## 核心优化与改动特性

### 1. 节点大纲纯选中交互模式（消除意外画布平移跳跃）
- **原问题**：点击左侧大纲面板中的节点时，旧版底层直接调用 `GO_TARGET_NODE` 命令，触发了画布 `moveNodeToCenter` 强制平移居中。在节点较多的大型思维导图中，频繁点击大纲会导致整个画布剧烈晃动跳跃，完全打乱用户的全局浏览视野。
- **优化改动**：
  - 新增 `activateNodeWithoutCentering(id)` 与 `editor.selectNodeById(id)` / `editor.focus(id, center = false)` API；
  - 点击大纲节点时，仅展开必要折叠祖先并在画布上高亮该节点的选中边框与操作手柄，同步刷新右侧属性检查器与大纲高亮条目；
  - **画布视口偏移量与当前缩放比保持完全静止**，不发生任何自动平移或居中晃动；
  - 幻灯片演示模式等确实需要视口聚焦的场景仍按需保持 `center = true` 平滑居中。

### 2. 节点内文字精准水平与垂直居中排版（Node Text Centering）
- **原问题**：节点在默认主题下文本对齐为左对齐（`textAlign: 'left'`），且纯文本 SVG 渲染在计算文字定位时未指定锚点坐标 `x`，导致单行文字左右留白不均、多行文本无法对齐节点中心，同时中文字符基线缺少垂直对称居中。
- **优化改动**：
  - **文字布局引擎升级**（`scripts/mindmap-text-layout.mjs`）：
    - 文本默认对齐改为 `center`（`const align = this.getStyle('textAlign', false) || 'center';`）；
    - 计算每一行的精准锚点坐标 `x`（居中为 `width / 2`，左对齐为 `0`，右对齐为 `width`），配合 `text-anchor: middle` 彻底消除负坐标与留白失衡；
    - 接入标准 SVG `dominant-baseline: central`，基准高度设为 `(index + 0.5) * lineHeight`，使中英文文字在节点区域内实现真正的像素级垂直居中；
    - 兼顾自定义节点宽度（`this.hasCustomWidth()` / `this.customTextWidth`），拖拽改变节点尺寸后文字依然对称居中；
    - 重新编译构建 `simple-mind-map` 运行包（`editor.mjs`）并更新 provenance 校验。
  - **主题与格式面板联动**：
    - 在编辑器的 `themeConfig` 与服务端导出配置中将各级节点 `textAlign` 统一声明为 `'center'`；
    - 右侧格式面板文字排版组默认选中“居中对齐”按钮，隐藏下拉选择器同步默认 `center`。

### 3. 右侧格式属性检查器紧凑化布局（Compact Inspector Layout）
- 调优右侧格式面板（`.xmind-inspector`）在标准分辨率下的垂直间隔节奏，将各属性分组内边距由 14px 收拢至 10px、分组间距由 12px 缩减至 8px、小行间距精简为 4px；
- 确保笔记本与常规屏幕（如 1080P）在不滚动的情况下，能够一屏完整呈现结构、形状、填充、边框、字体、字号、字重、颜色、对齐、内边距、连线等全部常用排版属性。

### 4. 顶部导航栏与大纲面板精简去重
- **移除大纲面板顶部冗余编辑按钮**：大纲现已支持在节点文字上直接双击或点击悬浮微图标进行原地内联编辑，彻底移除了面板头部原本容易误触的冗余“编辑”按钮。
- **顶部工具栏去重**：顶部操作栏不再展示与右侧画布面板重复的“主题库”和“主题包”按钮，功能统一收拢于右侧格式面板“画布”Tab，保持顶部主工具栏精简聚焦。
- **文档名称显示加宽**：移除内联标题包裹容器原本的 `max-width: 240px` 硬性限制，将标题输入框扩展至 `max-width: 380px`，长标题（如“验证工作计划导图”）完整展现无截断省略。

### 5. 个人主题库与自定义主题包弹窗交互升级
- **响应式宽度与视口适配**：设置最大宽度为 `min(760px, calc(100vw - 32px))`，彻底消除横向滚动条；
- **配色微标与安全渲染**：主题方案配色点统一接入 Pivot 现代圆点胶囊设计，完全符合安全 HTML 策略；
- **全量 SVG 矢量图标**：全量清除弹窗表格内的 Emoji 图标，改用标准的线性矢量 SVG 图标；
- **等宽代码与快捷工具**：自定义主题包编辑框采用等宽字体与柔和深色代码区，集成“格式化 JSON”与“复制配置”实用按钮，输入验证逻辑更加鲁棒。
