# v0.2.23 文字识别按钮对齐与OCR模型服务收拢系统设置

发布日期：2026-10-14

## 交付内容

- **文字识别工作区操作按钮 2×2 网格对齐**：
  - 将侧边栏 4 个核心操作按钮（「创建任务」、「截取已授权窗口」、「授权监控目录」、「停止目录监听」）由原有流式换行重构为 `repeat(2, minmax(0, 1fr))` 双列等宽等高网格对齐布局（8px 间距，文字居中与多行防折行）。
  - 为各操作按钮补充原生 `title` 气泡提示；按钮文字超出时自适应省略，单按钮或奇数按钮自动跨满整行，彻底解决不同屏幕分辨率下按钮高低不平与不对齐问题。
- **OCR 识别模型服务彻底收拢至系统设置**：
  - 将系统级 OCR 模型服务与业务工作区操作彻底解耦。移除文字识别业务侧栏冗余的内联配置表单（`#ocr-settings-form`），保持业务侧专注任务创建与文档处理。
  - 在「系统设置 → 模型配置（基础模型与算法服务）」中新增第 4 张服务状态卡片「OCR 识别服务」，与向量生成（Embedding）、重排序（Reranker）、检索策略（Strategy）保持统一风格与栅格自适应。
  - 新增独立的 `#ocr-service-modal` 配置弹窗，支持外部 OCR HTTP 服务地址配置（`setting-ocr-service-url`）及实时联通性测试（`ocr-service-test-btn`）。
  - 服务端提供超管专属的 `GET /api/settings/ocr`、`PUT /api/settings/ocr`、`POST /api/settings/ocr-test` API，并在全局设置接口返回只读脱敏的 `ocrConfig`。
- **工作区状态降级与跨模块联动引导**：
  - 文字识别工作区侧栏新增紧凑型提示条（`#ocr-service-alert`）。当外部 OCR 服务未连接或不可用时温和提示，并提供「前往系统设置配置」快捷按钮，管理员可一键跨工作区跳转至系统设置模型服务页；服务连接正常时自动隐藏不打扰。

## 兼容性与安全

- 外部 OCR 服务配置继续复用 `DOCUMENT_PROCESSING_OCR_SERVICE_URL` 环境变量及数据库运行态设置，已配置的服务地址平滑继承。
- OCR 服务的读取、修改与连通性测试接口严格限定为超级管理员权限（`isSuperAdmin`）。
