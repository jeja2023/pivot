# v0.7.13 聊天 Markdown 渲染与阅读样式修复

日期：2026-10-20。升级基线：v0.7.12。

本版本集中修复聊天回复中残留的强调标记，以及列表、表格、代码、公式、模型统计和窄屏消息操作的排版问题。

## 中文 Markdown 与流式输出

中文正文紧贴加粗标记，且强调内容以引号、书名号、括号或其他标点开头和结尾时，可能不符合原解析器的强调边界规则，导致页面直接显示星号或下划线。本次在原 Markdown 词法分析流程中补充兼容处理，支持多余空格、斜体及嵌套强调，保留原有合法语法。

逐字符输出期间临时恢复尚未闭合的强调；助手最终漏写闭合符时按当前段落恢复，避免格式扩散到下一段。思考块使用相同选项，流式重绘仍读取完整原始消息，不修改已保存的回复。

链接文字中的加粗、斜体和行内代码通过内联解析显示。链接地址、标题与附件卡片继续使用现有处理；显式转义、真实代码块、行内代码、公式及链接地址中的原始字符不会被统一删除。渲染结果仍经现有安全 HTML 组件消毒后插入页面。

## 阅读排版

| 场景 | 修复后的行为 |
| --- | --- |
| 嵌套任务清单 | 只移除任务项本身的项目符号，普通父项与同级项目保留符号 |
| 表格对齐 | 表头与数据单元格遵循 Markdown 指定的居中、右对齐方式 |
| 长表格单元格 | 限制过度撑宽并允许换行，多列表格保留独立横向滚动 |
| 窄屏代码工具栏 | 语言名称、复制和保存按钮按空间分行，按钮文字保持完整 |
| 引用中的代码 | 行内代码、代码正文与工具栏保持正常字形，不继承引用斜体 |
| 长公式 | 超宽公式从开头展示，可横向滚动到末尾，不再因居中而裁掉开头 |
| 长模型名称与统计 | 名称省略显示并保留完整提示，历史、实时、最终和任务统计可按宽度换行 |
| 窄屏及触屏消息操作 | 可用按钮显示在气泡内，避免落在屏幕外或依赖鼠标悬浮 |
| 深浅主题 | 回复气泡、表格、思考正文和统计文字复用全局主题变量 |
| 减少动态效果 | 关闭消息入场、思考脉冲和相关展开过渡 |

## 升级与生效

1. 更新服务端源码或镜像，按项目流程重启服务，并重新加载聊天页面。新静态资源 URL 使用 `v0.7.13` 版本参数。
2. 连接该服务端的桌面客户端重新加载页面即可获取本次聊天修复；没有新增桌面原生接口。
3. 本次修复不新增依赖、数据库迁移或必需环境变量，既有消息重新渲染时也会使用新的格式与样式。
4. 版本由 `CHANGELOG.md` 顶部条目驱动，通过 `npm run version:sync` 同步 `package.json`、锁文件与 README。当前交付为工作区源码、版本元数据与文档，尚未构建安装包、上传更新包或部署生产。
