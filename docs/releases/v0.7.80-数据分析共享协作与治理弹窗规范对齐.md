# v0.7.80 数据分析共享协作与治理弹窗规范对齐

日期：2026-11-01。本记录描述工作区版本更新和已验证的修改；版本号更新不代表安装包、镜像或目标环境已更新。

## 修改内容

- **数据集共享协作与 PPT 规范统一**：字段治理顶部操作栏的“共享范围”升级为“共享协作”，直接接入与演示文稿制作应用、知识库专题及工作流一致的通用协作者标准弹窗（`share.collaborators`），支持按单位选人、直接搜索用户与按单位批量授权三层精细授权，并清晰展示所有者与已加入协作的成员列表。
- **敏感字段四级权限脱敏前置**：统一共享面板顶部醒目强化机密与受限字段自动隔离说明，被授权成员角色预设为受控查看者，仅能浏览和消费脱敏后数据。服务端数据集序列化补齐 `userId`，完整支持 `scope`、`allowedUnits` 与 `allowedUserIds` 的原子更新与所有权鉴权。
- **字段治理功能弹窗视觉系统升级**：全面优化计算字段管理、业务指标口径管理、跨数据集关联模型及模型关联配置弹窗，统一输入框与下拉框为 36px 标准高度与 0.84rem 字号，全局清除 emoji 图标并替换为专业矢量 SVG 图标，下拉选择器内置 SVG 展开箭头并完成暗黑模式适配。
- **弹窗样式作用域隔离与尺寸修复**：规模化数据管道表单样式精准限制作用域，修复对原生数据选择器与文件上传按钮的样式溢出；调整 Agent 执行方向弹窗去除右上角冗余关闭按钮，升级为带字数统计的 `textarea` 文本域，输入字体优化为 0.84rem，常用方向选项去除 emoji。
- **架构治理与存量大文件瘦身**：废除字段治理旧的独立简易共享弹窗 DOM 与冗余 CSS，`extra-panels.js` 源码缩减至 61,148 字节，永久降至 61,440 字节大文件阈值以下并移出存量大文件监控列表；`engine.js` 压缩至 995 行维持在 1000 行大文件红线之内。
