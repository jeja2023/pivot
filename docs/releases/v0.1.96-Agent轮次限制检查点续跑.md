## 核心调整

此前30/50/60轮达到后，Agent 会直接生成部分结果并结束任务。现在这些数字表示单个执行时间片的轮次上限：

1. 当前时间片达到轮次上限；
2. 服务检查最新安全检查点；
3. 如果没有未完成工具调用，任务重新进入队列；
4. 下一时间片从检查点继续执行；
5. 原任务 ID、上下文、步骤记录和审计链保持不变。

流式工具调用和 JSON 规划器均已接入该逻辑。

## 安全边界

自动续跑不会绕过以下限制：

- 自动续跑次数，默认12次；
- 总运行时长，默认2小时；
- Token、工具调用、连续错误、风险、副作用和文件/网络预算；
- 用户停止、人工审批和未完成高风险工具调用；
- 重复工具调用和无进展检测。

可通过以下配置关闭轮次上限自动续跑：

```env
AGENT_AUTO_CONTINUE_ON_STEP_LIMIT=false
```
