# Pivot v0.1.158 发布记录：个人 Agent 交互、受控终端与渐进式工具发现

发布日期：2026-09-20  
版本来源：[CHANGELOG.md](../../CHANGELOG.md) 顶部版本标题；已同步至 `package.json`、`package-lock.json` 与 README。

## 发布目标

本版本继续提升 Pivot 的个人 Agent 连续体验和可执行能力：让用户能看懂、纠正和撤销 Agent 的学习结果；让 Agent 在不获得宿主机 Shell 权限的前提下完成受控代码与项目检查；让大工具目录按“搜索、阅读契约、执行”逐步披露，而不是把全部 Schema 放进模型上下文。

## 核心能力

### 1. 记忆、学习、复用与纠正

- 用户在任务详情提交“需要修正”的反馈时，服务端保留脱敏反馈并判断是否进入个人学习队列；前端会明确说明“已记录”还是“将生成待确认个人经验”。
- 自动匹配个人 Skill 的 Run 会显示经验名称、匹配理由和匹配词。用户可将误匹配经验暂停，后续 Run 不再自动命中；历史版本、审计记录和恢复操作仍保留。
- 学习仍只从多步骤成功、恢复成功、用户纠正或显式请求中产生候选。候选继续经历已有的内容安全、权限差异、声明式检查、沙箱验证、发布和撤销链路；学习不会自动授权网络、写入或副作用。

### 2. Terminal Runtime

- 新增 `terminal.runtime` 工具，限定操作为 `exec`、`read`、`write`、`list`；执行运行时限定为 Node、Python、只读 Git 子命令及 ripgrep。
- 每个用户/Run 获得独立 Jail 工作区。路径必须是工作区内相对路径；穿越路径、符号链接逃逸、绝对路径、宿主机 Shell、任意二进制和任意网络均被拒绝。
- 执行使用无 Shell 的进程调用，支持 AbortSignal 取消、120 秒上限、脚本/文件/参数/输出大小上限及工作区级文件列表限制。
- 生产执行使用 Capability Worker：固定摘要镜像、固定入口、无网络、只读根文件系统、无业务凭据、`no-new-privileges`、能力裁剪、PID/CPU/内存/tmpfs 限制和仅挂载任务工作区。未登记镜像时 Runtime fail-closed 且不出现在工具目录。

### 3. 渐进式工具发现

- 标准 Agent 规划器和流式原生 Tool Call 初始只看见 `tools.search`、`tools.describe`、`tools.execute`；不再把完整业务工具 Schema 批量注入模型。
- `tools.search` 仅返回当前用户已授权工具的摘要与稳定 `toolRef`；`tools.describe` 验证该引用并返回输入/输出契约、风险、连接和审批要求；`tools.execute` 只能使用本轮已描述的引用。
- 实际业务调用仍通过既有 Tool Policy Enforcement Point。`toolRef` 不是权限令牌：工具版本、定义摘要、当前 ACL、连接账户、输入/输出 Schema、审批、网络策略和能力策略都会再次验证。
- 工具库工作台对人工用户也采用相同节奏：搜索候选，查看完整契约，再输入 JSON 执行；高风险动作的审批和审计规则保持不变。

## 配置与启用

默认保持终端关闭。生产启用需要以下最小配置：

```dotenv
PIVOT_CAPABILITY_WORKER_ENABLED=true
PIVOT_AGENT_TERMINAL_WORKER_IMAGE=registry.example/pivot-terminal@sha256:<64位摘要>
PIVOT_AGENT_TERMINAL_WORKER_COMMAND=pivot-terminal-runner
PIVOT_AGENT_TERMINAL_WORKER_CPU=1
PIVOT_AGENT_TERMINAL_WORKER_MEMORY_MB=512
PIVOT_AGENT_TERMINAL_ALLOW_UNSAFE_LOCAL=false
```

`PIVOT_AGENT_TERMINAL_ALLOW_UNSAFE_LOCAL=true` 仅用于隔离的本地开发/诊断，不得在生产、测试群或含真实业务凭据的环境开启。终端 Runner 必须实现受限 JSON 协议，不得将传入参数拼接到 Shell。

## 升级与回滚

1. 本版本不引入数据库迁移；按既有流程升级服务即可。
2. 部署前备份 PostgreSQL 与 `uploads/`，并确认 `.env` 中不含开发环境的本地终端后备开关。
3. 初次启用终端前，在 staging 使用无敏感样例验证文件 Jail、取消、超时、异常输出、容器销毁和审批恢复。
4. 如需回退，停用 `PIVOT_CAPABILITY_WORKER_ENABLED` 或清空终端 Runner 镜像配置即可让终端能力立即从新 Run 的目录消失；个人经验可在界面恢复，已暂停版本和审计记录不丢失。
