# v0.1.65 发布记录：统一桌面连接器本机多浏览器自动化

发布日期：2026-09-01

## 已完成

### 本机浏览器授权

- “工具库 → 管理本机资源授权”新增“授权本机浏览器自动化”。
- 用户先填写允许访问的精确站点 Origin，例如 `https://oa.example.internal`，再选择一个或多个浏览器程序。
- 支持 Chrome、Microsoft Edge、Brave、Chromium，以及 Playwright 兼容的 Firefox；也可选择同内核的自定义浏览器可执行文件。
- 浏览器可执行文件的绝对路径仅保存在当前电脑的桌面客户端配置；服务端只得到浏览器标识、显示名称、内核类型和允许站点。

### 统一连接器任务

桌面连接器新增四个本机浏览器工具：

| 工具 | 作用 | 本机确认 |
| --- | --- | --- |
| `browser.open` | 打开授权页面并等待用户完成登录 | 需要 |
| `browser.inspect` | 读取页面标题和受限正文文本 | 不需要额外确认 |
| `browser.click` | 点击指定页面元素 | 需要 |
| `browser.screenshot` | 回传不超过 1 MB 的当前页面截图 | 需要 |

所有任务必须指定已绑定的桌面设备和已授权的浏览器标识。服务端校验目标 Origin 和端口；桌面端在实际用户网络中再次校验 DNS、私有地址、重定向和下载限制。

### 隔离与凭据边界

- 每个授权浏览器使用 Pivot 专属的本机隔离 Profile，不使用也不读取用户日常浏览器的 Profile、Cookie、密码、历史记录或扩展。
- 需要登录时，用户在可见的本机浏览器窗口中自行登录；连接器只等待用户确认，不读取或上传凭据。
- 下载默认禁止；不提供任意脚本执行、开发者协议端口或任意 Profile 路径参数。
- 站点未授权、浏览器未授权、设备不匹配、用户取消确认时均 fail-closed。

## 使用方式

1. 使用 Pivot 桌面客户端打开“工具库”。
2. 点击“管理本机资源授权”，切换至“授权本机浏览器自动化”。
3. 填写可访问站点的 Origin，每行一个；点击“选择浏览器并授权”，可多次选择 Edge、Firefox、Brave 等不同浏览器。
4. 在 Agent 任务或工作流中选择 `mcp.0.browser.*` 工具，并填写当前设备 ID、浏览器 ID 和已授权页面地址。
5. 本机弹出确认时完成登录、确认点击或确认截图；结果以受限文本或截图摘要回传。
