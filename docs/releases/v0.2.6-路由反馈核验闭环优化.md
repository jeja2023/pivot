# v0.2.6 路由反馈核验闭环优化

发布日期：2026-10-12

## 概述

本版本将大模型回复后的路由反馈从单次、紧凑的“修正”表单，升级为可审计的用户建议与人工核验闭环。用户可表达对检索、工具调用或回复方式的改进建议；系统不会追溯修改已生成的回答，也不会把未经核验的建议直接用于训练。

## 用户侧变更

### 明确建议边界

- 回答下方入口统一为“路由优化建议”，说明建议仅用于后续优化，**不会重新生成、重跑或改变当前回答**。
- 表单先要求选择需要反馈的路由，再要求选择建议路径；替代路径默认保留“请选择建议路由”，提交按钮在用户明确选择前保持不可用。
- 用户可以看到“当前路由：场景 · 动作”，从而清楚区分系统当时的选择和建议选择。

### 可读性与反馈质量

- 桌面控件最小高度调整为 36px，窄屏触控环境调整为 44px；原因和补充说明分层展示，避免原有信息密度过高。
- 增加可选原因：误判任务意图、缺少必要依据、工具或检索不适用、不符合使用偏好、其他原因。
- 增加最多 500 字的补充说明，并在界面提示不要填写敏感信息。
- 单条回答包含多个可修正决策时，用户可以连续提交多项建议；已提交项保留提示，并可在人工核验前调整建议。
- 重新打开会话时，系统只读取当前账号、当前会话的反馈状态，并在选择项上显示待核验、已采纳、未采纳或已替换。

### 视觉规范与全局样式对齐

- **全局字体与排版统一**：表单整体绑定全局 `var(--font-sans)` 字体变量，所有输入框、下拉框、说明文本域及按钮显式继承 `font-family: inherit`，消除 Windows 平台默认回退到粗糙系统控件字体的视觉脱节问题；标签字重调整为优雅标准的 600。
- **消除浏览器原生下拉箭头**：为下拉框注入统一的轻量级内嵌 SVG Chevron 指针指示器，浅色模式采用优雅的灰度配色，深色模式自适应浅色指示器；右侧预留 32px 安全间距以防选项长文本与箭头重叠。
- **双列网格对称与高度平齐**：第二行的问题原因下拉框与补充说明文本域调整为与第一行严格对齐的 50%/50% 双列网格；所有输入框初始高度严格对齐 36px，文本域在获取焦点后平滑展开至 56px 并支持垂直调整大小，保持整洁与功能性并存。
- **状态与交互动效**：聚焦状态注入全局柔和主题色外发光光环（`box-shadow: 0 0 0 3px color-mix(in srgb, var(--primary) 14%, transparent)`）；禁用状态下背景、边框、光标和箭头均自动切换至半透明置灰态；提交与取消按钮高度和圆角严格统一为 32px / 7px。

## 数据与审核边界

### 用户建议不是训练标签

提交时服务端会校验：

1. `decision_id` 属于当前账号和当前会话；
2. 建议动作属于当时允许的候选；
3. 建议动作与数据库保存的原动作不同。

原动作从 `decision_records.selected_action_id` 读取，浏览器提交的同名字段不会被信任。待核验建议按决策幂等写入：网络重试或再次提交会更新同一条待审核记录，而不会产生两条冲突的待审核标签。

### 管理员核验队列

管理员在“系统设置 → 反馈核验”中按状态查看建议并执行“采纳”或“不采纳”。

该入口复用系统设置侧边栏的既有导航标签样式，与“系统监控”等相邻菜单保持相同的左对齐、行高和选中态，不使用次级操作按钮样式。

- **采纳**：以决策记录中保存的原动作和已建议动作生成独立的 `verification` 结果，成为可训练样本。
- **不采纳**：只保存审核结论，不生成训练样本。
- **待核验**：保持为用户建议，不进入训练导出、模型训练或主动灰度。
- **全局统一表格样式与分页控件**：反馈核验表格全面对齐全局 `.compact-table` 与 `.data-table` 规范，采用 38px 标准行高、单元格垂直居中和悬停微底色；移除表格上方多余的状态汇总文字，界面更加干净整洁；数据表格首列新增标准的“序号”列（56px 居中排版），跨页连续计序；列宽通过 `<colgroup>` 规范约束（序号 56px、提交时间 140px、路由场景 110px、动作变更高亮 190px、状态 96px、操作 140px，原因说明自适应展开）；状态标签与操作按钮保持居中；接入全局统一分页控件（`renderWorkspacePagination`），支持首页/上一页/页码与总量统计/下一页/末页平滑翻页与状态联动，无多余外框或溢出。

审核接口仅向管理员开放：

```text
GET  /api/stats/observability/decision-feedback?reviewStatus=pending
POST /api/stats/observability/decision-feedback/:id/review
```

普通用户只能读取本人当前会话的状态：

```text
GET /api/sessions/:id/decision-feedback
```

## 升级与运维

本版本包含 PostgreSQL 迁移 `202610120001_decision_feedback_review_governance`。部署新版本后，应用启动会在事务中补齐审核字段、将非用户反馈标记为“不需要审核”、收敛历史重复待审核项，并创建待审核反馈索引与唯一约束。

升级前应按既有流程备份数据库和附件目录。服务恢复后以管理员账号确认“系统设置 → 反馈核验”可打开，并核对迁移记录：

```sql
SELECT id, applied_at
FROM schema_migrations
WHERE id = '202610120001_decision_feedback_review_governance';
```

该功能不会改变当前决策器的影子/主动灰度模式，也不会自动训练、注册或激活模型制品。
