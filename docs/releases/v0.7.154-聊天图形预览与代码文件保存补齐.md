# v0.7.154 聊天图形预览与代码文件保存补齐

日期：2026-11-12（Asia/Shanghai）。本版修复生产反馈的 SVG 回复只显示代码且无法保存的问题，并检查补齐其他常见代码块格式。启用新源码版本；功能验证在 v0.7.153 工作区完成，原始日志和截图不因升版改写身份。

## 功能变化

| 场景 | 本版行为 |
| --- | --- |
| SVG 绘图回复 | 默认显示静态图形，支持预览/源码切换、复制、放大、下载 SVG 和保存到本机授权目录。支持有效 `viewBox` 或固定宽高，省略 SVG 命名空间时补齐。 |
| 不安全、异常或未完成 SVG | 预览和保存检查脚本、动态事件、外部资源、非法声明和大小；预览额外检查尺寸。流式未完成或检查失败时保留源码和状态提示，不直接插入 SVG 到主页面。 |
| HTML/HTM 页面代码 | 默认显示静态预览，可切换源码。独立沙箱无脚本、无同源权限，内容策略禁止网络并移除表单等主动行为；下载和保存使用原始源码，动态页面效果需在实际运行环境另行验证。 |
| CSV/TSV、JSONL、INI/TOML 和常见源码别名 | 浏览器与服务端共用格式表，保存为相应扩展名及 MIME；识别 `python3`、`csharp`、`plaintext` 等标记。HTM、Markdown、NDJSON 文件名统一为 HTML、MD、JSONL。 |
| 无语言标记或未识别语言 | 明确提示按 TXT 保存，不能通过自选扩展名改成可执行文件或其他文件类型。JSON、YAML、XML 等仍按源码展示，不引入新的渲染或转换引擎。 |
| 浏览器与本机文件保存 | 普通代码块新增“下载文件”，沿用 Artifact → CAS → Rendition、鉴权与短期下载令牌；“保存到本机”继续校验设备和目录授权。 |
| 空白与异步内容 | 代码块连续空行不再被正文规则压缩，避免改变 CSV 引号字段或源码。旧账号、已移除节点或已变化内容的回调不能继续触发下载或本机交付。 |

Mermaid 继续使用现有图形预览、下载及 TXT 源码保存方式。任务已有可下载 SVG 时，由结果文件提供图形预览和保存入口，正文仅保留折叠补充源码，不将文件名或格式视为源码与结果一致的证据。

## 升级与兼容

- 没有新增依赖、数据库迁移或必填配置。按现有流程更新源码并重启服务，页面资源及 `/version.json` 使用 v0.7.154；浏览器应重新加载页面以取得新脚本。
- 新增 CSV/TSV、JSONL、INI/TOML 的本机保存需要同步更新桌面客户端中的格式白名单。旧客户端可先使用浏览器“下载文件”；受限制的目录授权仍须允许对应格式，不因服务升级自动放宽个人授权。
- 本机保存继续需要设备身份及目录授权；没有桌面客户端时使用浏览器下载。SVG 仅支持受检查的静态内容；HTML 预览不会执行源码中的脚本或加载外部依赖。
- 更新日志为版本来源，包版本、锁文件、README 与设计基线同步为 v0.7.154；使用帮助保持面向普通用户的操作说明。旧发布说明、测试日志、安装包及镜像继续保留原版本身份。
- 本次只启用源码版本，未运行全仓 `npm test`、真实 Electron 文件落盘、生产模型或生产负载验收，未构建安装包/容器镜像、发布更新通道或部署生产。源码升版不表示现有运行实例已完成升级。
