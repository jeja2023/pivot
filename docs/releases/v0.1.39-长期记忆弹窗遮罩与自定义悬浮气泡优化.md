# v0.1.39 版本发布记录

**发布日期**：2026-08-24
**版本主题**：长期记忆弹窗遮罩全屏、自定义截断悬浮气泡与设置布局优化

---

## 一、 更新背景

在系统设置管理后台的日常使用中，长期记忆管理与全局参数配置存在以下视觉与交互痛点：
1. **弹窗遮罩层（Mask Backdrop）未覆盖全屏**：在“长期记忆”标签页中打开“编辑记忆”或“来源追溯”弹窗时，受父级缩放容器（`.settings-scale-canvas`）的 Containing Block 约束，遮罩层只遮盖了右侧内容区域，未与系统其它弹窗（如公告管理、模型配置、用户管理等）保持一致的全屏暗色遮罩。
2. **长记忆文本默认悬浮体验欠佳**：记忆列表中的“内容”列在文本截断后若使用原生浏览器 `title` 属性，会导致显示延迟高、黄色或纯黑底色原生样式不协调、长文本不支持换行排版等问题。
3. **全局参数智能体后台开关排版局促**：“智能体后台”卡片中原先将 3 个数字并发输入框与连续 Agent 切换开关挤在同一行，布局较为拥挤。

---

## 二、 核心升级内容

### 1. 长期记忆弹窗遮罩层全屏统一

- **顶层挂载与包含块脱离**：
  在打开“编辑记忆”(`memory-edit-modal`)或“记忆来源”(`memory-source-modal`)时，通过 `ensureMemoryModalsAttached` 将 DOM 元素动态挂载到 `document.body` 根节点，彻底脱离 `.settings-scale-canvas` 缩放容器所创建的局部层叠上下文。
- **全屏暗色遮罩一致性**：
  遮罩层（`.modal-overlay`）以 `position: fixed; inset: 0; z-index: 5250;` 完整铺满全屏视口，与系统设置中模型配置、公告管理等全站弹窗的交互与遮罩表现 100% 保持一致。
- **弹窗样式解耦与自适应**：
  更新 `admin-layout.css` 中的记忆弹窗选择器，使其脱离 `.settings-workspace-view` 祖先选择器的强绑定，兼顾桌面与各种屏幕尺寸下的弹窗居中与响应式缩放。

---

### 2. 高颜值自定义截断悬浮气泡（Hover Tooltip/Popover）

- **彻底废除浏览器默认悬浮**：
  移除了原生 `title="..."` 属性，避免出现浏览器原生迟钝、简陋的默认悬浮框。
- **现代深色极客风气泡**：
  通过独立模块 `admin-memory-ui.js` 统一管理自定义浮层（`.memory-custom-tooltip`），具备深色背景、微透毛玻璃拟态、精致阴影、圆角边框与适宜行高。
- **长文本排版与滚动**：
  支持多行自动断字换行（`pre-wrap; word-break: break-word;`），最大宽度 580px、最大高度 280px，支持长文本内嵌滚动查看，并允许光标移入选择复制文本。
- **智能边缘对齐算法**：
  悬浮时根据单元格 `getBoundingClientRect()` 计算屏幕位置，水平方向自动防溢出对齐；靠底时自适应翻转向上弹出，防止内容被视口边缘裁切。

---

### 3. 全局参数 - 智能体后台卡片排版优化

- **分行层次化排版**：
  - 第一行：**智能体任务并发**、**工作流节点并发**、**记忆压缩并发**（3 列对称并排）；
  - 第二行：**普通会话自动连续 Agent**（独立整行展示），并附带清晰的灰色说明文本。
- **视觉舒展度提升**：消除移动端或窄屏下的挤压重叠，操作开关更加直观明确。
