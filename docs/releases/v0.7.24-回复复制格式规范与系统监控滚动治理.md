# v0.7.24 回复复制格式规范与系统监控滚动治理

日期：2026-10-21。

### 1. 聊天回复一键复制规整与消除粘贴多余空行
- **根因分析**：
  - 大模型生成的原始 Markdown 文本以及 DOM 的 `innerText` 默认使用双换行符（`\n\n`）作为段落间距标志。
  - 原客户端消息一键复制清洗函数 `normalizeClipboardText` 采用了 `.replace(/\n{3,}/g, '\n\n')`，原样保留了段落之间的双换行。
  - 当用户在对话气泡点击“复制”并粘贴到外部输入框、Word、微信或纯文本编辑器时，`\n\n` 会被直接呈现为空白行，迫使人工逐行删除空行。
- **治理与算法优化**：
  - 重构 `client/chat/app/main.js` 中的 `normalizeClipboardText`：
    - **代码围栏智能隔离**：精准切分并识别 ` ``` ` 与 `~~~` 代码块，对代码块内部合理格式空行（如函数/类定义间的空行）受控保留（至多保留单空行），绝不破坏代码排版结构。
    - **正文段落连续规整**：正文、有序列表、无序列表及引用块中的多余连续换行统一合并为单个换行（`\n{2,} -> \n`），粘贴后各段落紧凑整齐。
    - **多余符号清洗**：自动剔除行尾空白残留字符以及孤立的空引用符号（如单独成行的 `>` 空行）。
  - 在 `chat.sessionActions` 模块和 `window.Pivot.legacy` 中规范暴露剪贴板规整工具函数。
  - 新增专用单元测试套件 `tests/chat-clipboard-normalize.test.js`，全面覆盖常规正文段落、代码块、列表、引用及思考块（`<thought>`）剔除等核心场景，测试全量通过。

### 2. 系统监控滚动条状态消除与跨页面隔离治理
- **根因治理**：
  - 系统监控页面本身需要数据大屏与卡片滚动展示，但在用户从系统监控切出至其他系统设置标签页时，外层容器的滚动条状态与类名未能及时清除。
  - 导致用户在点击完系统监控后，进入本身不应出现垂直滚动条的设置页面时出现多余的垂直滚动条。
- **状态恢复与视口清理**：
  - 在系统监控模块的切换与卸载钩子中加入严格的样式与滚动状态清理逻辑，切出时强制移除相关滚动容器样式和类名，彻底杜绝状态污染。

### 3. 智能体执行详情与卡片交互全栈优化
- **任务卡片即时挂载**：
  - 创建聊天任务草案后，直接在当前会话中挂载助手侧 Agent 任务卡片，避免用户在等待任务排队规划期间感知断层。
  - 将任务初次挂载逻辑统一归拢至 `chat-task-drafts.js`（`mountInitialTaskMessage`），由 `chat.taskDrafts` 模块承接，保持主引擎 `engine.js` 纯粹聚焦。
- **运行诊断与技术链路梳理**：
  - 任务详情面板重构为技术运行诊断面板折叠结构，直观呈现业务进度指标、耗时、模型用量与异常概览，将底层链路追踪与哈希快照移入技术折叠区，兼顾普通用户易读性与工程师排障需求。
  - 优化审计记录表格排版与列宽样式，抽离为标准 CSS 类，彻底杜绝内联样式侵入。
