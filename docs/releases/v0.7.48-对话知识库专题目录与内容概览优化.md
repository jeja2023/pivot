# v0.7.48 对话知识库专题目录与内容概览优化

发布日期：2026-10-28

## 问题与改进

- “专题有哪些文档、文档名称是什么”改为直接查询当前权限范围内的文档元数据，并标明就绪、处理中、索引失败或已停用状态；目录不依赖语义召回，也不让模型编造名称。最多展示 100 份，超过时明确提示截断。
- 对话输入中选择或输入的 `@专题` 限定当前轮范围；紧接着询问“这个专题”等指代问题时，在上一条用户消息有明确 `@` 且当前用户仍可访问、名称唯一的前提下继承范围。无法确认时提示重新选择，不回退到全库。
- “文档内有哪些内容”等概览问题按当前专题获取有限的已启用、就绪文档的原始开头片段，仍通过原有的引用和语义核验；输出标注覆盖范围有限，不能代表全文。片段中类似引用和内部边界标记不会成为新来源。
- 修正短追问计划将当前已保存消息误认为上一条用户问题的问题；普通具体事实问题仍走原有检索和证据核验。

## 验证与边界

- 隔离 PostgreSQL 测试覆盖用户权限、删除和停用、处理中状态、目录截断、专题继承及片段引用保护。
- 浏览器端使用真实对话接口、隔离 PostgreSQL 数据与测试模型，验证专题概览、紧接着的目录追问和消息保存。测试模型用于固定可复现输出，不代表生产模型的概览质量。
- 本次不改变已有知识权限或向量索引；未就绪、停用或没有正文片段的文档不能作为正文依据。大专题仅概览有限片段，应继续针对具体内容提问或查看原文。

无需数据库迁移。更新服务端代码并重启，随后重新加载页面。
