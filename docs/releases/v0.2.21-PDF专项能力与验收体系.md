# v0.2.21 PDF 专项能力与验收体系

发布日期：2026-10-13。

## 本次完成内容

- **页面工作区**：任务详情中的缩略图可进入页面工作区；可前移、后移、旋转、删除、插入空白页，保留最多 20 步撤销/重做草稿。提交后使用明确 `pagePlan` 创建新任务版本，原件和旧输出不被覆盖。
- **授权加密与保护**：接入受控 qpdf 适配器。授权密码写入任务期加密秘密表并经密码文件传递给 qpdf，不出现在参数、命令行、日志和公开接口；支持 AES-256 输出保护、打印/修改权限、加密输入的授权结构处理、线性化和嵌入图片 JPEG 优化。未检测到 qpdf 时能力接口会明确下线这些操作。
- **高风险内容处理**：永久脱敏会生成全新栅格化 PDF，移除原文本、隐藏层、交互表单、注释、链接、附件和签名；页面上以比例坐标明确选择区域。裁切仍明确标记为仅改变可见区域。新增轻批注和 AcroForm 字段填写，填写后校验字段值与交互字段树。
- **复核与互操作**：新增两份 PDF 的逐页视觉差异图与 JSON 报告、可复核 Word 与 Excel 文本导出。复杂布局、图形、合并单元格和专业排版不被宣称为无损转换。
- **归档验证**：接入 veraPDF CLI，PDF/A 操作只导出验证报告；仅报告 `isCompliant=true` 时才可标记合规，普通 PDF 保存不会被冒充为 PDF/A 转换。预检还会披露加密、表单、批注、签名字段、书签和附件等结构风险。
- **大输出下载**：多输出 ZIP 改为服务端流式生成与浏览器原生下载，下载前先验证每一项的访问范围、路径、存在性与总量上限。
- **质量基准与回归**：新增 60 份可重复生成的非敏感 PDF 夹具矩阵，覆盖页数、纸张尺寸、横竖方向、旋转、裁切、表单/批注占位及规模边界；新增 qpdf、veraPDF、页面编排、脱敏、比较、表单、Word/Excel 和 Chromium 工作区回归。
- **创建任务表单修复**：文件选择统一由应用层校验，移除与脚本校验重复的浏览器原生 `required` 拦截。未选文件时显示明确提示并聚焦文件控件，不发起创建请求；修复 `An invalid form control with name='' is not focusable` 控制台报错。
- **multipart 字段上限修复**：创建任务时只提交当前处理方式需要的参数，不再把所有隐藏选项的空值和默认值一并发送；PDF 专用上传通道设置为 32 个受限字段，兼容缓存未刷新时仍会发送旧字段集合的客户端，且不影响其它上传接口的通用 20 字段限制。
- **快速方案交互优化**：原“常用预设”下拉框改为紧邻处理方式的“快速方案（可选）”标签组。快速方案会填入处理方式和推荐参数，但不直接创建任务；再次点击当前高亮方案可切回自定义状态并保留已填参数，手动改变处理方式或参数后也会自动取消选中，避免被误解为与处理方式重复的第二层选择。

## 部署要求

- qpdf：生产环境配置 `DOCUMENT_QPDF_PATH` 到受控绝对路径，或将 qpdf 放入服务 `PATH`。启动能力接口会报告其版本和可用性。
- veraPDF：生产环境配置 `DOCUMENT_VERAPDF_PATH` 到受控绝对路径，或安装并提供 `verapdf` / `verapdf.bat`。它只用于 PDF/A 验证，不能替代转换引擎。
- 密码或保护功能需要 `DATA_ENCRYPTION_KEY` 已配置；没有密钥时部署必须按既有秘密存储策略拒绝启动相关任务。

## 仍属于真实环境发布门槛的事项

本版本完成了可在仓库和受控本机验证的实现与自动化回归，但不能伪造现实世界证据。生产发布前仍须按方案完成：组织批准的证书/时间戳/撤销服务下的数字签署试点、指定 PDF/A 转换引擎的合规输出验证、8 名真实目标用户的可用性研究、目标 8 vCPU/16 GB 环境的并发与故障注入压测，以及分级灰度和回滚演练。它们不是“待修复的代码缺陷”，而是必须在持有真实证书、真实用户和生产环境权限时取得的验收证据。
