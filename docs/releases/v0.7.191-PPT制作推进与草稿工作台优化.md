# Pivot v0.7.191 发布说明

2026-11-20 · PPT 制作推进与草稿工作台优化

## PPT Master 制作推进

- AI 自由制作和按模板制作沿用直接出初稿流程。系统自行规划沟通方向并核对最终清单。旧任务停在出稿前确认环节时可继续制作，创建可复用模板时仍需确认模板方案。
- 运行包内固定文档误用任务文件读取时，宿主自动切换至指引读取。项目文件和输入材料继续从任务工作区读取。首张 SVG 阶段沿用已登记清单及所选模板，优先写入设计规范、执行锁和页面源稿，按需完成项目校验及文字校准。
- 宿主管理的初稿连续六轮没有规范写入或必要校验进展时，要求推进制作或指出缺项。必要的定向补读可以和制作动作同批执行。纠正后仍无进展时保存检查点和具体错误。最终清单及首张 SVG 阶段的总轮次上限分别为 18 和 16，整项任务的执行轮次与令牌预算另行计量。
- 「每轮模型用量明细」分别记录读取与检查、有效写入及上下文压缩。任务收到对应 SVG 写入回执后登记「首次页面写入」。引文仍无充分证据时，标为「引文待核对」，沿用待核对占位文字继续制作，并列出具体问题。

## 逐页修复与交付

- 自动修页和「仅修复所选页面」续作共享修复范围。模型写回失败的已选 SVG 源页，宿主完成整稿复检、定稿、导出与回读，继续核对未选页和依赖资源。
- SVG 复检失败时记录能识别的页码和问题，例如文字溢出或区域重叠。同一选页范围续作时优先处理上次复检失败的页。超出范围或复检多次失败时保留草稿和诊断。
- 完整制作记录保留「查看材料与提纲」，可核对已读材料、清单状态、逐页标题和数据。已有正式 PPTX 或完整源包时，隐藏对应的重复快照入口。仍需核验的草稿继续提供可用的快照、通过页或源包。

## 文稿库与标准工作台

- 已通过交付核验且仍有访问权限的 PPT Master 初稿直接进入「我的演示文稿」的草稿列表。点击初稿可预览、下载或进入原稿编辑器。列表复用原任务和文件，按归属、租户及当前材料和文件权限复核。名称、模板、创建者和时间可筛选，历史任务仍可从完整制作记录回看。
- 状态列和筛选菜单使用一致的名称。悬停「需处理」可查看原因说明，修复阻断项并保存后会重新检查并恢复为草稿。切换筛选条件或账号时忽略旧请求的响应。
- 标准工作台的整稿任务显示检查状态和摘要。完成后可打开「查看整稿检查结果」，核对页数、阻断项和优化建议，查看已有的版面与字体测量、原生 PPTX 回读、视觉模型复核、Office 渲染、素材和字号结果。问题明细按级别筛选，支持定位对应页面和元素。
- 调整模板预览操作区、整稿摘要和结果弹窗样式，重新生成工作区样式包。标准页面生成入口兼容未提供选项的调用。

## 升级与兼容

- 容器部署更新包含 v0.7.191 前端、后端和更新日志的 Pivot 主应用。沿用当前兼容的 PPT Master v6.10.0 独立服务镜像、访问配置及任务数据卷。已有检查点在运行身份、工作区和权限有效时可继续使用。
- 数据库启动流程复查已登记的 Artifacts 迁移字段。老库有缺失字段时重新执行原有幂等迁移。本次沿用既有迁移编号和自动执行流程。[部署说明](../deployment/PPTMaster独立服务部署与更新.md#v07191-ppt-制作推进与草稿工作台优化)

## 实际验证

- 通过 `npm run version:sync`、`npm run check`、`npm run lint`、`npm run typecheck` 和发布文档链接校验。本地开发入口的 `/version.json` 返回 `v0.7.191`。
- 97 项 PPT 定向测试和 12 项隔离 PostgreSQL 测试通过。覆盖首张页面写入、检查点续跑、选页修复、草稿入库、状态筛选、逐轮明细及整稿报告中的问题定位。另在独立 PostgreSQL 中验证已登记迁移的缺失字段能自动补回，后续运行会跳过已完整的迁移。
- 升版前使用模拟模型和真实 PPT Master v6.10.0 执行器，通过两项 Docker 端到端测试。核对分页读图、指引读取转换、实际写入、三页 PPTX 导出回读、项目源包及文稿库草稿入口。另一用例验证补充事实后，仍无法核实的项目可以占位出稿。
- 测试使用合成材料和隔离 PostgreSQL。生产截图的原始材料、模型回复及任务日志未用于回放。本次启用源码与本地开发版本。发布制品构建、生产部署和同单验收仍待进行。
