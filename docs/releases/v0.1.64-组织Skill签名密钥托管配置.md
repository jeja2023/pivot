# v0.1.64 发布记录：组织 Skill 签名密钥托管配置

发布日期：2026-09-01

## 已完成

### 管理员配置入口

- 在“设置 → 全局参数”新增“组织 Skill 共享签名”区域。
- 系统最高管理员可以生成并启用 3072 位 RSA 密钥，或在迁移时一次性导入既有 RSA 私钥 PEM。
- 支持生成新密钥进行轮换、选择已有密钥重新启用，以及停用后续共享签名。
- 普通管理员只能查看不含私钥的状态、活动密钥标识和公钥指纹；密钥生成、导入、轮换、停用只允许系统最高管理员执行。

### 私钥与历史验证

- 托管私钥以现有 `DATA_ENCRYPTION_KEY` 或 `JWT_SECRET` 派生的 AES-GCM 密钥加密保存至 `app_settings`；浏览器接口、通用设置接口、审计日志和 Skill 文件均不返回私钥。
- 轮换或停用不会删除历史密钥的公钥，因此已发布 Skill 的签名信封仍可按其 `keyId` 完成复验。
- 未配置加密根密钥时拒绝保存私钥；环境变量中出现组织私钥时视为部署端接管，页面不能覆盖。环境密钥无效会直接拒绝共享发布，不会悄然降级。

### 与共享发布的关系

首次使用时，系统最高管理员只需生成一次服务器密钥；之后管理员点击“发布到组织/团队”会自动完成批准、签名、复验和发布。

若组织已有部署平台或密钥管理系统，可继续注入：

```dotenv
AGENT_SKILL_ORGANIZATION_KEY_ID=organization-default
AGENT_SKILL_ORGANIZATION_PRIVATE_KEY_BASE64=
```

配置环境私钥后，它优先于页面托管密钥，适合由 Vault、Kubernetes Secret 或内网部署平台统一轮换的场景。
