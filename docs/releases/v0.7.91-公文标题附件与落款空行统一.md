# v0.7.91 公文标题附件与落款空行统一

日期：2026-11-04。

按用户补充要求，统一编辑静态预览、DOCX 和 PDF 的三处间距：

- 标题最后一行结束后空一行，再开始主送或正文；两行标题同样只在完整标题之后空一行。
- 正文与附件说明之间空一行，多份附件不逐项重复加空行。
- 署名、成文日期作为整体，前面留三行空白；署名与日期之间保持相邻行。若前面有附件说明，在该说明之后保留这三行空白。

统一一行按既有28磅行距计算。DOCX 使用真实空白段落并与后续内容保持同页，避免页首段前距被 Word 自动忽略；PDF 使用相同的空白行数量并在分页前预留位置。原稿已含相关空白行时，静态预览不会再重复叠加，原文仍保留不变。

渲染器版本更新为 `docx-2.0.1`、`pdf-2.0.1`，重新导出会生成新的版式结果。

验证：81 项相关 Node 回归、8 项完整应用 E2E 通过；Word/PDF 对有主送和无主送的两行标题样稿均做页面核对。PDF 正文末行到附件说明基线相距56磅（一行内容加一行空白），附件说明到署名基线112磅（一行内容加三行空白），署名到日期28磅。Word 导出页面测得对应56.04～56.07、111.96～111.98和约28磅，符合存储精度范围。

更新后重启服务并刷新客户端，无新增依赖或数据库迁移。
