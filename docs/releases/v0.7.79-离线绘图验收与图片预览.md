# v0.7.79 离线绘图验收与图片预览

日期：2026-11-01。本记录描述工作区版本更新和已验证的修改；版本号更新不代表安装包、镜像或目标环境已更新。

## 修改内容

- 自动任务的文件存在性验收使用当前用户、当前任务关联的受控渲染文件，并检查文件状态、有效期与内容完整性。模型输出中的文件名称不能代替真实文件；独立语义核验仍需确认交付内容。
- 会话结果卡片的图片“查看”通过一次性下载许可读取渲染文件，以图片展示；关闭预览后释放临时地址。SVG 不作为可执行 HTML 展示。
- 仅因调用绘图网络工具不再自动要求外部资料来源。知识或网页检索、用户明确要求依据的任务仍保留来源检查。
- 已保存的 SVG 不再重复作为完整 MCP 文本传给模型，减少上下文占用；等待补充信息时使用提示状态图标。

## 验证与限制

- 31 项定向测试通过；隔离 PostgreSQL 的 26 项测试通过，覆盖真实 SVG 文件持久化、任务和用户隔离、就绪状态以及交付验收。客户端图片预览使用模拟接口测试。
- 对相关文件的 Lint、文本完整性、前端静态资源和增量开发规范检查通过。整个工作区的差异空白检查仍提示另一项界面改动中存在两处行尾空格。
- 未运行全量回归，也未在目标 Linux、Kroki、真实模型及浏览器环境复测。模型仍可能因具体内容要求补充或判断交付不完整；文件存在不等于语义验收自动通过。
- 更新主程序后，需要重新发起或按现场流程重新执行验收；已有任务的历史验收结果不会自动改变。

v0.7.78 多表关联汇总的真实数据库和 DuckDB 查询仍待验证；v0.7.76 普通客户端渠道重放尚未启用，多节点严格预检继续阻断。详细故障分析与验收条件见[绘图验收修复记录](../reports/离线绘图任务验收与预览修复-20261031.md)，服务登记和测试步骤见[离线工具部署手册](../deployment/离线工具服务部署与验收.md)。
