# v0.1.83 发布记录：模型原生工具调用自适应降级与多节点预检及安全治理升级

发布日期：2026-09-05

## 一、更新背景

随着智枢接入的模型生态多样化（涵盖云端主流大模型与私有化部署的各类兼容网关），以及系统在企业私有集群和多节点高可用环境的部署推进，系统在工具协议自适应、集群部署验收与桌面端安全等层面提出了更高的可靠性要求：

1. **兼容端点对原生工具调用支持参差不齐**：部分私有化部署的开源模型或第三方转发网关在声明兼容 OpenAI tools 协议时，可能因端点限制或参数兼容问题返回 400 异常；若缺少统一的端点能力感知与回退机制，会导致 Agent 执行直接失败；
2. **多节点集群部署缺乏标准化的前置验收工具**：多节点部署要求所有节点连接同一 PostgreSQL 数据库、配置相同租约锁机制，并确保 `DATA_DIR` 与 `PIVOT_UPLOAD_DIR` 严格位于同一挂载好的网络共享卷（NFS / CephFS 等）内。此前缺少开箱即用的命令行预检工具，容易因误配置引发分布式状态不同步；
3. **主进程核心请求路径中的同步 I/O 风险**：附件下载、法规文档分发与文件上传等热点路径中，若存在 `fs.readFileSync`、`fs.writeFileSync` 等同步文件调用，在高并发上传下载时会短暂阻塞 Node.js 主事件循环，影响整体响应吞吐；
4. **桌面客户端外部链接存在被宿主内嵌加载的安全隐患**：Electron 桌面端如果未对 `will-navigate` 与新窗口创建建立强约束的受信源白名单，恶意网页可能利用内嵌导航实现跨站钓鱼或提权；
5. **Agent 控制台待办中心排版细节体验**：待办中心默认分页条数偏少，且底部分页按钮组靠右排布，在宽屏面板下视觉视觉不平衡。

本版本针对上述多项可靠性、运维与安全场景进行了全面加固升级。

## 二、核心变更与技术实现

### 1. 模型原生 Tool Calling 端点能力探测与自适应降级
- **数据库表结构扩展**：新增版本化数据库迁移脚本 [`server/db/migrations/model-tool-call-capabilities.js`](../../server/db/migrations/model-tool-call-capabilities.js)（`202609050004_model_tool_call_capabilities`），在 `models` 表新增 `tool_call_mode` 字段（`auto`、`enabled`、`disabled`），支持单个模型粒度配置；
- **能力探测与自适应降级引擎**：新增 [`server/services/model-tool-call-capabilities.js`](../../server/services/model-tool-call-capabilities.js)，封装 `shouldUseNativeToolCalls` 与 `isNativeToolCallIncompatibleError`；
  - 优先级：模型独立配置（`tool_call_mode`）> 全局环境变量覆盖（`AGENT_NATIVE_TOOL_CALLS`，默认 `auto`）；
  - 当端点返回不受支持的原生 tools 调用错误时，将其识别为协议不兼容，在 [`server/services/agent-streaming-runtime.js`](../../server/services/agent-streaming-runtime.js) 中自动记录审计事件并优雅回退到回合制 JSON 规划器，保障任务连续执行；
- **前端配置界面支持**：在模型管理弹窗（[`client/chat/partials/pre-app-modals.html`](../../client/chat/partials/pre-app-modals.html) 与 [`client/chat/models.js`](../../client/chat/models.js)）中增加“原生 Tool Calling”模式下拉框，提供直观的配置选项。

### 2. 多节点集群部署预检脚手架与真实验收
- **预检 CLI 脚手架**：新增预检脚本 [`scripts/preflight_deployment.js`](../../scripts/preflight_deployment.js)，支持通过 `npm run preflight:deployment -- --require-multi-node` 执行集群部署前置体检；
- **共享卷同源校验**：在 [`server/services/deployment-profile.js`](../../server/services/deployment-profile.js) 与 [`server/services/deployment-providers.js`](../../server/services/deployment-providers.js) 中验证共享卷挂载（`DATA_DIR` 与 `PIVOT_UPLOAD_DIR` 必须同时位于 `PIVOT_SHARED_STORAGE_ROOT` 内），并验证 PostgreSQL 数据库租约与分布式锁状态；
- **文档指南完备**：新增运维指南专文 [`docs/多节点部署预检.md`](../多节点部署预检.md)，系统健康检查（[`server/services/system-health.js`](../../server/services/system-health.js)）同步集成多节点就绪状态诊断。

### 3. 请求热路径同步 I/O 深度治理与静态门禁
- **静态扫描门禁**：新增 [`scripts/check_sync_io_hotpaths.js`](../../scripts/check_sync_io_hotpaths.js) 并接入 `npm run check`，基于 Acorn AST 自动遍历扫描服务端路由与中间件中的同步文件操作，坚决阻断新增的阻塞调用；
- **异步重构消除卡顿**：
  - 附件服务（[`server/routes/attachments.js`](../../server/routes/attachments.js)）：全面使用 `fs.promises.stat` 与 `createReadStream` 处理文件下载分发；
  - 法规文件接口（[`server/routes/apps/regulations/documents.js`](../../server/routes/apps/regulations/documents.js)）：改造为异步状态读取与流式分发；
  - 文件上传中间件（[`server/upload.js`](../../server/upload.js)）：目录检测与移动改为 `fs.promises` 异步处理。

### 4. 桌面客户端外部链接安全导航策略治理
- **外链沙箱策略引擎**：新增 [`desktop/external-navigation-policy.js`](../../desktop/external-navigation-policy.js)，集中拦截 Electron 窗口的 `will-navigate` 与 `setWindowOpenHandler` 事件；
- **严格同源与外部浏览器调用**：仅允许加载配置的本地/远端服务主页及白名单受信协议，其他一切外部超链接强制调用操作系统默认浏览器（`shell.openExternal`）安全打开，防止恶意页面利用内嵌窗口执行权限逃逸；
- **多入口拉通**：[`desktop/main.js`](../../desktop/main.js)、[`desktop/server-config.html`](../../desktop/server-config.html) 与 [`desktop/config.js`](../../desktop/config.js) 全面接入统一策略，并由自动化测试 [`tests/security-desktop-update.test.js`](../../tests/security-desktop-update.test.js) 保障防护生效。

### 5. Agent 控制台待办中心分页体验优化
- **默认分页条数扩增**：在 [`client/chat/agent-harness.js`](../../client/chat/agent-harness.js) 将待办中心默认分页大小由 15 升级为 20（`inboxLimit: 20`）；
- **底部分页居中排布**：在 [`client/chat/styles/workspaces/agent/agent-harness.css`](../../client/chat/styles/workspaces/agent/agent-harness.css) 将 `.agent-inbox-pagination` 样式定义为 `justify-content: center`，使操作按钮组水平居中排布，视觉效果更加均衡优雅；
- **契约测试固化**：在 [`tests/automation-page-contract.test.js`](../../tests/automation-page-contract.test.js) 中增加断言保护。

### 6. 环境变量配置与模板同步对齐
- 同步补齐 [`.env`](../../.env) 与 [`.env.example`](../../.env.example) 的多节点集群配置块、`AGENT_NATIVE_TOOL_CALLS` 与双轨采样快照注释，确保开发与生产环境配置清晰透明。
