# v0.7.95 Mermaid 图形预览与源码交付

日期：2026-11-05。源码基线：v0.7.94。

本次将聊天回复中的 Mermaid 从普通代码块升级为可预览图形，保留源码查看、复制与受控本机保存。

## 使用变化

- `mermaid` / `mmd` 代码块默认显示图形，可切换到源码。
- “放大查看”打开统一弹窗，可放大、缩小、适应窗口，支持 Esc 关闭和焦点恢复。
- “下载 SVG”下载实际渲染的静态矢量图；“保存源码”使用已有本机交付和目录授权，将 Mermaid 文本保存为 TXT。
- 未接收完整的流式代码先等待，语法失败显示原因并提供重新渲染入口。浅色、深色主题与移动端沿用全局样式。
- 通用决策动作的直接回答说明改为“由当前选定模型直接生成最终回答”，移除固定 Qwen 品牌描述；语义路由和工作流推荐共用这一说明。

## 实现与边界

固定使用 Mermaid 11.17.2，作为开发依赖构建并提交离线静态资源；生产运行直接读取已提交资源，无需安装绘图服务或连接公网。构建替换 D3 的动态表格转换函数，`npm run check:mermaid-vendor` 检查版本、摘要、许可与语法；该入口已纳入 `npm run check`。依赖许可与资源摘要位于 `client/common/vendor/mermaid/11.17.2/`。

隔离渲染页仅允许脚本执行，不开放同源权限；限制网络、字体、子页面和表单。自定义初始化指令不会扩大预览权限，最终 SVG 经静态内容校验后作为图片展示。预览与下载拒绝外部资源、动态元素和无效尺寸。最大源码 64KB、连线 500 条、结果 2MB，单次绘图等待上限 15 秒；复杂或不支持的图形仍可查看并保存源码。

账号切换、节点移除、主题重绘及页面离开时释放旧图片地址；渲染缓存按账号和主题隔离且有容量上限。此预览不依赖模型调用独立绘图工具，也不代表此前文字提到的服务端 SVG 文件已经生成；下载内容来自当前代码块的实际渲染结果。

## 升级

更新源码或重新构建镜像、桌面制品后重启服务并刷新页面。现有聊天里的 Mermaid 代码块会在重新打开时显示预览，不需要数据库迁移。当前交付为源码改动，未执行生产部署或安装包发布。
