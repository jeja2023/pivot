# Pivot v0.1.52 发布记录：模型端点运行时监控与智能体长文本生成保底加固

**发布日期**：2026-08-26
**版本号**：v0.1.52
**发布主题**：模型端点运行时监控与智能体长文本生成保底加固

---

## 核心更新概览

Pivot v0.1.52 重点聚焦于生产环境运维监控大屏模型端点状态实时同步、Agent 智能体规划与长篇最终回复防截断预算保底，以及全链路自动化与测试沙箱健壮性加固。

主要改进包括：
1. **模型端点运行时监控实时同步修复**：彻底解决生产环境虽然模型正常可用但概览页面偶发显示“暂无模型端点运行数据”的问题，实现活跃模型与内存信号量/并发指标的即时同步；
2. **Agent 智能体长文本生成预算（Max Tokens）保底加固**：引入全局长文本回复最低预算保障机制（`AGENT_ANSWER_MIN_MAX_TOKENS = 4096`），彻底杜绝 Agent 在输出综合性总结大报告时因沿用单步 1200 兜底预算被截断的问题；
3. **前端 DOM API 防御与测试沙箱健壮性**：为所有全局选择器绑定函数补全安全防御，并完善单测 VM 沙箱 DOM 模拟，实现全套 700+ 单元测试与 8 项 E2E 冒烟测试 100% 绿灯通过；
4. **Agent 工作台选项卡绑定时序优化**：提前自动化工作台选项卡交互绑定至网络请求之前，杜绝高并发与慢网络下的点击丢失。

---

## 详细改进明细

### 1. 模型端点运行时监控与概览状态实时同步
- **直接透传活跃模型记录**：在 `server/routes/admin-stats.js` 中将实时查询出的活跃模型行数据直接传入 `getModelEndpointRuntimeStatus(rows)`，解耦对后台异步 30 秒轮询更新周期的强依赖。
- **内存活跃模型缓存即时刷新**：`server/services/model-runtime.js` 中的 `getModelEndpointRuntimeStatus(models)` 接收外部模型数组并即时刷新内部活跃模型缓存，确保并发、排队、健康检查与熔断状态实时准确呈现。
- **单测用例覆盖**：在 `tests/security-model-runtime.test.js` 中新增针对直传模型数组即时同步端点的自动化测试用例。

### 2. Agent 智能体规划与长篇最终回复防截断机制
- **长文本输出最低预算下限保障**：在 `server/services/agent-model.js` 中定义 `AGENT_ANSWER_MIN_MAX_TOKENS = 4096`。在综合多步观察生成面向用户的最终长篇 Markdown 报告时自动抬高预算下限，不被单步 1200 预算所压低。
- **规划内联最终答案同等保护**：规划阶段模型若直接生成 `{"action":"final","answer":"…"}` 时同样享受最低 4096 输出预算。
- **输出截断结构化告警日志**：当由于上下文或超大报告导致输出触碰上限（`finish_reason === 'length'`）时，透传 `usageRef.truncated` 标识并记录警示日志，方便运维与调用方排查。

### 3. 前端 DOM API 防御与测试沙箱健壮性加固
- **DOM 选择器安全防御**：在 `client/chat/agents.js` 的 `syncAutomationPrimaryTabs`、`bindUnifiedAutomationTabs`、`bindAgentWorkbenchShortcuts`、`bindAgentConfigModal` 等函数入口处添加 `typeof document?.querySelectorAll !== 'function'` 防御判断，避免轻量运行环境下抛出 TypeError。
- **Node.js VM 沙箱模拟补全**：在 `tests/security-helpers.js` 的 `createChatRenderSandbox` 中为 mock `document` 对象补全 `querySelector`、`querySelectorAll`、`getElementById` 等标准方法。

### 4. Agent 工作台选项卡绑定时序优化与 E2E 测试对齐
- **选项卡事件绑定提前**：在 `client/chat/agents.js` 的 `openAgentWorkbench` 中将子视图切换事件绑定提升至并发数据拉取之前，并自执行一次初始化，彻底消除慢网络下点击无响应的问题。
- **E2E 冒烟测试子视图对齐**：在 `tests/e2e/smoke.spec.js` 中按子选项卡切换检验 `goals` 与 `channels` 面板可见性，确保测试行为与 UI 真实交互完全一致。
