# v0.1.61 发布记录：Agent 控制面表格按钮交互规范化与持续目标存储修复

发布日期：2026-09-01

## 已完成

### 服务端与数据存储修复

- **PostgreSQL 参数化类型推断修复**：修复在 `UPDATE agent_goals` 与 `INSERT INTO agent_goals` 中使用 `CASE WHEN ... THEN ? ELSE ... END` 语句时，PostgreSQL 参数占位符被推断为 `text` 导致 `TIMESTAMPTZ` 赋值报错 `500 Internal Server Error (字段 "paused_at" 的类型为 timestamp with time zone, 但表达式的类型为 text)` 的问题。显式为所有时间戳参数添加 `?::timestamptz` 类型转换。
- **持续目标软删除过滤修复**：修复前端删除持续目标提示已删除后数据仍在表格列表展示的问题；在 `listAgentGoals` 查询中引入默认 `status != 'deleted'` 过滤条件。

### 界面与视觉规范统一

- **操作栏与下拉框像素级水平对齐**：为 `.agent-harness-inline-actions` 容器内的所有下拉框（`<select>`）与按钮（`<button>`）统一施加 `30px` 绝对高度、盒模型重置与 `margin: 0 !important`，配合 Flexbox 居中布局，彻底消除浏览器原生边距与基线偏移。
- **表单与卡片动作按钮统一收拢**：将「添加渠道」、「保存治理策略」、「打开记忆清单」等按钮统一样式收缩为 `28px` 紧凑标准尺寸（`btn-xs` 规范，高度 `28px`、字号 `0.75rem`、内边距 `0 12px`、圆角 `6px`）；同步调整任务页面顶部「新建任务」、「删除审计」与工作流页面「新建工作流」按钮。
- **数据表格行高与行内按钮统一**：
  - 将工作流列表数据表格（`.automation-assets-table`）行高由原本过高的 `48px` 统一下调至全局标准的 `36px`，单元格内边距调整为 `6px 10px`。
  - 将任务列表与工作流列表数据行内操作按钮统一为 `24px` 高度（行高 `22px`、字号 `0.72rem`、圆角 `4px`）。
- **任务列表操作列间距对称居中**：操作列宽度保持 `140px` 紧凑宽度，通过优化按钮间距（`gap: 4px`）与内边距（`padding: 0 6px`）并配合 `justify-content: center`，确保「详情」、「编辑」、「删除」3 个按钮在单元格内完美等距对称居中。
- **质量大屏与监控优化**：优化质量与可靠性大屏 Tab 切换交互，更新契约测试；个人模式下隐藏模型端点监控卡片。
