# v0.7.61 现有功能稳定性与数据分析优化

发布日期：2026-10-29

## 更新内容

- 数据集列表在数据库中保守筛选候选资源，再复用现有共享可见性规则确认所有者、单位和个人范围。共享数据集的字段敏感性按批次读取，并继续过滤受限字段及其画像、预览；统计只读取必要字段，不再构造完整列表。
- Excel 导入将工作簿解析和 Parquet 写入放到工作线程，维持原有表头、字段、行列上限、截断提示及错误行为，降低解析期间对主进程响应的影响。上传、并发控制和数据权限沿用现有机制。
- Node 测试运行器纳入 `tests` 子目录中的测试；更新工作流模板服务、评分和实例的旧测试，修复实例服务使用错误模板服务导出的问题，并覆盖私有模板权限和必填变量。
- 智能路由审阅包生成器会将含错误的预审核标记为“预审核失败”，将不在允许动作中的结果标记为“无有效结果”；这些状态不会替代人工审核，也不更改灰度策略。

## 验证结果与限制

- `npm run check` 和 `npm run lint` 通过。最终共享范围筛选调整后另行通过 PostgreSQL 权限专项回归及语法检查。
- 使用独立 PostgreSQL 实例执行数据集权限与统计、Excel 工作线程、数据分析及工作流模板专项测试；浏览器 XLSX 和 SQLite 导入端到端测试通过。审阅包异常结果回归通过。
- 本机 2 万行合成表单次对照中，原同步解析期间定时器最大间隔约 411 毫秒，工作线程解析及写入期间约 16 毫秒。两组总耗时范围不同，不能据此比较整体速度，亦不能代表目标环境性能。
- 工作线程仍整体解析工作簿；大型或并发导入的进程内存峰值仍需在目标环境测量。未运行完整全量测试套件，也未进行生产环境负载测试。
- 智能路由 v2 冻结集的 15 条业务标签仍待授权审核人核验；尚未完成目标环境提供器效果对照，不能据此认定主动灰度已具备发布条件。参见 [人工审阅包](../reports/decision-evaluation-human-review-packet-v2-2026-10-11.md) 和 [实施验收清单](../智能路由持续学习实施验收清单.md)。

## 更新方式

更新服务端代码和依赖后重启服务；桌面客户端使用对应版本构建。本次没有新增数据库迁移、必需环境变量或第三方依赖。
