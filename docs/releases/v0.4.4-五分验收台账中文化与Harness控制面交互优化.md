# v0.4.4 五分验收台账中文化与 Harness 控制面交互优化

发布日期：2026-10-19

## 版本摘要

v0.4.4 版本全面升级了 Agent Harness 控制面与运行质量面板的前端交互体验。重点完成了五分验收台账区域的全面中文化与模态弹窗化改造，对组织协作角色策略治理面板进行了深度自适应紧凑化重构以彻底消除垂直滚动条，并集成了声明式 Hook 包导入弹窗、测活审计日志降噪屏蔽、以及运行超时与并发 CAS 状态控制加固。

## 详细功能变更

### 1. 五分验收台账区域前端 UI 全面中文化

- **18 个领域中文化**：将底层的 18 个英文领域标识在前端展示层全面映射为标准规范中文术语：
  - `model_routing` → **模型路由与降级**
  - `tool_discovery` → **工具按需发现**
  - `tool_concurrency` → **工具并发与幂等**
  - `tool_policy` → **工具策略与审批**
  - `sandbox_execution` → **沙箱与本机执行**
  - `long_task_recovery` → **长任务故障恢复**
  - `multi_agent` → **多 Agent 协同**
  - `dag_orchestration` → **DAG 任务编排**
  - `lifecycle_extensions` → **生命周期扩展**
  - `context_governance` → **上下文治理与压缩**
  - `prompt_structured_output` → **提示词与结构化输出**
  - `long_term_memory` → **长期记忆与知识库**
  - `skill_ecosystem` → **技能生态与工具箱**
  - `browser_automation` → **浏览器自动化交互**
  - `evaluation_release` → **评测与发布门禁**
  - `observability` → **全链路可观测性**
  - `code_semantics_ide` → **代码语义与 IDE 集成**
  - `voice_multimodal` → **语音与多模态交互**
- **5 类证据中文化**：`implementation_review`（实现审查）、`automated`（自动化测试）、`nonfunctional`（非功能指标）、`canary`（灰度金丝雀）、`committee`（委员会签署）。
- **委员会角色中文化**：平台安全代表、运行时架构代表、测试与SRE代表、产品与业务代表。
- **状态标签与缺项友好提示**：原英文逗号拼接列表全面转为胶囊芯片（Missing Chips），清晰提示“待补齐：实现审查、自动化测试”或“五类工程证据齐备，待四方委员会统一评分”。

### 2. 按钮加弹窗形式与全局统一视觉规范

- **卡片头部操作化**：移除了原运行质量面板中平铺的大面积台账和原 `<details>` 折叠面板，替换为带证据齐备度进度条（百分比与领域完成数）的高级统计卡片头部，提供清晰的 3 个操作按钮：
  - 【五分验收台账】按钮
  - 【配置委员会四方成员】按钮
  - 【提交五分验收证据】按钮
- **标准模态弹窗系统**：
  - **五分验收台账详情弹窗**（`#agent-acceptance-ledger-modal`）：集成实时搜索与“全部 / 已齐备 / 待补齐”分类过滤，自适应网格卡片列出 18 领域状态；
  - **配置委员会四方成员弹窗**（`#agent-acceptance-committee-modal`）：双列网格表单分别指派四方代表，自动同步最新活跃管理员；
  - **提交五分验收证据弹窗**（`#agent-acceptance-submission-modal`）：集成领域下拉、证据类型下拉、一键填入受控模板、结构化 JSON 清单与不少于 20 字符摘要。
- **全局统一设计规范**：采用系统标准的 `.modal-overlay` 遮罩、`.agent-config-modal-head` 弹窗头部、`.form-input` 输入控件与全局字体体系，并完整适配明暗主题。

### 3. 协作角色策略治理面板消除垂直滚动条

- **紧凑型指标网格**：治理指标卡片高度由 92px 降至 50px，优化为横向 KPI 状态条。
- **单行快照工具栏**：策略快照版本标题与父任务继承说明并列，预设按钮精炼至 22px，高度由 46px 降至 32px。
- **核心策略表格深度重构**：
  - 单元格内边距由 `14px` 优化为 `4px 10px`；
  - 角色头像缩减为 26px，SVG 图标 14px；
  - 步数与 Token 的 Stepper 按钮与输入框高度统一精简至 22px，进度条优化至 3px；
  - 4 行策略表格总高度由 402px 骤降至 216px（节省 186px）。
- **视口自适应**：整个面板纵向高度从 742px 降至 406px（缩减超 45%），在常规桌面高度与小窗口模式下均可一屏完整呈现，彻底消除垂直滚动条。

### 4. 生命周期 Hook 弹窗化与测活审计降噪

- **Hook 导入弹窗**：生命周期 Hook 页面的“导入已签名声明式 Hook 包”全面改为按钮触发统一弹窗。
- **测活审计日志彻底屏蔽**：屏蔽模型自动连通性测试的系统审计日志，关闭页面自动高频探活，避免审计流水被测试日志刷屏。

### 5. 运行控制面高可用与边界加固

- 增加运行超时与用户取消的 AbortSignal 传播，覆盖模型调用、流式调用、DAG 节点、HTTP 和 MCP 工具。
- 修复 `withTimeout`：超时或父级取消立即 reject，不等待底层 Promise 结束。
- 增加运行状态 CAS 更新，避免审批、恢复、取消等并发操作互相覆盖。
- 恢复器接管 stale run 时先 CAS 标记失败，再中止当前进程内协程；周期恢复 runner 单例化。
- 触发器增加轮询租约、结构化数据库结果读取、数值水位线处理和文件扫描异常隔离；软删除后允许复用 dedupe key。
