# v0.1.86 发布记录：桌面端企业级管控加固与工作台极简交互深度优化

发布日期：2026-09-06

## 一、更新背景

随着 Pivot (智枢) 在政企私有化部署和复杂内网环境中的深入落地，不同层级的企业 IT 运维管理与终端日常操作体验提出了进一步的深化要求：
1. **企业终端防篡改诉求**：在集中统一下发的桌面安装包中，需要防止普通终端用户擅自篡改服务器连接地址、隐身通信密钥等敏感内网参数；
2. **离线与弱网自动更新可用性**：内网环境终端机器启动较早时，常常因为网络尚未完全就绪而导致首次启动检查更新失败，且缺乏运行期间的静默定时轮询与窗口焦点唤醒检查机制；
3. **桌面端品牌一体化与极简视觉**：原顶栏分散的纯文本按钮不够精致，缺少品牌标识与深色模式沉浸感；工作台弹窗多处冗余的关闭按钮也亟需进一步克制收拢；
4. **会话链路状态割裂**：从工作台跳转进入对话视图时，侧栏会话列表若处于折叠状态会使用户失去上下文连贯感。

针对上述场景，v0.1.86 正式发布，重点落实**桌面客户端企业策略锁定、自动更新高可用轮询、受控文档交付独立窗口与工作台极简联动交互**。

## 二、核心变更与技术实现

### 1. 桌面端企业集中管控加固与配置防篡改（`lockServerConfig`）
- **企业托管参数锁定**：
  - 在 `config.example.json` 与 `desktop/config.js` 中引入 `lockServerConfig: true` 规范；
  - 当企业下发的安装包包含该标记时，客户端连接配置中心（`desktop/server-config.html`）顶部展示专用安全提示条（`.lock-banner`），并全局禁用模式切换、远程地址输入、通信密钥修改、外链白名单输入及保存按钮；
- **配置单向继承与防降级防护**：
  - 在 `desktop/config.js` 的 `mergeDesktopConfigs` 算法中建立单向策略继承逻辑，严密防范用户目录下的本地覆盖配置降级或消除预装包中的企业只读属性与隐身密钥；
- **外链 Origin 动态折叠与便捷交互**：
  - 仅在用户勾选“允许在系统浏览器中打开受信任的外部站点”时才展开 Origin 域名列表，界面更简洁；支持 `Esc` 快捷键一键关闭弹窗。

### 2. 自动更新高可用轮询与平滑生命周期治理（`desktop/updater.js`）
- **静默定时轮询（`checkIntervalMinutes`）**：
  - 支持配置更新检查间隔时间（默认 30 分钟），支持按需动态调优或设为 0 关闭定时轮询；
- **启动失败容错与 30 秒快速重试**：
  - 启动阶段执行检查更新时，若遇内网或网络代理尚未连通返回错误，自动排期在 30 秒后执行一次静默重试（`initialRetryTimer`），保障更新不漏检；
- **窗口聚焦唤醒检查（Focus Throttle）**：
  - 监听主窗口 `focus` 事件，当应用重新激活且距离上次检查超过 15 分钟时，自动触发一次平滑静默更新探测；
- **析构函数与完整生命周期安全**：
  - 补齐 `destroy()` 接口，统一清除所有超时定时器、轮询定时器并解除窗口事件监听；向外暴露 `getState`、`checkForUpdates`、`downloadUpdate`、`installUpdate` 与 `destroy`，便于运维集成与自动化单元测试。

### 3. 客户端品牌一体化顶栏菜单与深色模式沉浸感
- **品牌一体化 Logo 菜单**：
  - 将原顶栏分散的“页面”、“显示”、“客户端”三级纯文本按钮，收敛为统一的品牌 Logo 按钮 **`[Pivot 智枢]`**；
  - 浮层菜单划分为 `[操作 / EDIT]`、`[视图 / VIEW]` 与 `[交付与更新 / SYSTEM]` 三大区块，标注规范快捷键；
  - 动态状态微动画：菜单触发器在检测到新版本时亮起蓝色呼吸红点，更新包下载就绪后转为绿色提示；
- **全链路深色模式适配**：
  - 为 `body.dark-mode` 精准适配顶栏菜单拖拽区、触发器、浮层面板、分割线与悬浮态高对比度色彩；
- **受控文档交付状态独立窗口**：
  - 新增 `desktop/delivery/status-window.js`、`desktop/delivery-status.html` 与 `desktop/delivery-status-preload.js`；
  - 提供无边框现代化模态窗口，在保持主进程安全权限控制的前提下，向用户直观展示受控文档的交付目录授权、执行进度与快捷重置。

### 4. 个人工作台与极简交互深度体验优化
- **用户信息弹窗右上角关闭按钮精简**：
  - 依据界面极简设计原则，从 `client/chat/partials/workspaces/personal.html` 中移除用户信息弹窗（`#personal-user-modal`）右上角多余的 `×` 关闭按钮；关闭动作收敛到底部统一明确的“关闭”按钮与遮罩点击，视觉排版更为统一协调；
- **工作台与会话抽屉展开状态联动保持**：
  - 在 `client/chat/sidebar.js` 中重构 `readChatSidebarDrawerState`：在未显式手动折叠时默认返回展开态（`true`）；
  - 从个人工作台点击“新对话”、“开始对话”、“历史会话”以及点击最近工作项进入对话时，自动唤醒并保持会话抽屉展开（`setChatSidebarDrawerOpen(true)`），解决进入对话页面后历史会话被异常收起的困扰；
  - 修正个人工作台自动化入口 (`open-automation`) 直接导航至任务列表 Tab (`tasks`)。

### 5. 架构稳定性、日志治理与自动化测试保障
- **服务端日志输出安全性**：
  - 在 `server/logger.js` 中将文件日志输出模式设为 `sync: true`，消除快速退出或多实例检测单例退出时，sonic-boom 异步写入句柄未就绪导致的偶发异常；
- **单测与工程门禁全量通过**：
  - `tests/desktop-server-config.test.js`：新增企业配置锁定继承与防降级单测；
  - `tests/security-desktop-update.test.js`：新增轮询周期、配置合并与生命周期控制器单测；
  - `tests/personal-workbench.test.js`：新增抽屉展开联动与自动化跳转单测；
  - `npm run check` 架构规范、AST 门禁与 ESLint 全量绿灯。
