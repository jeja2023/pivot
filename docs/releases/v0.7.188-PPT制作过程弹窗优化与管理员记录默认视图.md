# Pivot v0.7.188 发布说明

2026-11-20 · PPT 制作过程弹窗优化与管理员记录默认视图

本版整理 [v0.7.187](v0.7.187-PPT制作逐轮步骤与异常诊断.md) 新增的过程诊断界面，并修复管理员查看用户对话记录时的默认视图。仅更新 Pivot 主应用。

## 主要变更

| 范围 | 当前行为 |
| --- | --- |
| 每轮用量明细中文化 | 本轮工作中的运行包指引、工具及子命令、输入材料、页面矢量稿、演讲备注和导出文件均显示中文名称，例如「默认生成流程指引」「项目管理（初始化项目）」「第 1 页矢量稿」。错误原因使用中文说明，不再显示英文错误码，原始路径和错误码保留在悬浮提示中。 |
| 材料与提纲弹窗 | 「查看材料与提纲」改为按钮，与「查看每轮模型用量」并排，点击后打开独立弹窗。弹窗内分为输入材料卡片（带读取状态徽标）、各阶段方案卡片（沟通方向、逐页提纲、模板方案，带已确认、待确认、引文待核对、历史方案状态）和逐页提纲卡片。摘要使用左色条强调。桌面端逐页提纲为双列，窄屏为单列。 |
| 弹窗尺寸与遮挡 | 「完整制作过程」最宽 1140px，「每轮模型用量明细」与「材料与提纲」最宽 1180px。高度限制在遮罩容器的可视区域内，修复底部被遮挡。隐藏中的复核预览区不再显示空黄框。 |
| 代码整理 | 两个子弹窗复用 `ensureSubModal`，常用图标、路径中文名前缀映射集中定义，页面单文件体积保持在治理基线内。 |
| 管理员用户记录 | 管理员重新打开「用户输入输出记录」弹窗时，会话下拉默认回到「全部会话」，加载该用户全部记录，不再沿用上次选中的会话或其他用户的选择。接口未改动。 |

## 升级与兼容

- 只需更新 Pivot 主应用，无需重建独立执行服务镜像，无数据库迁移。
- 浏览器需刷新以加载新的 `chat.workspace.apps.css`，经反向代理缓存时需清缓存。[部署说明](../deployment/PPTMaster独立服务部署与更新.md#v07188-制作过程弹窗优化) · [用户操作](../../使用帮助.md)

- 浏览器测试：`tests/presentation-master-browser.test.js` 中 4 项专项通过，覆盖用量弹窗轮询保持展开、停滞与工具失败诊断、材料与提纲弹窗（含弹窗不超出视口）以及桌面、笔记本、窄屏明暗主题布局。
- 管理员记录：`tests/admin-user-records-client.test.js` 通过。该测试使用模拟页面元素，没有在真实浏览器中点开弹窗。
