# Pivot v0.1.55 发布记录

**发布日期**：2026-08-27

---

## 概述

Pivot v0.1.55 聚焦于**自动化中心与智能体控制台（Agent Control Plane）的信息架构解耦、质量与可靠性大屏紧凑化重构、以及统一收件箱跨视图穿梭任务详情修复**。本次更新消除了自动化中心历史遗留的功能混装与入口重复问题，极大提升了控制台大屏的信息呈现密度与跨模块跳转流畅度。

---

## 主要更新内容

### 1. 自动化信息架构解耦与 Agent 控制台子视图重组

- **任务工作台与控制台权责清晰化**：
  - **任务工作台**：统一承载任务执行列表、全生命周期过滤、计划任务监控与沉浸式 5-Tab 详情面板；
  - **工作流编排**：统一承载 DAG 可视化拓扑绘制、节点参数配置与发布管理；
  - **Agent 控制台**：收敛智能体控制与治理能力，清晰划分为 5 大子视图：
    - `统一收件箱`：集中展示运行结果、待审批事项、自进化提案与系统事件，新增标准居中序号列与状态操作；
    - `持续目标`：支持定时调度、外部 Webhook 或数据库文件变更自动触发的常驻目标；
    - `通知与审批渠道`：管理向企业微信、钉钉、飞书、邮件或 Webhook 推送任务提醒与审批；
    - `质量与可靠性`：运行质量看板、评测中心、工具可靠性与反馈闭环；
    - `能力与治理`：技能包、资源包、常驻实例运维、个人档案与进化提案。

### 2. 统一收件箱跨视图穿梭任务详情深度修复

- **跨 Tab 可见性感知与自动平滑切换**：
  - 修复用户在「Agent 控制台」统一收件箱点击记录的「详情」按钮时，因任务主视图带有 `.hidden` 导致详情被渲染进隐藏 DOM、界面无响应的异常；
  - 在 `openAgentRun` 中引入前置视图状态感知：当在非任务主视图触发打开任务详情时，自动调用 `openAgentWorkbench({ tab: 'tasks' })` 平滑切回任务工作台，并立即展示包含 **概览、执行步骤、实时日志、输出物产物、审批与异常** 的全功能 5-Tab 详情视图；
  - 完善失效或被删除历史任务的加载异常拦截与轻量 Toast 友好提示。

### 3. 质量与可靠性大屏全面紧凑化与数据联动加载加固

- **双栏平衡对称布局与指标胶囊化**：
  - 将原本全宽拉伸的大号统计方块重构为精致的**行内紧凑 KPI 徽章/胶囊**（`min-height: 24px; font-size: 0.74rem;`）；
  - 采用左右平衡对称的双栏网格布局（左 56% 质量与评测 : 右 44% 反馈与工具可靠性）；
- **数据按需联动加载机制修复**：
  - 修复子 Tab 切换时的数据请求断层：点击或刷新进入「质量与可靠性」时，系统自动并发拉取运行质量指标、评测概览 5 项指标（评测集、用例、最近均分、最近通过率、运行中）、工具调用样本与反馈闭环数据；
  - 评测集为空时自适应单栏紧凑空状态卡片（`.is-empty`），彻底消除大白框与多余边框。

### 4. 能力与治理大屏全局样式统一与精简

- **字阶与间距规范化**：
  - 统一下调技能、运行时资源包、常驻实例、个人档案等卡片内的字体字阶（0.76rem~0.8rem），紧凑化内边距与排版间距，与系统全局设计语言严格保持一致。

### 5. 质量与代码治理

- **代码行数与规范门禁**：`agent-harness.js` 严格受控于 1000 行安全门禁；`npm run check` 与 `npm run lint` 均 100% 绿灯 PASS；
- **全量自动化测试**：契约测试与核心功能测试全部通过。
