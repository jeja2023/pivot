# v0.7.126 — PPT 原生能力与技能格式兼容升级

日期：2026-11-07。上一版本：v0.7.125。

本版汇总 PPT Master 对标后的首批 PPT 改造，以及随后对技能格式兼容的通用增强。版本号统一更新不代表已完成完整上游引擎接入、全能力超越或生产部署。

## 1. PPT 制作改造

| 能力 | 本版行为 |
| --- | --- |
| 原生形状 | 从 4 类扩展为 187 类，中文选择器、按实际尺寸与调整参数求值；PPTX 保留预设类型与调整值，PDF 保留矢量路径 |
| 图示 | 明确节点与连接；循环闭合、层级拒绝循环；编辑器可改节点/边，导出为可编辑组合和附着节点的原生连接线 |
| 图表/表格 | 全序列及负数/零值共享预览，保留表头；修复图表工作簿零值为空；拒绝无效饼图、空值与极端值 |
| 故事线 | 受众、目的、阅读方式、目标时长和逐页职责/结论/阶段/关系可编辑，不自动改写画布 |
| 事实与推导 | 逐页来源、论点类型、原文片段/偏移/摘要/定位、明确运算复算；页面文字/数值/讲稿变化使旧绑定失效，单纯移动对象不影响内容绑定 |
| 交付检查 | 现有后台任务增加 production 模式，核对真实字体、证据/计算、素材及最终 PPTX；按对象身份回读文字、单元格、图表缓存/嵌入工作簿、图示连接、图片/媒体/备注 |
| 编辑与展示 | 默认适应画布；编辑、演讲者视图及远程展示共用图形；远程展示按公开内容摘要识别草稿变化，继续隐藏证据与讲稿 |

原生图表、图片与媒体导出失败不会静默替换后报告完成。结构通过、原文片段匹配、计算一致、视觉复核和实际 Office 渲染是不同检查范围，报告分别呈现。

## 2. 技能兼容改造

- 复用原导入入口，增加格式特征适配器，覆盖 Pivot v1、Agent Skills 标准及扩展、Claude Code 扩展、通用头部、纯 Markdown，以及 JSON/YAML 清单容器。
- 名称、说明和许可证映射到新的个人草稿；原版本、扩展 metadata、未知描述字段与来源摘要保留，支持保存、发布与导出往返。未知原生清单版本和冲突正文明确拒绝。
- 字段处理报告区分“已映射”“保留来源”“重新核对授权”“宿主行为未适配”；脚本/参考文件、环境和宿主占位符单独列为待适配。
- 原始 allowed-tools、permissions、scope、hooks 和签名不授予权限。有效工具来自当前账号本次选择，有效能力由登记表解析，继续走已有验证、签名、发布和访问控制。
- YAML 间接引用按实际语法事件拒绝，引用文本中的 &、*、!! 不再误报；保留重复键、大小、深度、原型字段与编码限制。迟到的识别响应不覆盖新文件或用户输入。
- 修复原有 JSONB 清单在导出/对比时被错误解析为字符串的问题；确认工具、许可证及嵌套来源信息在发布后仍完整。

## 4. PPT Master 后续复用决策

采用完整上游发行包作为可选制作引擎，是减少重复开发的推荐方向。保留其工作流、参考、脚本、模板、原稿保留与校验契约，由 Pivot 适配任务、权限、素材、模型、进度、取消及文件交付。复杂原生对象优先通过上游路径生成/保留；已有 Pivot 文稿继续使用现有编辑器和服务。

这一方向需要完整运行时接入。当前单文件兼容只转换指引；现有普通技能包流程仍拒绝 scripts 等可执行内容，不能直接把上游整个目录上传为个人技能并假定其可运行。详见 [整体引擎集成与复用方案](../design/PPTMaster整体引擎集成与复用方案-2026-11-07.md)。

本版没有完成上游完整引擎安装或对等模型/预算下的成稿盲评。复杂原稿保真、自由路径/公式/混合文字、完整动画旁白视频和跨 Office 矩阵仍按对应方案推进；不标记为全部完成。
