# v0.7.120 — BI 容器协调部署与私有对象预检

- 新增可选 Docker CLI 协调镜像与 Linux Compose 覆盖，明确受信任 API socket 权限、固定镜像和 daemon 同名绝对路径；默认服务不自动授予容器管理权限。
- Worker 继承协调进程的非 root 身份，保留输入对象 0600/目录 0700，输出 0700；预检读取真实私有 CAS 字节并核对摘要，检查只读、网络、凭据、socket、capability 与五秒终止。
- 实际 Linux API 容器到受限 Worker 完整检查、发布、刷新、视图/仪表盘、真实登录与 CSV/XLSX 下载、一百万行受控摄取共八项通过，零跳过。
