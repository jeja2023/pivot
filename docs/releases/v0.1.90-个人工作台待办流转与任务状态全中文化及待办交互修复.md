# v0.1.90 发布记录：个人工作台待办流转与任务状态全中文化及待办交互修复

## 版本概述

**发布日期**：2026-09-07  
**版本号**：v0.1.90  
**适用范围**：Pivot Web 端、个人工作台、待办中心、Agent 控制面与前后端协同服务

本版本主要针对用户在日常业务协作与自动化处理中的体验反馈，对个人工作台的待办流转逻辑、全系统任务状态中文本地化规范，以及待办中心的详情交互进行全面修复与体验加固。

---

## 一、核心更新

### 1. 个人工作台“需要我处理”精准流转与已读闭环

- **历史任务与已完成/失败任务智能过滤**：
  - 此前服务端待办聚合并行获取了用户的最近运行记录，但未做人工干预态的严格筛选，导致已完成（`completed`）或执行失败（`failed`）的历史记录残留于个人工作台首页“需要我处理”区域，且用户无法在此区域进行后续操作；
  - 本版本重构待办聚合机制（`server/services/personal-workbench.js`）：仅当任务处于真正需要人工审批或确认介入的状态（`waiting_approval`、`approval_required`、`awaiting_approval`）时才会被纳入“需要我处理”流；已完成、已失败或正在运行的常规记录自动归入最近工作或历史记录，不再形成待办干扰。
- **点击标记已读与待办动态递减**：
  - 前端为每个待办条目绑定点击查看事件（`client/chat/personal-workbench.js`），用户点击卡片查看时，自动调用待办标记已读接口；
  - 服务端（`server/services/agent-inbox.js`）支持对运行记录已读状态的持久化更新（存储于 `agent_runs.metadata.inboxRead` 与 `inboxReadAt`）；
  - 前端在用户点击查看后立即实时递减首页“需要我处理”徽标计数，并将已读条目平滑移除，形成完整的待办处理闭环。

### 2. 任务状态全链路中文化规范（彻底消除裸英文状态）

- **全量标准状态中文字典**：
  - 在 `server/services/agent-validators.js` 中新增权威中文映射字典 `AGENT_STATUS_LABELS` 与 `formatAgentStatus(status)` 转换函数，杜绝系统直接向用户展示任何裸英文状态代码；
  - 覆盖系统所有主流与边界执行状态：
    - `running` / `active` $\rightarrow$ **运行中**
    - `completed` $\rightarrow$ **已完成**
    - `completed_with_errors` $\rightarrow$ **完成（含部分异常）**
    - `failed` $\rightarrow$ **已失败**
    - `error` $\rightarrow$ **运行异常**
    - `waiting_approval` / `approval_required` $\rightarrow$ **待审批**
    - `awaiting_approval` $\rightarrow$ **等待审批**
    - `queued` $\rightarrow$ **排队中**
    - `paused` $\rightarrow$ **已暂停**
    - `draft` $\rightarrow$ **草稿**
    - `timeout` $\rightarrow$ **运行超时**
- **全界面统一接入**：
  - 个人工作台首页（`client/chat/personal-workbench.js`）：任务副标题统一展示 `任务状态：已完成`、`任务状态：运行中` 等；
  - 待办中心（`client/chat/agent-harness.js`）：待办列表标题、说明及状态统一中文化；
  - 运行记录列表与 Agent 详情弹窗（`client/chat/agent-run-utils.js`）：状态徽标与步骤面包屑 100% 转换为规范中文。

### 3. 待办中心「详情」按钮交互响应修复

- **事件绑定与全局命名空间修复**：
  - 待办中心列表行内的「详情」按钮原先直接查找 `globalThis['openAgentRun']`，而实际模态框开启方法注册在 `window.Pivot.legacy.openAgentRun` 命名空间下，导致函数引用为 `undefined`，点击按钮静默无响应；
  - 修正后优先从 `window.Pivot?.legacy?.openAgentRun` 获取调用引用，并在 `agent-run-utils.js` 中做好稳健的兜底导出；
  - 用户点击待办中心中任意任务的「详情」按钮，即可平滑唤起 Agent 运行记录详情模态弹窗，完整查看执行计划、执行步骤面包屑、中文状态及审计日志。

### 4. 环境变量模板对齐与注释加固

- 对齐 `.env` 与 `.env.example` 中的所有配置项（包括 Agent 长任务超时、首响应看门狗、流空闲看门狗、工具规划思考模型控制等）；
- 确保新增的环境变量在两份模板中均具备清晰、规范的中文注释与默认值配置。
