# v0.2.15 法规目录索引与批量索引治理

发布日期：2026-10-12

## 概述

本版本面向 1,000+ 法规文档的生产使用场景，将法规库入口升级为数据库驱动的分类目录，补齐分类动态索引页、当前范围一键全选，以及向量索引失败的有限重试与人工重建机制。

## 主要变更

### 1. 分类文件夹与动态目录页

- 法规查询默认先展示分类目录，而非一次性渲染全部法规列表。
- 每个分类显示法规数量、条文数量、已核验现行数量、待治理数量和最近更新时间；“未分类”自动形成独立目录。
- 点击分类后进入该分类的动态目录页和法规列表，可返回分类目录。
- 分类目录由数据库实时汇总，不会创建或重复保存“目录法规文档”，因此不会产生目录过期、版本不一致或目录被误当作法律依据的问题。

### 2. 大范围批量选择

- 批量处理工具栏新增“全选当前范围”：在分类目录内全选当前分类；在总目录内全选全部可操作法规。
- 选择仍支持跨页保留；单次上限提升至 2,000 份，覆盖千份法规生产库的常见批量治理场景。
- 批量修改、删除、审计和并发保护撤销沿用既有安全机制。

### 3. 向量索引失败治理

- 文本抽取、条文解析和入库与向量索引解耦：向量服务失败不会阻塞法规入库，法规立即保留关键词检索能力。
- 为法规版本新增索引次数、最大次数、下次重试时间和最近尝试时间；临时服务故障按退避策略有限重试，达到上限后自动停止。
- 未配置模型、凭据、参数或出站安全策略等不可自动恢复的错误直接降级为关键词检索，不会在每次服务重启后持续请求失败的向量服务。
- 管理员可在法规详情中手动“重建向量索引”；详情会显示当前索引状态和降级原因。
- 后台索引恢复巡检每分钟处理到期重试项；不会重新抽取或重新解析正文，只对已保存条文建立向量。

## 数据库升级

新增迁移：`202610120008_regulations_index_retries`。

它为 `regulation_versions` 增加索引重试元数据和索引，不会删除或改写已有法规、版本及条文内容。部署后重启服务即可自动执行迁移。

## 验证

- 浏览器测试覆盖分类目录、进入/返回分类、分类范围一键全选、批量修改与现有治理流程。
- 服务回归覆盖分类聚合、分类范围选择、向量重试退避和人工重新排队。
- PostgreSQL 迁移覆盖与关键索引基线通过；临时库验证新增后共有 135 张表、220 个索引。
