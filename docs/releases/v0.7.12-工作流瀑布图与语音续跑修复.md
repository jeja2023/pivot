# v0.7.12 工作流瀑布图与语音续跑修复

日期：2026-10-19。升级基线：v0.7.11。

本版本集中修复工作流耗时图不更新、实时语音误打断与漏读、语音输入尾句丢失，以及任务点击“继续”后出现预算冲突的问题。

## 工作流耗时瀑布图

修复安全 HTML 组件引用错误造成的点击无响应，以及旧弹窗选择器错误造成的重复叠加。弹窗支持节点定位、关闭按钮、遮罩关闭、Escape 关闭和键盘选择节点。

瀑布图改为读取实际运行记录，预览或正式运行创建后立即绑定运行标识。没有本地绑定时，从最近 100 条个人运行记录中查找与当前工作流和画布定义匹配的快照；节点输入、依赖、路由、缓存和重试配置参与匹配，布局移动不影响匹配。发布版与草稿定义不同时，不把发布版耗时套用到当前草稿。

弹窗打开期间约每 1.5 秒刷新一次，避免并发重入；关闭时清理定时器并取消在途请求。刷新保留滚动位置与键盘焦点。数据状态明确区分：

| 显示 | 含义 |
| --- | --- |
| 加载中 | 正在获取实际运行数据 |
| 尚未运行 | 当前画布暂未关联到匹配的运行记录，可先预览运行 |
| 待调度 | 已有关联运行，节点尚未开始 |
| 运行中 | 节点已开始，耗时持续增长 |
| 已完成、缓存、已跳过、异常后继续、失败 | 根据执行记录展示对应结果 |
| 未执行 | 运行已经结束，但该节点没有实际执行 |
| 未获取数据 | 请求失败并显示原因，后续自动重试 |

甘特条按真实起止时间对齐，总耗时使用整体执行跨度，节点累计耗时单独保留在计算结果中；并行节点不会重复计入总执行时长。服务端在节点完成时保留开始时间，旧记录缺少开始时间时按结束时间和已保存耗时还原。未执行节点没有虚假的最小蓝色进度。

窄屏采用分行显示，避免节点名称、工具标签、状态和耗时挤出弹窗。

## 实时语音与语音输入

实时语音在朗读时保留识别通道，确认最终识别结果后再打断旧回复；中间结果不会直接取消朗读。回声比对容忍少量同音错字、漏字和跨分段结果，同时保留明确否定或纠正。打断时停止当前播放和模型请求，清空旧队列，迟到内容与取消回调不会重新播放或误报为设备故障。

移除单段文字只朗读前 2000 字的限制，改为不超过 120 个 UTF-16 单元的短段连续播放，保留代理对；最终全文补齐流式阶段未到达的尾部，重复完成事件不重读。播放启动观察延长到 15 秒，若声音实际正在播放或排队，不因缺少 `onstart` 事件结束会话。

完整识别到“退出”“退出实时语音”“关闭语音”“结束实时语音”等命令时，直接结束实时语音，取消当前模型请求、清空临时上下文和朗读队列、释放麦克风并恢复按钮。退出指令不提交给模型，也不转换为后台任务控制。

语音输入点击完成时允许最后识别结果返回；切换模式、关闭页面等取消操作仍立即释放资源。浏览器停止前排空音频工作线程不足一块的尾部，等待已经排队的转写，不因第一段返回而丢掉第二段尾句；英文分段保留必要的词间空格。

部署内识别保留约 400ms 句首预录，改善低音量触发并适当延长句末静音，减少自然短停顿造成的分段。默认设备打开成功后再尝试回声消除与降噪，不支持增强参数的设备保留原轨道。Windows 桌面与服务器听写的句末等待调整为 850/1200ms；桌面原生通道增加 `finish` 收尾指令，先交付缓存音频的尾句再结束，原有立即停止通道保留。

识别引擎及选择顺序没有替换：Windows 客户端优先系统本地识别，再尝试部署内识别和浏览器本地识别；录音不持久化、不转发外部语音服务。上述优化改善采集、分段和播放控制，不能据此宣称实际环境字错率已经提升。版本差异与合成音频验证见 [语音专项报告](../reports/语音功能版本对比与优化验收_2026-10-19.md)。

## 任务继续与重跑预算

修复 `/api/agents/runs/:id/resume` 复制原任务总预算的问题。例如原始总额为 2048000，已用量及预留扣除后仅剩 1735413 时，旧逻辑仍申请 2048000，触发 `AGENT_CHILD_BUDGET_EXCEEDED`。

续跑、完整重跑与工作流节点重跑改为由资源账本在事务内分配实际剩余额度，并将新运行的 `max_token_budget` 与 `budget_config.max_tokens_total` 同步收紧。父任务存在更小的总预算时按更紧限制扣除已用量和预留；显式零额度、其他工具及风险限制继续有效，不自动扩大原任务授权。

显式子任务请求超出剩余额度仍拒绝。实际额度不足或子任务并发受限时返回 HTTP 409、业务错误码和可读原因，不再被包装为“服务器内部错误”。并发点击“继续”只分配一次相同的剩余额度，失败请求不遗留预留。

## 升级与交付范围

1. 更新服务端源码或镜像并重启，重新加载页面以获取带新版本参数的脚本及样式；瀑布图数据接入、节点开始时间保存和续跑预算修复由服务端更新生效。
2. Windows 原生识别工作进程、句末等待参数和尾句收尾 IPC 需重新构建并升级桌面客户端。旧客户端缺少新收尾接口时保留原有停止行为，仅刷新网页不能补齐原生组件。
3. 无新增依赖、数据库迁移或必需环境变量，不修改生产模型、既有任务的总预算或已有审批快照。
4. 版本号统一为 0.7.12，来源为 `CHANGELOG.md`，通过 `npm run version:sync` 同步至 `package.json`、锁文件与 README。当前为工作区源码及文档交付，尚未打包、上传更新包或部署生产。
