# Pivot v0.7.189 发布说明

2026-11-20 · PPT Master 模板清单恢复与逐轮计时

生产截图中的 8 页任务已确认沟通方向，但最终清单出现页数不足和引文缺漏，反复修复后用完该阶段的 18 轮。截图显示任务仍在最终清单阶段，没有首次页面写入回执。

## 主要变更

- **直接生成可编辑初稿。** AI 制作和按模板制作 PPT 时，模型规划沟通方向，宿主自动核对最终清单，完成后可预览并下载初稿 PPTX。标准工作台自动生成大纲和页面。旧任务停在出稿前确认环节时可点击「继续制作」。创建可复用模板工作区时仍确认模板方案。
- **保留完整清单。** 逐项修复引文时，宿主在已保存的清单上更新指定页和数据项，沿用其他页面、顺序和模板应用设置。重提整份清单时仍须提交要求的全部页面。清单通过系统校验后才写入页面 SVG。
- **按原文核对。** 仅当已匹配的短引文和完整数据能唯一定位到同一条完整原文时自动补齐。数字、单位、限定条件或出处有歧义时保留待核对项。修复轮优先使用已读原文和当前证据，缺少具体范围时再定向补读。
- **优先出可用初稿。** 同一批引文重复失败或达到 18 轮阶段上限时，已有完整清单可用「数据待核对」占位继续出稿，并列出页码与原因。没有可用清单时保留检查点供续跑。
- **出稿后提交修改。** 整份修改用原材料或当前文稿保存的来源证据生成独立新版。标准工作台可改写当前页。PPT Master 初稿可在原稿编辑器中按要求修改当前页文字，复用原稿编辑的版本记录。
- **完善逐轮计时与用量。** 模型调用记录北京时间和从进入模型调用到返回或报错的耗时。失败的调用显示开始时间、用时和原因，自动重试单独记录。失败轮缺失的令牌用量显示「未知」，任务累计计入供应商已返回的量。历史计时缺项显示「未记录」，零耗时显示「0 毫秒」，119.9 秒显示「2 分钟」。
- **说明写入诊断的口径。** 「首次页面写入」依据已校验的页面 SVG 写入回执登记。「已收敛 0 条文件写入正文」统计模型上下文中被压缩的旧写入正文数量。已有输入材料、模板副本与项目初始化文件有各自的记录。[使用帮助](../../使用帮助.md)

## 升级与兼容

- 容器部署需要构建并替换包含 v0.7.189 前端、后端与更新日志的 **Pivot 主应用镜像**。本版沿用当前兼容的 PPT Master v6.10.0 独立服务及其运行包，**无需重新打包 PPT Master 独立镜像或执行数据库迁移**。
- 保留独立服务的运行身份、配置和数据卷。已有任务在权限有效、检查点与原工作区仍可用时可续作。若同时从早于 v0.7.186 的执行服务升级，按对应版本的能力要求判断是否换独立镜像。[部署说明](../deployment/PPTMaster独立服务部署与更新.md#v07189-模板清单恢复与逐轮计时)

## 实际验证

- 本次升版通过 `npm run version:sync`、`npm run check` 和发布文档链接校验。运行时、README、软件包及锁文件的版本均为 v0.7.189。
- 功能阶段运行 93 项后端相关测试和 23 项 Chromium 测试。覆盖模拟的 8 页清单、9 项引文、误提交部分页面、阶段轮次耗尽、旧检查点续跑、模型超时持久化以及桌面和窄屏计时。收紧旧检查点的阶段识别后，复跑的 PostgreSQL 与引文核对专项共 35 项通过。
- 取消沟通方向确认后，95 项后端相关测试和 24 项 Chromium 测试通过。使用现有 PPT Master v6.10.0 镜像和模拟模型，分批通过 5 个端到端场景，覆盖 AI 自由制作、咨询决策和学术研究模板的实际 PPTX 下载，以及制作快照和引文检查点续跑。
- 初稿流程更新后，101 项相关测试及 7 个端到端场景分批通过。核对标准工作台直接出稿、缺页补齐与整份新稿，PPT Master 首稿预览、下载、待核对占位与单页文字改稿。单页改稿保留原版本，未选页的 PPTX 页面 XML 逐字节一致。
- 回归使用合成材料、模拟模型和隔离 PostgreSQL。生产截图对应的原始材料、运行记录和部署版本未用于回放。镜像制品构建和生产同单验收仍待进行。
