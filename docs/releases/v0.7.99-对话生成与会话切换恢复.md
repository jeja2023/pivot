# v0.7.99 对话生成与会话切换恢复

日期：2026-11-06。源码基线：v0.7.98。

## 变化

普通聊天原先只有一份全局取消控制器和发送任务。在另一会话发送消息时会中断旧请求；会话历史又只包含已保存的回复，因此重新打开时，原流的消息节点和已有正文不能恢复。

本次增加按账号、会话持有的生成管理模块。切换视图保留流连接和当前消息节点，切回时合并服务端消息编号并重新挂载，继续更新正文。同一页面可以在不同会话生成回复，停止按钮只操作当前会话；旧请求完成后的清理不会覆盖另一个会话的按钮或内容。

同一会话仍维持新消息串行替换规则。已交接的 Agent 运行继续由持久任务模块跟踪；普通生成不会冒充持久任务。退出、删除、页面离开清理本页请求，已结束但尚未被历史确认的节点缓存最多保留 20 轮，并按账号隔离。

## 使用边界与升级

本次保证当前页面内切换会话继续生成。普通回复仍依赖当前页面的 HTTP 连接，刷新、关闭页面或断网后不提供跨进程续跑；完整落库后的答案可以从历史查看。长期后台工作沿用持久 Agent 任务。

更新客户端静态文件并刷新页面后生效，无新增数据库迁移、依赖或配置。
