# v0.1.176 发布记录：AI 演示大纲层级阅读模式

发布日期：2026-09-24

## 发布摘要

AI 创建 PPT 的大纲确认页此前按照页面顺序展示大量卡片和字段。对于长演示，这种方式会重复显示“第 N 页”和编辑控件，不利于快速审阅结构。本版本将确认页调整为 连续层级阅读模式，用正常标题、章节、主题、目标说明和圆点要点展示整份演示内容。

## 主要变更

### 连续层级大纲预览

- 演示标题以突出标题展示；
- 每个章节以章节标题展示；
- 每个主题以主题标题展示；
- 页面目标以辅助说明展示；
- 核心要点以圆点列表连续展示；
- 页面不再出现逐页卡片、页码徽标、版式下拉框和内部结构字段。

### 使用方式

1. 在“AI 创建”中填写主题和材料并生成大纲；
2. 在确认页按连续层级从头到尾审阅章节、主题和要点；
3. 内容符合预期时直接点击“生成页面”；
4. 需要调整主题、页数、受众、风格或材料要求时，点击“返回调整要求”，修改后重新生成大纲。

### 数据与安全

- 层级预览只负责展示，不作为后续页面生成的解析输入；
- “生成页面”继续读取系统保存的结构化大纲，因此页面版式建议、来源引用和内容边界仍受原有校验保护；
- 不引入新的富文本执行、HTML 渲染或外部链接能力。

## 验证记录

- 确认页契约验证 层级预览节点存在，旧 JSON 编辑器与逐页表单节点不再出现；
- PPT 生成、表格图表容错、JSON 自动修复、导出与结构化 IR 专项测试均通过；
- 已重新构建应用工作区 CSS，并通过语法、ESLint 和增量开发规范检查。

## 部署说明

- 无新增数据库迁移或环境变量；
- 远程模式请部署 v0.1.176 的服务端与静态资源后重启 Pivot 服务；
- 如果仍显示旧的逐页大纲或 JSON 框，说明客户端连接的服务端未更新，需要刷新缓存并确认远程服务版本。
