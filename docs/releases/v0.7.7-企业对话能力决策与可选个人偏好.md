# v0.7.7 企业对话能力决策与可选个人偏好

对话意图器在同一次结构化判断中输出回复/任务动作、知识依据需求、工具处理方式、能力范围及消解指代后的完整问题。组织业务问答与自然表达不再被旧关键词规则提前挡在理解流程之外，明确问候、短确认和带分隔符的单次文本转换保留快速路径。历史、附件、偏好和能力目录均为数据，不构成本轮授权。

知识库路由与工具路由消费统一判断，继续执行原有权限与检索质量控制。明确需要组织依据时进入检索，缺少可信来源不能补造答案。短只读查询可在已有账号权限内自动规划；模型仅看到权限过滤后的少量工具元数据，不接触凭据。候选与执行边界均限制能力、工具来源、幂等性、审批要求和风险。多业务来源未明确时先澄清，不能按工具排序猜测；写入、发送、删除等操作继续进入受控任务。

自动任务关闭时仍理解业务问题，但不能因语义建议创建或续接运行。语义失败、影子模式、权限撤销、工具契约变化与检索无结果均按限制回退，保留已有评测、灰度和回滚机制。统一判断保留决策 ID、来源消息和耗时等既有审计字段。

“应该查知识库”“不用知识库”通过控制消息调整当前任务，保留其他能力与运行状态；排除知识库同时进入执行策略。撤销执行授权、仅给方案或禁用工具时，仍先收紧能力再暂停，不能自动撤销已经完成的外部操作。

个人档案默认可用，不再自动弹出四步首次设置。工作台提供“个人偏好”按需管理入口，称呼、职责、详略和常用任务仍可编辑；通知连接、凭据和工具权限独立管理。对话与持久任务共享偏好冲突处理：当前明确要求优先，其次会话与项目范围，同一范围采用最新明确设置；系统默认值不冒充用户偏好。沟通风格更新时间依据已有版本账本独立读取，修改称呼不会覆盖新表达偏好。无需数据库迁移或新增依赖。

部署需要更新服务和前端资源；不要求用户重新填写档案。未自动部署远程 Docker，也未据此批准或激活全局学习策略。工程证据见[验收报告](../reports/企业对话能力决策与可选个人偏好验收报告_2026-10-19.md)。

合成意图评测集升级为 v4，新增组织休假、实习生追问、自然销售查询、多来源歧义和创作场景。`scripts/evaluate_chat_intents.js` 同时检查动作和检索/工具决策契约；可由有权账号选择模型运行，仅发送公开合成问题，不执行业务工具。工程回归和模拟模型通过不等于真实业务模型准确率已获认证。

验证结果：工程检查、ESLint 通过；全量回归 2010 项、相关模块 94 项、聊天与 MCP 安全回归 203 项、浏览器关键流程 4 项通过，包含真实数据库与桌面/手机窄屏验收。
