# v0.7.73 基础能力第四轮：公文、任务恢复与备份

日期：2026-10-30。当前工作区版本包含前面三个基础能力版本的修改。

## 更新内容

### 公文与配置

- 恢复公文正文和材料编辑区；已命名的新公文即使正文为空也会保存。相同文档的保存按顺序执行，响应只确认实际发送的内容；删除等待已发出的保存完成。
- 带版本号的旧窗口修改会收到冲突提示，当前页面正文保留以便复制；相同内容重复提交保持幂等。未携带版本的旧客户端仍按兼容方式处理，不具有同等冲突保护。
- OCR 与文档处理配置先校验，再在数据库事务提交并刷新缓存后返回，避免写入失败却报告保存成功。

### 任务恢复与文件清理

- 文档处理执行器使用 PostgreSQL 任务锁和独立持锁连接；连接失效时旧执行不能回退到普通连接池继续写入。新版任务按实际租约到期恢复，旧版本任务保留保守等待。
- 维护巡检分批核对新版任务生成的页面和输出。只有文件及所属已终结任务均超过保留期、没有引用或待处理导出、且任务锁可用时才清理；保留期至少 30 天。手动导出与清理共享任务锁。
- 清理不处理历史命名文件、原文件、通用 `tmp` 目录或缺少任务记录的文件。数据库核对失败或检测到目录链接时保留相关文件。

### 备份与测试

- 离线备份清单扩展到文档处理、数据分析、Agent 大对象、运行包和技能目录；文档处理及分析的临时目录不纳入。默认可选目录不存在时记录为缺失，显式指定的目录不存在时报告错误。
- 保留旧版备份清单的校验能力，但旧版清单只能证明当时记录的数据库、CAS 和上传文件；不能据此推断新增目录已有备份。新版备份由支持新版清单的工具校验和恢复。
- 新增隔离应用恢复演练，检查登录、会话、附件、数据库运行配置、OCR 配置、分析数据、PDF 输出和 Agent 文件。环境配置、外部数据库及加密密钥需要独立备份与恢复。
- 浏览器测试调整合成音频采集时序、长流程时限和隔离测试登录配额；正式环境登录限流保持原有策略。

## 验证与边界

- 最后一次包含真实 FastMCP、Mermaid 和 Graphviz 的完整 Node 回归 **2422 项通过、0 失败、0 跳过**。强制终止隔离执行器后验证任务恢复和未登记页面清理；测试覆盖活跃任务、待导出、数据库故障、目录链接及分批扫描。
- 孤儿清理前完整浏览器回归 **103 项通过、0 失败**；清理改动后 OCR 与 PDF 浏览器专项 **2 项通过**。使用合成数据和受控 OCR 服务，不代表真实 OCR 识别质量。
- 独立 PostgreSQL 与应用恢复演练通过；受控浏览器在有限 CPU 负载下的下载、中断和租约失效用例共 9 项通过。有限复测不代表生产容量或长期稳定性验收。

## 更新方式

更新并重启主服务、刷新页面，并让文档处理和知识库工作进程使用同一版本；不应与不支持新任务锁和连接围栏的旧文档执行器混跑。此轮无新增数据库迁移或必需环境变量。

升级前按实际部署配置备份数据库和全部数据目录，并单独保管匹配的配置与加密密钥。生产模型、OCR、目标设备、负载与完整恢复仍需在目标环境验收。
