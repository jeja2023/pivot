# v0.7.147 智能体协议、视觉核验与项目技能资源升级

日期：2026-11-10。将此前基于 v0.7.146 工作区完成的两轮智能体改造统一归入 v0.7.147。此记录覆盖源码功能与文档，不表示生产服务、镜像或桌面安装包已经更新。

## 使用变化

- 在个人工作台左侧打开“项目”，集中管理工作规则、知识库集合、已有文件和里程碑，查看项目任务及结果文件。点击“创建项目任务”后填写本次具体要求；任务详情显示项目和规则版本。
- 项目规则在任务创建时冻结，同时进入规划和独立交付核验。修改项目影响之后的新任务；资料读取继续依据当前权限，归档阻止新运行。持续目标可选择项目，每次触发重新检查项目及资料范围。
- 里程碑完成可以填写人工确认依据，或关联同账号、同项目已核验通过的完成任务。依据失效会显示提示，人工进度标记不代替实际任务验收。
- 技能导入可选择含根目录 SKILL.md 的目录，将支持的配套文本和图片一起预览。确认资源摘要与工具授权后，沿用个人草稿、验证和发布流程；选择已发布技能的任务可按需读取配套资料。
- 支持视觉的模型能在后续规划中读取已授权工具返回的真实截图。文件登记、操作完成、内容核验和本机保存继续分别显示；图像不可读、证据缺失或核验容量不足时保留已有结果并说明未完成原因。
- 完成型持续目标可接续同版本前次的未完成事项，最终验收核对前后实际交付；普通定时与监控任务按次独立运行。旧目标修订、暂停和重复回执不能错误完成当前目标。

操作说明见[使用帮助](../../使用帮助.md#210-项目空间与技能配套资料)。

## 执行链改造

### 协议与图像

Agent 统一处理 Responses 工具调用的名称映射、调用 ID、系统角色、结构化输出、图像、用量与结束状态；明确拒绝未完成参数、重复调用标识和超量调用。显式 Responses 地址也在普通聊天和聊天工具规划中识别，继续经过现有出网、并发、预算、取消及首响应/空闲超时控制。

当前执行进程内，同端点、同模型后续请求保留供应方返回的加密推理项；它们不进入普通公开步骤，切换模型或端点不复用，进程重启仍依赖已持久化工具事实，不声称加密状态跨重启延续。

截图和 MCP 图像先经格式、像素及字节限制和 PNG 转换，再封装进现有 CAS。模型读取时复查归属、类型、有效期与摘要；外部工具自报的受控图像引用会移除。持久观察保留真实引用，恢复后可以再次生成模型原生图像输入。

### 完整核验与质量路由

最终核验从持久步骤、DAG 节点、已应用控制回执和工具检查点补齐执行记录，覆盖只写检查点、尚未写入界面步骤时的中断。续跑及完成型目标沿来源关系读取前次真实交付；同内容的两次真实操作保留次数，持久记录与内存窗口重叠去重。

压缩观察保留原文引用，核验按当前账号读取完整原文和完整答复，早期证据不再因只保留最后24项或500字摘要而消失。证据缺失、撤权、失效、超量或模型容量不足时保留未核验状态。参数预览继续脱敏且限长，缺少工具输出时不把未经脱敏的原参数再作为结果发送；零和 false 保持原值。

质量路由读取每个 Run 唯一的最新验收，以首次验收时间计算30天窗口并绑定执行期端点与模型名称摘要。重复修复不增加样本，旧任务重验不刷新窗口，模型配置改名或换端点不沿用旧身份；部分完成、缺口和无效核验响应继续入账。自动升级优先采用同类任务的有效质量证据，无证据时只允许上下文扩容，不再把高价格直接当成更高质量。

### 项目、目标与技能资源

项目按账号私有，采用预期修订号、账号行锁与配额限制；列表、详情、文件、里程碑依据及新任务复查当前权限。项目编辑与账号切换绑定异步序列，保存冲突保留输入，退出清空界面；配置纳入个人数据导出及明确擦除事务。项目身份供任务使用同一记忆范围，不把已有普通会话自动归档进项目。

持续目标保存、预览和触发共用项目及模型校验。完成回执以事务锁核对目标版本、活动状态、真实终态和验收结果，同一 Run 仅应用一次；接续不继承审批。触发文件、数据行等参数进入规划上下文，材料过大或无法完整保留时明确停止。

技能静态资源清单以路径、大小和 SHA-256 绑定版本。`skill.resources` 列出当前任务已选发布包，`skill.read_resource` 分页读取文本或返回图片；二者必须由用户显式选择。安装采用排他创建，重用已有文件前检查字节，运行逐次检查发布、版本、来源、签名和完整目录摘要。资源配方的个人验证、传统完整包导入和组织共享签名分别按现有门禁执行；无脚本、无依赖且逐项摘要绑定的静态配方可沿个人指引路径验证，显式签名要求与共享门禁保留。

实际读取的资源来源写入可信任务元数据；发布暂停、版本变化、撤权或篡改同时影响下一次模型请求、旧任务和产物读取、以及继承父任务资料的子任务。资源内容本身不构成新增指令或工具授权。

## 当前容量与兼容边界

| 对象 | 当前范围及超限行为 |
| --- | --- |
| 工具视觉 | 单幅输入/转换图像不超过2 MiB，源图最多1600万像素，最长边缩至1440；每次模型请求最多4幅最近工具图像，未提供项有提示 |
| 核验 | 执行记录最多2000条，记录载荷及受控原文各受32 MiB预算限制，并检查模型上下文；超限不裁剪成“核验通过” |
| 续跑来源 | 最多128层来源关系，权限遍历最多256次；不完整、循环或撤权时拒绝沿用 |
| 项目 | 每账号最多100个；每项目最多12个知识库集合、50个关联文件、32个里程碑。文件选择器展示最近100个当前可访问文件 |
| 技能目录 | 最多32个配套文件、合计4 MiB、单文件2 MiB，位于 references/assets/templates；文本为UTF-8，图片仅静态PNG/JPEG/WebP |
| 技能读取 | 文本默认8000字符、每页最多16000字符并返回下一页位置；传统包中的其他二进制文件仅描述，不声称已解析 |
| 历史数据 | 保留旧任务、仅选择知识库的资料包和旧项目记忆标识；资源清单为可选字段，原单文件技能继续兼容 |

模型质量证据至少需要30个样本并满足既有质量阈值；历史无身份摘要的样本保留但不作为新路由依据。当前语义核验仍使用任务执行模型，是独立调用，不代表独立模型、人评或所有文件的视觉验收。

## 升级与运行配置

1. **数据与文件**：更新前按现有备份流程保存 PostgreSQL、上传文件、CAS、技能包及配置的一致恢复点。新增迁移 `202611100001_agent_projects` 创建 `agent_projects` 和项目查询索引，由现有迁移机制执行；无需手工改旧任务或技能清单。
2. **部署顺序**：更新主应用代码及静态资源，按现有部署流程执行迁移并重启服务，浏览器重新加载新缓存标识。镜像、离线 tar 和桌面安装包须单独重新构建与验收；独立PPT、OCR和语音服务不因本次源码升版自动更新。
3. **模型协议**：Agent 对 `api.openai.com` 上当前适配规则中的 GPT-5/6、o1/o3/o4 自动使用 Responses。其它网关保留原协议；网关实际支持时可配置完整 `/responses` 端点。检查网关是否接受工具、图像和结构化输出；不要仅因模型名称相同而认定协议可用。读取截图须选择支持视觉的模型。
4. **持久目录**：项目配置位于 PostgreSQL，任务和交付物复用原存储；技能包继续使用已有 `AGENT_SKILL_ROOT`，未配置时使用 `DATA_DIR/agent-skills`。图像及原文进入现有 CAS。升级、备份与恢复保留这些目录及其权限，不能只保存数据库。
5. **配置与权限**：本版无新增依赖或必填环境变量。既有签名、工具授权、逐操作审批、网络与隔离 Worker 要求继续生效；项目选择、技能导入或视觉观察不授予额外执行权。
6. **回退**：如需回退，按既有备份及回滚流程核对数据库和文件共同恢复点；不要删除新项目表、手改迁移记录或移除资源摘要来让旧版本读取新资料。生产回退仍需目标环境演练。

详细流程参见[离线部署](../生产环境离线部署.md)、[PostgreSQL运行与升级](../生产环境PostgreSQL主库运行与升级说明.md)。

## 范围与后续

本轮按单组织部署，不接入OA、邮件、日历，不扩展多租户。跨账号项目共享、普通会话归档进项目、任意外部脚本/宿主钩子/依赖环境全兼容、通用跨平台电脑操作、日常浏览器授权扩展和整站多节点就绪仍需对应实现与环境验收。

本版未进行新的商业产品同任务对照、目标Office/WPS往返或生产故障切换验收，不宣称整体追平。源码版本由 CHANGELOG 顶部条目驱动，同步包清单、锁文件两处根版本、README三处版本及设计基线；本次未创建Git提交、标签，未构建或发布新制品，未重启生产服务。
