# v0.7.17 工作流编排产品体验全面升级

发布日期：2026-10-20。

本版本落实 [工作流编排产品体验升级方案](../design/Pivot工作流编排产品体验升级方案_2026-10-20.md) 的 A—D 工程任务。业务用户可从场景模板出发，在同一工作区配置字段、试运行、查看结果、修正错误并发布；日常运行者直接填写实际发布版本的参数。

## 主要变化

- 三个业务模板、示例预览、授权模型选择、空白与自然语言建稿入口；AI 建议先看计划与差异，再应用为可撤销草稿。
- 步骤/画布共用定义、选择和撤销；分支大纲、分组折叠、子流程定位、就地添加、线路插入及引用安全复制。
- 参数来源标签、类型/样例选择、记录表格编辑、日期与统一文件上传；高级表达式和原始数据继续可用。
- 节点测试、测试到这里、全流程试运行、历史样本复用和失败处继续；报告、表格、文件优先展示，测试与发布运行身份分别保留。
- 允许未完成 JSON 的自动保存草稿，保存失败、本机恢复、双窗口冲突、查看差异、另存/导出和加载服务器修订；草稿独立于可执行版本与线上版本。
- 发布前查看相对线上版本差异、变更参数、依赖及计划/事件启动状态；确认发布固定版本，首次发布不自动开启计划。
- 共享接收者使用当前账号的授权依赖和实际发布版本；收藏、最近使用及限时显式复用上次参数。
- 修复 F01—F10：复制引用、迟到测试、发布参数串版、隐藏画布快捷键、字段路径、创建去重、稳定版本比较、多选对齐、测试有效性及并发调度补位。
- 深浅主题、桌面与窄屏布局、键盘焦点、触屏入口及减少动态效果支持。

## 更新与回退

1. 更新服务端和前端代码，正常重启服务；客户端重新加载页面。
2. 启动时应用 PostgreSQL 迁移，增加编辑草稿与个人偏好两张表。无需新增依赖或必需环境变量。
3. 已发布流程保持原快照；编辑后试运行，确认影响再发布。计划与事件启动分别检查。
4. 回退旧应用代码时保留新增表及草稿数据，旧代码忽略它们。升级前沿用现有数据库备份流程。
