# v0.1.102 发布记录：系统架构解耦与深度性能治理

发布日期：2026-09-09

## 版本摘要

本版本为系统底层架构治理与深度性能优化专项版本。重点针对超千行单体遗留大文件进行模块化职责解耦、优化核心数据库热路径与参数转换效率、压缩前端静态资源体积、加固 RAG 向量检索堆内存安全边界，并完成质量门禁契约修复与全局变量规范收敛。全量 984 项自动化测试与 21 项架构门禁脚本均 100% 通过。

---

## 主要变更

### 1. 架构解耦与超千行存量大文件治理
- **数据库 DDL 巨石拆分（`schema/base.js`）**：
  - 针对原全后端最大的单文件 `server/db/schema/base.js`（原 1,548 行）进行高内聚分治，重构后入口文件仅 **39 行（下降 97.5%）**；
  - 拆分为 4 个职责分明的 DDL 模块：
    - `server/db/schema/tables-core.js`（638 行）：核心用户、会话、文件、用量与知识库核心表；
    - `server/db/schema/tables-agent.js`（715 行）：智能体、工作流、MCP 工具链、调度任务与治理分析表；
    - `server/db/schema/indexes.js`（124 行）：全量基础性能与约束索引；
    - `server/db/schema/fts.js`（61 行）：SQLite FTS5 全文检索虚拟表及级联同步触发器。
  - 完全保持数据库初始化及迁移逻辑 100% 行为一致与向后兼容。
- **文档处理服务分治（`document-processing/jobs.js`）**：
  - 抽离新建 `server/services/document-processing/settings.js`，承载配置提取、OCR 引擎选项归一化及切片/任务序列化纯逻辑；
  - 主任务文件 `server/services/document-processing/jobs.js` 聚焦任务状态机与调度流转，行数由 **1,069 行降至 925 行**；
  - 由 `server/services/document-processing/index.js` 统一导出，外部接口契约零破坏。
- **智能体审批请求服务解耦（`agent-approval-requests.js`）**：
  - 抽离新建 `server/services/agent-approval-levels.js`，分离多级审批人用户引用解析、超时计算与层级决策满足性判定纯逻辑；
  - 主服务 `server/services/agent-approval-requests.js` 行数由 **1,154 行降至 928 行**。
- **系统统计路由解耦（`admin-stats.js`）**：
  - 抽离新建 `server/services/admin-stats-service.js`，下沉时区边界、端点聚合、Token 用量子查询与知识块统计逻辑；
  - 路由文件 `server/routes/admin-stats.js` 行数由 **1,134 行降至 931 行**。
- **大文件治理豁免清单收敛**：
  - `scripts/governance_baseline.json` 正式将上述文件全部移出豁免清单，基线豁免大文件数由 **10 个净减至 7 个（下降 30%）**。

### 2. 数据库热路径微性能与参数转换优化
- **消除热路径动态引用与短路开销**：
  - 在 `server/db/client.js` 中持久持有 `recordSlowSql` 单例引用，彻底消除每次查询执行时的动态模块查找开销；
  - 增加 `duration >= SLOW_SQL_THRESHOLD_MS` 前置短路判断，使 99.9% 以上的常规快查询直接 O(1) 穿透，消除高频执行时的对象分配与耗时计算冗余。
- **SQL 模板参数转换 LRU 缓存**：
  - 在 `toPostgresParams` 中引入容量为 512 的 `sqlParamsCache`；
  - 相同 SQL 模板重复查询时直接命中缓存的参数占位符映射元数据，避免每次重复执行正则表达式全局匹配与参数切片。

### 3. 前端构建产物优化与安全体积压缩
- **安全 CSS 压缩管道**：
  - 在 `scripts/build_chat_css.js` 构建脚本中引入 `minifyCss`，安全移除 CSS 冗余注释与多余空白符；
  - 针对 CSS 现代语法，严格保护 `calc(...)`、`min(...)`、`max(...)` 等函数中的加减法运算符空格，杜绝浏览器语法解析错误。
- **生产 CSS 产物体积大幅缩减**：
  - 重新构建生成 `client/chat/chat.bundle.css`，体积由 **1,122,662 字节 (~1.07 MB)** 降至 **862,413 字节 (~842 KB)**，**体积净减 260 KB（-26.67%）**，显著加快客户端首屏资源加载。

### 4. RAG 向量检索与运行时堆安全保护
- **纯 JS 余弦降级候选集硬上限**：
  - 在 `server/services/rag-index/index.js` 中将纯 JS 余弦降级检索的候选集硬上限严格限制在 1,000 块以内，防止冷启动或缺少向量扩展时因全库扫描撑爆 Node.js V8 堆内存引发 OOM。
- **切片嵌入缓存批量淘汰与健壮性加固**：
  - 切片向量缓存 `chunkEmbeddingCache` 达到 5,000 条上限时，单次批量剔除 50 条最老记录，降低高频检索下的 GC 颠簸；
  - 增加对 `entry?.vec` 的健壮空指针防范，避免向量解析异常导致检索崩溃。

### 5. 门禁阻断修复与前端全局命名空间收敛
- **Legacy Window 全局别名治理**：
  - 重构 `client/chat/workspace-settings-scale.js`、`client/chat/users.js` 与 `client/chat/stats.js`，全面收敛全局暴露属性，全局 legacy 别名数量由 279 降至 274（严格符合预算 <= 276 指标）。
- **测试断言与 Raw SQL 基线恒定**：
  - 修复 `tests/security-chat/rendering-streams.js` 统计导出断言的正则匹配；
  - 重构迁移中保持 `scripts/raw_sql_baseline.json` 全局 Raw SQL 总数恒定在 1,420，未引入任何未经审查的裸查询。
