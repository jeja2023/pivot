# v0.7.35 对话附件核验与 PPT 主题模板优化

发布日期：2026-10-23。版本类型：对话体验修复、PPT 主题与排版优化、草稿版本管理调整。

## 变更内容

### 对话附件与任务验收

- 用户添加的附件先保留在待发送队列，点击发送时再随消息上传。
- 发送后通过统一附件清理流程清空输入框预览，避免已发送附件仍显示为待发送状态。
- 任务验收可读取当前消息中与本地上传文件匹配的文档片段，作为来源证据交给核验流程；空内容、手工伪造的文档分隔标记及未匹配附件不会被采纳。

### 执行步骤展示

- 缩小步骤记录的间距、内边距和列表留白。
- 把操作名称与目标服务器放在同一标题行，状态和耗时仍单独显示，长标题可按可用宽度换行。

### PPT 主题模板与版式

- 内置主题模板收敛为单套商务蓝汇报主题，并参照《数智侦查项目阶段性汇报.pptx》调整深海军蓝页眉页脚、青色标题标记、灰色正文层级、多色章节强调和浅色内容卡片。
- 封面采用上下色带、突出标题与副标题、章节导航条和汇报元信息；章节标签根据后续页面标题生成。
- 内容页统一标题区域、页脚和卡片边界；双栏与三栏布局增加清晰的彩色侧边强调。
- 当封面已有步骤图、表格、图表或其他主要视觉元素时不再自动添加重复章节标签。重新选择当前主题时可确认重新排版现有封面，保留文字并避开图形区域。
- 优化模板卡片的紧凑布局和无障碍选中状态；支持依据当前页面内容生成三种可编辑的 AI 版式候选。

### 草稿与里程碑版本

- 编辑过程的自动保存更新当前草稿，不再逐次创建版本历史记录；用户主动保存时才新增里程碑版本。
- 数据库迁移为文稿记录增加草稿内容和核验状态字段，并从现有当前版本回填数据；同时清理非当前的自动保存快照，保留当前版本及手动保存的历史版本。部署时服务启动会执行迁移。

## 升级与兼容

项目版本号已启用为 `0.7.35`，同步到 `package.json`、`package-lock.json` 和 README。升级服务后重启并刷新页面。数据库迁移由现有迁移机制执行；无需新增环境变量或依赖。

版本号同步不会创建 Git 提交或发布标签，也不代表生产服务或桌面安装包已发布。
