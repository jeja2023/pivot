# v0.7.92 公文写作优化汇总与版式更新

日期：2026-11-04。

本版本汇总前述公文写作改造、截图版式和空行补充要求，统一更新日志、使用帮助、设计文档与项目版本入口。历史发布记录保留。

## 已完成优化

- 编辑过程中保持文字与光标稳定，支持中文组合输入、空行、粘贴及统一撤销重做。
- AI 起草和改写先预览后采纳，请求绑定原公文与正文快照；建议核对原文锚点，避免跨文档覆盖、位置错移和重复应用。审校说明与替换文字分离，中断及截断结果明确标识。
- 文档服务端分页、搜索、筛选、排序；保存状态持续可见，失败可重试，版本冲突可对比、复制或另存副本。历史材料去重，支持清理历史、备份导出与导入新公文。
- Word、PDF、图片材料复用统一解析/OCR任务；引用保留来源标识及快照，可核对来源变化。每篇公文独立维护导出产物和版本历史。
- 编辑静态显示与服务端导出共用截图版式规则，提供普通/红头选择和实际页面预览。

## 最终版式和间距

| 项目 | 规则 |
| --- | --- |
| 页面 | A4；上3.7、下3.5、左右2.7厘米；页眉1.5、页脚3.0厘米 |
| 网格与行距 | 每页22行、每行28字；固定28磅行距；网格对齐与自动调整右缩进开启 |
| 标题 | 2号方正小标宋_GBK，居中，支持按词意调整梯形/菱形分行；完整标题最后一行后空一行，两行标题同样适用 |
| 主送与正文 | 3号方正仿宋_GBK；主送顶格，正文首行空二字、续行顶格；阿拉伯数字和西文使用 Times New Roman |
| 四级层次 | “一、”“（一）”“1.”“（1）”；字体依次为方正黑体、方正楷体、方正仿宋、方正仿宋，均为3号 |
| 附件说明 | 与正文之间空一行，首行左空二字，长名称悬挂对齐；多份自动编号，不逐项重复添加空行 |
| 署名和成文日期 | 作为整体在前面留三行空白，署名与日期保持相邻行；前面有附件说明时，在说明之后留三行。署名以日期中心排布，日期右空四字，月日不补零 |
| 附件正文与页码 | 附件另起页，标识顶格不加冒号；4号宋体半角页码配左右一字线，主文与附件连续编号 |

DOCX 使用真实空白段落保持所需间距；PDF 按相同行数预留。原稿已有的相关空白行不会在静态预览中重复叠加，保存的原文保持不变。当前渲染器版本为 `docx-2.0.1`、`pdf-2.0.1`。

## 升级

更新代码并重启服务，刷新客户端后生效。新导出使用当前渲染器，已有下载文件不会被改写。相对于上一版本，本次没有新增依赖或数据库迁移；从早于公文改造的版本升级时，仍应执行已有文档库迁移。

本机已核验四种方正原字体、宋体和 Times New Roman；PDF 嵌入对应字形。其他服务器及 DOCX 接收电脑需要按[字体配置说明](../../assets/fonts/official/README.md)配置相应原字体。缺字体会明确提示，标题词意和正式行文内容需在预览中核对。
