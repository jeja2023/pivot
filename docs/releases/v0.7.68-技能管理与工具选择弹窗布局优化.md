# v0.7.68 技能管理与工具选择弹窗布局优化

发布日期：2026-10-29

## 更新内容

### 1. 技能管理面板整体布局与单文件导入区域优化
- **消除底部大面积空白**：重构治理视图下的技能管理主面板（`.agent-harness-panel[data-agent-harness-section="skills"]`）与子视图弹性高度，填充满屏幕视口，彻底消除底部留白。
- **已安装技能卡片升级**：重构双列栅格，左侧面板新增清晰的表头图标与状态徽标，空状态展示轻量居中的指引卡片与快速操作入口。
- **SKILL.md 导入区域增强**：右侧单文件导入区域新增支持拖拽与点击上传的专用文件放置区（动态显示文件名与大小），整合表单字段间距，优化验证与提交操作按钮流向。

### 2. 「选择可用工具」弹窗体验与视觉重构
- **标题栏规范化**：修复原弹窗头部文字与按钮居中堆叠错位的问题，统一采用标准 `.agent-config-modal-head` 弹性布局。
- **消除横向滚动条**：通过弹窗主体 `overflow-x: hidden` 与卡片栅格自适应约束，彻底消除卡片网格底部的横向滚动条。
- **工具卡片质感升级**：
  - 卡片圆角调优（10px），新增平滑选中外边框、淡青色（`#10a37f`）背景高亮与卡片浅阴影；
  - 工具标识（如 `agent.llm`、`agent.content_review`）采用代码药丸胶囊样式（Mono 等宽字体与浅色背景块），防止长标识字符串折行破损；
  - 工具描述支持 3 行省略裁切（`-webkit-line-clamp: 3`），保持工具卡片整体高度均匀美观。
- **工具栏与计数联动**：搜索框输入高度调至 34px，全选/清空按钮与工具栏计数胶囊（`已选 X / Y`）实时动态联动同步更新。
- **去除冗余元素**：清理右上角与左下角多余的关闭按钮与统计文字，底栏「取消」与「确认选择」按钮靠右自然对齐。
- **隐藏原生多选框**：将作为数据存储载体的原生 `<select multiple>` 列表（`.agent-skill-import-tools-hidden`）进行平滑视觉隐藏，收敛至弹窗与已选标签胶囊预览区域。

### 3. 「高级：手动创建或导入签名技能包」弹窗优化
- **清理底部多余按钮**：移除弹窗底栏左侧重复的关闭按钮，操作按钮（「导入技能包」和「创建技能草稿」）靠右对齐。
- **对齐全局红色关闭按钮规范**：右上角关闭按钮切换为全局统一规范，呈现红色文字与淡红边框，悬停时触发平滑红底高亮微交互。
- **弹窗整体尺寸放大**：弹窗宽度扩展至 **980px**，高度扩充至 **780px**，适配大屏编辑场景。
- **代码编辑器体验提升**：`SKILL.md` 工作指引编辑器高度扩充至 **420px**（支持最大拉伸至 580px），采用等宽字体与 1.55 行高，支持 Frontmatter YAML 与工作指引的舒适阅读与修改。
