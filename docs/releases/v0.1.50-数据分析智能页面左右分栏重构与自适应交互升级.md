# Pivot v0.1.50 发布记录：数据分析智能页面左右分栏重构与自适应交互升级

**发布日期**：2026-08-26
**版本号**：v0.1.50
**发布主题**：数据分析智能页面左右分栏重构与自适应交互升级

---

## 🌟 核心更新概览

Pivot v0.1.50 重点重构了数据分析工作台中的 **「AI 智能分析」面板布局体系**。

此前「即时 AI 探索与图表」与「全量语义分析批处理任务」采用上下单列纵向堆叠排布，当上方生成建议或下方生成大篇幅全量报告时，页面纵向滚动条过长，操作体验割裂。

本次更新将其全面重构为 **左右双轨分栏架构（左 46% : 右 54%）**，实现了“即时轻量交互”与“长耗时批处理任务”的双轨并行，配合完善的响应式断点与暗黑模式适配，大幅提升了数据分析工作台的操作效率与视觉质感。

---

## 🚀 详细改进明细

### 1. 左右双轨分栏布局重构
- **黄金比例双栏分配**：
  - **左栏（46% 宽度）**：承载「即时 AI 探索与图表」，提供针对数据集的快捷提问、深度分析开关、生成建议与图表流式输出；
  - **右栏（54% 宽度）**：承载「全量语义分析任务」，提供字段选择、Token 预算、多行任务指令、批次进度条以及全量汇总 Markdown 报告。
- **消除长滚动与操作干扰**：
  - 用户在右侧启动全量大文本批处理任务后，可直接在左侧继续与 AI 进行即时对话和数据探索，互不遮挡、并行不悖。

### 2. 双栏数据集独立选择与列名按需解耦
- **独立选择器**：左栏与右栏各自拥有独立的「分析数据集」下拉选择器；
- **消除列名误填充**：右栏初始进入时默认为“未选择全量分析数据集”，不再自动绑定左侧的数据集，也不会自动将第一列文本字段填入。只有当用户明确在右侧下拉框中选择数据集后，才会按需拉取字段和加载任务历史，完全按需触发。

### 3. 响应式自适应断点（Responsive Design）
- 在宽屏设备（$\ge 1100\text{px}$）上呈现舒展的左右双栏；
- 在笔记本小屏或移动端（$< 1100\text{px}$）下平滑回退为单列纵向自适应堆叠，保障任意屏幕分辨率下的操作舒适性。

### 4. 暗黑模式与视觉对比度调优
- 统一补齐了左侧 AI 探索卡片、右侧全量任务配置框及各类标题说明在深色模式下的背景色与边框对比度，提升一致性体验。
