# v0.7.195 PPT Master 离线制作与续跑修复

- 任务目录盘点接受安全的相对路径。整批动作校验通过后按顺序执行，字段错误可单独重提出错项。模型接收当前项目校验的具体缺项，宿主等资源与规范就绪再校验。
- 首张阶段的基础上限为 16 次上游请求。一次性的有效里程碑可补足最多四轮收尾空间。Pivot 本地窗口、额度和排队拒绝在请求发送前处理，不消耗阶段请求次数。重复检查、持续失败与整项任务的步骤及累计预算各自计量。
- 续跑可添加说明，勾选调整清单时才重新提交清单。项目诊断和超时续跑优先发送当前目标与已登记清单，完整运行包指引仍可定向回读。
- 短引文可从唯一的完整原文补齐。证据不足时，已核对条目继续制作，待核对数据使用占位。标题只保留能安全使用的部分，必要时使用通用待核对标题。
- 新执行器核验同一组内连续可见的标题对象和精确等值金额。页序、数值、权限及正式交付检查继续执行。离线打包检查新执行器能力。
- 冷启动完整性检查允许最多五分钟。启动超时单独提示核对磁盘和容器资源，业务制作动作继续使用原时限。

本次无需新增数据库迁移。旧任务续跑使用原运行身份和任务数据卷。新建模板任务用于验证配套的 PPT Master v6.10.0 镜像。关联合适的生产模型后，核对首张校验、逐轮用量、待核对占位和 PPTX 下载。 [离线部署与续跑](../deployment/PPTMaster独立服务部署与更新.md#v07195-ppt-master-离线制作与续跑)
