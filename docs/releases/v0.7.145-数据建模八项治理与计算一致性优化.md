# v0.7.145 数据建模八项治理与计算一致性优化

日期：2026-11-09。上一版本：v0.7.144。本次将已完成的数据建模八项改造登记为 v0.7.145，并通过既有版本同步脚本更新源码标识与相关文档。没有重新构建镜像、历史归档或桌面安装包，也未部署生产环境。

## 八项改造

| 问题 | 当前行为 |
| --- | --- |
| 预览缺少交付前权限复核 | 任务读取、响应发送和物化提交核对当前账号、模型、全部来源及所需字段。停用或撤权后拒绝旧结果交付，共享未发布模型不能从节点入口读取 |
| 节点执行绕过正式治理 | 预览和物化复用持久队列、统一预算、隔离 Worker、租约代次、取消、幂等与审计；执行关闭、模型归档或修订失效时拒绝新运行 |
| 样本输出变成完整数据、来源丢失 | 数据集、不可变版本、全部来源血缘及任务成功状态同事务确认；保留算子配置、固定来源版本、原截止时间与部分/未知范围，取消或失效执行权不能留下已提交输出 |
| 数值不等于筛错记录 | 等于与不等于使用互补规则，支持自动识别、文本或数值比较；编号需要保留前导零时明确选择文本 |
| 最大最小值按文本排序 | 默认按数值统计，可显式选择文本顺序；求和与均值使用八位定点规则，避免大金额尾数丢失，非法数值提示先清洗 |
| 取消全部字段却输出全列 | 明确取消所有字段时阻止运行并提示至少保留一列；未配置字段选择保留原有兼容行为 |
| 旧预览覆盖新配置 | 结果绑定账号、编辑会话与配置修订；上游变更清除下游字段缓存，迟到响应不应用到新配置，历史/过期结果明确标注 |
| 模型目录只覆盖前二百条 | 服务端搜索、归属/生命周期/数据状态筛选、稳定分页与真实总数；分析来源选择和问数目录同步支持分页。交付复核使用精确时间文本，避免小数秒差异误报冲突 |

## 用户流程与保留规则

- 算子流属于数据准备能力，正式分析继续使用明确绑定的数据集和发布版本。输出完成后可点击“基于输出新建正式模型”，再定义事实粒度、维度和指标并检查发布；不隐式改变历史发布语义哈希。
- 节点运行显示任务状态，可取消或在请求丢失后以原幂等标识重试。重开模型后可查询最近二十条任务；当前任务历史查询具有对应索引。
- 节点预览沿用七天结果保留策略，到期清除数据载荷并提示重新运行。物化数据随不可变数据集版本保留；后续修改字段名称或数据版本不会改写旧输出预览，读取仍复核当前来源及输出字段权限。
- 输出保留所有来源的固定数据版本、来源修订、覆盖声明和水位，整体截止时间采用最早来源时间。部分、增量或未知来源不会通过物化变成完整业务范围。
- 桌面和窄屏复用现有表格、按钮、抽屉、分页及图内滚动；窄屏初始收起组件栏。没有新增依赖、配置项或私有样式体系。

使用步骤见[使用帮助](../../使用帮助.md)，产品语义见[设计规范](../design/DESIGN.md)，逐项实现与原始证据见[八项交付记录](../reports/数据建模八项优化交付-20261109.md)。

## 接口与升级合同

新增迁移 `202611090001_analysis_node_flow`，为 `model_node_preview` / `model_node_dataset` 接入既有任务来源约束、运行监测与历史查询索引；缺少完整血缘的旧 `modeled` 数据集保守标为未知范围并推进当前来源修订，不改写原发布快照。迁移可重复执行。

| 接口 | 合同 |
| --- | --- |
| `POST /api/apps/data-analysis/models/:modelId/node-preview` | 返回 `202 { success, job }`，携带目标节点、来源节点、算子图、`expectedVersion` 和 `requestKey` |
| `POST /api/apps/data-analysis/models/:modelId/node-datasets` | 返回 `202 { success, job }`，另需输出数据集名称；只有任务成功后返回已登记的输出数据集 |
| `GET /api/apps/data-analysis/async-queries/:jobId` | 按当前权限查询状态及固定预览/输出 |
| `POST /api/apps/data-analysis/async-queries/:jobId/cancel` | 沿用现有任务取消合同，终止确认后释放执行资源 |
| `GET /api/apps/data-analysis/models/:modelId/node-jobs` | 返回当前账号在该模型最近二十条节点任务元数据 |
| `GET /api/apps/data-analysis/models` | 提供 `page`、`limit`、`search`、`ownership`、`lifecycle`、`availability`；分页响应为 `models/total/page/limit`，旧无页码读取保持兼容 |

预览默认五十行、最多二百行；节点输出至多一百二十列，物化至多五十万行且不超过二 GiB。更大范围须先筛选或聚合。具体运行与失败恢复见[运行手册](../BI数据建模运行与事故处置手册.md)。

部署时须关闭接纳、排空或取消旧任务并确认执行单元结束，再同步升级数据库、API 与 Worker。就绪探针必须声明 `node_flow` 能力；旧客户端缺少修订或请求标识时提示刷新，不回退至 API 进程内直接执行。不能让只理解旧任务类型的协调器消费新队列，回退继续保留支持新 Schema 的兼容读取端，不执行破坏性降级。
