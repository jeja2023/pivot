# v0.1.63 发布记录：管理员一键共享发布

发布日期：2026-09-01

## 结果

管理员不再需要先单独批准 Skill。验证通过的个人版本可在“共享发布”中直接选择团队或组织并点击发布；服务端会在同一次请求中完成批准、组织签名、完整复验和发布。

## 行为规则

| 发布者 | 目标范围 | 结果 |
| --- | --- | --- |
| 普通用户 | 个人 | 验证通过后可直接发布 |
| 普通用户 | 团队/组织 | 拒绝；不能自行签名或绕过共享权限 |
| 租户管理员 | 团队/组织 | 自动批准、组织签名、复验并发布 |
| 已有有效组织签名的授权发布者 | 团队/组织 | 复用既有签名并按原发布权限发布 |

## 安全边界

- 自动批准只在当前租户管理员发起共享发布、且个人验证已通过时执行。
- 组织私钥始终只从服务端环境或密钥管理读取；浏览器、Skill 配方和数据库均不保存私钥。
- 自动签名后的版本重新通过清单、供应链、声明式检查、沙箱和评测门禁；任何一项失败都会阻止发布。
- 发布审计会记录“自动批准、组织签名并发布共享 Skill”及组织密钥标识。

## 界面变化

Skill 治理窗口的共享区只保留范围选择和“发布共享版本”按钮。成功提示会说明本次操作是否已自动完成批准和组织签名。

- `npm run check`、`npm run lint`：项目静态与规范检查通过。
