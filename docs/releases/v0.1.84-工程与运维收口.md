# v0.1.84 发布记录：工程与运维收口

发布日期：2026-09-05

## 一、更新背景

在智枢系统完成多轮架构加固、多端上下文审计契约规范化以及模型原生 Tool Calling 自适应降级演进后，系统在面向生产环境的高可用交付、企业内网部署验收、持续集成效率与长期可维护性方面进行了全面的工程与运维收口：

1. **架构与审计收口**：将沉淀的核心运行时架构拆分（Agent 运行时三层解耦、MCP 路由分层、对话意图识别与图谱抽取算法独立）和统一 `AgentStepContext` 审计快照持久化协议正式收口归档；
2. **前端与工程质量门禁全覆盖**：业务脚本全局变量访问全面收敛至受控的 `window.Pivot.modules` / `window.Pivot.legacy` 体系，彻底删除历史全局基线豁免，通过 AST 门禁严格阻断新增自由业务全局暴露；同时将 HTML 片段 AST 标签配对平衡、未等待异步数据库调用强阻断、核心热路径同步 I/O 消除三大门禁全面固化至常规 CI 与提交检查流；
3. **自动化测试与回归稳定性加固**：优化测试套件中的异步挂起与泄漏风险，针对 SSE 流式测试增加有界超时兜底并在服务关闭时主动清理连接；PostgreSQL 测试运行器支持原生测试用例名筛选，避免单例排查时的全量执行与无限等待；
4. **依赖现代化与零开销外部探测体检**：全面升级基础核心框架至 Express 5、Playwright 1.63 以及最新数据库驱动与安全依赖，修复并清零全部已知依赖漏洞；新增 `npm run check:external:live` 实时体检工具，通过零生成开销的模型列表探测、Embedding 探针、外部 MCP ping 与数据库只读连通性校验，确保内网开箱验收的安全与高效。

## 二、核心变更与技术实现

### 1. 运行时与审计治理收口
- **Agent 运行时三层领域解耦**：彻底收敛 `server/services/agent-runtime/index.js`，固化 `run-state.js`（状态机流转与执行状态维护）、`run-lifecycle.js`（生命周期管理、超时与完成态收敛）与 `run-execution.js`（单步规划、模型调用与工具编排）；
- **MCP 路由与能力解耦**：固化 `server/routes/mcp/configuration-routes.js` 与 `management-routes.js`，将 `chat-mcp-intent.js` 与 `knowledge-graph-extraction.js` 算法完全解耦为无副作用的纯计算模块；
- **统一 Agent 上下文审计协议**：在 `agent_tool_calls` 表增加 `context_snapshot`（JSONB）及 `contextHash` 索引，定义 `AGENT_STEP_CONTEXT_SCHEMA_VERSION = 1`，使 Web 对话、Agent 工作台与 Desktop 桌面端均固化不可篡改的标准上下文快照；
- **流式双轨采样器稳定运行**：基于 `createStreamingSnapshotSampler` 实现 UI 渲染防抖节流与审计事件分步归集，并在终态（`finishReason`）触发时强制保全快照落盘。

### 2. 前端全局收敛与质量门禁强校验
- **前端全局受控治理**：前端全部业务模块与组件的全局交互收敛至 `window.Pivot.modules` 与 `window.Pivot.legacy` 规范体系；删除旧有的宽松历史豁免基线，通过静态 AST 扫描门禁阻断任何未经审查的自由 `window.*` 业务挂载；
- **HTML 片段标签栈 AST 平衡校验**：`scripts/check_chat_assets.js` 结合 `parse5` 与 `acorn` 深度分析所有静态 HTML 片段与 JS 模板字符串中的 HTML，严格校验标签配对完整性与合法 Void 标签，杜绝浏览器渲染歧义；
- **未等待异步/数据库调用强阻断**：`scripts/check_async_db_calls.js` 启用 `--enforce` 强阻断模式，配合白名单签名基线，禁止任何新增未捕获/未等待的 Promise 或 DB 语句；
- **请求热路径同步 I/O 门禁**：`scripts/check_sync_io_hotpaths.js` 自动阻断核心路由与上传下载中的同步文件操作，确保主线程高吞吐无阻塞。

### 3. 回归测试稳定性与高效单例调试
- **SSE 流式测试有界超时保护**：聊天路由集成测试装置为本地 SSE 连接增加精确超时控制，在测试服务关闭（`close`）时主动清理未断开的套接字与悬挂定时器，消除测试进程假死；
- **PostgreSQL 测试用例原生精准筛选**：优化测试启动脚本，支持通过命令行传入针对用例名称的精确正则过滤，允许开发者在分钟级全量套件外瞬间完成单个边缘用例的诊断与复验，避免失败路径挂起。

### 4. 依赖升级与零开销外部探测体检
- **现代化依赖底座升级**：
  - 核心 Web 框架全面升级至 **Express 5**，享受原生 Promise 路由错误捕获与路由性能优化；
  - 端到端测试底座升级至 **Playwright 1.63**；
  - 全面更新核心 PostgreSQL 驱动（`pg`）、安全加解密依赖与桌面端运行时包，通过 `npm audit` 实现生产与开发依赖漏洞全部清零；
- **零开销外部配置验收工具 (`npm run check:external:live`)**：
  - 提供开箱即用的实时探针，仅通过拉取模型目录、轻量 Embedding 校验、MCP Ping 以及数据库只读探针快速验证多模型、知识库与工具库连接；
  - 过程绝不调用实际的大模型推理生成（Zero-Cost Token），同时对敏感地址、账号与密钥建立严密的脱敏边界，适应企业等保合规交付。
