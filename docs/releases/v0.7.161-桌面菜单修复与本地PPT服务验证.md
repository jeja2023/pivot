# v0.7.161 桌面菜单修复与本地 PPT 服务验证

日期：2026-11-16。启用源码版本 v0.7.161；此前的 PPT Master 制作弹窗与模板库优化继续归档于 [v0.7.160 发布说明](v0.7.160-PPTMaster制作弹窗与模板页深度优化.md)。

## 桌面菜单

修复桌面客户端左上角“Pivot 智枢”按钮点击后没有菜单的问题。菜单脚本原先调用不存在的 `Pivot.module()`，初始化时抛错，未绑定点击事件；现改用项目模块注册表提供的 `Pivot.moduleApi()`。菜单继续提供原有服务器连接、受控交付、客户端更新、显示、维护和退出操作。

回归测试加载实际的前端模块注册表和更新错误模块，验证菜单初始化、点击展开、再次点击关闭和更新入口，不再模拟不存在的模块接口。

## 本地 PPT Master 服务

本地 Windows 开发机使用固定上游版本和当前适配器源码构建 `pivot-ppt-master:local-dev`，以独立容器运行，服务只映射到 `127.0.0.1:8502`。本地 `.env` 服务地址已调整；已运行的 Pivot 进程需重启以读取该环境配置。服务仍使用鉴权和隔离任务执行，本机运行状态及配置不是生产发布制品。

未配置独立服务且没有其他可用完整执行器时，PPT Master 模板的制作按钮不可用；标准 PPT 创建和编辑仍可使用。生产环境反复出现模板工作区校验失败时，应按 [PPT Master 独立服务部署与更新](../deployment/PPTMaster独立服务部署与更新.md) 核对是否已部署包含 v0.7.159 工作区适配修复的独立服务镜像，并在升级后新建任务；仅有相同上游版本号不能证明镜像已更新。

## 验证与限制

- `node --test tests/desktop-menu-updates.test.js tests/desktop-update-errors.test.js`：8 项通过，包括菜单展开、关闭及更新错误行为。改动文件 ESLint 与 `check:standards` 通过。
- 本地服务鉴权通过；通过真实 HTTP 接口逐项复制和校验 14 个内置模板，全部通过。此结果不代表真实模型生成完整 PPT 或生产服务验收通过。
- 校验后测试任务清理返回 HTTP 500；已确认复制的模板包含只读目录，本次测试遗留目录已清理。自动清理问题尚未修复。
- 客户端窗口截图超时，未完成真实桌面窗口点击复验；未运行全仓测试或生产验收。此前 v0.7.160 的测试证据保留原执行版本，见其发布说明。

## 升级

更新 Pivot 主应用并刷新客户端页面以加载新的菜单脚本；不新增依赖、数据库迁移或桌面 IPC。菜单修复位于服务端页面资源，不要求为此单独重装桌面客户端。升级后应在实际客户端点击验证菜单。

本次未构建、发布或部署 v0.7.161 的 Pivot 主应用镜像和桌面安装包；本地 PPT Master 镜像不等于生产镜像或生产验收结果。
