# v0.7.169 任务详情与工作流编排体验修复

日期：2026-11-17。本版启用源码版本 v0.7.169，包含此前尚未部署的 [v0.7.168 PPT 制作与技能治理修复](v0.7.168-PPT制作恢复与技能治理修复.md)。本次未构建或部署新制品。

## 任务详情

- 任务工作区和大模型对话的任务详情统一显示可操作的完整记录与诊断提示；加载期间避免重复请求，失败保留当前内容并允许重试。刷新时保留提示和焦点，加载成功后移除提示。
- 切换任务、返回列表及关闭详情时隔离请求和界面状态，避免旧任务内容或重复提示残留。任务详情按钮绑定一次，避免一次操作重复触发。

## 工作流编排

- 新建空白或模板草稿时通过弹窗输入名称，未保存的草稿可在“更多工作流操作”中修改；已保存工作流的名称和简介仍在资产列表编辑。顶部选择器只展示一次名称，长名称可悬停查看。
- 工作流切换框限制宽度并可随窗口收缩；更多操作菜单统一图标和文字对齐，窄屏时保持在窗口内。
- 查看结果弹窗覆盖工具栏，关闭操作在窄屏可达；打开时将焦点移入，关闭后恢复焦点。关闭编辑器时同步关闭结果弹窗。

## 升级与兼容

从 v0.7.168 升级无需新增数据库迁移、第三方依赖或桌面 IPC；更新主应用并刷新页面即可使用本版任务与工作流界面。如果从更早版本直接升级，还需遵循 [v0.7.168 升级说明](v0.7.168-PPT制作恢复与技能治理修复.md)：文件分页和文字校准需更新独立 PPT Master 服务镜像，并保留数据库、CAS、技能目录及 PPT 工作区，处理在途任务后再切换服务身份。

已有本机助手开发验证包仍为 v0.7.164；源码升版不代表安装包、镜像或生产环境已更新。
