# v0.1.100 发布记录：审计整改收口与桌面交付优化

发布日期：2026-09-08

## 版本摘要

本版本集中完成 v0.1.84 审计线索中除暗色主题未完整接线、`stealthSecret` 分发模型外的工程整改与优化，并将开发机配置、正式桌面分发配置和自动更新策略明确分离。

## 主要变更

- 数据库 MCP 只读治理补齐 `SELECT INTO`、`OUTFILE`、文件读取、序列修改、锁、睡眠和进程控制等副作用边界；用户自带 `LIMIT` 会被夹取，IPv6 等价回环地址统一拦截，共享连接强制显式表白名单。
- 权限能力矩阵接入服务端关键接口；Access Token、Refresh Token、API Key、密文信封和审计详情完成安全加固。
- Agent DAG 非幂等恢复必须重新审批；节点重试使用稳定的 `run + node + inputHash` checkpoint key；运行元数据改为可重试 CAS 补丁。
- 模型流、SSE、健康检查、写入队列、存储 GC 和优雅关闭路径完成可靠性优化；关闭时会释放 SSE、沙箱和能力工作进程。
- 个人、应用、Agent、工作流、知识库、工具库和设置工作区统一使用受控模块 API；Agent Runtime 只导出具名领域 API。
- 隐藏工作区改为同源按需模板；聊天 CSS 生成单一受校验 bundle，并删除无引用的历史样式选择器。
- 远程桌面包默认不携带本地 Agent Chromium，本地档位才注入；正式发布配置、HTTPS 更新和构建事务恢复机制完成优化。
- Docker 与桌面包默认移除未启用的 MySQL、SQL Server、MongoDB 连接器依赖闭包。
- `DATABASE_URL` 仍校验 PostgreSQL URL 格式，但不再因存量数据库密码复杂度不足阻止启动，兼容当前可用密码。

## 桌面配置

- 开发机根目录 `config.json` 保持 `http://127.0.0.1:3000/`、开发 session 和关闭自动更新。
- 正式构建使用独立 `PIVOT_DISTRIBUTION_CONFIG`；普通用户安装后无需自行准备 `config.json`。
- 正式 Windows 发布仍需 HTTPS 更新源、发布者和代码签名凭据。

## 验证结果

- Node 完整回归：964/964 通过；两个隔离 PostgreSQL 分组分别为 502/502、462/462。
- 覆盖率：行 78.11%、分支 64.33%、函数 80.46%。
- 浏览器 E2E：15/15 通过。
- `npm run check`、ESLint、依赖审计策略和差异检查通过。
