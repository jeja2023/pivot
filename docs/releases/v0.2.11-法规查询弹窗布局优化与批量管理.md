# v0.2.11 法规查询弹窗布局优化与批量管理

发布日期：2026-10-12

## 概述

本版本重点针对法规查询应用的弹窗布局与界面视觉规范进行重构优化，彻底解决弹窗内部区域框与外边框无留白、贴边紧绷的交互缺陷；同步落地法规文档的多文件批量导入、批量修改元数据与批量删除管理闭环；并对个人工作台顶栏的冗余帮助入口进行收敛，统一全局导航与交互规范。

## 详细变更

### 1. 法规查询弹窗布局与留白重构

- **弹窗主体内边距与呼吸感重构**：
  - 重构 `.apps-workspace-modal .workspace-modal-body` 容器样式，将弹窗内容区域内边距统一规范为 `20px 24px 24px !important`，元素纵向间距规范为 `gap: 16px !important`。
  - 彻底解决三大核心弹窗（“批量修改法规信息”、“导入文档”、“检索法规”）内部卡片/表单区域框与外层弹窗边缘无留白、紧贴边框的视觉挤压问题，带来舒适清晰的视觉呼吸感。
- **结构化卡片分组与视觉层次优化**：
  - **批量修改弹窗 (`#regulations-batch-edit-modal`)**：将分类、发布机构、适用范围和状态表单整体封装至 `.regulations-admin-group` 卡片容器中，配备专属标题行（`.regulations-admin-group-header`）与勾选更新操作提示，使修改项与确定操作区分离清晰。
  - **检索法规弹窗 (`#regulations-search-modal`)**：将关键词、发布机构、状态、分类等检索表单项包裹于 `.regulations-admin-group.regulations-search-group` 卡片中，补充副标题与指引文案；已保存检索条件卡片（`.regulations-saved-search-item`）优化圆角与悬浮反馈，形成协调统一的层次设计。
  - **导入文档弹窗 (`#regulations-import-modal`)**：重构导入模式与多文件选择说明文案，统一主次按钮层级与内外留白。
- **操作按钮与样式编译**：
  - 优化弹窗操作按钮行（`.regulations-admin-actions`）间距与外边距，主要操作高亮与次要操作取消对齐全局规范。
  - 重新编译并打包压缩前端样式文件 `client/chat/chat.workspace.apps.css`。

### 2. 法规查询批量操作与管理闭环

- **多文档批量导入**：
  - 系统管理员（admin）在“导入文档”弹窗中支持一次性选择并上传多个法规文件，自动解析与入库，大幅降低规章制度初始录入与集中更新的操作成本。
- **批量处理模式与当页全选**：
  - 法规列表新增“批量处理”切换入口，开启后动态展开勾选列并浮现底部批量管理工具栏；提供快捷全选/反选本页操作。
- **元数据统一批量修改**：
  - 支持对选中的多条法规统一更新分类、发布机构、适用范围和状态。
  - 采用细粒度字段级勾选控制，仅被勾选的属性会被更新；已勾选属性若文本留空则安全清空原值，避免意外覆盖无关字段。
  - 严格沿用管理员权限校验，保障法规数据修改的合规性与安全性。
- **批量安全删除与容错处理**：
  - 批量删除功能仅限超级管理员（admin）执行，触发前具备明确的数量确认机制，防止误操作。
  - 翻页或主动退出批量处理模式时自动清空选择状态；当部分文档因并发或校验导致处理失败时，系统精准反馈失败原因并保留失败项的选择状态，方便用户一键排查并重试。

### 3. 个人工作台交互规范与导航清理

- **清理顶栏冗余使用帮助入口**：
  - 移除个人工作台页面头部右侧的“使用帮助”按钮，消除与左下角全局导航“帮助”按钮的功能重复。
  - 收敛桌面工作区顶栏视觉焦点，统一全系统“使用帮助”唯一的全局访问路径（左侧全局底栏与 `/manual` 独立访问）。
- **样式与测试用例同步维护**：
  - 清理 `client/chat/styles/workspaces/personal.css` 中废弃的 `.personal-workbench-header-actions` 样式定义，重新构建 `client/chat/chat.shell.css`。
  - 更新 `tests/personal-workbench.test.js` 自动化回归测试，确保帮助入口单一性与工作台顶栏元素断言准确。

### 4. 系统监控健康检查项中文化

- **健康检查名称中文化补齐**：在 `client/chat/stats-monitor.js` 的 `HEALTH_NAME_MAP` 中补齐 `decisionProviders`（“决策服务提供方”）、`decisionDeployment`（“决策部署就绪”）与 `agentBrowser`（“浏览器运行时”）等检查项的中文名称映射。
- **消除原始标识直出**：修复“健康与维护”矩阵卡片在展示外部决策服务提供方健康探针时直出英文键名 `decisionProviders` 的问题，使系统监控健康矩阵全面保持优雅一致的中文界面体验。
- **契约测试固化**：在 `tests/settings-page-contract.test.js` 中增加针对 `decisionProviders` 中文化映射的断言保护，杜绝后续迭代发生回归。

### 5. 法规混合检索性能与 HTTP 响应头防护加固

- **混合检索并行化与超时缩短**：重构 `searchRegulationArticlesHybrid`，采用 `Promise.allSettled` 并行发起词法检索与向量嵌入计算；将交互式检索向量超时从 10,000ms 缩短为 4,000ms，在外部向量模型服务发生网络抖动、欠费或响应迟缓时，在毫秒级无感知优雅降级为词法检索，避免请求堆积。
- **响应头已发送（ERR_HTTP_HEADERS_SENT）防御**：
  - 在法规检索相关接口（`/search/hybrid`、`/articles/:articleId/similar`、`/documents/search`）中调用 `res.json` 前增加 `res.headersSent || res.writableEnded` 前置判断，杜绝超时响应已发出后的二次写入。
  - 增强底层 `asyncHandler`（`server/http.js`），在检测到响应头已发送或捕获 `ERR_HTTP_HEADERS_SENT` 时，安全结束响应流（`res.end()`）且不再向后级全局错误中间件传播错误。
  - 完善全局错误处理器（`server/app.js`），在响应已发送且错误为重复响应头异常时，不再误记录为虚假的系统 500 审计日志。
- **前端网络异常容错**：在法规检索入口（`runSearch`）增加网络与服务端异常捕获，在接口异常时及时通过 Toast 提示用户并重置加载状态，提升排障与交互体验。

## 升级与兼容性说明

1. 本版本为纯前端视觉样式优化与管理能力增强，不涉及数据库破坏性迁移与后端破坏性变更。
2. 历史法规数据与条文解析索引完全兼容，升级后直接刷新页面即可生效最新弹窗样式与批量处理功能。
