# v0.1.67 发布记录：Agent 控制台日常入口收敛

发布日期：2026-09-01

## 结果

Agent 控制台原“能力与治理”入口改名为“技能与助手”，日常界面仅保留两个页面：

| 页面 | 用途 |
| --- | --- |
| 我的智能助手 | 设置个人档案、沟通偏好、记忆与隐私策略 |
| 技能 | 创建、验证、发布和管理个人或共享 Skill |

## 默认收起的能力

- 常驻实例：属于会话/任务复用诊断，保留服务端能力但不再在日常界面加载或显示。
- 进化提议：属于实验性治理和人工审核，保留服务端能力但默认隐藏。
- 运行资源包：仅保留内部安全实现，由 `PIVOT_RUNTIME_PACKS_CONSOLE_ENABLED=true` 和系统最高管理员临时开放。

## 设计原则

- 个人偏好与记忆边界属于“我的智能助手”，不再拆成两个需要理解治理术语的页面。
- 技能是当前唯一面向用户的可配置能力入口，保持可见。
- 运维、实验和未完成业务闭环的能力不占用普通用户视野，也不在进入页面时产生额外请求。

## 验证

- Harness 入口契约覆盖“档案与记忆合并、技能保留、高级页隐藏”。
- `npm run check`、`npm run lint` 通过。
