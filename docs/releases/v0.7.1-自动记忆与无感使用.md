# v0.7.1 自动记忆与无感使用

正常聊天和执行任务即可在后台形成可复用记忆，不需要点击“记住”、打开第二个输入弹窗或逐条维护。默认自动采集与调用不弹通知、不阻断回复；设置保留查看、删除、导出及长期记忆总开关。

## 实现

- 复用持久化抽取队列，解除与任务经验学习开关的耦合；任务续接同样采集用户补充。模型临时失败时先规则兜底，再有限次后台重试；向量恢复继续由现有维护任务负责。
- 模型候选必须引用真实用户消息和可核对原文。引用、代码、附件、问句、假设及用户明确要求不保存的内容不自动转为个人事实；临时要求仅留在会话范围。
- 自动推断个人、项目、会话范围。新增抽取任务的 `project_id` 持久字段，贯通普通回复和 Agent 完成通知；未知项目不能扩散为个人事实。
- 常见回答偏好按语言、顺序、篇幅、格式统一属性，相关偏好自动注入普通问题。当前输入与项目要求继续优先。
- 用户级门禁锁内重新查重和检查来源先后顺序，防止并发重复与延迟旧任务覆盖新值。单条遗忘仍抑制重建，但不关闭同会话其他新偏好的采集。
- 同一句话中的多个偏好拆开维护；用户要求仅限当前会话时不会扩散到同项目的其他会话，任务经验事实也收窄到来源范围。
- 移除输入框记忆菜单、独立弹窗及其事件与样式；保留语音输入和设置入口。高级采集/确认/类别策略默认折叠，尊重用户已有设置。

## 部署与验证

重启服务后自动执行新增项目范围字段的幂等迁移；已有记录和主动关闭的开关保留。无需重新采集全部历史对话。
