# v0.7.128：PPT原稿编辑与离线视频

日期：2026-11-08。

PPT制作新增“原稿编辑与离线视频”。无需模型或公网，可从上传PPTX、当前工作台文稿或完整制作结果打开原生包，在浏览器修改支持的对象，保存版本并下载；导出文件可再次导入继续编辑。

- 定点适配富文本、Office公式、纯色与线性渐变、自由路径控制点、位置尺寸、组合、表格和同结构分类图表/嵌入工作簿。原对象身份、未修改页面及未映射内容继续保留。
- 原稿和预览持久保存，按租户/账号隔离；保存检查预期版本，支持历史版本恢复，旧窗口和失效租约不能覆盖新稿。
- 禁网容器使用LibreOffice、Poppler和FFmpeg导出页面视频，支持本地逐页旁白、720p/1080p、24/30帧和直接切页/淡入淡出，明确区分静态页面视频与原生动画保真。
- 后台任务支持进度、取消、租约、并发接纳和检查点恢复，临时目录有清理策略；原稿及文件使用既有CAS，MP4沿用Artifact、Rendition和受控下载。

编辑仅覆盖明确字段。SmartArt/OLE内容、母版和兼容分支保持原稿；页面视频不播放原生对象动画和嵌入视频。LibreOffice预览与PowerPoint可能有字体或复杂效果差异。

仍使用通用镜像名 `ppt-master:6.8.0`，本轮新增本地渲染器，须重建并登记新摘要及正式签名。开关默认关闭，未部署生产或构建桌面安装包。

详见[离线部署与支持范围](../deployment/PPT原稿编辑与视频离线部署.md)、[验证报告](../reports/PPT原稿编辑与离线视频验证-20261108.md)。
