# v0.7.139：智能体工具发现与准备进展修复

日期：2026-11-09。承接[v0.7.138](v0.7.138-智能体执行与交付验收可靠性升级.md)，本版修复智能体发现工具和执行前准备的衔接问题，同步帮助文档及诊断、复验记录。

## 修复后的行为

- 工具搜索接受的文字风险等级与目录规范化后的数字等级按同一语义精确匹配，沿用现有风险转换逻辑；保留旧数字筛选和零值。未知或越界值不匹配，零值在候选输出、目录摘要和缓存键中保持有效。
- 能力、来源和风险是可选精确筛选，不是自然语言任务描述。首次通常只需要关键词与候选数量；空结果会区分“无授权工具”“筛选条件未匹配”和“关键词未命中”，反馈当前任务授权范围内的可用条件，供模型修正检索。
- 已有工具但检索未命中时，不再直接提示用户重新授权。系统不自动删除筛选、不扩大目录或放宽审批，重复空搜索仍有界停止，缓存继续以实时授权、任务范围和发布摘要校验。
- 首次读取每个工具的有效契约获得一次有界准备机会，避免准备阶段尚未执行业务操作就触发无进展停止。重复读取、换版本、空搜索和无效契约不能反复延长窗口；准备不计业务进展或自动续跑依据，已有轮次、Token、工具次数、风险和副作用限额继续执行。
- 用户帮助补充了检索未匹配、必要准备与等待业务输入的区别。报销登记缺少收款账号时，应读取资料后询问并等待，不猜测账号或先行登记。

实现复用现有工具目录、风险规范化、授权/审批和持久化预算。没有新增运行时、外部依赖、环境配置或数据库字段，未通过扩大默认预算达成复测结果。
