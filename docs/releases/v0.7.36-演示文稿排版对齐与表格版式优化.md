# v0.7.36 演示文稿排版对齐与表格版式优化

发布日期：2026-10-23。版本类型：演示文稿排版缺陷修复、正文标题标柱对齐、版本交互升级与 Markdown 表格版式优化。

本版本重点解决用户在实际使用 PPT 编辑工作台与大模型对话时反馈的排版与交互问题：
1. **封面页排版窜行治理**：修复议程卡片文字被误判定为副标题文本流导致纵向堆叠重叠、多余空白底板叠加以及与页脚碰撞的排版缺陷；
2. **正文标题左侧标柱统一样式**：修复单栏内容页标题装饰规则匹配，使其与多栏卡片页等统一呈现 12px 宽圆角青色标柱与呼吸间距；
3. **版本管理交互升级**：顶部控制栏常驻“保存版本”快捷操作，修复版本记录抽屉中“恢复”按钮的样式与对齐；
4. **Markdown 对话表格右侧空白修复**：优化流式输出下多列表格的自适应排布，消除右侧异常留白。

## 1. 具体变更

| 范围 | 本版行为 |
| --- | --- |
| **封面排版防窜行** | 修复 `server/services/presentations/presentation-template-reflow.js` 中 `reflowCoverDescriptions`，增加卡片与导航文字过滤判定，防止议程文本被误吸入副标题描述流；阻断多余的 `cover_nav_panel` 空白底板重复生成；页脚元信息下移并加入障碍避让，杜绝重叠碰撞 |
| **正文标题标柱统一** | 修复 `server/services/presentations/presentation-templates.js` 中装饰匹配正则 `/(?:^\|_)title_bar$/`，让 `title-content` 布局正确匹配并生成 12px 宽、44px 高、圆角 3px 的青色标柱（`#17A8C7`），与 `three-card` 等其他版式保持完全一致 |
| **版本管理与控制栏** | 将“保存版本”按钮从右侧折叠抽屉抽离至顶部控制栏常驻显示，支持一键创建里程碑版本；修复版本面板中“恢复”按钮与操作列的对齐及主次样式 |
| **模板列表卡片还原** | 恢复模板选择器为原有的紧凑网格视图，避免卡片占幅过大遮挡或挤压画布空间 |
| **Markdown 表格排版** | 优化 `client/chat/styles/base/markdown.css` 中表格容器样式，修复流式回复渲染时多列或长文本表格右侧异常大面积留白的问题 |
