# v0.7.117 — BI 独立安全日志与恢复授权核对

本次完成建设方案第 22.4 节的独立安全事件、确认后完成和恢复授权核对，并保持现有模型、来源、字段和交付栅栏。数据库/文件物理共同恢复点、完整离线交付和目标生产验收继续分别推进，版本号不表示 G0—G7 放行。

## 实际行为

- 主事务记录账号、来源、模型、字段和分析共享资产的安全修订，以及 BI 审计事件；前后摘要、稳定事件、真实数据库登录身份和可信请求主体可追溯。独立记录不含密码、密钥、原始 SQL、结果和字段原值。
- 主库收紧权限后，只有独立加密日志落盘并确认才返回完成。副本失败返回明确的“已生效、待确认”，不回滚已收紧权限，也不让新增授权在确认前读取。原子不可覆盖发布、事件幂等、连续位置与摘要链覆盖追加后未 ACK 的断点。
- 历史清单回填使用持久主键游标、计数和有限事务，可中断续跑；并行安全变化不会被旧基线覆盖。回填、全部独立确认和完整性保护完成前不开放读取。
- 安全强制标记持久保存；关闭重型执行开关、移除配置、重启进程和旧探索入口不能绕过已启用的确认要求。安全捕获保护丢失时停止读取并记录恢复关闭，修复触发器不自动恢复业务。
- 恢复旧库后先关闭读取、重放撤权和删除墓碑，失效旧 Token、API Key、槽位及执行代次；自动刷新与业务告警暂停。不能证明最新撤权时继续关闭，要求当前身份源与业务授权负责人完成独立 Ed25519 签认。
- 当前签认绑定实例和安全高水位，覆盖全部恢复主体与分析共享资产，并核对活跃账号凭据指纹。篡改、缺项、错误凭据和过期证明均拒绝。签认应用后副本确认中断可以沿同一证明继续确认，避免重复提交。
- 运营监测展示安全模式、独立副本可用性、待确认年龄及回填进度，复用现有告警路由。提供固定边界的日志核查、重放、待核对草稿、独立签名和当前授权核对命令。

- 千模型真实 HTTP 目录、就绪和安全交叉回归 13 项通过，0 失败、0 跳过；包括分批回填续跑与并行当前变更。目录延迟见 `.codex-tmp/bi-m5-security-seventh.log`。批量清理需要完成同一已提交事务的独立确认，不重新执行删除。
- 全量 `npm run check`、`npm run lint` 和 `npm run typecheck` 通过。原始 SQL 仅按实际仓储与安全边界逐文件审查，未新增异步调用豁免。
- 浏览器建模全流程和真实共享收紧待确认页面 2 项通过。测试在权限写入已通过前置读取、等待主库提交时中断独立密钥，确认共享实际已转为私有、页面明确显示已生效待确认；修复密钥并等待同一 outbox 完成后继续使用。桌面、移动端与待确认页面截图均已检查。全量自动化总验收在 M5 各项开发完成后执行。

本地 Windows 的文件 fsync 和测试目录分离只构成功能证据；Linux 目录 fsync、生产独立身份/主机/存储、密钥保管和完整物理恢复均须各自验收。历史容量证据仍对应 v0.7.116 的固定源码指纹，不能改写为本版或生产认证。
