# v0.2.12 法规查询全面优化与治理闭环

发布日期：2026-10-12

## 概述

本版本完成法规查询应用的正确性、可追溯性、治理协作和批量维护闭环。法规检索、AI 问答、导入、版本、引用、来源定位、回收站与个人使用体验不再是彼此独立的功能点，而是围绕“可验证的法规版本和条文依据”协同工作。

## 主要变更

### 1. 权限、可见性与版本正确性

- 统一文档、条文、批注、相似条文、版本对比、引用图和 AI 依据的可读范围：已删除法规不会通过关联接口泄露；普通用户默认看不到归档法规。
- 管理状态、法律效力和删除状态分离。版本支持发布日期、生效/失效日期、待核验/待生效/现行有效/失效/废止及审核状态；可按指定日期查看当时适用的版本。
- 引用关系保存来源版本、目标版本、固定/随当前版本绑定模式、证据摘录和审核状态；重建跨法规引用时会更新随当前版本变化的关系，保留历史固定引用。
- 版本对比支持重复条号场景，引用图正确保留关系类型。

### 2. 检索、AI 问答与证据链

- 关键词与向量检索独立召回并进行排名融合，关键词强命中不会因缺少向量被丢弃；向量检索和相似条文严格校验模型配置指纹，避免同维度不同模型混算。
- 检索可在后端按分类、发布机构、适用范围、状态筛选；法规名称别名参与召回，长条文摘要围绕真实命中位置截取。
- AI 问答支持法规库/当前法规范围、SSE 流式生成与停止按钮；回答依据携带文档、版本、条文和关联关系。
- 每次成功问答会保存问题、回答、模型、上下文快照、版本化来源和用量；详情页可查看个人问答记录。
- 问答报告支持导出 Markdown、Word 与 PDF，Word/PDF 统一使用项目 Document IR 渲染器生成。

### 3. 导入、解析与来源追溯

- 导入改为可恢复的持久化队列，展示进度、失败原因，支持排队取消、失败/取消后重试与进程重启恢复。
- 导入预览可编辑条号、标题、正文和章节路径，可合并相邻条文；确认后将校正结果直接作为入库内容。
- 空正文、无可用条文及不安全源文件路径会明确失败，不再创建空法规。
- 文件指纹可识别完全重复文件；管理员可选择“继续并标记重复”或“跳过完全重复文件”。
- 条文保存页码、字符范围、块序号和置信度；PDF 可打开同一版本的来源页，其他格式可受权限保护地下载原文件。
- 解析器补齐章/节层级和同一行连续条号识别，并记录稳定条文键与检索状态。

### 4. 治理、协作与持续更新

- 新增法规质量概览，集中显示待核验元数据、版本治理、索引、引用、来源定位和义务审核项。
- 用户可关注法规更新；仅当版本为“审核通过的现行有效”时才推送通知。
- 合规义务可记录主体、触发条件、要求动作、期限、凭证和责任人；管理员审核通过后转为待办并通知责任人。
- 支持个人法规收藏及专题整理，不改变公共法规元数据。
- admin 可在法规回收站恢复软删除法规；超过保留期后只清理原始源文件，仍保留法规和版本审计元数据。

### 5. 批量治理与可恢复操作

- 点击“批量处理”才显示选择列和操作栏，选择跨页保留，表头复选框仅影响当前页并明确显示跨页选择数量。
- 可批量修改分类、发布机构、适用范围和状态；每项记录修改前后值。
- 可撤销一次批量修改；撤销前会检测该法规是否已被后续编辑，发生变化时不会覆盖新内容。
- 批量删除仅限 admin，保留失败项和明确失败原因，并可从回收站恢复。

## 数据库升级

新增并自动应用以下 PostgreSQL 迁移：

- `202610120003_regulations_governance_foundation`
- `202610120004_regulations_collaboration`
- `202610120005_regulations_ai_audit`
- `202610120006_regulations_batch_audit`
- `202610120007_regulations_bookmarks`

升级前请正常备份数据库；迁移均为增量、幂等的 `CREATE/ALTER ... IF NOT EXISTS` 或兼容更新，不会删除现有法规记录。应用升级后重启服务即可执行迁移。

## 外部来源边界

系统已支持登记官方来源地址、版本来源地址、审核人和审核后通知。第三方权威网站的自动抓取未在本版本默认启用；如需接入，组织应先明确允许来源、访问方式、更新频率及人工审核责任人。
