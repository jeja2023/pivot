# v0.4.3 路由复核命名收敛

发布日期：2026-10-19

## 版本摘要

“决策审核”统一入口中，原“反馈核验”子页正式更名为“路由复核”。新名称准确限定了该流程的职责：管理员复核用户针对检索、工具调用和回复方式的路由建议。

## 用户可见变化

- 子页签、动态页面标题与说明显示“路由复核”。
- 队列筛选中的 `pending` 显示为“待复核”。
- 表格操作列、详情弹窗、复核状态、备注输入和完成提示统一使用“复核”。
- “金标审核”名称和双人独立一致规则保持不变。

## 不变的治理边界

`route-feedback` 仅是稳定的内部标识与 API 路由，未因页面命名改变而迁移或修改。采纳路由建议仍只形成受控训练候选；它不会自动成为金标，也不会解除冻结评测集所要求的双人一致和发布门禁。
