# v0.7.60 个人工作台入口与顶部体验优化

发布日期：2026-10-28

## 更新内容

- 工作台顶部输入框统一用于开始 Agent 任务，输入目标后点击“开始处理”进入任务设置；“整理待办”“项目风险”“安排自动化”仍可作为示例快速填入。
- 移除顶部与左侧导航重复的“在对话中继续”入口；普通对话从左侧“对话”进入。
- 删除重复的表单提交监听，避免同一次提交触发两次处理。
- 压缩顶部说明，并调整任务说明与示例在窄屏下的排列。
- 搜索快捷键提示按平台显示：macOS 为 `⌘ K`，Windows 和 Linux 为 `Ctrl K`；原有快捷键行为保持不变。

## 验证与更新

个人工作台及个人助手相关测试 14 项通过；JavaScript 语法、开发规范和差异检查通过。尚未进行真实桌面端及 macOS 界面验收。

更新服务端后重新加载页面；桌面客户端使用对应的新版本构建。此次改动无需新增数据库迁移或环境变量。
