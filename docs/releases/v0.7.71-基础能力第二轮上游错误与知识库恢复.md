# v0.7.71 基础能力第二轮：上游错误与知识库恢复

日期：2026-10-30。

## 更新内容

- 安全 HTTP 客户端在调用方未指定状态策略时恢复默认的非 2xx 错误判断；错误响应流超时后主动释放资源。模型连接测试对地址、密钥、名称和来源的非文本参数返回明确的客户端错误。
- 知识库任务绑定执行者和领取次数；任务重领后，旧执行不能续租、改变任务状态或覆盖文档失败状态。正式索引切换在事务内核对当前租约。
- 知识库批量重试等待调度结果，返回实际数量并传播调度错误，不再提前显示空统计。

## 验证与边界

使用隔离 PostgreSQL、可控 HTTP 服务和真实浏览器验证上游认证失败、索引重领与切换、失败文档重试，以及 TXT、DOCX、XLSX 和文字型 PDF 解析。模型连接测试只验证模型列表接口，不等同真实推理测试。

该轮完整 Node 回归有两项受控浏览器测试失败，单独复测通过；后续轮次补充了清理重试、有限负载测试与完整回归。真实 OCR、外部模型和生产环境未在此轮验收。详见[第二轮验证与修复](../reports/2026-10-30-基础能力第二轮验证与修复.md)。

## 更新方式

更新并重启主服务。此轮无新增数据库迁移或必需环境变量；索引任务运行时应使用同一版本的服务和工作进程。
