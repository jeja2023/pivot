# v0.7.150 项目审查修复与工程可靠性优化

日期：2026-11-10（Asia/Shanghai）。本版对应项目审查的 F01—F11，聚焦来源权限、模型额度、资料完整性、会话撤销、产物版本和异步界面可靠性。

## 使用变化

- 产物来源撤回或权限收紧后，通用详情、历史和公开链接不能继续返回原内容。含受治理来源的产物通过原业务工作台查看，PPT 修订保持在 PPT 工作台。
- 产物保存和回滚共用版本链；冲突时保留输入并提示重新打开合并。切换产物、关闭和退出账号后，迟到响应不能恢复旧内容。
- 公开分享链接有真实只读页面，支持桌面与手机；链接到期、删除或来源失效后拒绝读取。
- 法规导入遇到缺页、OCR 失败、空正文或超长截断时明确拒绝，不将部分资料登记为完整版本；条文保留真实页跨度。
- 知识库问答及共享文本模型调用统一校验每日额度和预留预算，明确的输出上限不被模型默认值扩大；取消与失败释放预留。
- 密码、账号及会话撤销会关闭既有实时事件连接，长期连接持续复核认证和到期时间。
- 文件监听分批续扫并回绕，不再让保留的前部文件长期挡住新文件；数据库水位线保留数字和时间的正确顺序。

## 工程与升级

没有新增依赖或生产必填配置。产物查看器按需加载，错误与 MCP 审计复用脱敏；对水位线与文件扫描的公共契约增加局部类型检查。

数据库升级包括法规提取覆盖字段和三张新增业务表的共同恢复写入屏障。迁移均保留原权限和恢复状态；历史法规的提取完整性保持未知，需要重新导入取得新证明，不能自动标为已完成。

测试默认使用隔离临时目录、本地受控执行器和单库串行；故障、容量、目录及负载组分配独立 schema。CI 完整验证有界预算为 90 分钟，保留所有既有硬门。

实现、具体回归、最终验收结果及剩余范围见[项目审查问题修复记录](../reports/project-audit-fixes-20261110.md)。源码版本不代表已经构建或部署镜像、安装包，也不替代真实外部模型、OCR、Office 与目标生产环境验收；原制品保留各自版本身份。
