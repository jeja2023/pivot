# v0.7.50 知识库续处理与治理验收升级

发布日期：2026-10-28

## 本次改动

- PDF OCR 按原文件哈希和文档所有者保存页级结果；文档列表提供“续处理”，每轮处理最多 10 个未完成扫描页，失败页可重试，文件变化不会复用旧结果。处理完成后仍通过既有暂存索引切换与引用发布链路。
- 数据源的大比例删除保护新增管理员审批：对完整扫描产生的最多 50 条待归档清单进行确认，审批绑定来源、清单、版本与更新时间，30 分钟有效、一次使用；重新扫描不完整或快照改变不执行删除。外部 Markdown Wiki 页面在 v0.7.51 加入同类审批。
- 用户选择严格所有者隔离：知识产品文档、引用、Wiki 来源批量检查只允许所有者和系统管理员；历史 viewer 等授权不再生效，也不再支持为其他用户、单位和角色新增授权。文档审核和验证仅允许所有者或系统管理员，旧的跨用户审核分配不再可执行。
- 对新建或重建的 PDF 索引，按提取正文字符范围映射真实页码并写入引用定位；当前版本 PDF 引用可打开原文页码。旧版本没有对应原文件快照时不会错误跳转到当前版本；旧索引需重建才能补齐页码。
- 增加 WebDAV 深度一只读目录接入，使用受控凭据引用、同源路径检查、出站地址防护和文件格式检查。只采集直接文件，不继承源端 ACL，不自动同步删除；使用令牌时要求 HTTPS。
- 增加受控检索负载测试和恢复后只读对账工具，操作流程见 [知识库生产验收与恢复演练](../deployment/知识库生产验收与恢复演练.md)。

## 部署与限制

新增 PostgreSQL 迁移 `202610280002_knowledge_ocr_resume` 和 `202610280003_knowledge_source_deletion_approval`，依赖 v0.7.49 的 `202610280001_knowledge_index_coverage`。更新服务端并完成迁移后重新加载页面；原文件和数据库备份均须纳入恢复方案。

OCR 缓存内容属于知识资料，数据库备份和访问策略应按正文敏感级别管理。续处理依赖 OCR 服务可用，超过字符索引上限仍会标记部分就绪。PDF 定位为页码而非坐标高亮。WebDAV 测试使用模拟目录，尚未针对特定产品或源端权限体系认证。

生产黄金集标注、真实并发容量与备份恢复演练须由目标环境执行；不能以隔离测试代替生产验收。恢复对账仅比较关键表计数与孤儿分块，还须核验原文件、密钥、权限和实际检索。
