# v0.7.163 数据建模工作台与弹窗交互优化

日期：2026-11-16。启用源码版本 v0.7.163，归档本轮数据建模编辑页、画布交互、配置弹窗及 PPT 模板库弹窗关闭防误触优化。

## 使用变化

### 1. 数据建模编辑区布局与精简

- **消除外层页面垂直滚动条**：桌面端编辑器通过弹性高度锁定视口（`overflow: hidden`），左侧组件与数据集栏、中央画布与预览、右侧抽屉各自内部独立滚动；模型目录列表与 `1080px` 以下窄屏继续保持正常纵向滚动。
- **顶部与画布界面聚焦建模**：精简编辑器顶部栏为单行紧凑样式并隐藏冗余的「业务时区」状态拼接；移除画布上方占用高度的事实粒度状态条和空闲占位提示文字，压缩底层预览空态与未启用执行器提示条高度。
- **右侧配置抽屉统一规格与样式优化**：「节点配置」「维度指标」「检查血缘」「试算分析」四个页签统一使用 `432px` 等宽抽屉，切换页签不再造成画布宽度跳动；抽屉右上角「关闭」按钮改为红字红框（`.btn-danger-outline`），内部单行输入框、原生 `<select>` 下拉框与算子参数行统一为紧凑一致的高度与字号。
- **字段快速建键与预览兜底**：节点属性卡片支持一键切换「+主键 / 主键」；底部预览栏支持切换「运行输出」与「字段结构」，并支持放大高度；隔离计算执行器未启用时，可直接查看来源数据集本地入库样本。

### 2. 左栏数据集筛选与画布直接滚轮缩放

- **海量数据集管理**：「可用数据集」非空时常驻名称搜索框；画布已有表时显示「仅未加入 / 全部」切换按钮；当匹配数据集超过 30 个时自动分段展示，点击「展开更多」按需加载后续项。
- **节点真实缩放与直接滚轮缩放**：修复小模型画布在缩小时因 `min-width: 100%; min-height: 100%` 限制导致节点无法缩小的问题；支持直接在画布及节点上滚动鼠标滚轮（围绕指针坐标）放大或缩小（`40%–200%`），配合工具栏「放大」「缩小」、点击缩放比例恢复 `100%` 及双向「适合视口」。

### 3. 数据建模全系列弹窗深度优化

- **自适应弹窗尺寸与排版**：修正弹窗继承全屏高度造成的底部大面积留白问题，按内容自动切换紧凑单栏（`460px`）、标准双栏（`660px`）、宽版表格/树（`760px`）与只读无底栏查看模式；统一弹窗内标签字号、输入框、`34px` 下拉框、主键多选列表样式（实时显示 `已选 N 项`）及右上角红字红框「关闭」按钮。
- **专项表单修正与底栏精简**：修复「共享与业务口径复核」中单位/用户复选树因通用 `label` 规则导致的竖向错位并优化字段排布；去除「模型基本信息与更新策略」「共享与业务口径复核」「选择模型接收人」「设置事实表与业务粒度」「添加维度表」右下角多余的「取消」按钮。

### 4. PPT 模板库弹窗关闭防误触

- 收窄数据分析扩展面板对 `.modal-overlay` 的全局点击监听范围至 `.data-analysis-modal-overlay` / `id^="data-analysis-"`，并在 `#presentation-catalog-modal` 增加显式防冒泡保护，确保 PPT 模板库弹窗仅点击「关闭」按钮（或按 `Esc`）关闭，点击弹窗外遮罩区域不会误关。
