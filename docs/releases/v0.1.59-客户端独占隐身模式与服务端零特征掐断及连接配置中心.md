# Pivot v0.1.59 发布记录

**发布日期**：2026-08-27

---

## 概述

Pivot v0.1.59 聚焦于**客户端独占隐身模式（Stealth Mode）、服务端零特征连接掐断（Socket Destroy）、管理后台一键安全开关与密钥管理、以及企业级客户端服务器连接配置中心（Dynamic Server Config）**。本次更新实现了普通浏览器与外部网络扫描完全无法探查站点存在的最高级别终端安全防护，同时提供客户端可视化动态配置、连接失败脱敏保护、以及本地测试开发无感直连体验。

---

## 主要更新内容

### 1. 客户端独占隐身模式与服务端零特征掐断（Stealth Guard）

- **底层 TCP 物理掐断门禁**：
  - 在服务端接入顶层连接掐断中间件（`stealthAccessGuard`）。当系统开启隐身模式后，任何未携带有效官方客户端签名的 HTTP/HTTPS/WebSocket 请求直接被物理掐断底层连接（`req.socket.destroy()`），不返回任何 HTTP 状态码、响应体或响应头，外部扫描器与普通浏览器直接显示 `ERR_EMPTY_RESPONSE` / 连接重置，彻底隐身。
- **官方客户端毫秒级 HMAC-SHA256 动态签名握手**：
  - 官方桌面客户端在底层网络请求层自动注入动态防重放签名（`X-Pivot-Stealth-Time` 与 `X-Pivot-Stealth-Token`），服务端在 120 秒安全时间窗口内采用恒定时间比对（`crypto.timingSafeEqual`）验证合法性并毫秒级放行。

### 2. 管理后台全局参数一键开关与通信密钥管理

- **全局参数安全设置独立通栏卡片**：
  - 在管理控制台「系统全局参数」中新增独立的「安全与终端隐身」通栏配置卡片（`global-params-stealth-section`），支持单机与远程部署下的一键开关。
  - 支持密钥明文切换查看（「显示密钥」/「隐藏密钥」）、一键复制到剪贴板，以及超级管理员专属的「重新生成」密钥功能。
- **防锁死安全警示与应急恢复机制**：
  - 在管理员开启隐身模式前弹出高危防锁死确认弹窗，明确提示外部浏览器将被直接阻断；
  - 提供服务端环境变量应急覆盖开关（`PIVOT_STEALTH_MODE=false`），即使密钥遗失也能秒级恢复 Web 访问。
- **UI 像素级排版与垂直对齐校准**：
  - 密钥输入框与操作按钮高度统一定为 `28px`，采用盒模型与 `inline-flex` 垂直居中对齐，彻底消除上下错位。

### 3. 企业级客户端服务器连接可视化配置中心

- **动态配置持久化与环境热切换**：
  - 客户端配置支持用户级持久化（`userData/user-config.json`），优先级高于打包预置的 `config.json`，便于分发通用安装包并在现场灵活切换本地（Local）与远程（Remote）服务端。
- **可视化配置弹窗与快捷键入口**：
  - 菜单栏新增「客户端 -> 服务器连接配置...（`Ctrl+,`）」，连接失败页面提供醒目的「配置服务器」操作入口。
  - 弹出现代化配置模态窗口，支持模式切换、URL 格式合法性校验、通信密钥输入，以及带 HMAC 签名的服务端连通性探测（`testServerConnection`），点击「保存并连接」即时热重载。
- **连接失败页面全面脱敏防护**：
  - 错误页面全面清洗并移除所有目标 URL、IP、端口及内部协议路径，彻底杜绝内网资产暴露。
  - 消除错误页与重试加载之间的 `ERR_ABORTED (-3)` 竞态冲突，错误信息提供清晰的中文本地化说明。

### 4. 服务端密钥持久化优先级加固与本地开发无感直连

- **异步 DB 缓存优先级修复**：
  - 修复了服务端在启动建立数据库连接前 `getStealthSecret` 误将临时随机内存密钥写入缓存的问题，确保数据库与 `.env` 中固化的密钥永久一致。
- **开发机与本地回环自动无感解析**：
  - 客户端在连接本地回路地址（`localhost` / `127.0.0.1` / `::1`）时，自动回退读取本地凭据，开发机测试时无需手动输入密钥即可无感直连。
