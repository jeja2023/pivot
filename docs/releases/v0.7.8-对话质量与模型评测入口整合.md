# v0.7.8 对话质量与模型评测入口整合

撤下系统设置侧栏中的独立“决策审核 / 路由复核”入口，将管理员质量治理归入已有产品分区。

- **系统监控 → 对话质量**：查看任务执行范围、反复误判及证据冲突，按需复核；可切换自动归档与已处理历史，原证据、会话关联、复核状态及管理员记录继续使用原账本。
- **模型配置 → 评测管理**：管理冻结评测集、案例详情与双人独立金标审核。审核冲突、候选动作校验和发布阻断规则继续执行，审核操作不自动激活模型或策略。
- **系统监控 → 运行概览**：保留服务资源、并发、检索与异常告警面板。切到对话质量时取消概览请求和自动刷新，避免无关请求更新列表页面；返回概览再加载与恢复刷新。

旧 `decision-review`、`route-feedback`、`decision-gold-review` 导航与保存状态映射到对应新分区；旧脚本调用保留薄兼容入口。普通用户只看到自己的模型配置，无法通过保存状态、旧入口或直接接口访问管理员质量和评测数据。

本次复用现有表格、分页、筛选、详情和审核接口，无需数据库迁移，不删除历史纠正、核验、评测或审计记录。更新服务和前端资源后生效，未部署远程 Docker。详见[验收报告](../reports/对话质量与模型评测入口整合验收报告_2026-10-19.md)。

验证结果：工程检查与 ESLint 通过，全量回归 2014 项、定向回归 28 项、浏览器验收 5 项通过，包含桌面与手机窄屏检查及真实普通用户的权限拒绝验证。
