# 智枢 Pivot v0.1.118 发布记录

## 1. 个人工作台视口自适应与无垂直滚动条保障

- **紧凑化布局与尺寸自适应**：
  - 顶部 Header 高度由 66px 优化为 54px，标题与操作区更加精致干练；
  - 滚动容器内边距由 `20px 28px 28px` 紧凑调整为 `12px 24px 14px`，释放 22px 垂直空间；
  - Hero 快捷开始横幅高度由 60px 紧凑为 44px，排版留白自适应优化；
  - KPI 概览指标卡片最小高度由 84px 优化为 62px，间距由 16px 缩紧为 10px，图标与数字字号轻量化；
  - 卡片栅格解绑原有强制硬占位的 `minmax(220px, 1fr) minmax(260px, 1fr)`，采用响应式弹性分布 `grid-template-rows: 1fr 1fr; gap: 10px;`；
  - 卡片头部高度由 58px 紧凑为 42px；「继续工作」条目内边距优化为 8px 14px，4 项记录高度压缩约 48px；
  - 「常用入口」6 宫格卡片最小高度由 94px 优化为 52px 垂直居中展示，整体压缩约 76px。
- **默认视口无滚动条锁定**：
  - 在 `@media (min-height: 650px)` 条件下将滚动容器锁定为无滚动（`overflow-y: hidden`）；
  - Windows 客户端默认窗口（1320×860，视口约 800px）及标准桌面屏幕下，整个工作台核心内容 100% 完整容纳在一屏内，彻底消除右侧突兀的垂直滚动条；
  - 极端小高度窗口（< 650px）自动安全回退为平滑垂直滚动。
