# v0.1.167 发布记录：PPT 制作应用全功能补齐、协作增强与工作台跳转优化

发布日期：2026-09-23
版本号：v0.1.167

## 发布结论

Pivot v0.1.167 全面补齐了“PPT 制作”应用的产品级全量能力，构建了完整的演示文稿多人实时协作基础（评论线程与在线 Presence），优化了解耦架构并严格受控在大文件治理指标内；同时全面修复与规范了个人工作台“继续工作”跳转行为，使未命名演示文稿直达 PPT 编辑器，消除多余冗余提示。

---

## 核心更新与用户可用能力

### 1. 个人工作台“继续工作”跳转精准分流与交互优化
- **跳转精准分流**：彻底修复在个人工作台“继续工作”区域点击成果误进任务活动抽屉的问题。后端增强 `toRecentWork` 结构化透传 `artifactType` 与 `targetId`，前端对各类条目精准路由：
  - **演示文稿成果**：直达 PPT 制作工作台打开对应文稿；
  - **公文写作成果**：直达公文写作单篇编辑；
  - **任务活动条目**：直达智能体任务详情抽屉；
  - **会话记录**：恢复 Chat 会话并展开侧边栏；
  - **通用独立产物**：安全降级至已完成产物列表。
- **Hero 命令栏视觉优化**：去除输入框上方冗余渲染的标签文本“输入要处理的事情”，统一使用输入框内部占位符并补充无障碍 `aria-label="输入想处理的事情"`；修正 `.sr-only` 在各工作区视图下的样式隔离规则，保证读屏可达且无视觉外露。

### 2. 演示文稿评论线程与批注树（Comment Threads）
- **多级批注与回复树**：支持文稿全文与单页幻灯片维度的评论批注，支持父子层级回复树（`parent_id`）；
- **生命周期与状态**：支持标记“已解决”与“重新打开”，具备已解决样式标记；支持作者与管理员权限删除；
- **右侧检查器评论面板**：右侧属性面板新增“评论”独立选项卡，支持按“当前页 / 全部”快速筛选，未解决评论条数实时徽标展示。

### 3. 协作者管理与实时在线状态（Presence & Collaborators）
- **协作者权限角色**：支持按用户添加协作者，提供编辑者（`editor`）、评论者（`commenter`）与查看者（`viewer`）细粒度权限控制，放行协作者安全查看与协作编辑；
- **实时 Presence 头像条**：基于内存 Presence 注册表与 15 秒心跳保活机制，编辑器顶部实时展示在线人员头像、呼吸灯与协作者当前聚焦的幻灯片页码（如“正在查看第 3 页”）；用户离开或 45 秒超时后自动离线回收。

### 4. 前端架构解耦与大文件治理
- 为严格遵循单文件行数 `< 1000` 行的架构治理硬指标，将评论回复、协作者弹窗与在线 Presence 逻辑独立抽取至 `client/chat/apps-workbench-presentations-collab.js`；
- 主编辑器 `client/chat/apps-workbench-presentations.js` 精简至 793 行，按需异步加载与事件代理协同工作。

### 5. PPT 制作产品级全能力补齐
- **AI 增强**：AI 继续生成、单页改写、内容/事实检查，提供请求取消与幂等重试机制；
- **模板与组织治理**：组织/部门模板治理，模板审核（草稿 → 待审核 → 已发布/已下架）状态机，品牌元素锁定与受控自定义字体上传；
- **演示体验**：演讲者备注、计时提词器、键盘快捷翻页、短时令牌远程投屏与控制端翻页；
- **受限导入与多媒体**：受限外部 PPTX 模板导入，受控图示、音视频、附件、元素动画、页面转场；宏/VBA 仅作静态安全审计附件，坚决不执行任何宏或 Office 二进制对象；
- **性能与基准**：8 套模板快照视觉基准、20 页渲染性能基准（`npm run benchmark:presentation`）及 Prometheus 运营指标。

## 数据库迁移

本次更新包含 PostgreSQL 数据库迁移，服务启动时将自动应用：

| 表 / 迁移 | 用途 |
| --- | --- |
| `presentation_comments` | 演示文稿评论批注表，包含单页定位、回复树、解决状态与租户隔离 |
| `presentation_collaborators` | 协作者权限表，包含文稿关联、用户关联与角色定义 |
| 品牌/封面/文稿库/投屏/多媒体迁移 | 支撑受控媒体资产、版本治理与投屏审计 |

---

## 永久安全边界

- 绝不执行宏/VBA、ActiveX 或任意 Office 二进制对象；宏文件仅作为静态审计附件。
- 绝不建立裸文件下载接口；所有导出、媒体均需短时令牌与用户/租户双重鉴权。
- 外部 PPTX 导入严格限制为布局与主题解析，不承诺第三方复杂专有格式的逐字节无损还原。
