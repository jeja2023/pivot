# v0.7.155 项目空间与模态弹窗深度优化与体验统一

日期：2026-11-12（Asia/Shanghai）。本版对工作台项目空间列表弹窗、新建/编辑项目弹窗与里程碑编辑交互进行深度重构与体验优化，解决弹窗拥挤、原生 Emoji 风格脱节、输入框与操作按钮纵向错位、字号不规范以及 CSS 语法错误等问题，接入全局统一的模态对话框与分页布局规范。启用新源码版本；功能与浏览器验证在 v0.7.154 工作区完成，原始日志与截图不因升版改写身份。

## 功能变化

| 场景 | 本版行为 |
| --- | --- |
| 弹窗尺寸与呼吸感 | 项目空间主弹窗（列表与详情）宽度扩充至 `min(1180px, calc(100vw - 32px))`，高度扩充至 `min(840px, calc(100dvh - 40px))`，内边距增至 `20px 28px`，整体视觉开阔舒展，消除拥挤感。 |
| 新建与编辑项目表单 | 表单结构重构为「基本信息」、「资料范围与交付物」、「项目里程碑」三大独立卡片，采用自适应双列网格布局，紧凑微调控件高度，标准视口下无需主表单滚动即可完整展现全部表单内容并常驻吸底操作栏。 |
| 里程碑管理体验 | 里程碑新增与编辑从主表单中解耦为独立子模态对话框（宽度 `min(640px, calc(100vw - 32px))`，最大高度 `min(720px, calc(100dvh - 40px))`），支持 Esc 键与遮罩退出、表单校验、卡片化列表管理与回填编辑，杜绝主弹窗垂直高度无限膨胀。 |
| 矢量图形与图标规范 | 彻底移除所有 Emoji 原生字符（如 `📁`、`📂`、`🎯`），全量替换为原生安全的轻量 SVG 矢量图标（文件夹、空状态、同心靶心），统一视觉风格并消除跨操作系统字体回退差异。 |
| 控件排版与水平对齐 | 重置弹窗内部从全局 `.form-input` 继承的 15px 底部外边距，重置偏大字体（1.1rem）为全局工作台规范字号（`0.85rem` / `0.82rem`）；搜索输入框、状态下拉选择框、查询按钮与新建项目按钮高度严格统一为 `34px`，实现像素级水平基线对齐。 |
| 分页控件规范与空状态 | 接入全局统一的工作台分页组件规范（`.workspace-pagination.pagination`）；当数据总数 ≤ 20（包括 0 条项目）时智能隐藏底部分页条，空状态居中舒展；仅当总数 > 20 时展示标准居中分页条。 |
| 样式表语法规范 | 清理 `client/chat/styles/workspaces/shared.css` 中遗留的孤立样式属性与多余闭合花括号，实现样式表零语法错误，并通过 `npm run build:chat-css` 重新编译生产压缩包。 |

## 升级与兼容
