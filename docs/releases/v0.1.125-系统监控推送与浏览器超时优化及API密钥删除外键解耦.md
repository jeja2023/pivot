# Pivot v0.1.125 发布记录：系统监控推送与浏览器超时优化及 API 密钥删除外键解耦

## 版本概览

- **版本号**：v0.1.125
- **发布日期**：2026-09-10
- **核心定位**：解决系统监控“配置推送”按钮事件冲突与文字排版优化、提升本机浏览器单点测试针对慢速内网站点的耗时容错能力，以及修复 API 接入页面删除密钥触发 PostgreSQL 外键约束冲突（23503）的系统问题。

---

## 变更背景与根因分析

### 1. 系统监控配置推送按钮无反应与徽章样式问题
- **双重监听冲突**：前端在 `client/chat/app/main.js` 与 `client/chat/stats-monitor.js` 中同时为 `.observability-toggle-btn` 注册了点击事件监听。在单次点击触发时，抽屉在同一个 tick 中先移除 `hidden` 又立即加上 `hidden`，导致用户感知为“点击无反应”。
- **排版粗糙**：“未配置推送”徽章字体字号偏大、内边距不协调、状态指示点缺失。

### 2. 本机浏览器单点测试打开网站超时（`Timeout 30000ms exceeded`）
- 企业内网或部分外部网站加载较慢，首屏渲染及 `domcontentloaded` 耗时超过自动化驱动预设的 30 秒硬超时阈值。
- 超时抛出 `device_failed` 导致单点测试中断报错，而此时本地浏览器实际上已成功启动并正在后台加载该站点。

### 3. API 接入页面删除密钥报外键约束冲突（PostgreSQL `23503`）
- `api_call_logs`（外部 API 与模型调用审计日志表）中的 `api_key_id` 外键约束原本未显式声明 `ON DELETE SET NULL`（在 PostgreSQL 生产环境中默认为 `RESTRICT`）。
- 当 API Key 产生过调用审计日志后，在 API 接入页面点击“删除”按钮时，PostgreSQL 拦截了物理删除并报 `violates foreign key constraint "api_call_logs_api_key_id_fkey" on table "api_call_logs"`。

### 4. API 接入页面意外叠加呈现工具策略面板
- 进入“API 接入”Tab 时，`loadApiKeys()` 函数内部无前缀使用了 `document.querySelectorAll('.super-admin-only')` 全局匹配并调用 `classList.toggle('hidden', !isSuperAdminUser())`。
- 在系统管理员账号下，该全局调用直接将同样带有 `.super-admin-only` 类的 `#tab-content-tool-policy` 容器解除了 `hidden`，导致非活跃的工具策略面板直接叠加呈现在 API 接入页面正上方。

## 核心改进与实现

### 1. 系统监控告警配置与徽章交互优化
- **事件绑定收口**：将配置按钮在 `client/chat/partials/settings/monitor.html` 中统一声明为 `data-static-action="toggle-observability-webhook"`，并在 `client/chat/app/main.js` 中进行单点安全派发，彻底消除双重切换冲突。
- **视觉层精细重构**：
  - 在 `client/chat/styles/stats-monitor/stats-system-monitor.css` 中重构 `.observability-status-badge`：字体统一为 `0.72rem`（11.5px）、字重 600、高度 20px、圆角 10px，增加状态微指示圆点（`::before`）；
  - 未配置状态（`.is-empty`）采用淡灰蓝 `#f8fafc` 搭配铅灰 `#64748b`；已开启状态（`.is-active`）采用浅绿 `#ecfdf5` 搭配翠绿 `#047857`；
  - 按钮 `.observability-toggle-btn` 优化为 24px 高度的紧凑胶囊按钮；
  - 修复 CSS 语法微瑕并固定 6 区域高度，杜绝多余垂直滚动条。

### 2. 本地浏览器慢速网站容错与超时机制增强
- **超时阈值放宽**：在 `server/services/local-browser-connector-tools.js` 与 `server/services/agent-tools.js` 中将导航默认超时从 30 秒提升至 60 秒，并支持最大 180 秒（3 分钟）显式超时参数覆盖。
- **慢速加载平滑降级**：在 `desktop/local-browser-automation.js` 中增强容错处理。当捕获到 `page.goto` 等待超时但浏览器已经成功打开目标 URL（`page.url() !== 'about:blank'`）时：
  - 对于 `browser.open` 操作，按“已成功在本地浏览器打开并后台加载”友好返回，避免直接被 `device_failed` 中断；
  - 对于内容提取工具提供清晰详细的慢速站点诊断与重试建议。

### 3. API 密钥删除外键解耦与平滑迁移
- **数据库版本化迁移**：新增 `server/db/migrations/api-call-logs-fkey-soften.js`（迁移 ID `202609100002_api_call_logs_fkey_soften`），执行外键更新：
  `ALTER TABLE api_call_logs DROP CONSTRAINT IF EXISTS api_call_logs_api_key_id_fkey;`
  `ALTER TABLE api_call_logs ADD CONSTRAINT api_call_logs_api_key_id_fkey FOREIGN KEY (api_key_id) REFERENCES api_keys(id) ON DELETE SET NULL;`
- **基线 Schema 同步**：在 `server/db/schema/tables-core.js` 的 `api_call_logs` 表定义中显式加入 `ON DELETE SET NULL`。
- **接口层双重防御**：在 `server/routes/auth.js` 的 `DELETE /auth/keys/:id` 中，先验证密钥存在与权限范围，物理删除前主动执行 `UPDATE api_call_logs SET api_key_id = NULL WHERE api_key_id = ?`，完好保留全部历史审计日志（模型名、Token 消耗、IP、时间戳等）的同时彻底解除外键关联，即使在历史库或未执行 DDL 变更的环境中也能安全稳定删除。
- **契约单测全覆盖**：在 `tests/security-auth.test.js` 中新增针对附带审计日志的 API Key 删除契约单测。

### 4. API 接入页面与全局权限选择器严格隔离
- **作用域精确收拢**：在 `client/chat/auth.js` 中将 `loadApiKeys()` 内部的 `.super-admin-only` 切换查询严格限制在 `#tab-content-keys` 容器范围内，杜绝跨面板误触其它分区。
- **面板排除保护**：在 `client/chat/admin.js` 的 `openAdmin` 中将批量权限选择器过滤条件增加 `:not(.admin-tab-content)`；在 `switchTab` 中对全部 `.admin-tab-content` 面板进行强制单一激活与隐藏管控，确保非当前活跃面板绝对保持不可见。
- **契约测试固化**：在 `tests/settings-page-contract.test.js` 中增加针对该隔离机制的契约单测，杜绝未来迭代退化。
