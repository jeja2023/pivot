# Pivot v0.1.131 发布记录：工作流生产安全、版本治理与触发可靠性全面改造

## 版本概览

- **版本号**：v0.1.131
- **发布日期**：2026-09-10
- **核心定位**：围绕安全、正确性、易用性和生产运维，对工作流发布、灰度、回滚、编辑并发、触发器、嵌入资源和节点目录进行系统收口。

## 一、发布与版本治理

### 评测门禁

- 普通用户不能通过请求体伪造 `skipEvaluationGate` 或 `fixedEvaluationRequired=false` 绕过门禁；
- 紧急发布只允许系统管理员执行；
- 必须填写至少 10 个字符的紧急原因，并写入发布审计；
- 非 admin 用户在前端只看到完成评测的引导，不再看到可误操作的跳过发布入口。

### 评测绑定版本

评测运行快照新增 `workflowVersionId`。发布工作流时只认当前待发布版本的已完成评测结果，旧版本评测不能为新版本背书，避免节点、参数或依赖变化后仍沿用旧评测结论。

### 灰度与回滚

- 灰度用户未命中时只回退到明确的 100% 稳定版本；
- 没有稳定版本时返回明确的 `WORKFLOW_ROLLOUT_NOT_ASSIGNED`，不会把新候选版本意外覆盖给所有用户；
- 兼容旧库中只有 `published_version_id`、还没有 release 投影记录的历史工作流；
- 首次发布没有上一版本时回滚会清空 `published_version_id` 和 `published_at`。

## 二、编辑与节点可用性

- 工作流保存请求携带当前版本号；服务端发现版本已经变化时返回 `WORKFLOW_VERSION_CONFLICT`，提示重新加载合并；
- 代码执行、循环/批处理节点仍保留在高级节点目录，但在未启用受控 Worker 时显示明确的不可用提示，避免用户运行时才遇到沙箱拒绝；
- 最近会话、知识库文档列表、可用模型、文档渲染和渲染结果列表加入节点预设；
- 节点目录继续统一使用输入契约、输出契约和参数向导，新增节点不需要用户手写 JSON 才能使用。

## 三、嵌入资源安全

工作流页面、图片、视频、音频和链接节点统一使用资源地址安全策略：

- 同源路径默认允许；
- 外部 HTTP/HTTPS Origin 默认拒绝；
- 管理员可通过 `PIVOT_EMBED_ALLOWED_ORIGINS` 配置逗号分隔的精确 Origin 白名单；
- 图片、视频、音频和 iframe 的 CSP 只允许同源和已配置 Origin；
- 禁止 `javascript:`、`data:`、`file:`、协议相对地址以及包含账号密码的地址；
- “网站嵌入代码”节点仍可生成外站 HTML，但生成代码前仍会校验地址格式；外部站点是否允许 iframe 由目标站点的 `X-Frame-Options` / `frame-ancestors` 决定。

## 四、Webhook 触发可靠性

- Webhook 触发器可开启 HMAC-SHA256 签名校验；
- 调用方使用 `X-Webhook-Timestamp` 和 `X-Webhook-Signature`，签名原文为 `timestamp.JSON.stringify(payload)`，密钥为触发器 Token；
- 时间戳默认限制在 ±5 分钟内，防止旧请求重放；
- 没有配置字段去重路径时，可使用 `Idempotency-Key` 作为幂等键；
- 原有基于业务事件 ID 的 `dedupePath` 逻辑保持兼容。

## 五、当前仍建议的后续阶段

本版本重点完成 P0 安全和正确性收口，以下能力建议作为下一阶段独立迭代：

- 单运行总输出预算与 Artifact/CAS 引用化，避免大 DAG 输出撑大数据库；
- 按工作流、租户、模型、数据库和 HTTP 工具分层限流；
- 无代码循环子图、Try/Catch、补偿和并行汇合节点；
- 上下游端口类型和字段映射可视化；
- 文件触发器稳定窗口、递归/排除规则和死信重放；
- 运行指标、节点耗时、失败率、Token 成本和版本对比看板。
