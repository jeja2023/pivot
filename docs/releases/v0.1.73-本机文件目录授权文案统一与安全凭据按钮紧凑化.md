# v0.1.73 发布记录：本机文件目录授权文案统一、表格列宽调优与全屏自适应撑满

Pivot `v0.1.73` 聚焦于工具库本机授权能力概念准确性对齐、凭据管理区域按钮视觉尺寸紧凑化，以及智能体工作台各数据表格列宽、分页与全屏自适应高度的深度调优。主要涵盖：

---

## 一、核心变更

### 1. 授权本机文件目录文案与语义统一
- **选项卡与动作卡片标题**：将本机授权中心内及工具库“我的电脑”卡片中的「授权本机报表目录」统一重命名为 **`授权本机文件目录`**，更准确地表达只读扫描和文件检索的通用能力边界；
- **描述与引导文案同步**：
  - 授权说明更新为：`选择一个本机目录，只读扫描授权范围内的文件。`；
  - 授权弹窗头部说明更新为：`授权本机数据库、文件目录或浏览器后，后续操作仍由当前桌面端执行...`；
  - 撤销确认提示更新为：`确定撤销当前设备上的本机文件目录授权吗？已保存的本机目录会从桌面客户端本机配置中移除。`；
  - 状态提示与上下文错误引导提示同步更新为 `打开授权中心选择本机文件目录` / `在“我的电脑/管理本机资源授权”里授权文件目录`。

### 2. 连接与安全凭据按钮紧凑化
- **受控安全凭据操作栏**：将「新建安全凭据」与「管理凭据抽屉」按钮由全局默认继承的 38px 粗大样式收敛为标准的紧凑规格 **`24px`**（`height: 24px; line-height: 22px; padding: 0 10px; font-size: 0.72rem; font-weight: 650; border-radius: 5px;`）；
- **视觉风格统一**：与工具库工作台内其他面板的操作按钮尺寸达到 100% 协调一致。

### 3. 工作台数据表格列宽与排版深度调优
- **「我的记忆」表格**：增加 **`序号`** 列（`56px` 居中等宽数字呈现），将 **`类型`** 列宽由 80px 扩充至 **`120px`**，类别徽标排版更加舒适舒展；
- **「任务活动」表格**：**`任务目标`** 列宽精确减少 3 字符（`width: calc(22% - 36px)`），**`状态`** 列宽精确增加 3 字符（由 80px 扩展至 **`116px`**），运行状态徽标展示更充裕；
- **「待办中心」表格**：**`事项名称`** 列宽由 140px 增大至 **`200px`**（`min-width: 180px`），大幅提升待办标题可视空间；
- **「工具可靠性」与「反馈闭环」表格**：**`序号`** 列宽统一增大至 **`56px`**，反馈明细 **`运行 ID`** 列与 **`时间`** 列列宽增大至 **`160px`**，默认单页数据条数统一规范为全局标准的 **`10 条/页`**。

### 4. 全屏自适应撑满与页面大块空白彻底消除
- **运行质量（工具可靠性 & 反馈闭环）**：
  - 打通质量视图顶层布局容器 `.agent-cp-quality-layout` 与 `.agent-cp-quality-panel` 全高伸缩链路；
  - 解除反馈列表 280px 旧高度上限限制（解耦类名为 `agent-feedback-list-panel`）；
  - 配置表格与空状态容器最小高度为 **`440px - 500px+`**，空状态垂直居中，彻底消除底部大块空白；
- **评测概览**：评测集双栏布局区域高度增大至 **`460px - 640px`**（空状态提升至 420px），大幅扩充评测用例可视空间；
- **通知设置**：打通 `.agent-cp-subview-pane` 全高链路，为通知渠道表格与空状态容器设定 `flex: 1 1 auto` 与 **`380px+`** 最小高度，彻底消除下方留白；
- **工作流工具栏操作状态严格对齐**：修复工作流资产中心返回时未严格按选项卡区分按钮显隐的问题，锁定在「工作流」标签页下只展示「新建工作流」并隐藏「新建计划任务」，计划任务创建统一收敛至表格各行「计划」按钮与「计划任务」专属选项卡。
