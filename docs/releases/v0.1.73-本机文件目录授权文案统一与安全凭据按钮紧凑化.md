# v0.1.73 发布记录：本机文件目录授权文案统一与安全凭据按钮紧凑化

Pivot `v0.1.73` 聚焦于工具库本机授权能力概念准确性对齐，以及凭据管理区域按钮视觉尺寸的紧凑化优化。主要涵盖：

---

## 一、核心变更

### 1. 授权本机文件目录文案与语义统一
- **选项卡与动作卡片标题**：将本机授权中心内及工具库“我的电脑”卡片中的「授权本机报表目录」统一重命名为 **`授权本机文件目录`**，更准确地表达只读扫描和文件检索的通用能力边界；
- **描述与引导文案同步**：
  - 授权说明更新为：`选择一个本机目录，只读扫描授权范围内的文件。`；
  - 授权弹窗头部说明更新为：`授权本机数据库、文件目录或浏览器后，后续操作仍由当前桌面端执行...`；
  - 撤销确认提示更新为：`确定撤销当前设备上的本机文件目录授权吗？已保存的本机目录会从桌面客户端本机配置中移除。`；
  - 状态提示与上下文错误引导提示同步更新为 `打开授权中心选择本机文件目录` / `在“我的电脑/管理本机资源授权”里授权文件目录`。

### 2. 连接与安全凭据按钮紧凑化
- **受控安全凭据操作栏**：将「新建安全凭据」与「管理凭据抽屉」按钮由全局默认继承的 38px 粗大样式收敛为标准的紧凑规格 **`24px`**（`height: 24px; line-height: 22px; padding: 0 10px; font-size: 0.72rem; font-weight: 650; border-radius: 5px;`）；
- **视觉风格统一**：与工具库工作台内其他面板的操作按钮尺寸达到 100% 协调一致。
