# v0.7.32 离线工具受控接入与产物交付

发布日期：2026-10-23。版本类型：功能修复、离线接入与交付完善。

本版在 v0.7.31 文档重构基础上落实运行时代码与真实交付，修复技能示例能够预览却无法按实际全名执行、单文件技能包导入丢失正文、普通用户无法使用受管内网工具等问题；新增带认证的扫描/绘图服务和产物适配，使结果可在原有流程中预览、下载和追溯。

版本号已在源码中启用，不表示已经提交 Git、推送版本标签、更新生产服务或重新发布客户端安装包。

## 2. 升级与兼容

主程序升级后重启服务并重新加载页面。本版没有数据库结构迁移，不要求为保持原有业务而安装新的微服务。若使用离线扫描/绘图能力，需要独立导入工具镜像、设置密钥、登记全局连接、刷新工具目录，并配置风险治理和任务网络白名单。

- 主程序版本：`0.7.32`，从 `CHANGELOG.md` 同步至 package 元数据和 README，运行时版本由现有服务读取。
- 独立工具镜像版本：`pivot-offline-tools:1.0.0`；Kroki/Mermaid：`0.28.0`，不随主程序版本号自动改名。
- 旧技能重新编辑或验证时，若含 `workspace.read` 等裸工作区名，须按实际目录改为完整名（例如 `mcp.0.workspace.read`）；本机连接器必须在线且目录已授权。
- 外部工具的数字服务 ID 使用现场实际分配值，不能照搬示例中的 42。个人自行创建的内网连接不会获得全局委托。
- 保持现有签名校验和完整验证流程；预览成功不等于版本可以发布。新草稿先调用验证，再按 `personal/team/organization` 范围发布。
- 完整备份仅在确认暂停全部写入的维护窗口执行；配置和凭据加密密钥另行保管，不能以同一时间戳替代一致恢复点。

完整操作见[离线工具服务部署与验收](../deployment/离线工具服务部署与验收.md)。
