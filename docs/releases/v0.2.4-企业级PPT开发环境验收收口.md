# v0.2.4 企业级 PPT 开发环境验收收口

发布日期：2026-10-11

## 开发环境已完成事项

本版本完成《企业级智能PPT制作应用升级方案》中可在当前代码库和本地 PostgreSQL 环境实现、自动验证的项目。

### 页面审批与局部修改

- 页面新增草稿和已批准状态。批准动作由服务端保存到版本快照，记录批准时间和用户；普通保存不会覆盖已批准状态。
- 已批准页面禁用当前页编辑、AI 改写和版式方案，用户必须显式解除批准。
- AI 改写会计算当前页新增、修改、移除元素的影响摘要；锁定元素在候选页面中强制保留。
- 当前页提供高管摘要、证据聚焦和平衡对比三种原生对象版式候选。应用候选后仍保留可编辑性、来源关系和锁定元素。

### 数据叙事与演讲交付

- 数据图表接口根据数据类别和序列生成推荐图表类型、趋势结论、演讲提示及可编辑的数据备份行。
- 用户可在插入图表时选择是否追加结论文本和原始数值备份页。
- 演讲交付建议按文稿内容估算时长，提供可能问题和应准备的数据口径备份页。

### 渲染与交付质量

- “质量检查”会对每一页执行实际 PNG 渲染，校验输出尺寸、格式和渲染成功状态。
- 渲染结果与文本溢出、元素重叠、低对比度、低分辨率素材、字体回退、敏感信息及来源治理规则合并展示。
- 检测到密码、令牌、手机号、证件或银行卡等可能敏感内容时，导出默认阻止；用户必须在导出选项中明确确认人工核对，确认记录进入交付审计。
- 原生 PPTX、PDF、PNG 导出、版本回退、协作权限、品牌模板、受控素材和证据链保持兼容。

## 自动化验证

- PPT 工作台、模板导入、协作、服务端审批、版本隔离、原生导出、数据叙事、渲染质检和版式候选专项回归通过。
- 工程门禁覆盖架构、迁移、索引、语法、HTML 安全、死导出、异步数据库调用和治理约束。

## 外部验收前置条件

以下事项需要真实企业环境、实际数据或人工业务授权，不能由开发机自动化测试代替：

1. 确定试点团队、企业模板范围、验收数据集和业务负责人，并以真实任务计算可用初稿率、品牌合规率、关键主张可追溯率、严重视觉缺陷率、首次生成时长和局部修改成功率。
2. 对接企业 SSO、身份目录、数据分级、导出审批或水印策略，以及模型地域、数据保留和人工审核政策。
3. 在目标 PowerPoint、WPS 和 LibreOffice 版本中人工验证真实模板、中文字体、编辑后保存、备注、动画和 PDF 输出。
4. 配置 Google Workspace 后验证 Google Slides 原生交付与协作；当前开发交付格式为 PPTX、PDF 和 PNG。
5. 接入经批准的视觉模型后，补充真实视觉模型复核与自动修复效果评估；当前开发环境已完成逐页实际渲染和确定性质量检查。
6. 完成生产安全评审、备份恢复、容量压测、监控告警和多租户运维演练。
