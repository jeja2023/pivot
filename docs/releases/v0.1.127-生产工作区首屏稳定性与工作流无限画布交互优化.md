# Pivot v0.1.127 发布记录：生产工作区首屏稳定性与工作流无限画布交互优化

## 版本概览

- **版本号**：v0.1.127
- **发布日期**：2026-09-10
- **核心定位**：消除生产环境工作区短暂空白与无样式首帧，缩短知识库、工具库首屏可操作时间，完善系统监控视口布局和桌面会话滚动，并将工作流升级为可自由浏览的无限画布。

---

## 用户可感知改进

### 1. 工作区不再以空白页面作为加载状态

应用的数据概览、知识库、工具库、设置和自动化工作区统一接入样式分包就绪等待、预加载与超时降级机制：

- 在样式或模板尚未完成时显示稳定、可辨识的加载页，而不是先绘制无样式结构；
- 已预热自动化工作台的 CSS 与模板，降低首次进入“自动化”“工作流”时的白屏和样式跳变；
- 样式加载异常或超过等待窗口时保留明确的可恢复状态，后续样式到达后自动展示工作区，避免入口被永久阻塞；
- 设置页也纳入同一就绪链，减少工作区容器未完成排版即进入首帧的闪动。

### 2. 知识库、工具库优先展示可操作内容

- **知识库**：文档表请求从专题、标签、统计、质量报告和知识图谱等辅助请求中解耦。首屏优先绘制文档表，随后异步补齐统计及辅助信息；加载过程中会清晰提示“文档已加载，正在补充统计信息”。
- **工具库**：将原本串行的工作台数据获取改为并行执行。加载中、部分数据不可用和重试入口均可见，某个 MCP 治理或健康接口暂时失败时，不再留下没有解释的空壳页面。

### 3. 系统监控无整页滚动且维护记录带日期

- 系统监控在设置工作区可用视口内完成布局，页面和外层容器不再产生额外横向或纵向滚动条；
- 慢查询与异常告警列表是唯一允许内部纵向滚动的区域，保证高频告警可浏览而不挤压其它监控卡片；
- “审计清理”“API 日志清理”“令牌清理”“数据库备份”等维护记录改为显示 `MM-DD HH:mm`，鼠标悬停可查看完整时间，避免只显示时分导致跨日记录无法判断日期；
- 监控卡片、资源区与告警区的高度和溢出边界均作收敛，适配常见桌面视口。

### 4. Windows 客户端会话列表可稳定上下滚动

桌面端会话列表在浏览器中正常、但 Electron 客户端中无法滚动的问题得到进一步加固：

- preload 在指针进入和离开会话列表时同步可信悬停状态；
- 主进程滚轮桥接优先使用该状态，规避 Windows 高 DPI 或窗口缩放场景下屏幕坐标与渲染坐标不一致造成的误判；
- 会话列表保留细窄、可拖拽的滚动条作为直接备用操作，鼠标滚轮、触控板和拖拽都可用于查看历史会话；
- 弹窗、组合键缩放和非会话区域的滚动不会被桥接逻辑接管。

## 工作流画布交互升级

### 1. 从受限画布改为可自由平移的无限画布

- 工作流节点坐标允许保存负值，前端序列化与服务端校验均限制在安全的 `±100000` 范围内，不再把向左、向上拖动的节点强制钳回 `0`；
- 可在画布空白处直接拖拽平移，也支持中键拖拽或按住空格拖拽；
- 鼠标滚轮缩放以当前指针位置为锚点，放大后不会丢失关注位置；
- 小地图以实际内容包围盒为坐标系，负坐标节点、当前视口和点击定位均保持正确。

### 2. 视图控制语义修正

旧“复位”会把 SVG 视口机械设置为逻辑原点 `(0, 0)`。当节点位于负坐标或用户此前已平移画布时，节点仍然存在，但会落在视口外，形成“点击复位后节点消失”的错觉。

本版本将其改为“初始视图”：

- 恢复默认缩放；
- 用当前节点包围盒的中心重新定位视口，确保现有节点仍处于可见区域；
- “适配画布”保留为单独操作，用于缩放并居中显示全部节点；
- 自动布局完成后自动执行适配；正常刷新不再强制改变用户当前的平移和缩放位置；
- 缩放按钮与小地图调整到左侧，避免被右侧节点属性抽屉覆盖而无法点击。

## 升级与发布说明

- 服务端页面通过版本标识刷新工作区 CSS/JS 缓存；部署 v0.1.127 后建议让浏览器完成一次硬刷新，或等待静态缓存版本自然切换。
- 桌面会话列表滚动修复包含在 Electron preload 中，需随 v0.1.127 桌面客户端安装包升级；仅发布服务端页面不会替换已经安装的客户端 preload。
- 本版本不包含数据库结构迁移；常规应用服务发布与桌面客户端发布可分别执行。
