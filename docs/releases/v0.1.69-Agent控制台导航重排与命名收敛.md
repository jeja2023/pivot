# v0.1.69 发布记录：Agent 控制台导航重排与命名收敛

发布日期：2026-09-01

## 导航顺序

Agent 控制台按日常使用流程调整为：

1. 技能与助手
2. 待办中心
3. 自动目标
4. 通知设置
5. 运行质量

首次进入默认展示“技能与助手”，帮助用户优先完成个人助手和技能配置；之后会继续恢复用户上次访问的页面。待办数字提醒仍保留在“待办中心”标签上。

## 名称调整

| 原名称 | 新名称 | 含义 |
| --- | --- | --- |
| 统一收件箱 | 待办中心 | 集中处理任务结果、审批与需要关注的信息 |
| 持续目标 | 自动目标 | 配置按时间或事件自动执行的目标 |
| 通知渠道 | 通知设置 | 配置任务提醒和审批通知方式 |
| 质量与可靠性 | 运行质量 | 查看运行、评测、工具可靠性和反馈 |

“技能与助手”保留为日常配置首屏，内部包含“我的智能助手”和“技能”。
