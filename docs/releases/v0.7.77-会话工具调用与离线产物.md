# v0.7.77 会话工具调用与离线产物

日期：2026-10-31。此版本记录工具调用链路的开发成果；工作区版本号已更新，目标内网部署与现场验收尚未完成。

## 已实现

- **会话与任务授权**：会话中通过 `@` 选择的工具传递到自动任务；续接时可以重新选择，工具允许列表和网络范围与任务元数据一同更新。数据库、本机连接器和外部服务可混合选择；系统 MCP 别名仅在当前账号可见且通过治理时映射。
- **工具发现和执行**：候选优先包含用户选择及与目标相关的工具；按搜索、读取契约、执行的流程校验当前目录、授权及工具引用。对同一目标、目录版本和用户修订累计四次空搜索时暂停并提示补充工具，避免反复搜索耗尽预算。
- **网络与权限**：自动外部 MCP 调用将工具与服务登记端点绑定，执行前继续检查共享连接权限、任务范围、审批、SSRF 及 DNS。工具调用和续接读取最新的任务权限范围；具体工具被撤权、服务停用或地址变化时可能拒绝执行。
- **结果与交付**：MCP 返回 `isError: true` 时，工具调用和单步测试按失败处理。渐进式调用只对业务结果生成一次产物；有效的 Mermaid 单步样例可用于验证离线绘图服务。
- **诊断与界面**：审计包增加工具标识、错误码与已有策略原因的受限投影；新建任务在没有旧版工具复选框时沿用账号授权目录。任务网络设置说明允许填写受控服务的 Origin。

## 验证范围

- 最新一轮 117 项工具发现、交接、网络边界、错误处理、产物处理和 MCP 传输相关定向测试通过。
- 数据库相关用例分批验证，最终均通过：覆盖权限范围原子更新、旧快照、普通及流式运行器的连续空搜索暂停、续接与审计包 HTTP 权限及脱敏。此前独立的隔离数据库测试覆盖产物持久化和授权下载。
- 相关文件 Lint、文本完整性、增量开发规范和差异空白检查通过。未运行全量回归或完整浏览器端到端测试。

## 部署与验收边界

本次修改主要位于 Pivot 主程序；工具镜像的既有版本和 Compose 配置没有因本次改动更新。目标环境需按现有部署流程准备主程序版本，使用普通授权账号从会话中选择绘图工具，验证实际调用、图片预览与下载，并检查错误输入、撤权和审批场景。模型意图识别及各类服务的实际可用性受现场配置影响。

本次没有构建安装包、发布镜像或连接生产环境；定向测试和隔离数据库结果不代表目标内网验收通过。多节点方面，v0.7.76 的限制继续适用：普通客户端渠道重放尚未启用，严格多节点预检仍然阻断；故障恢复和滚动升级仍待现场验收。
