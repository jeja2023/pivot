# v0.1.119 发布记录：用量审计外键解耦与 CI 稳定性加固

发布日期：2026-09-10

## 版本摘要

本版本主要修复 PostgreSQL 写入队列在特定并发场景下的外键约束异常，彻底消除模型用量审计事件与用户/模型实体物理生命周期的时序竞态；同时治理 CI 环境（Ubuntu / 多 Worker 并行）下的测试隔离缺陷，确保全量自动化测试套件持续高可靠运行。

## 主要变更

### 1. PostgreSQL 用量事件外键解耦与异步队列韧性

- **外键约束软化迁移**：新增版本化迁移 `202609100001_model_usage_events_fkey_soften`，在 PostgreSQL 中对 `model_usage_events` 执行 `ALTER TABLE ... DROP CONSTRAINT IF EXISTS`，剥离对 `users(id)` 和 `models(id)` 的强外键依赖，与 `mcp_call_logs` 设计理念保持一致。
- **建表 DDL 同步对齐**：更新 `server/db/schema/tables-core.js`，移除建表时的外键约束声明，避免新安装环境再次引入约束。
- **写入队列容错隔离**：在 `server/services/db-write-queue.js` 增加 `isForeignKeyViolation` 检测逻辑（涵盖 PostgreSQL 错误码 `23503` 及约束冲突正则），发生实体生命周期不匹配时安全隔离单条数据并降级输出警告日志，避免误报为严重系统故障。
- **基线校验更新**：同步更新 `scripts/raw_sql_baseline.json`，确保新迁移 DDL 符合严格的 SQL 基线门禁。

### 2. 测试夹具生命周期与并发隔离加固

- **测试清理异步等待**：在 `tests/security-chat/ops-models.js` 的测试 `finally` 阶段显式调用 `await flushAllWrites()`，防止物理删除测试用户或模型时，异步写入队列中残留的事件尚未入库。
- **数据分析测试目录生命周期收敛**：在 `tests/data-analysis.test.js` 中移除用例 1、4、5 内部对套件级根目录 `analysisTestRoot` 的过早删除操作，改为在 `test.after()` 钩子中统筹清理，彻底避免 Linux 环境下无文件句柄锁导致目录立即蒸发、从而破坏后续测试的跨平台缺陷。
- **快照迁移环境变量时序修正**：在 `tests/db-migration-snapshots.test.js` 中调整 `finally` 块的恢复顺序，优先恢复 `process.env.DATA_DIR` 的原始值，再清理缓存的数据库模块，防止后续测试重新加载 `server/db/connection.js` 时误绑定至已被清理的临时路径。
