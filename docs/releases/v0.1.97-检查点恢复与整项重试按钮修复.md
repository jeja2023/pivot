# v0.1.97 发布记录：检查点恢复与整项重试按钮修复

## 版本信息

- **发布日期**：2026-09-07
- **版本号**：v0.1.97
- **适用范围**：Agent 任务详情、异常任务、检查点恢复、整项重试

## 问题原因

“重新运行”和“从检查点恢复”按钮位于任务详情顶部操作区 `#agent-detail-header-actions`。此前详情刷新时只给详情内容容器绑定了按钮事件，顶部操作区虽然正常显示按钮，但没有对应监听器，因此点击没有反应。

## 修复内容

- 顶部操作区与详情内容区统一调用 `bindAgentRunDetailDomEvents`；
- “重新运行”调用 `/agents/runs/:id/rerun`；
- “从检查点恢复”调用 `/agents/runs/:id/resume`；
- 请求成功后刷新任务列表并重新打开新任务详情；
- 保留操作锁，防止重复点击造成重复任务。

## 验证结果

- Agent 控制台详情专项测试通过；
- 客户端 ESLint 检查通过；
- 全量 `npm run check` 通过。
