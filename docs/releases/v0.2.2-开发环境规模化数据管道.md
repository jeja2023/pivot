# v0.2.2 开发环境规模化数据管道

发布日期：2026-10-11

## 功能交付

数据分析工作台在“字段治理”中新增“规模化数据管道”：

- 增量文件会校验字段顺序，追加到新版本的列式数据副本，不覆盖原版本；
- 可按可访问字段生成受控分区副本，记录版本、字段值和行数；
- 可创建 `count`、`sum`、`avg`、`min`、`max` 物化聚合，保存结果预览、来源版本和刷新版本；
- 所有写操作仅允许数据集所有者；字段权限在分区和物化前再次校验，受限字段不能借规模化资产暴露给共享用户。

开发环境使用托管本地/共享文件目录与受控 DuckDB 列式执行面，不要求外部对象存储即可完成版本、分区、物化和查询功能开发。S3、分布式对象存储或多节点 OLAP 集群仍必须在目标生产架构中显式接入、验收和监控。

## 数据库变更

迁移 `202610100005_analysis_scalability` 新增：

- `analysis_dataset_versions`：数据集版本与来源清单；
- `analysis_dataset_partitions`：分区元数据；
- `analysis_materializations`：物化聚合定义、预览、版本和受控结果引用；
- `analysis_datasets` 的存储模式与分区字段元数据。

迁移幂等，旧数据集默认使用托管本地存储，不需要回填即可继续读取。

## 开发验证

- 数据分析专项测试覆盖增量版本、分区、副本行数、物化聚合和状态读取；
- 浏览器回归 38/38 通过，覆盖字段治理中创建分区和物化聚合、非法查询与网络中断提示；
- 覆盖率回归 1,477 项通过，行/函数/分支为 78.37% / 80.53% / 63.76%；
- PostgreSQL 迁移、索引、SQL 基线、前端安全 HTML 和工程门禁均通过。

同时补齐数据查询异常体验：非法查询维持受限只读边界，浏览器网络中断会显示中文重试提示。该行为有真实浏览器回归保护。
