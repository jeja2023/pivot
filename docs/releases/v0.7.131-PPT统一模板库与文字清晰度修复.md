# v0.7.131：PPT统一模板库与文字清晰度修复

日期：2026-11-08。

PPT制作默认使用“AI自由设计”，按需进入“使用单位模板”或“沿用原稿设计”。统一模板库展示通用用途、单位/个人、PPT Master模板及按需显示的历史主题，标明来源、版本和可用制作方式。

- 通用内置模板保留汇报、正式材料、培训三类，蓝/绿旧主题从默认选择中收起。全部旧模板标识和版本保留，已有文稿继续读取自己的模板快照。
- 完整制作引擎就绪时，自由设计直接使用PPT Master；未配置时明确说明当前使用标准AI工作台。固定上游模板由宿主按目录选择复制、校验；单位PPTX模板按当前账号授权和固定版本作为原稿输入，采用保留原稿路径。
- 管理员可以在同一模板库导入单位模板，继续沿用预检、审核、发布和素材权限。模板下架后不再用于其他用户的新制作，历史文稿仍能读取旧快照。
- 修复编辑画布未设置文稿背景色、切页残留旧背景图，以及形状外层重复边框；缩略图标题按实际背景选取清晰颜色。
- 显式切换主题时，背景、默认字体与文字配色由同一服务端模板快照处理。当前模板的新配色以独立版本保存：三类用途模板为v3，蓝/绿历史主题的新配色为v2；用途模板v1/v2、历史主题v1继续可解析，不批量改写旧稿。
- 对明确实色背景下的默认文字槽位和装饰文字检查4.5对比度，并考虑文字下面的实色卡片；图片背景与复杂透明叠加仍需实际视觉核对。

专项回归、真实容器、浏览器和本机PowerPoint证据见[验证报告](../reports/PPT统一模板库与清晰度验证-20261108.md)。尚未部署生产或构建安装包。
