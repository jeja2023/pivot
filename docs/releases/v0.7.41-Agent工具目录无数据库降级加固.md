# v0.7.41 Agent 工具目录无数据库降级加固

发布日期：2026-10-26。版本类型：Agent 工具目录组装与执行链路的无数据库容错加固。

本版本重点解决未配置 `DATABASE_URL` 时，Agent 工具目录组装、渐进式工具发现与工具执行链路直接抛出“PostgreSQL 连接池未初始化”错误的问题。相关能力在无数据库环境下本应有安全的默认行为：能力包禁用配置不存在时工具默认启用、MCP 工具缓存与工作流 API 操作列表为空、共享工具并发租约退化为单实例内存令牌。本次将这一假设显式落到代码中，5 个相关测试套件全部恢复通过：
1. **能力包过滤降级**（`server/services/capability-market.js`）：`filterBuiltInToolsByCapability` 与 `filterMcpToolsByCapability` 在未配置数据库连接时直接返回带默认治理信息（启用）的工具列表，不再查询 `capability_packages` 表；
2. **MCP 工具缓存降级**（`server/services/mcp-client.js`）：`listCachedMcpTools` 在无数据库时跳过 `mcp_tool_cache` 查询，仅返回本机直连工具——无数据库场景下缓存表必然为空，跳过查询语义等价；
3. **工作流 API 操作降级**（`server/services/workflow-api-operations.js`）：`listWorkflowApiOperations` 无数据库时返回空列表，目录组装不再因查询失败而整体中断；
4. **共享工具并发租约降级**（`server/services/agent-shared-tool-guard.js`）：`acquireSharedToolLease` 无数据库时发放一次性内存令牌，工具执行结束即失效，不依赖 PostgreSQL 事务级咨询锁；
5. **已知环境依赖**：`tests/agent-shared-tool-guard.test.js` 需要真实 PostgreSQL 才能验证跨调用方并发限制与过期租约回收，属于环境依赖测试，本次不调整。
