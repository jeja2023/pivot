# v0.1.160 发布记录

**发布日期**：2026-09-22
**版本号**：v0.1.160
**主题**：知识库严格所有者隔离与桌面滚轮精确命中修复

---

## 概述

本版本包含两个独立方向的修复：

1. **知识库数据隔离安全加固**：将知识库集合、文档及 RAG 资源的访问控制从原有"共享范围 + 单位白名单"的宽泛过滤彻底收紧为严格所有者隔离（`user_id = ?`），管理员保留跨用户只读权限。这消除了普通用户因 `scope = 'shared'` 或单位白名单配置读取到其他用户资源的安全隐患。

2. **桌面端（Electron）滚轮侦测区域精确化**：将侧栏滚轮接管判定从整个 `.sidebar` 容器收窄到 `#session-list` 与 `.sidebar-session-section-label` 两个精确元素，根治右侧聊天消息区滚轮在合成层切换期间被误判并强行重定向至会话列表的问题。

---

## 变更详情

### 1. 知识库严格所有者隔离

#### `server/services/knowledge-access.js`

- **移除** `buildAllowedTargetSql`：删除基于 `scope = 'shared'`、`allowed_units`、`allowed_user_ids` 的宽泛共享过滤 SQL 生成逻辑。
- **`buildCollectionAccessFilter`**：管理员返回 `1 = 1`（全量），普通用户改为 `alias.user_id = ?`（严格所有者），不再携带单位参数。
- **`buildDocumentAccessFilter`**：同上，普通用户改为 `docAlias.user_id = ?`，去除 `knowledge_permissions` 的 `EXISTS` 子查询和 `content_owner`/`verifier` 关联。
- **`canReadKnowledgeResource`**：逻辑简化为 `isAdmin || user_id === 当前用户`，移除共享范围与单位白名单的判定分支。

#### `server/services/knowledge-content.js`

- **`getProductDocumentForUser`**：访问判定从"所有者 OR 集合共享范围 OR `knowledge_permissions` 授权 OR 内容负责人/审核人"收紧为"管理员 OR 所有者"。
- **`listProductDocumentsForUser`**：查询层直接加入 `owner_user_id = ?` 过滤，不再依赖后置的 `getProductDocumentForUser` 循环过滤，查询量从 `safeLimit * 3` 降至实际 `safeLimit`，性能更优。
- 移除对 `canReadKnowledgeResource` 的依赖引入。

#### `server/services/knowledge-graph.js`

- `getGraphSummary` 接受完整用户上下文（含 `id`、`role`、`unit`），查询改为以所有者隔离为基准，与知识库访问控制策略保持一致。

#### `server/services/rag-documents.js`

- **`getKnowledgeQualityReport`**：修复 `getGraphSummary(userId)` 的错误调用——原先传入裸 `userId` 导致图谱摘要逻辑以字符串参数执行；改为 `await getGraphSummary(normalized)` 并加入 `try/catch` 容错：图谱摘要失败只记录 `warn` 日志并以空指标兜底，不影响质量报告整体可用性。

#### `client/chat/rag-documents.js`

- 知识库工作台辅助统计失败时细化错误提示：分别标注"统计摘要"、"质量诊断"、"图谱摘要"哪个面板不可用，替代原来笼统的"统计"标签；对每个 rejected promise 打印 `console.warn` 便于排查。

### 2. 桌面端滚轮精确命中修复

#### `desktop/preload.js`

- **新增 `getSessionListScrollRegion(list)`**：根据 `#session-list` 的 `getBoundingClientRect` 与 `.sidebar-session-section-label` 的矩形合并计算精确的可接管滚动区域，替代原来直接取整个 `.sidebar` 的边界框。
- **`isPointerInsideSidebar` → `isPointerInsideSessionList`**：重命名并调整命中判定：`target.closest` 检测范围从 `.sidebar` 收窄到 `#session-list, .sidebar-session-section-label`；坐标命中从 `sidebar.getBoundingClientRect()` 改为 `getSessionListScrollRegion(list)`。
- **`getSessionListTarget`**：移除 `target.closest('.sidebar')` 的宽泛命中分支；坐标回退时改用 `getSessionListScrollRegion(list)` 并在返回 `null` 时安全退出。
- **视口同步**：`publishSessionListViewport` 改为使用 `getSessionListScrollRegion(list)` 计算活跃区域；滚动区域不可用时主动上报 `active: false`，防止主进程持有过期区域数据。
- **侦听器绑定**：`pointerenter/pointerleave` 从整个 `sidebar` 迁移到 `sessionLabel`（`.sidebar-session-section-label`）；`pointermove`/`pointerdown` 回调更新为调用 `isPointerInsideSessionList`。

#### `desktop/session-list-wheel.js`

- `shouldForwardSessionListWheel` 新增边界测试：指针在侧栏宽度内但位于会话列表右侧（如 x=289，侧栏宽 290）时，正确返回 `false`，不再误转发。

### 3. 测试更新

#### `tests/knowledge-sharing.test.js`

- 用例「共享资源可以只授权给指定个人」→「知识库文档严格按所有者隔离，普通用户不能因共享范围读取其他用户资源」：断言 `canReadKnowledgeResource(shared, otherUnit)` 从 `true` 改为 `false`，补充管理员可读断言。
- 用例「知识库资源判定与 SQL 过滤器绑定用户和单位范围」→「知识库资源 SQL 过滤器仅允许所有者，管理员可跨用户读取」：断言 `buildCollectionAccessFilter` 不再含 `scope = 'shared'` 和 `allowed_user_ids` 参数；`buildDocumentAccessFilter` 普通用户断言简化为 `d.user_id = ?`，补充管理员 `1 = 1` 断言。
- 用例「单位白名单 SQL 使用精确 token 匹配」→「知识库集合筛选不受普通用户单位字段影响」：断言过滤 SQL 简化为 `c.user_id = ?`，不再含 `LIKE`/`strpos`。
- 用例「Graph-RAG 汇总接受完整用户上下文以应用共享单位范围」→「…以应用文档所有者隔离」。

#### `tests/recipient-permissions-http.test.js`

- 用例「shared RAG recipients can list resources but cannot mutate documents or collections」→「non-admin RAG users cannot list or mutate another user's shared resources」：断言接收者列表中不应包含其他用户的集合/文档（`some(item => item.id === X)` 期望为 `false`）。

#### `tests/desktop-session-list-wheel.test.js`

- 补充边界测试：x=289（侧栏宽 290 内、列表右侧）应返回 `false`。
- 补充 `preload.js` 的结构性断言：包含 `getSessionListScrollRegion`、`isPointerInsideSessionList`、`target.closest('#session-list, .sidebar-session-section-label')`；不再包含旧的 `if (target.closest('.sidebar')) return true;` 分支。

## 升级注意事项

- **无新增数据库迁移**，无新增环境变量。
- **知识库共享语义变更**：普通用户不再能通过 `scope = 'shared'` 或单位白名单读取他人的知识库集合与文档。如果业务上存在合法的跨用户知识库共享需求，需由管理员账号统一管理，或后续通过 `knowledge_permissions` 细粒度授权（需对应服务层恢复相关查询）。
- **桌面端**：本版本修复后，右侧消息区的滚轮不再被误转发至会话列表；若发现 Electron 环境中滚轮行为异常，请确认 `desktop/session-list-wheel.js` 的 `SIDEBAR_WIDTH` 阈值与实际 CSS 侧栏宽度一致。
- 升级前按既有流程备份 PostgreSQL 与上传文件。
