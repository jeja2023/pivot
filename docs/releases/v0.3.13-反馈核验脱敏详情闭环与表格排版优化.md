# v0.3.13 - 反馈核验脱敏详情闭环与表格排版优化

## 版本概述

本版本重点解决管理员在进行**模型与路由反馈核验**时的“上下文缺失盲区”与“界面排版溢出截断”问题，在严格坚守**用户隐私安全与最小知悉原则**的前提下，构建了**单轮提问脱敏关联、全信息对比详情弹窗、原地核验流转、紧凑表格列宽重构与环境配置对齐**的完整工程闭环。

---

## 核心更新

### 1. 反馈核验当轮提问脱敏关联（Routing Query Preview）
- **隐私保护与最小知悉**：严禁向管理员暴露用户的全量私有会话历史长文；坚持决策审计底表（`decision_records`）的安全架构设计，绝不持久化用户提问原文，全套决策学习与审计门禁测试保持 100% 通过。
- **单条提问动态关联与规则脱敏**：核验队列接口在按需查询反馈数据时，动态通过子查询定位触发该轮路由决策时的单条提问；下发前强制调用 `redactRoutingText` 规则脱敏引擎，彻底滤除手机号、身份证、邮箱、Token 密钥、本地绝对路径以及内网 IP 等隐私标识，让核验人员能够理解当轮业务提问意图，同时杜绝隐私泄漏风险。

### 2. 反馈核验详情弹窗（#route-feedback-detail-modal）与操作闭环
- **独立顶层定位**：将核验详情弹窗脱离 `.settings-scale-canvas` 的 CSS 变换缩放画布，自动挂载至顶层 `document.body`，杜绝弹窗位置偏移、居中剪裁与视口遮罩范围不全问题。
- **全要素决策对比呈现**：
  - **当轮提问卡片**：醒目展示规则脱敏后的提问内容，并附带 `已规则脱敏·不含隐私` 状态标识；
  - **决策对比网格**：直观对比“路由场景”、“原始系统决策”与“用户建议修正”（如 `直接回答` → `请求补充信息`）；
  - **用户与上下文追溯**：展示提交用户名、账号及所属单位，并提供关联会话标题及一键复制完整会话 ID 功能；
  - **反馈说明与核验备注**：清晰展示用户选择的原因分类与补充说明卡片；支持核验人员在弹窗内直接录入核验备注（可选，最多 500 字）。
- **原地流转与精简交互**：弹窗底部直接提供【采纳此建议】与【不采纳 / 驳回】操作，核验完成后自动刷新列表并关闭弹窗；移除头部多余重复的 `×` 按钮，保留底部【关闭】按钮并支持 `Esc` 键与背景遮罩点击关闭。

### 3. 反馈表格紧凑排版与字段防截断重构
- **38px 单行紧凑高标准**：数据表格严格保持 `height: 38px` 紧凑表格视觉标准，彻底杜绝换行撑高导致的高度不一致与版面混乱。
- **各列列宽与 Flex 弹性精细重构**：
  - **提交时间**：由 `125px` 扩展至 `160px`，完整展示 `YYYY-MM-DD HH:mm:ss`（如 `2026-10-12 08:06:44`），根除截断为 `08:06...` 的缺陷；
  - **提交用户**：由 `110px` 扩展至 `160px`，并将主名称设置为 `flex-shrink: 0`，保证 `管理员 (@admin)` 及单位标签完整舒展；
  - **关联会话**：由 `120px` 扩展至 `190px`，将标题调整为 `flex: 1 1 auto; min-width: 0`，彻底解决短 ID 挤压导致会话标题被压成一条竖线 `|` 的问题；
  - **当轮提问**：表格新增当轮提问专属列（分配 `220px`），文本单行截断并支持点击直接呼出详情弹窗；
  - **路由场景**：调整至 `100px`，适配各类场景定义；
  - **当前 → 建议**：由 `160px` 扩展至 `230px`，完整显示长动作对比（如 `直接回答 → 请求补充信息`），不再出现省略号；
  - **原因与补充说明**：由纯 `auto` 调整为 `auto; min-width: 180px`，合理分配弹性剩余空间；
  - **核验操作**：由 `160px` 扩展至 `200px`，并将操作按钮统一配置为 `white-space: nowrap; flex-shrink: 0`，确保【详情】、【采纳】、【不采纳】三个按钮一字排开完整显示，杜绝第三个按钮被挤压为 `...`；
- **全单元格悬停 Tooltip 气泡**：`appendTextCell` 自动注入原生 `title` 属性，鼠标悬停任意单元格均可即时查看完整文本；表格最小宽度设为 `1560px` 并支持容器平滑横向滚动。

### 4. 样式体系解耦与文字左对齐加固
- **解耦通用弹窗样式继承**：弹窗节点移除 `modal` 类名，彻底阻断通用样式库中 `.modal { text-align: center; }` 的全局居中污染。
- **主壳与工作区双 CSS 样式包锁定**：在 `modals-forms.css`（编译入 `chat.shell.css`）与 `admin-layout.css`（编译入 `chat.workspace.settings.css`）中，对 `.route-feedback-query-card` 与 `.route-feedback-note-card` 双重声明 `text-align: left !important`，确保输入与展示卡片内的文本严格左对齐。

### 5. 生产环境配置（.env）与模板（.env.example）完全对齐
- **配置补齐**：排查并补齐 `.env` 中此前遗漏的知识库语义蕴含复核核心参数：
  - `PIVOT_KNOWLEDGE_SEMANTIC_VERIFIER_ENABLED=true`
  - `PIVOT_KNOWLEDGE_SEMANTIC_VERIFIER_MAX_TOKENS=700`
- **逐行结构一致性**：`.env` 与 `.env.example` 达到 902 行逐行 100% 对齐，各配置分组与注释严格一致，仅在密钥与特定实例参数保留本地安全配置。
