# v0.7.137：应用服务配置独立页面

日期：2026-11-09。

在设置导航中新增“应用服务”，集中维护OCR、语音识别和PPT Master，支持按应用或服务名搜索、刷新状态、测试连接并打开原有配置弹窗。模型配置页保留聊天模型列表、向量、重排序和检索策略，知识库中的模型配置跳转不受影响。

迁移只调整导航和界面职责，不迁移配置数据、密钥或服务容器。系统admin继续维护全站服务连接，其他管理员按原权限查看状态；普通账号保留个人模型配置，不显示管理员应用服务页，后端配置接口的权限校验仍独立执行。

应用服务目录独立加载，模型列表加载和分页不再触发OCR及语音状态检查。切走或关闭设置时取消旧请求，迟到结果不覆盖新分区；搜索隐藏或显示已有卡片，不重新填充刚保存的服务配置。OCR原有测试和保存事件改由稳定设置容器委托，动态卡片刷新后仍可操作。

后续服务在统一目录添加名称、用途与既有配置模块入口即可，不必继续扩展模型列表的职责。此次没有建立新的配置数据库或插件运行框架。

验证见[专项报告](../reports/应用服务配置独立页面验证-20261109.md)。未部署生产，PPT Master等独立服务镜像无需更换。
