# Pivot v0.1.124 发布记录：工具策略系统管理员专属权限收口与前后端鉴权对齐

## 版本概览

- **版本号**：v0.1.124
- **发布日期**：2026-09-10
- **核心定位**：工具策略页面前端与后端微权限能力矩阵严格对齐，彻底收敛为系统管理员（内置 `admin`）专属可见与治理，消除普通管理员权限不足报错与空白页面问题。

---

## 变更背景与根因分析

在生产环境中，普通管理员（非内置 `admin`，`role = 'admin'`）账号登录并打开“系统设置 → 工具策略”页面时，系统提示“权限不足”通知，且页面工具列表完全空白。

### 根因排查

1. **前端入口权限偏松（`admin-only`）**：
   前端侧边栏 [`shell-start.html`](../../client/chat/partials/settings/shell-start.html) 与面板容器 [`tool-policy.html`](../../client/chat/partials/settings/tool-policy.html) 使用了 `.admin-only` 样式类。在此规则下，普通管理员能看到并点击“工具策略”标签，前端逻辑中甚至包含面向只读态的降级逻辑（隐藏编辑按钮、开关置灰）。

2. **后端安全矩阵强校验（`manageGlobalMcp`）**：
   工具策略页面载入时调用 `GET /capabilities/packages?include_tools=true`。该路由在 [`management-routes.js`](../../server/routes/mcp/management-routes.js) 中强制受守卫 `requireCapability('manageGlobalMcp')` 保护。而在 [`permissions.js`](../../server/permissions.js) 的权限矩阵中，`manageGlobalMcp` 仅向系统管理员（`ADMIN_TIER`）授权，普通管理员（`MANAGER_TIER`）为 `false`，且专门有安全测试强制断言普通管理员请求该接口时必须返回 HTTP 403 `PERMISSION_CAPABILITY_REQUIRED`。

3. **前后端脱节冲突**：
   前端允许普通管理员进入页面，但发起的关键数据请求被后端权限守卫 403 拦截，导致前端直接提示“权限不足”，页面无法呈现任何数据，造成困惑。

---

## 核心改进与实现

### 1. 工具策略入口与面板类名收敛为超管专享
- **侧栏导航标签**：在 [`client/chat/partials/settings/shell-start.html`](../../client/chat/partials/settings/shell-start.html) 中，将 `#tab-tool-policy` 类名由 `admin-only` 改为 `super-admin-only`。
- **页面内容容器**：在 [`client/chat/partials/settings/tool-policy.html`](../../client/chat/partials/settings/tool-policy.html) 中，将 `#tab-content-tool-policy` 类名由 `admin-only` 改为 `super-admin-only`。
- 普通管理员打开“系统设置”时，侧栏不再展示“工具策略”标签，彻底消除误导与报错。

### 2. 设置 Tab 路由守卫与回退重定向
- 在 [`client/chat/admin.js`](../../client/chat/admin.js) 中新增 `SUPER_ADMIN_ONLY_SETTINGS_TABS` 集合（包含 `'tool-policy'`）。
- 在 `normalizeSettingsTab` 中增加超管校验：非超管用户若请求 `tool-policy`（如历史本地缓存或直接调用），自动安全回退至其有权访问的默认分区（普通管理员回退至 `ops`，普通用户回退至 `models`）。

### 3. 数据加载与跨模块入口安全防御
- 在 [`client/chat/tool-policy.js`](../../client/chat/tool-policy.js) 的 `loadToolPolicy` 中将前置判定更新为 `if (!isSuperAdminUser()) return;`，杜绝非法调用出站请求。
- 在 [`client/chat/mcp-workbench-main.js`](../../client/chat/mcp-workbench-main.js) 的工具库工作台中，将“查看工具策略”入口按钮绑定 `isSuperAdminUser()` 条件渲染。
- 在 [`client/chat/mcp-workbench-actions.js`](../../client/chat/mcp-workbench-actions.js) 中增加点击前置权限拦截。

### 4. 文档与自动化契约测试
- 更新 [`README.md`](../../README.md) 中治理权限边界说明，明确“工具策略页面由系统管理员专属管理”。
- 在 [`tests/settings-page-contract.test.js`](../../tests/settings-page-contract.test.js) 中增加专属契约测试用例，断言类名隔离、路由拦截集和函数守卫，防止未来迭代退化。
