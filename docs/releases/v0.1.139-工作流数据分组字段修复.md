# v0.1.139 工作流数据分组字段修复

- **发布日期**：2026-09-18
- **修复范围**：`data.group_summary` 节点参数向导。

## 修复内容

`groupBy` 的多字段标签控件不再仅依赖工具目录对象的单一名称。渲染时同时校验节点持久化的工具名、MCP 完整名/短名、工具标题和 Schema 描述，因此工具目录缓存或 MCP 前缀差异不会把“分组字段”降级为普通文本输入。

多字段会按用户添加顺序保存为数组，例如：

```json
[
  "部门",
  "状态"
]
```

运行时按字段组合生成分组键；历史单字段字符串仍继续支持。

## 发布说明

版本从 `v0.1.138` 升级至 `v0.1.139`，用于更新前端静态资源缓存键。部署后需重启 Pivot 服务或桌面应用，并刷新浏览器页面。

## 同版本体验优化

- 数据契约的“编辑契约”操作移至标题行右侧，避免与契约摘要混排。
- 输出字段编辑区的根类型、字段类型、列表项类型统一使用全局 `form-input` 下拉框；字段名、说明、必填和删除操作对齐为响应式表单行。
- 契约弹窗改为输入/输出两个清晰面板，保留代码字体只用于 JSON 内容，其他标签、按钮和控件使用全局字体和字号。
