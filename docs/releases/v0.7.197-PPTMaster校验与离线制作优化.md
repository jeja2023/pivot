# v0.7.197 PPT Master 校验与离线制作优化

## 变更内容

- 末步成功导出后，宿主直接进入交付核验。任务步骤达到上限不会丢失已登记的 PPTX。
- 项目校验记录安全的错误键集合。缺项减少时保留推进状态，不会因连续修正规范而误触发重复失败暂停。
- 一次模型动作批次收集全部可公开的字段问题。模型可以返回 `repairActions`，每项带原批次 `index` 和完整动作。只有问题数量或字段数量减少时才继续局部纠正。
- 模型预检和正式动作共用代码围栏 JSON 解析。视觉探针兼容蓝、蓝色、藍、藍色和 blue 等等义回答。
- 增加「仅作排版素材」图片用途。此类图片登记为装饰资源，不要求视觉模型阅读。事实图片、图片重建和图片引文仍受视觉能力与读取进度约束。
- 图表数字核验支持千分位和末尾小数零的精确等值。执行器扩展每页和全稿清单容量到 24 项和 480 项，仍逐项回读核验。
- 页序核对与 PPT Master 的数字分段排序一致。模板规则引文变为可选复核信息，模板安装版本摘要继续强制核验。标准号和明确型号不会被识别为业务指标。
- 已核验 PPTX 与项目源包分开处理。源包生成、读取或存储失败时返回单独提示，PPTX 仍可完成交付。模板工作区交付继续要求有效源包。

## 执行器能力

新版离线执行器 `/v1/info` 必须包含以下能力标识。

- `checklistGroupedValues: 1`
- `expandedChecklist: 1`
- `optionalSourcePackage: 1`
- `startupHealthTimeoutSeconds: 300`

构建打包时会验证这些能力，`--skip-build` 也会验证。旧任务保留原执行器身份和任务卷，新任务使用包含本版能力的 `ppt-master:6.10.0-pivot0.7.197` 镜像标签。
