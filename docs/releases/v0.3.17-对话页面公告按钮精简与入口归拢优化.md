# v0.3.17 - 对话页面公告按钮精简与入口归拢优化

发布日期：2026-10-16

## 版本概述

本版本重点针对对话页面侧边栏的交互布局进行精简收敛。鉴于主页个人工作台顶部已常驻公告中心入口（`#personal-announcement-btn`）并具备完整的未读红点提示与弹窗交互，本次更新彻底移除了对话页面（`/chat`）侧边栏中的重复公告按钮与动态注入的浮动铃铛，避免页面导航区域元素堆叠，使会话列表与对话主视口保持清爽聚焦。

## 核心改动

### 1. 对话页面侧边栏布局精简

- 从对话主界面侧边栏模板（`client/chat/partials/workspaces/chat-shell.html`）中移除 `chat-sidebar-announcement-btn`（“公告中心”按钮）。
- 消除“返回工作台”、“新对话”、“搜索会话”与“最近会话”之间的多余横向/纵向操作干扰，提升会话列表在不同分辨率与窄屏环境下的展示纯粹度。

### 2. 动态铃铛挂载逻辑治理

- 治理 `client/chat/announcements.js` 中的 `mountAnnouncementBell` 兜底逻辑：取消原先在找不到 `.app-brand-mini` 时自动向 `.sidebar-tools` 或 `.sidebar-header` 追加 `#announcement-bell`（“公告”小胶囊）的行为。
- 彻底解决对话页面侧边栏同时出现“公告中心”与“公告”双按钮的排版冗余问题。

### 3. 公告中心状态驱动与显示解耦

- 更新 `renderAnnouncements` 渲染逻辑：仅在宿主容器被显式且合法挂载时激活铃铛样式，未挂载的辅助节点默认保持隐藏。
- 确保系统通知、重要公告与强确认弹窗的查阅入口统一归拢至个人工作台页面顶部操作区（`personal-top-announcement`），其未读红点计数、多分类查阅及详情弹窗交互保持完整可用。

### 4. 自动化契约与渲染测试对齐

- 同步更新前端安全与流式渲染测试集（`tests/security-chat/rendering-streams.js`）：将公告模板断言调整为 `chatHtml` 不匹配 `chat-sidebar-announcement-btn`，同时继续校验 `personalHtml` 保留 `personal-announcement-btn`。
- 聊天安全回归 156 项测试及前端静态资源检查全量通过。

## 兼容性与影响

- 向后兼容：不涉及数据库模型、后端接口及本地存储结构变更。
- 用户操作：用户若需查阅系统公告中心、全部已读或历史公告，点击左上角“返回工作台”即可在工作台顶部直接进入，交互链路更统一。
