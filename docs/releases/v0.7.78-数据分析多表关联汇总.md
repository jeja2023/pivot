# v0.7.78 数据分析多表关联汇总

日期：2026-10-31。本记录描述工作区中的基础版功能与验证情况；版本号已更新，尚未构建发布包或完成目标环境验收。

## 已实现

- 在“数据分析 → 字段治理 → 跨数据集模型”中复用已有模型和关联配置，按关联后的数据选择分组字段，计算记录数、求和、平均值、最小值或最大值。
- 第一条关联的左表是起点，后续关联从已连接表指向新的右表；支持左关联和内关联，最多使用 8 条有效关联。查询会拒绝环路、重复连接已加入的右表和不连通的关系。
- 运行时重新检查模型、数据集和关联字段权限；分组及数值字段也必须属于当前用户可访问的字段。界面展示关联后的汇总表，最多显示 100 组并提示截断。
- 更新使用帮助，说明关联方向、结果限制、数值转换和一对多、多对多关系可能造成的重复统计。

## 范围与限制

关联字段按文本形式比较，空值不匹配；数值汇总忽略不能转换为数值的值。计数计算关联后的记录数，关联造成的重复行也会计入。用户需要先核对关联键、基数与统计口径。

当前只提供单个分组字段和一个汇总值，结果以表格展示；跨表结果接入图表、透视表、分析资产和导出仍未实现。各关联的既有预览仍是单条两表关系的预览。

## 验证与后续验收

- 关联规划测试通过，覆盖四表链路、环路和不连通关系；相关改动文件的 ESLint、语法和差异空白检查通过。
- PostgreSQL 集成测试因测试库连接超时未能启动；独立 DuckDB 查询测试未返回结果。已添加相关测试，但多表真实查询、权限和数值结果尚需在可用环境补跑验证。
- 本轮未运行全量回归、构建安装包或镜像，也未完成浏览器及目标环境验收。版本更新不代表已经部署。
