# v0.7.112 — BI 对象保留与持续完整性巡检

对应 v2.0 建设方案第 13.5、20.2、20.4 节。对象回收和完整性检查接入既有维护服务，巡检读取占用统一持久分析预算，不建立第二套队列。

## 保留规则

来源对象解除引用后至少保留三十天，普通结果文件保留七天，终态运行记录保留九十天，已可靠投递的审计保留一百八十天。未投递审计继续保留。当前数据绑定、活动任务、固定分析视图、仪表盘上次成功结果和备份引用均阻止删除；固定报告不因创建时间较早而失去数据。

固定报告与运行登记共用对象行锁，更新或删除消费者时释放旧保留；软删除资产经过九十天后才清理记录。没有消费者的旧检查和清单分批解除引用，来源对象从解除时重新计算最短保留期。结果到期后保留来源记录和明确的到期状态，分页及导出拒绝继续读取，用户可以按原版本重新计算。

GC 先在事务中确认无有效引用并进入带代次的 deleting 状态，再删文件和登记 expired；删除失败保留回收状态供重试。另行核对当前绑定、活动任务和当前受控数据版本，避免引用异常时误删。损坏对象只隔离，不自动生成替代字节或修改业务结果。

## 持续巡检

每五分钟处理一批对象和文件，数据库保存对象、文件及来源清单游标。分批全量检查摘要、长度、清单成员、发布绑定与完整检查、结果产物、过期槽位和引用泄漏。记录最近完成全清单检查的时间，超过一天仍未完成形成异常记录。

孤儿文件和符号链接形成诊断记录，不自动认领。对象缺失或内容不符会隔离对象、标记依赖绑定为来源完整性异常，并阻断新的分析及受影响运行的读取。巡检不改变权限、不切换数据水位、不修补数值。

临时目录清理逐任务判断状态和槽位；即使父目录年龄很旧，也不递归删除活动任务。原有工作区导出清理保持兼容。

- 与对象、摄取、模型流水线组合二十二项通过，包含百万行完整导入；与统一预算及流水线组合二十一项通过，均无失败/跳过。
- 完整静态门禁、全量 ESLint 和 TypeScript 检查通过；真实浏览器原建模消费链回归通过，用例 25.8 秒。
- 新增幂等迁移 202611070004_analysis_retention_reconciliation，初始化快照同步；索引声明二百五十条、关键清单三十六条。

这些结果是本机隔离工程验证。生产环境的每日全清单时长、目标容量、独立备份和运营告警认证仍按用户约定暂不执行，不记为生产门禁通过。
