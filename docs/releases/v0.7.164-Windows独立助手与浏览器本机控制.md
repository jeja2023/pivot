# v0.7.164 Windows 独立助手与浏览器本机控制

日期：2026-11-16。启用源码版本 v0.7.164，归档独立 Windows 助手、浏览器配对、账号隔离和紧凑界面。此前数据建模和 PPT Master 优化分别保留 [v0.7.163](v0.7.163-数据建模工作台与弹窗交互优化.md) 和 [v0.7.162](v0.7.162-PPTMaster预算与制作体验优化.md) 的记录。

## 功能与界面

- 网页在工具库本机授权中心生成五分钟有效的一次性配对码，独立助手在用户当前 Windows 电脑确认服务地址和账号后配对。本机密钥和受限凭据由系统安全存储加密保存，专用通道使用设备签名及一次性挑战，不向助手复制普通浏览器登录凭据。
- 浏览器15秒续期，45秒无续期后拒绝新操作，连接最长8小时；后台任务持久化服务端确认的绑定。其他浏览器和调用方自报元数据不能使用该绑定。正常退出、重新登录、重建配对或撤销后旧连接失效。
- 断开并换号先停止、等待旧执行结束，清除本机授权并生成新身份。操作继续限制在标题和进程名匹配的前台应用，支持控件摘要、截图、点击、非密码输入和等待；每次本机确认，确认后还会复核任务及授权。超时的已领取桌面动作不自动重放。
- 默认窗口620×620、最小540×600，移除英文菜单；统一全局字体及控件尺寸，采用横向标签、紧凑按钮行，进程名支持常用建议和手动填写。支持尺寸下长账号、长状态和明暗主题均无页面溢出，完整提示保留。

## 升级与交付

1. 重建并部署 Pivot 主应用，按正常启动流程完成 `202611160001_web_local_helper` 迁移；迁移新增配对表、索引及 `agent_runs.helper_browser_key` 列。随后刷新网页加载配对入口。
2. 在用户电脑安装独立 Windows 助手并重新配对、授权。原发布实现要求远程 HTTPS；后续已补充经本机确认的远程 HTTP 直连，须更新含此改动的助手包，见[HTTP 兼容记录](../reports/windows-local-helper-http-20261116.md)。现有桌面客户端可继续使用原有桥接，无需为网页入口单独重装完整客户端。
3. 正式助手构建使用 `npm run build:local-helper`，要求现有 Windows 发布者与代码签名配置；开发验证使用 `--unsigned` 且安装包明确标记 Dev。支持独立安装、卸载和手动升级，没有自动升级功能。详见[部署说明](../deployment/Windows独立本机助手.md)。

没有新增第三方依赖。助手有独立的本地界面及受限预加载通道，不能将它作为普通网页的无限本机权限。离线断开可能尚未获得服务端撤销确认，需在浏览器撤销旧连接；已经发生的外部动作无法承诺回滚。现有客户端隐身网关环境还需按目标网关策略核对助手端点可达性。

本次只同步源码版本、包版本及锁文件、README、设计基线、使用与部署文档。已有 v0.7.162 未签名开发验证安装包、校验清单和截图均保留原身份；没有因升版生成 v0.7.164 安装包或主应用镜像。
