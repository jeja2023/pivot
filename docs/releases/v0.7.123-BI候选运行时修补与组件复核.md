# v0.7.123 — BI 候选运行时修补与组件复核

- DuckDB Node API与全部平台绑定固定为同一1.5系列维护版本1.5.6-r.2；实际Windows库报告v1.5.6。保留现有编译、语义及持久协议，未升级到2.0系列。
- Linux 镜像改为实际创建 SQLite 数据库并查询，避免仅加载惰性模块漏掉缺失绑定；Windows 打包隔离准备 Electron ABI 绑定，按目标包依赖版本和摘要核对后写入制品，并实际运行制品内查询。宿主 Node 使用的原生文件保留，不以 Node 内置 SQLite 通过代替旧读取入口可用。
- SQLite 固定为官方12.11.2维护标签，补充 Electron43/ABI148支持。npm注册表没有该版本，锁文件固定官方源码归档URL与SHA-512；对应官方发布原生资产另核对发行者提供的SHA-256，未改用13主版本。
- 最终组件扫描同时检查操作系统、npm、Python、Java、独立二进制及Windows包内组件；CPE同名、发行版回补和扩展适用性逐项核对，不通过全局豁免隐藏结果。
- 已完成52项正式功能组合和沙箱实际加载/拒绝扩展验证；金额、指标、全量导入、追加批次、发布刷新、缓存、分页与导出保持一致。构建、故障、容量和总验收以本修补版本继续执行。
