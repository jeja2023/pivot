# v0.7.18 对话任务执行体验升级

日期：2026-10-20。依据：[优化改造方案](../design/Pivot对话任务执行体验优化改造方案_2026-10-20.md)。

对话中的持续任务现在有独立于最终回答的执行过程：真实工具操作、耗时、尝试、审批和结果文件留在对应消息旁；历史消息与虚拟列表继续关联原任务。模型输出结束只表示参数或内容生成结束，工具开始、完成、失败、复用和暂存由实际运行事件决定。

任务进度改用轻量读取接口，按账号和有效来源会话校验。事件采用固定公开字段、脱敏、增量游标和有界历史分页；原始模型事件与审计上下文不直接展示。实时通知与轮询共享状态，断线保留最后确认结果，切换会话拒绝迟到响应。

对话和输入区提供补充、暂停、继续、停止及多任务选择。工具审批同时绑定输入摘要、请求标识和有效期，数据库比较更新避免重复放行并保留同期任务约束；过期请求可由用户重新申请。没有增加无边界“始终允许”，工作流审批、外部动作提交和回滚仍走既有受控详情。

文件卡来自实际 Artifact 与 Rendition，展示版本、格式、大小、就绪/过期及本机交付状态。查看、下载和本机保存复用现有权限、一次性下载令牌、目录授权与设备回执。文件生成与实际本机保存明确区分；没有核验记录不会标记为已核验。

升级步骤：更新源码，重启服务端，重新加载网页或桌面页面。启动迁移自动创建 `idx_agent_events_run_type_seq` 组合索引，原始事件和历史步骤保留，无新增运行依赖或必需环境变量。大型事件库应为索引构建安排正常维护窗口。

本次交付源码与验证记录。没有构建安装包、发布更新、推送 Git 或部署生产。具体回归数量、浏览器证据及未实测边界见 [验收报告](../reports/v0.7.18-对话任务执行体验验收报告_2026-10-20.md)。
