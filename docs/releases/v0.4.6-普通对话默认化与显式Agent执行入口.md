# v0.4.6 普通对话默认化与显式 Agent 执行入口

发布日期：2026-10-19

## 版本摘要

本版本取消聊天输入区中“普通 / Agent”的对等模式选择。普通对话成为唯一默认发送路径；需要后台任务语义时，用户通过“以 Agent 执行”按钮主动升级。

## 用户交互

```text
输入消息 → Enter / 发送 → 普通对话
输入任务 → 以 Agent 执行 → 持久 Agent Run
```

普通对话可以按需检索资料或请求工具授权，但不会因为消息长度、关键词、资料检索或工具候选而自动创建后台 Agent。

## 实现边界

- 删除普通/Agent 模式下拉及其本地持久化选择；历史 `pivot_chat_mode` 不再影响后续消息。
- `sendMessage()` 默认固定发送 `chatMode=normal`；只有 Agent 按钮调用 `sendMessage({ chatMode: 'agent' })`。
- 执行中同时隐藏发送和 Agent 按钮，避免重复提交；停止后恢复入口。
- 管理员关闭聊天 Agent 时，Agent 按钮禁用并提供原因；服务端仍以 `AGENT_EXECUTION_DISABLED` 为最终拒绝边界。
- 服务端保留 `chatMode=agent` 协议，以兼容恢复、API 和现有任务执行链；本次只收敛用户界面与默认行为。

## 升级说明

部署并刷新聊天页面后生效。用户无需迁移设置；旧版本保存的普通/Agent 选择不会再触发后台任务。若要执行连续任务，请在输入任务后点击“以 Agent 执行”。
