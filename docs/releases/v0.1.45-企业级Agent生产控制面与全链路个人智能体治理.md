# v0.1.45 版本发布记录

## 概述

**Pivot（智枢）v0.1.45** 是一次里程碑式的重大升级，正式推出了完整的**企业级 Agent 生产控制面体系（Production Control Plane）**与**全链路个人智能体治理体系（Personal Agent Control Plane）**。

本次版本涵盖了从 Agent 技能/工作流的版本化发布与灰度门禁、工具调用可靠性追踪与熔断、多企业通信渠道（钉钉、企微、飞书、Slack、Webhook、邮件）可靠 Outbox 投递与交互审批、事件收件箱与多智能体协作，到个人 Agent 档案字段级乐观并发控制、自主进化提案与安全回滚、持续目标（Goal-Driven）触发引擎、个人数据一键导出与安全擦除、高可用生产演练工具集以及 8 篇全景治理文档，全面构筑了面向企业级生产环境的安全、可控、高可用的智能体运行底座。

---

## 核心变更

### 1. 技能与工作流版本化发布治理 (Skill & Workflow Release Lifecycle)
- **细粒度版本模型**：建立 `agent_skill_versions`、`agent_skill_validations`、`agent_skill_releases` 与 `agent_workflow_releases`，支持 Draft → Validating → Approved → Published → RolledBack 完整发布生命周期；
- **全自动多维发布门禁**：发布前自动执行清单规范校验 (Manifest)、数字签名验签 (Signature)、沙箱测试 (Sandbox Regression)、依赖与供应链风险检测及基准评测回归 (Evaluations)；
- **灰度发布与作用域隔离**：支持金丝雀灰度发布 (Canary / Grayscale Rollout)，提供租户级 (Tenant) 与用户级 (User) 隔离作用域；
- **一键安全回滚**：发布异常或指标劣化时，支持一键无缝回滚至历史指定稳定版本并保留审计溯源。

### 2. 工具可靠性追踪与智能熔断 (Tool Reliability & Circuit Breaking)
- **多维度可靠性指标采集**：实时统计每个工具及版本的调用成功率、P95 延迟、连续错误计数、副作用与超时指标；
- **加权评分与置信度下限**：基于最小样本置信度过滤与加权评分模型（`agent-tool-reliability.js`），对低分工具自动告警与健康度降级，提升复杂 Agent 任务长周期执行的稳定性。

### 3. 多渠道适配与可靠投递 (Channel Outbox & Multi-Platform Adapters)
- **主流企业办公协同接入**：新增渠道适配器层（`agent-channel-adapters.js`、`agent-channels.js`），原生支持 Webhook、钉钉 (DingTalk)、企业微信 (WeCom)、飞书 (Feishu)、Slack 及 邮件 (Email)；
- **事务型 Outbox 投递架构**：实现消息受控分块 (Chunking)、指数退避重试 (Exponential Backoff)、幂等投递与去重，保障网络波动下的可靠送达；
- **渠道内交互与签名防篡改**：支持渠道内的卡片交互与人机审批（`agent-channel-interactions.js`），采用时间常数 (Constant-Time) 算法校验交互签名。

### 4. 统一事件收件箱与多智能体协同 (Inbox & Multi-Agent Collaboration)
- **结构化智能体收件箱**：新增 `agent_inbox_events`，统一汇聚任务指派、执行状态变更、审批请求与人工干预事件；
- **多智能体协作机制**：提供智能体间的任务委派、DAG 子图调度与协作结果汇总（`agent-collaboration.js`）。

### 5. 个人智能体档案版本化与乐观并发 (Profile Versioning & Optimistic Locking)
- **多版本快照与回滚**：建立 `agent_profile_versions`，记录个人智能体身份设定、工作习惯、工具偏好的历史变更，支持版本一键还原；
- **字段级乐观并发控制**：在 `agent_profiles` 中引入 `field_versions`，防止多端并发编辑覆盖，精确报告字段冲突。

### 6. 自主进化闭环与审查验证 (Self-Evolution & Improvement Proposals)
- **提案全生命周期管控**：支持 Agent 自主进化提案的生成、规则审查、人工审批裁决、自动生效与一键安全回滚（`agent-evolution.js`）；
- **自优化建议生成器**：结合运行反馈与质量评估指标，自动产出高质量的智能体优化建议（`agent-improvement-suggestions.js`）。

### 7. 持续目标驱动引擎 (Continuous Goal-Driven Engine)
- **多模式触发源**：支持定时调度 (Timer/Cron)、Webhook 外部事件、文件系统监控与只读数据库变更触发（`agent-goals.js`）；
- **执行保护策略**：支持单触发幂等去重键 (Trigger Key)、冷却时间限制 (Cooldown) 与最大连续故障容错重试保护。

### 8. 个人数据自决与隐私合规 (Data Privacy & Compliance)
- **数据导出与全链路擦除**：支持一键导出个人 Agent 完整数据包（`agent-data.js`），并支持安全擦除所有个人画像、历史记录与私有记忆；
- **记忆分类与敏感数据治理**：记忆治理服务（`memory-governance.js`）支持敏感数据识别分类与临时上下文安全脱敏。

### 9. 生产运维工具与演练体系 (Operations & Reliability Drills)
- **高并发与故障演练**：新增 `scripts/agent-production-drill.js` 与 `scripts/agent-load-drill.js`；
- **数据恢复与密钥轮转**：新增 PostgreSQL 备份验证与灾备恢复脚本 `scripts/restore-pg-backup.js`，以及数据加密密钥安全轮转脚本 `scripts/rotate-encryption-key.js`；
- **完备的治理与运维文档**：在 `docs/agent-experience/` 目录下提供 8 篇全景文档，涵盖 P0-P2 需求清单、运维 Runbook、指标字典、发布 Checklist、安全回归矩阵与工作台原型设计。

### 10. 前端工作台与监控大屏升级 (Frontend Harness & Workspace UX)
- **智能体控制大屏**：`client/chat/agent-harness.js` 与 `client/chat/partials/workspaces/agent.html` 全新升级，支持发布管理、渠道投递、持续目标与进化审批等可视化操作；
- **内存与性能看板**：新增 `client/chat/memory-usage.js`，优化监控大屏性能与内存指标展示。
