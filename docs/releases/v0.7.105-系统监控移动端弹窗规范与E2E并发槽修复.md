# v0.7.105 系统监控移动端弹窗规范与 E2E 并发槽修复

日期：2026-11-06。

## 功能升级与缺陷修复

- 系统监控对话质量与移动端排版优化：
  - 为失败明细入口按钮补齐 `.hidden` 显隐样式控制，确保无失败记录时按钮正确隐藏，杜绝冗余元素残留。
  - 增强移动端（窄视口，如 390px）下监控卡片头部 `.monitor-panel-head` 与操作按钮组 `.monitor-panel-head-actions` 的自适应排版，支持纵向流式对齐与自动换行，避免产生横向滚动溢出。
  - 统一完善 `#monitor-failure-modal.modal-overlay` 遮罩与弹窗对话框的响应式宽度约束与盒模型内边距，弹窗关闭时主动清理已渲染的失败明细 DOM 节点，避免离屏超宽表格污染页面宽度计算。
- 端到端（E2E）并发回归测试稳定性保障：
  - 在 `scripts/run_e2e_tests.js` 统一注入保底 `MAX_CONCURRENT_AI_REQUESTS` 环境变量（默认至少 4 个并发槽），解决 CI 容器在缺省 `.env` 配置文件时回退至单并发槽导致多会话流式生成与切换测试死锁超时的环境依赖问题。
  - 为 `tests/e2e/chat-generation-navigation.spec.js` 的会话正文增量断言增加合理的异步超时宽限（15,000ms），保障高负载持续集成环境下的回归稳定性。

## 验证与发布

- 单元测试与基础门禁全部通过：`npm run check:standards`、`npm run check:text`、`tests/monitor-dashboard.test.js`。
- Playwright 端到端浏览器回归通过：
  - `tests/e2e/chat-generation-navigation.spec.js`（多会话独立生成与切换交互验证）。
  - `tests/e2e/smoke.spec.js`（系统监控概览、服务与质量分区移动端及桌面端无溢出访问验证）。
- 本次版本不涉及数据库迁移与接口协议破坏性改动。
