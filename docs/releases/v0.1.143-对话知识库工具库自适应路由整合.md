# Pivot v0.1.143 发布记录：对话、知识库与工具库自适应路由整合

## 发布概要

本版本把普通对话、知识库检索和工具库发现接入同一套受约束的语义路由层。用户可以继续用自然语言表达需求，系统在当前账号可访问、可授权的能力范围内为本轮会话缩小资料和工具候选；它不改变既有的权限、确认、审批与网络安全边界。

## 面向用户的变化

- 输入区新增“智能自适应”，默认按问题决定是否检索内部资料、是否给出已授权工具候选；
- 知识库可保持自动选择，也可通过专题库/标签筛选或“@”引用锁定本轮范围；
- 工具库支持模型自动选择、手动白名单和“@”显式引用；自动发现仅提供候选，首次启用与实际调用仍需要用户确认；
- 流式回答会呈现脱敏后的路由状态，长会话可恢复必要的路由摘要，避免重复输入选择；
- 普通对话仍是普通对话，不会因推荐工具而暗中转成持续运行的 Agent。

## 实现与运维

- 新增 Collection Catalog 与 MCP Tool Catalog，以规则、词法和可用时的向量相似度进行排序；同轮 Query Embedding 可被路由与检索复用；
- RAG 按真实整数 Collection ID 定向检索。目录未建立或 Embedding 服务不可用时，自动退回原有检索范围或既有工具链路，不因增强功能导致资料或工具不可用；
- 自动工具发现仅在 Capability 与会话授权、手动白名单过滤之后收敛候选，最终仍经 MCP Planner、执行策略、审批和网络预检；
- 增加可灰度启用、影子模式、路由指标批量聚合、管理端可观测性、按权限过滤的 MCP Resources 与 PostgreSQL 迁移；
- 对兼容的 Responses API 请求使用会话隔离 Prompt Cache；不支持该参数的端点会自动以无缓存请求重试。

## 安全边界

- 自动路由不得扩大用户的 Collection 可见范围、MCP 能力或手动工具白名单；
- 路由历史只保存脱敏摘要，不保存查询向量、工具 Schema、服务地址或凭据；
- 高风险、外部网络、本机浏览器和有副作用的工具继续遵循原有确认、审批、网络白名单和审计策略；
- 管理员可通过 PIVOT_CHAT_AUTO_ROUTE_ENABLED、PIVOT_CHAT_AUTO_RAG_ENABLED、PIVOT_CHAT_AUTO_TOOL_DISCOVERY_ENABLED 和 PIVOT_CHAT_ROUTE_SHADOW_MODE 进行总开关、分项灰度及影子观测；完整参数见 [配置注册表](../configuration-registry.md#对话自适应路由)。
