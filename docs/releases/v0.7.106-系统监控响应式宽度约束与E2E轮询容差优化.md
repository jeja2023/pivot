# v0.7.106 发布记录：系统监控响应式宽度约束与 E2E 轮询容差优化

- 发布日期：2026-11-06
- 版本编号：v0.7.106

## 变更摘要

1. **系统监控与路由反馈响应式宽度约束与盒模型修正**
   - 为设置工作区内 `.table-container`、`.route-feedback-table-wrap` 及 `.monitor-routes-table-wrap` 补齐 `min-width: 0; width: 100%; max-width: 100%; box-sizing: border-box;` 约束与横向溢出滚动，解决宽表格（如 1560px 宽度的质量复核明细表）在 flex 容器中因默认 `min-width: auto` 撑大 `.admin-content` 滚动宽度的问题。
   - 修复 `.route-feedback-filter-bar` 缺少 `box-sizing: border-box; min-width: 0; max-width: 100%;` 的问题，避免移动端视口（390px）下内边距与边框造成元素总宽度溢出容器宽度。
   - 对系统监控分区面板（`#tab-content-monitor [role="tabpanel"]`、`.monitor-panels`、`.monitor-panel-card`）强化宽度约束与横向裁剪保护，防止极端字体指标或布局浮点亚像素计算引起的微量溢出。
   - 同步重新编译打包 `client/chat/chat.workspace.settings.css` 产物。

2. **E2E 测试与高负载持续集成适配**
   - 调整 `tests/e2e/smoke.spec.js` 中系统监控缩放比例与全端无横向溢出断言的 `expect.poll` 超时等待至 `15_000ms`，与面板卡片加载等待时间保持统一，消除 CI 虚拟机构建与重压场景下的偶发超时。
