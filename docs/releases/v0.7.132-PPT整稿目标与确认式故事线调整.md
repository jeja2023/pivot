# v0.7.132：PPT整稿目标与确认式故事线调整

日期：2026-11-08。

创建前填写一份整稿目标：受众、整稿目的、阅读方式和目标时长。标准AI的大纲与初稿使用相同目标，生成后自动写入文稿；PPT Master制作请求、恢复查询和交付元数据保留同一合同。

侧栏按钮保持“结构”。整稿目标默认收起并带入原值，编辑重点改为每页职责、核心结论、故事线阶段、信息关系、与下一页的衔接和讲解时长，同时显示实际前后页标题。更改这些字段会随文稿保存；页面内容由独立的“按故事线调整”操作处理。

选择已授权模型、整稿或当前页并填写要求后，系统在后台生成方案。预览列出页序、每页原因、原结构与建议结构、原文字与建议文字；只有点击“确认应用并保存新版本”才修改页面。关闭预览可稍后继续，放弃或停止不会应用方案。重新打开文稿可恢复查询，过期的应用租约可重新确认。

方案保留全部页面，只允许重排未批准页、更新逐页结构与改写已有可编辑文字；单页范围不能改变其他页面或整稿顺序。已批准页位置、锁定及模板对象、图表表格、几何、来源、证据登记和素材均保留。引入当前页没有的数值、空文字删除及可检出的文字溢出会被拒绝；模型文字的事实含义仍需使用者在预览中核对。

生成及确认均复核编辑权限、原稿版本和内容摘要。自动保存不增版本时也会使旧方案失效；最终保存以原稿JSON为条件，并将文稿、所有者产物及两个版本登记放在同一事务。已保存的确认请求可重复提交而不增加版本。新方案仍消耗所选模型额度。

结构化在线编辑器提供上述逐页方案。完整引擎原稿PPTX仍走其原有原生对象编辑与方案确认流程，本轮不把任意原稿自动转换成结构化画布。
