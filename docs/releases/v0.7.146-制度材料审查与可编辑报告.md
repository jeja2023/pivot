# v0.7.146 制度材料审查与可编辑报告

日期：2026-11-09。源码工作区交付，未提交、部署或构建安装包。

## 使用方式

进入“应用 → 法规查询 → 材料审查”。填写报告标题、业务日期、执行模型与适用范围，选择制度，粘贴或上传材料，启动审查。任务列表保存进度，打开任务逐项核对制度和材料原文，修订说明、处理建议与人工备注后保存报告版本，再导出可编辑Word。

每条结论区分符合、不符合、待核实和不适用。符合或不符合必须带可逐字匹配的制度及材料引述，否则转为待核实；这只证明引用片段存在，不证明适用判断已经独立验证。报告明确保留该边界及未完成条目，不代表签批或法律适用认证。

## 执行与数据边界

- 制度按业务日期选择唯一有效且已复核的版本，多个版本重叠、未复核、归档或删除时拒绝继续。
- 最多三份制度、四份材料、一百六十个条目；制度与材料文字合计六万字符。支持粘贴文字、TXT/Markdown、DOCX文字和文本型PDF，每份上传不超过8MB。Word图片、嵌入附件不参与本次审查，PDF存在无法提取文字的页面时先要求文字识别复核。
- 全部制度上下文与材料参与每批判断，不静默裁剪；模型上下文不足时要求换模型或分次处理。每批最多八条，累计最多四十次模型调用、二百万计量Token，并接受个人模型额度；从Agent发起时进一步收紧到其剩余限制。
- 已完成批次、调用次数和用量持久保存；服务进程中断后打开任务可按过期租约恢复。停止后可显式续跑未完成批次，保留人工备注和已完成项；从属Agent结束或原额度耗尽时不能用续跑扩权。
- 修订与导出按预期报告版本执行，续跑生成新的报告版本。来源效力/内容变化、材料修改或撤回、账号失效和报告撤回会阻止旧报告读取或下载。已下载文件不受服务端撤回控制。
- 报告仅从本次已登记版本生成；通用产物接口不能分享或改写制度材料审查报告，也不能把任意文档内容挂到原报告的下载身份上。已导出的旧制品保留，本轮未提供未导出历史修订的恢复界面。
- Agent工具 `policy.review_report` 提供创建、进度、续跑、停止和Word导出；任务登记不是完成交付，真实导出记录才生成文件。
