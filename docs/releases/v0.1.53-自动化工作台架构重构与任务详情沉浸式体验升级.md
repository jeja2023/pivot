# Pivot v0.1.53 发布记录：自动化工作台架构重构与任务详情沉浸式体验升级

**发布日期**：2026-08-26
**版本号**：v0.1.53
**发布主题**：自动化工作台架构重构与任务详情沉浸式体验升级

---

## 核心更新概览

Pivot v0.1.53 重点对系统自动化中心进行了统一的信息架构收敛、界面排版重构与全链路交互打磨，确立了「任务」、「工作流」、「Agent 控制台」三权分立的清晰治理模型，并彻底消除了任务详情与列表上下堆叠拥挤的体验缺陷。

主要改进包括：
1. **自动化工作台 3-Tab 信息架构收敛**：梳理各模块职责，统一收敛为「任务」（执行与数据面）、「工作流」（DAG 图形化编排）与「Agent 控制台」（智能体控制与治理面），彻底消除命名混乱与定位重复；
2. **多 Tab 切换顶部标题栏绝对零位移**：统一 `.workspace-modal-header`、`.agent-modal-header` 与 `.agent-dag-modal-header` 容器的固定高度与内边距，实现无缝切换时零像素跳动；
3. **全宽任务列表与沉浸式详情视图切换**：彻底消除列表与详情上下垂直堆叠导致的表格压扁与详情挤压问题；默认 100% 全宽展示 15 列任务运行指标，点击任意记录平滑切入带返回面包屑的全屏详情视图；
4. **任务详情 5 大结构化 Sub-Tab 全局响应修复**：在全局事件总线中注入 `[data-agent-run-subtab]` 事件委托，彻底解决“概览、执行步骤、实时日志、输出物、审批与异常”子 Tab 点击无响应的问题；
5. **主页大模型会话 Agent 模式详情弹窗关闭机制修复**：补齐全局 `#agent-run-detail-close`、遮罩背景点击及 `Esc` 键监听，精准区分会话浮层模式与自动化工作区内嵌视图，确保随时一键关闭。

---

## 详细改进明细

### 1. 自动化中心 3-Tab 信息架构标准化
- **职责定位收敛**：
  - **任务（Tasks）**：统一承载一次性后台任务、工作流任务以及计划执行任务的执行状态、耗时、Token 用量与实时监控；计划任务统一并入任务筛选维度；
  - **工作流（Workflows）**：专注于 DAG 流程编排与图形化多步骤协同设计；
  - **Agent 控制台（Console）**：专注于自主智能体的控制与治理，管理持续目标、自主触发、通知渠道、技能包、常驻实例与运行环境。
- **文案与标签统一**：全面同步 `agent.html` 与 `agent-dag.html` 的二级导航标签为 `任务`、`工作流`、`Agent 控制台`，并在筛选下拉框中使用 `一次性任务`、`工作流任务`、`计划执行`。

### 2. 顶部导航与工作区标题栏视觉零跳动
- **尺寸与内边距统一**：在 `client/chat/styles/layout-refresh.css` 中将工作区模态框头部高度统一定义为 `64px`，内边距统一为 `12px 20px`。
- **单行文本防折行**：为标题 `h3` 和副标题 `p` 增加 `white-space: nowrap; text-overflow: ellipsis;` 规则，消除在不同选项卡之间切换时产生的标题栏高度抖动。

### 3. 任务列表与全屏沉浸式详情视图重构
- **全宽表格舒适呈现**：进入任务页面时，任务活动表格占满 100% 宽度，15 列详细指标（序号、标题、目标、类型、模型、模式、记录、工具、错误、Token 用量、创建时间、状态、操作）空间宽敞。
- **沉浸式全屏详情视图**：点击表格中任意一行或“详情”按钮时，列表隐藏，详情视图展开为整页黄金展示区；顶部呈现清晰醒目的 `← 返回列表 / 任务 / 标题 (#ID)` 面包屑。
- **一键平滑返回**：点击面包屑中的“返回列表”按钮或按键盘 `Esc` 键，立即返回全宽任务列表与对应分页。

### 4. 任务详情 5 大结构化 Sub-Tab 全局响应修复
- **全局事件委托**：在 `client/chat/agent-run-detail.js` 的 `document.addEventListener('click')` 中捕获 `[data-agent-run-subtab]`，确保无论在任何时机点击概览、执行步骤、实时日志、输出物、审批与异常均能毫秒级平滑切换。
- **空状态与首项自动聚焦**：完善数据装载与面板显示逻辑，确保选定任务后各子面板数据完整填充并移除空占位。

### 5. 主页大模型会话 Agent 模式详情弹窗关闭机制修复
- **弹窗关闭事件全局委托**：将关闭按钮 `#agent-run-detail-close` 及弹窗外侧遮罩点击事件纳入全局委托，支持 `Esc` 快捷键关闭。
- **场景模式精准路由**：在 `agent-run-detail.js` 中依据 `activeWorkspace` 精准判断调用场景：普通会话中呼出轻量浮层弹窗，自动化中心内激活沉浸式工作台视图，双向体验互不干扰。
