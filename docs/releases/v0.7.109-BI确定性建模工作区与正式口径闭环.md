# v0.7.109 BI 确定性建模工作区与正式口径闭环

日期：2026-11-07。上一版本：v0.7.108。实施依据：[BI 建设方案 v2.0](../design/Pivot_BI数据建模产品级建设方案-2026-11-06.md)。

本次完成 M1 确定性语义与工作区功能，并接通检查、发布和主要消费路径用于隔离验证。M2—M5 的可靠性、容量、运营和恢复建设仍继续，重型执行默认关闭；目标生产环境验证按用户要求暂不开展。任何本机通过记录均不代表 G0—G7 已通过。

## 用户行为

- 新建私人模型，选择唯一事实表，明确一行的含义和粒度键，添加最多八张维度表及一对一/多对一关联。
- 表单维护复合键、规范化、维度、指标 AST、单位/币种、有效期及新鲜度；拖图只改变布局，键盘和关系表提供替代路径。
- 显式保存整份草稿，修订冲突保留本页输入；全量检查固定不可变来源文件，再发布不可变口径版本。
- 正式分析选择固定发布版本，支持最多五个维度、十个指标和结构化筛选；总计覆盖完整过滤范围，展示截断有明确说明。
- 图表保留精确数值悬浮提示；透视小计通过固定清单重新查询；保存视图和仪表盘固定版本，升级须明确确认。
- 完整导出为后台任务，限二十万结果行/二百 MiB；CSV 转义危险公式前缀，XLSX 将编码与十进制显式写为字符串，附带口径和来源说明。
- 最新数据先检查后切换；检查失败保留原清单及原截止时间，字段逻辑类型、单位、币种和键业务含义变化要求重新发布口径。
- 默认个人资产；共享不扩展底层数据权限，另一位具有来源访问权的人员复核后才能启用。

## 配置与兼容

- `DATA_ANALYSIS_MODEL_ENABLED=false` 默认只允许保存与查看元数据；执行前需配置受限执行器。
- `DATA_ANALYSIS_MODEL_RUNTIME=docker` 为正式默认模式，镜像使用摘要或完整镜像 ID；开发进程仅限明确开发/隔离测试环境。
- 新增迁移扩展现有模型、指标、任务、视图和仪表盘；旧模型默认保持探索类型，旧查询接口不静默改变统计语义。
- 原始方案来源目录保持 610 条，不通过修改方案降低验收要求。生产容量、72 小时稳定性、独立灾备、业务签认和离线制品验收继续单独记录。
