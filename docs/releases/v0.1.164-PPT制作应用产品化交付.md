# v0.1.164 发布记录：PPT 制作应用产品化交付

发布日期：2026-09-22
版本号：v0.1.164

## 发布结论

Pivot 应用中心新增“PPT 制作”工作台。该能力以版本化演示文稿 IR 为事实源，集成主题模板、AI 双阶段生成、在线画布编辑、材料提取、数据分析图表、质量检查以及 PPTX/PDF/PNG 受控导出。它不是将 AI 回复或网页截图直接保存为文件，而是将编辑源稿、渲染结果和下载交付纳入现有 Artifact、CAS、Rendition 和 Delivery 治理链路。

## 用户可用能力

- 从空白文稿、内置模板、主题描述或已有材料开始创建。
- AI 先生成可编辑大纲，用户确认后再生成结构化幻灯片，避免一次生成整套不可控内容。
- 编辑器支持页面管理、文本、图片、形状、表格和图表，支持拖拽、位置和尺寸调整、撤销/重做、自动保存和历史版本恢复。
- 内置 8 套主题和 10 类布局，包含项目汇报、科技方案、政务、党建、培训、数据分析、极简正式和公益场景。
- 管理员可将当前主题保存为组织模板，模板经过草稿→待审核→已发布/已下架状态机后供组织使用；同时支持导入或导出经结构校验的 `.pivot-ppt-template.json` 模板包，模板包不携带脚本、宏或外部资源路径。
- 支持 Word、PDF、Excel、Markdown、CSV 等材料的安全文本提取；支持在页面插入当前账号可访问的数据分析数据集图表。
- 导出前检查文本溢出、低对比度、元素遮挡、内容过密、占位符、缺失图片、标题缺失以及可能的敏感信息，并在页面级定位问题。
- 可导出 PPTX、PDF 和 PNG；PPTX 保持常用文本、形状、表格和图表的可编辑性。

## 结构与安全边界

### 结构化文稿和版本

`presentation_documents` 管理文稿主信息，`presentation_versions` 保存每次已确认的 PPT IR 和内容摘要。保存采用 `baseVersion` 乐观并发控制，发生并发更新时返回冲突而不静默覆盖。模板通过 `Theme → Layout → Template` 三层表达，文稿持有模板版本和快照摘要，模板发布后的更新不会改变历史文稿。

### AI 与材料

AI 只能返回受限 JSON，不接受任意 HTML、外部 URL 或 data URI。服务端会校验页面比例、元素类型、边界、颜色、文本长度、表格/图表数据与素材引用。上传材料是事实来源，不可作为上游指令；模型无法确认的内容必须通过假设或警告返回，不能伪造成准确事实。

### 素材、导出和交付

图片素材复用安全上传检查，仅接受白名单图片类型，持久化为带用户与租户归属的 CAS 对象。导出结果使用内容摘要实现同一文稿版本、同一格式、同一渲染器版本的幂等复用；下载仍需要一次性短时令牌，并在兑换时复核用户、租户和产物归属。服务端不向浏览器返回存储键或绝对文件路径。

## 数据库升级

新增迁移：`202609220001_presentation_workbench_foundation`。

| 表 | 用途 |
| --- | --- |
| `presentation_documents` | 按租户和所有者隔离的文稿主信息与当前版本 |
| `presentation_versions` | 版本化 PPT IR、摘要、质量检查和保存说明 |
| `presentation_templates` | 管理员维护的组织模板、范围、状态与版本摘要 |
| `presentation_assets` | 图片素材到受控 CAS 对象的归属引用 |
| `presentation_exports` | 文稿版本到不可变 rendition 的导出记录 |

升级前请备份 PostgreSQL 和 Artifact/CAS 存储。应用启动会在事务内运行迁移；若数据库账户缺少 DDL 权限，修复权限后重新启动，禁止手工修改 `schema_migrations`。

## 依赖与兼容性

- 新增锁定依赖：`pptxgenjs@4.0.1`，许可证为 MIT。
- 渲染验证覆盖同一中文 IR 的 PNG（标准 PNG 文件头）、PDF（`%PDF`）和 PPTX（OOXML ZIP）输出。
- v0.1.164 首发时不支持任意第三方 PPTX 模板、VBA/宏、复杂 SmartArt、动画时间轴、音视频编辑或多人实时协作；后续 v0.1.167 已补齐受控实现与静态安全边界，复杂第三方对象仍不承诺逐字节无损还原。
