# v0.7.52 PDF 引用坐标高亮预览

发布日期：2026-10-28

## 改动

知识库和对话的 PDF 引用可在确认后打开带高亮的页面图片。服务端基于 PDF 原生文字坐标查找引用开头的唯一匹配，核验当前版本、访问权限和原文件 SHA-256，并限制文件大小、页面纵横比、请求频率及并发。无法唯一匹配时回退到原文页码，避免对重复文字或扫描件猜测坐标；预览不修改原文件。

高亮覆盖匹配文本所在的 PDF 文本项，可能包含文本项中的邻近字符；只匹配引用开头最多 100 个非空白字符，并非全文或跨页高亮。未包含原生文字的扫描页不能获得精确坐标，历史版本仅提供已保存摘录。引用预览需要浏览器允许新窗口；原文件大于 32 MiB 或页面尺寸超过限制时会降级为页码定位。

## 验证与限制

自动测试使用真实生成的 PDF 文件验证文字定位、重复及无匹配拒绝、来源哈希变化拒绝和 PNG 生成；生产法律文档、扫描件及具体浏览器效果尚需目标环境验证。无新增数据库迁移，依赖 v0.7.49–v0.7.50 的既有迁移；旧文档需重新索引生成页码定位。

WebDAV 可选择递归遍历同源目录，每次最多 100 个目录、最深 5 层和 1000 个文件，命中限制时标记扫描不完整；v0.7.53 增加了受保护的可选删除同步，仍不继承源端 ACL。因没有独立生产测试环境，真实业务黄金集、容量压测和恢复演练仍未完成，见 [生产验收与恢复演练指南](../deployment/知识库生产验收与恢复演练.md)。
