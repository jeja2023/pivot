# v0.1.36 生产客户端自动更新与运行依赖修复发布记录

## 版本信息

- 版本：`v0.1.36`
- 日期：2026-08-24
- Windows 更新源：`http://50.64.150.51:9006/downloads/`

## 客户端更新

- 安装包同时内置启用自动更新的 `resources/config.json` 和 `Pivot.exe` 同目录的 `config.json`。
- 更新源由生产 `remoteUrl` 和 `/downloads/` 自动推导。
- 受控局域网 HTTP 更新显式开启，并将来源严格限制为 `http://50.64.150.51:9006`。
- 现有客户端可由 IT 在 `Pivot.exe` 同目录投放新版 `config.json`，重启后激活自动更新。
- 外置配置优先于安装包内配置；两份配置应保持一致，避免外置旧配置覆盖新版设置。

## 发布文件

执行 `npm run dist:win` 后，以下文件会同步到 `downloads/`：

- `latest.yml`
- `Pivot Setup 0.1.36.exe`
- `Pivot Setup 0.1.36.exe.blockmap`
- `Pivot-Setup.exe`
- `SHA256SUMS.txt`

生产服务器挂载 `downloads/` 后，替换这些文件即可发布更新。当前客户端基线为 `0.1.36`，后续必须发布更高版本号才能触发自动更新。

## 其他修复

- `unzipper` 纳入 Docker 正式生产依赖并增加镜像构建校验。
- RAG 指标记录器解除 CommonJS 循环依赖，消除生产启动告警。
- 全量语义分析增加有界批次并发，缩短大任务总耗时。

## 国产化 Linux 客户端

- 正式支持目标收敛为 UOS/Debian 系 AMD64 和 ARM64；新增 `npm run dist:linux:x64`、`npm run dist:linux:arm64`、`npm run dist:linux:appimage:x64` 和 `npm run dist:linux:appimage:arm64`。
- Linux 构建要求 Node.js 22.12+、目标架构 Linux 构建机或同架构容器、干净 `node_modules`、目标架构 Chromium 和内置 Python。
- 构建前后会校验 Linux 元数据、PNG 图标、运行包 manifest，以及 `better-sqlite3`、DuckDB、Sharp 和 unzipper 原生模块是否可以加载。
- `dist:loong64` 已改为明确拒绝；当前 Electron Builder 和相关原生依赖没有完整 LoongArch64 发布链。
- 多架构校验清单分为 `SHA256SUMS-linux-amd64.txt`、`SHA256SUMS-linux-arm64.txt`，并自动生成合并的 `SHA256SUMS.txt`。
- `.deb` 不是无依赖静态包，离线 UOS 镜像必须预装 Electron 所需 GTK、NSS、通知和桌面集成库，或提供离线 apt 依赖源。
