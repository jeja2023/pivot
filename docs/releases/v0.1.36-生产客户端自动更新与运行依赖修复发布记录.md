# v0.1.36 生产客户端自动更新与运行依赖修复发布记录

## 版本信息

- 版本：`v0.1.36`
- 日期：2026-08-24
- Windows 更新源：`http://50.64.150.51:9006/downloads/`

## 客户端更新

- 安装包同时内置启用自动更新的 `resources/config.json` 和 `Pivot.exe` 同目录的 `config.json`。
- 更新源由生产 `remoteUrl` 和 `/downloads/` 自动推导。
- 受控局域网 HTTP 更新显式开启，并将来源严格限制为 `http://50.64.150.51:9006`。
- 现有客户端可由 IT 在 `Pivot.exe` 同目录投放新版 `config.json`，重启后激活自动更新。
- 外置配置优先于安装包内配置；两份配置应保持一致，避免外置旧配置覆盖新版设置。

## 发布文件

执行 `npm run dist:win` 后，以下文件会同步到 `downloads/`：

- `latest.yml`
- `Pivot Setup 0.1.36.exe`
- `Pivot Setup 0.1.36.exe.blockmap`
- `Pivot-Setup.exe`
- `SHA256SUMS.txt`

生产服务器挂载 `downloads/` 后，替换这些文件即可发布更新。已安装的 `0.1.35` 客户端读取外置新配置并重启后，会发现 `0.1.36` 并自动下载。

## 其他修复

- `unzipper` 纳入 Docker 正式生产依赖并增加镜像构建校验。
- RAG 指标记录器解除 CommonJS 循环依赖，消除生产启动告警。
- 全量语义分析增加有界批次并发，缩短大任务总耗时。
