# v0.7.97 Mermaid 预览加载与结果展示修复

日期：2026-11-06。源码基线：v0.7.96。

## 问题与修复

Mermaid 在不开放同源权限的沙箱页中运行，正式服务的 Helmet 默认发送 `Cross-Origin-Resource-Policy: same-origin`。沙箱具有独立的不透明来源，因此浏览器阻止其读取原脚本并报 `ERR_BLOCKED_BY_RESPONSE.NotSameOrigin`，随后页面显示“本地绘图组件加载超时”。原浏览器装置只设置 CSP，遗漏了 CORP，未覆盖这一部署条件。

新增两项固定公开脚本入口，使用匿名跨源脚本请求和对应的 CORS、CORP 响应头。只有 Mermaid 运行时与固定绘图桥脚本通过这些入口提供；其它静态资源保持同源限制。隔离页仍使用 `sandbox="allow-scripts"`，没有 `allow-same-origin`，并保留禁止联网、外部字体、子页面与表单的 CSP。固定页及脚本须重新校验缓存，避免加载旧桥接代码。

如果运行时资源加载失败而桥接脚本仍可运行，会立即报告错误并释放隔离页；重新渲染创建新的加载流程。整体加载与绘图仍有等待上限。

## 图形与结果文件

上方结果文件是工具已生成并登记的 SVG；正文 Mermaid 是模型回复的源码经浏览器再次绘图。后者使用内存图片地址，默认展示本身不再登记一份服务端文件，但会形成重复的查看、下载入口，两者内容也不保证一致。

任务存在就绪的 SVG 结果时，预览、下载和本机保存统一使用结果文件按钮，正文源码默认收起。展开后仅保留源码查看和复制，不再提供第二套预览、放大、下载及保存操作。没有就绪 SVG 的回复继续默认显示图形与完整工具栏。结果就绪、移除或失效时会同步更新正文展示。
