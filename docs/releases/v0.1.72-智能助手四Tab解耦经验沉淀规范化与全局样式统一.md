# v0.1.72 发布记录：智能助手四 Tab 独立架构、经验沉淀表格规范化与全局视觉统一

Pivot `v0.1.72` 聚焦于智能助手工作台架构解耦、个人经验沉淀数据表格规范化排版、以及管理后台全局视觉像素级对齐优化。主要涵盖：

---

## 一、核心变更

### 1. 智能助手页面重构为 4 个独立 Tab
将原先“我的智能助手”内混合的多个复杂业务区域彻底拆分为 4 个清晰独立、职责分明的子 Tab 导航：
- **个人档案 (`profile`)**：聚焦于助手身份定位、沟通语气风格、自主工作方式与高级 JSON 偏好配置；
- **记忆与隐私 (`memory`)**：集中呈现跨会话自动记忆策略、禁止捕获类别、三层合规安全保障机制与「我的记忆」轻量展示面板；
- **经验沉淀 (`learning`)**：全新独立页面，展示自动提炼策略设置（自动学习开关、低风险自动激活、完成提醒）与完整的个人经验数据表格；
- **技能管理 (`skills`)**：全宽呈现技能列表、双栏 0.75:1.25 黄金比例的 `SKILL.md` 编辑面板与技能导入导出。

### 2. 经验沉淀数据表格全面规范化改造
- **独立分列展示（消除多行堆叠）**：废除原先将类型、指标与说明混合堆叠换行的呈现方式，重构为 **8 个清晰的独立列**：
  1. **序号**（48px，居中）
  2. **经验名称**（160px，超长单行省略并带 Tooltip 提示）
  3. **类别**（75px，居中微徽标：技能 / 工作流 / 偏好）
  4. **状态**（80px，居中状态徽标：已启用 / 待确认 / 已暂停 / 已归档等）
  5. **使用次数**（80px，居中等宽数字）
  6. **成功率**（75px，居中等宽数字）
  7. **提炼说明与方法**（自适应填充，单行省略并带 Tooltip 提示）
  8. **操作**（230px，居中紧凑操作按钮组）
- **单元格完整边框（Full Border）**：全面启用全包围网格线（`border: 1px solid rgba(148, 163, 184, 0.22)`，深色模式同步适配），表格结构更具工业级质感；
- **标准行高与紧凑按钮**：表格行高统一固定为全局标准的 **`32px`**，操作列按钮统一收敛至 **`22px`** 紧凑高度，绝不撑高单元格；
- **统一分页控件**：容器完全对齐 `.pagination.workspace-pagination.agent-learning-pagination`，由全局统一的 `renderWorkspacePagination` 逻辑驱动。

### 3. 「我的记忆」展示面板紧凑精致化
- 表格行高精简压缩至 **`28px`**，操作列内 `编辑`、`暂停/恢复`、`删除` 按钮调整为紧凑的 **`20px`**，微徽标调整为 **`18px`**；
- 面板右上角 `刷新` 与 `查看全部` 按钮调整为 **`22px`**，底部 `保存治理策略` 与 `打开记忆清单` 调整为 **`24px`**，整体布局紧凑严整。

### 4. 管理后台全局标题与说明像素级对齐
- **系统监控页（Monitor）**：移除了 `.is-monitor-tab-active` 特例覆写的 `padding: 18px / 14px` 以及自定义的 `.settings-page-head` 字号和外边距，完全回归全局标准 `padding: 24px`、主标题 `1.08rem`、说明 `0.76rem` 与下边距 `14px`，彻底解决 Tab 切换时出现的 6px 向上向左跳动；
- **长期记忆页（Memories）**：移除 `.memories-tab` 针对标题字号（`1.02rem`）和副标题（`0.74rem`）的特例覆写，并将顶部操作栏按钮统一为 `34px` 标准高度。

### 5. 全局参数卡片图标精简
- 去除全局参数页面中 8 个参数分区卡片名称前的 SVG 图标盒子，保留干净利落的主副标题与说明文本，排版自然左对齐，视觉风格更简约轻盈。
