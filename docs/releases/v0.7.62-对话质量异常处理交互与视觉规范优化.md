# v0.7.62 对话质量异常处理交互与视觉规范优化

发布日期：2026-10-29

## 更新内容

1. **详情弹窗关闭按钮统一样式与去重**：
   - 对话质量异常详情弹窗底部“关闭”按钮统一使用全局规范的红色文字与边框线框按钮样式（`.btn-danger-outline`），并分配全局唯一按钮 ID（`#route-feedback-detail-close-btn`），提升视觉警示与关闭操作的一致性。
   - 移除弹窗头部重复多余的关闭按钮，保持弹窗头部整洁以及底部右下角单一明确的关闭出口。

2. **状态筛选与数据表格靠左对齐**：
   - 对话质量异常处理区域顶部的状态下拉筛选框文字设置为靠左对齐，改善中文字符视觉重心偏离问题。
   - 数据表格中“状态”列的表头与单元格（状态徽章标签）统一调整为靠左对齐，与左侧提交时间、用户、提问等内容保持齐头。

3. **复核操作列靠左对齐与长日期降噪**：
   - 数据表格中“复核”列的表头及操作按钮单元格全部靠左对齐。
   - 针对已完成复核的数据项，移除了表格单元格内直接内嵌的冗长复核时间文本，避免列内容溢出与排版割裂；将复核完成时间作为悬停提示（Tooltip）挂载在“详情”按钮上，兼顾信息完整与表格紧凑。

4. **详情复核记录排版对齐修复**：
   - 修复详情弹窗中复核记录区域由于模板缩进产生前导空格与换行导致文字未顶格显示的问题，使复核记录内容在卡片内整洁靠左靠上展示。
