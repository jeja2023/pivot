# v0.1.103 发布记录：高价值性能治理与交付加固

发布日期：2026-09-09

## 版本摘要

本版本聚焦前一轮审计后识别出的高价值优化项，覆盖日志热路径、后台数据库维护、覆盖率门禁、前端首屏资源、桌面构建安全、容器可移植性、配置治理、CI 交付矩阵、依赖安全与跨平台行尾规范。

## 主要变更

### 1. 日志与后台维护性能

- `server/logger.js` 使用模块级北京时间 formatter 单例，避免每条日志重新构造 `Intl.DateTimeFormat`。
- ANALYZE 维护任务拆出 `server/services/analyze-maintenance.js`，支持：
  - 单表 1–120 秒超时上限；
  - 默认 10 分钟、最大 60 分钟的整轮总时限；
  - 表级完成进度、失败数量、当前表和下一张表游标；
  - 总时限耗尽后下轮续跑；
  - 单表失败继续执行后续表。
- 测试从源码正则匹配升级为真实执行行为测试。

### 2. 覆盖率与工程门禁

`test:coverage` 门槛由行 40%/函数 40%/分支 30% 提升为行 75%/函数 75%/分支 60%。当前最终覆盖率为：

- 行：78.09%
- 分支：64.54%
- 函数：80.39%

同时，配置注册表、CI 交付、桌面 staging 和 Compose GPU 覆盖层均增加契约测试。

### 3. 前端资源拆分

聊天页面不再首屏加载所有工作区 CSS，改为：

- `chat.shell.css`：首屏聊天壳与个人工作台；
- `chat.workspace.apps.css`：应用中心；
- `chat.workspace.agent.css`：Agent 与工作流；
- `chat.workspace.knowledge.css`：知识库与知识图谱；
- `chat.workspace.mcp.css`：工具库；
- `chat.workspace.settings.css`：设置与监控。

工作区首次打开时通过独立样式加载器按需插入、自动去重，失败后允许重试。首屏样式压缩包约 138KB，gzip 约 26KB。

### 4. 桌面交付与容器

- Electron after-pack 默认裁剪至 `en-US`、`zh-CN` 语言包，可通过 `PIVOT_ELECTRON_LOCALES` 调整。
- 桌面分发配置、密钥、连接器和运行时档位使用系统临时 staging；不再临时改写 Git 工作区配置文件。
- staging 目录使用受限权限写入，构建结束或异常时清理。
- 默认 `docker-compose.yml` 不要求 GPU；GPU 主机使用：

  ```bash
  docker compose -f docker-compose.yml -f docker-compose.gpu.yml up -d
  ```

### 5. 配置、依赖与 CI

- 新增 [类型化配置注册表](../configuration-registry.md)，并生成 `.env.example` 与配置文档。
- CI 覆盖 Node 20、Node 22、真实 Docker 构建和 Windows 桌面未封装包。
- Electron 升级至 43.6.0，ESLint 升级至 10.10.0，MySQL2 升级至 3.24.4，MSSQL 升级至 12.7.1。
- 开发期 Hono 通过 override 固定到修复版本；生产依赖和全量依赖审计均无漏洞。
- `.gitattributes` 固定文本文件使用 LF，减少 Windows 与 Linux 间的无意义行尾变更。
