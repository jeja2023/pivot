# Pivot v0.7.186 发布说明

2026-11-20 · PPT 制作链路与过程回顾

本版更新 PPT Master 的准备、确认、首稿、复检与交付流程。失败记录可回看有检查点证据的材料读取和提纲。标准 PPT 工作台同步修复表格 PDF、单页改写、批次补页和模型输出处理。本版包含 [v0.7.185 的制作续跑与稳定性修复](v0.7.185-PPTMaster制作续跑与稳定性修复.md)。

## PPT Master 完整制作

| 范围 | 当前行为 |
| --- | --- |
| 项目准备与模板 | 支持宿主项目准备的执行器预建默认或快速制作项目，导入原始文字快照。内置模板在任务中复制、校验并读取规范，受管理的默认项目在沟通方向获批后安装模板。 |
| 方案与首张页面 | 沟通方向、最终清单和首张 SVG 的模型轮次上限分别为 12、18 和 16。读取新资料和查询图表目录均计入阶段轮次。达到阶段上限时保存检查点，续跑保留已确认内容、累计用量和步骤。受管理项目的页面写入须绑定已批准清单。 |
| 入口与兼容 | 模板入口、模型预检和创建任务按操作核对执行服务能力。生成或编辑 PPTX 缺少导出核验能力时提示升级。显式关闭思考时，DeepSeek 官方 Chat Completions 与 Responses 端点按各自协议传参。 |
| 引文恢复 | 空引文仅在已指定来源含有唯一可核对原文时补齐，格式或来源有问题的条目进入逐项查证。 |
| 复检和交付 | 补齐当前项目单页检查、原稿继承模式及原生往返检查。整稿复检可覆盖同项目、同模式的旧失败。当前导出回执失效时，可在已有导出参数和原目标范围内自动复检、重导出一次。 |
| 源包限额 | 独立执行器与主应用按共同支持的限额生成、读取项目源包。源包超限会给出提示，已通过正式清单核验的 PPTX 可单独交付。 |
| 过程回顾 | 失败、过期或取消后可展开「查看材料与提纲」，查看文字材料名称、连续读取范围、完成状态与失败次数，以及已保留的沟通方向和逐页提纲。提纲展示摘要、页序、标题与关键数据，并标明确认或核对状态。每轮用量明细可同时查看执行动作、重试及脱敏诊断。 |

## 标准 PPT 工作台

- **表格 PDF 与当前页改写。** 新旧模板的可见表格可导出 PDF。语义改写在原模板版本和画幅下编译成一页，保留锁定对象和批准页保护。只有用户确认且当前页仍匹配时才应用建议。
- **分批生成与草稿。** 编译成功的页先保存，缺页或编译失败页才重试，批次截断后逐页重试。生成示例要求原样返回大纲页标识，已确认的图表、表格和图片须提供对应内容。按原大纲续跑复用已有草稿，修改大纲使用新草稿。
- **材料与模型。** 摘录失败最多重试一次。空白差异仅在能唯一定位原文时接受，保留原文字串及字符位置。输出截断单独识别，端点明确拒绝 JSON 对象模式时兼容回退一次。模板导入区分 20 MiB 文件上限和 12 MiB 解包上限。

## 升级与兼容

- 计划续跑旧任务时，先更新主应用并保留原执行器、地址、密钥和工作区。旧记录的过程回顾取决于当前权限和检查点还保存的证据。
- 预建项目、新增检查参数和执行端源包限额需要重建独立服务。上游固定版本仍为 v6.10.0，服务协议为 1。切换后以新任务核对首次方案、首张 SVG 与正式下载。[升级步骤](../deployment/PPTMaster独立服务部署与更新.md#v07186-制作链路与过程回顾) · [用户操作](../../使用帮助.md)
