## 修复内容

### 1. 修复待办中心详情按钮无响应

待办中心点击“详情”时，任务详情模块原先只查找旧的全局入口 `globalThis.openAgentWorkbench`。当前工作台实际通过 `window.Pivot.legacy.openAgentWorkbench` 注册，导致任务详情被渲染到隐藏的任务区域，页面看起来像按钮没有反应。

本版本统一使用 Pivot 命名空间入口，在打开详情前切换到任务视图，并保留旧入口作为兼容兜底。适用于自主任务、工作流任务、计划任务和工具事件待办。

### 2. 完善详情失败反馈

- 详情加载请求失败时显示明确的错误提示；
- 详情模块尚未完成加载时提示刷新页面；
- 标记已读失败不再阻断详情打开；
- 关闭详情、面包屑返回、质量评测和治理入口使用同一套工作台切换逻辑。

### 3. 修复事件待办 ID 类型污染

事件待办的 `sourceId` 固定保存 `agent_inbox_events.id` bigint 主键，`agent.browser`、`agent.http`、`agent.code`、`agent.llm`、`workflow.output` 等业务来源标识单独保存，避免生成错误的 `/event/agent.xxx/read` 请求。

对历史缓存或异常请求中的非数字事件 ID，服务端返回明确的 400 错误，不再暴露 PostgreSQL 类型解析异常。
