# Pivot v0.1.54 发布记录

## 版本概述

Pivot `v0.1.54` 重点聚焦于**工具库与安全凭据体系架构收拢**、**工作流权责边界优化**、**全局轻量 Toast 状态提示替代嵌入式横幅**、**Agent 控制台统一收件箱序号列补齐**，以及**全系统工作区与多级子 Tab 刷新状态记忆与精准恢复**。

---

## 核心更新内容

### 1. 工具库与安全凭据体系架构收拢与布局重构
- **3 大核心 Tab 架构收拢**：将工具库工作区精简并重构为「工具服务」、「数据连接」与「连接与凭据」三大专业顶级 Tab，去除冗余的独立治理审计空页面；
- **治理与审计面板就近集成**：将 MCP 治理与审计面板直接内嵌至「工具服务」面板顶部，使工具配置与安全策略管理紧密贴合、一目了然；
- **设计规范与无 Emoji 视觉净化**：全面清理 Tab 标签和按钮中的 Emoji 符号与加号图标，保持严谨一致的企业级视觉风格；
- **作用域隔离与安全凭据抽屉交互修复**：将安全凭据与自动化资源模块封装为独立 IIFE 作用域，解决变量冲突与 `agentEscapeAttr` 声明问题，保障新建凭据、管理凭据抽屉在全局任意工作区均可稳定呼出。

### 2. 工作流工作区权责收拢与界面去噪
- **移除工作流顶部工具栏「凭据库」常驻按钮**：严格确立「凭据集中于工具库统一管理」的权责边界，避免不同工作区之间入口重叠与认知混淆；
- **轻量消费入口按需唤起**：工作流仅保留参数表达式引用（如 `{{credentials.slug}}`）与依赖配置弹窗中的「管理安全凭据」快捷按钮，使工作流画布与头部操作栏保持清爽纯粹。

### 3. 全局轻量 Toast 状态提示替代嵌入式横幅
- **清理知识库等页面嵌入式横幅占位**：彻底解决知识库页面顶部出现空白占位框与横幅挤压正文的问题；
- **统一服务状态与网络异常反馈**：全面改用全局轻量 Toast 消息浮层反馈数据加载、网络异常及操作结果，不侵入、不推挤页面主体布局。

### 4. Agent 控制台统一收件箱添加序号列
- **数据表格序号列补齐**：在 Agent 控制台「统一收件箱」数据表格第一列新增标准的「序号」居中表头与动态行号（`1, 2, 3...`），显著提升长列表及审批事项的阅读体验。

### 5. 全系统工作区与多级子 Tab 刷新状态记忆与精准恢复
- **主工作区刷新状态持久化**：深度排查全系统工作区刷新机制，通过 `sessionStorage` 全面覆盖所有 9 大工作区（对话主区、知识库、工具库、Agent 控制台、工作流、应用中心、系统设置、用户手册、打印预览）；
- **二级子 Tab 与子视图刷新不丢失**：
  - 工具库：精准记忆并恢复「工具服务 / 数据连接 / 连接与凭据」子 Tab；
  - Agent 控制台：精准记忆并恢复「任务 / Agent 控制台」顶级切换，以及「统一收件箱 / 持续目标 / 通知渠道 / 质量可靠性」子视图；
  - 系统管理：精准记忆并恢复系统设置各功能面板；
  - 对话主区：精准恢复当前选中的活跃会话上下文与历史流。
