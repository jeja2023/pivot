# v0.7.151 智能路由与技能审查修复及建模调度优化

日期：2026-11-11（Asia/Shanghai）。本版对应智能路由、智能体执行与技能目录十项审查问题（F01—F10）的深度修复，以及 BI 建模运行器高压调度与数据库锁竞争优化。

## 使用变化与可靠性提升

- **决策特征重复归一化保全**：规范化与任务状态使用同一白名单机制，重复归一化完整保留任务哈希、能力要求、证据需求及计数；缺失租户严谨保持 null。
- **核验阶段纳入租约与心跳生命周期**：`verifying` 状态纳入统一租约管理并正常续租；核验阶段失去租约或服务退出时保留既有输出并明确标记失败，不自动重放外部业务动作；旧持锁者和旧执行代次不能越权结束新任务。
- **队列认领执行严格校验启动 Hook**：队列认领后的执行器在调用模型和业务来源前运行启动前置检查，并按代次关联前后置审计；前置拒绝不会自动重试。
- **换模型身份同步持久化**：数据库普通/CAS 状态写入允许 `chosen_model_id`；初次执行、恢复与故障切换同步持久化实际生效的模型身份与内存状态，备用模型失败也保留真实身份。
- **学习决策与执行结果确定性闭环**：实际生效的学习决策作为结果主身份贯穿任务流转、反馈与纠正；终态投递使用确定性键去重；失败率统计仅以实际生效且取得结果的决策为分母，不混入影子或待完成记录。
- **自动化去重后正确推进水位**：已接纳批次先于新增运行配额识别并核对目标和版本；去重命中同样在当前 claim/version 下提交水位，未确认提交明确报错。
- **技能正文拒绝静默截断**：保留原 256KB 上限并移除 12k/16k 静默截断；创建、验证、发布和运行时共用正文容量校验；模型上下文超限时明确报错，不使用残缺规则。
- **技能目录排除他人历史挤占**：参数化键集分页在 SQL 中先排除他人私有范围，逐页复核当前 ACL、状态和灰度，仅有效条目消耗名额；任务创建绑定不可变 release 引用，执行时复核版本与显式激活要求。
- **技能负反馈率精准统计**：工具调用与用户反馈分别统计；负反馈率使用用户真实评价样本量及独立门槛，运行时内部反馈不计入用户评价。
- **BI 建模高压调度与锁竞争优化**：将运行器每 100ms 轮询中的重量级维保操作（`ensureReady`、`recoverExpired`、心跳和过期清理）节流至每 1000ms 最多执行一次，彻底消除高并发下的 PG 连接池与 Advisory 锁争用；任务释放槽位后立即通过 `setImmediate` 调度下一作业，显著提升混合负载吞吐能力。
