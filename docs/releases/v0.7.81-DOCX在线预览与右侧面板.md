# v0.7.81 DOCX 在线预览与右侧面板

日期：2026-11-01。本记录描述工作区的版本更新和预览开发成果；版本号更新不代表安装包或服务器已经更新。

## 修改内容

- 会话结果文件的 DOCX“查看”通过当前授权版本的受控文档数据生成 HTML 内容预览，显示在隔离的预览区域；不再把内部 JSON 当作文档正文展示。
- 可选接入自部署 ONLYOFFICE Docs，对实际 DOCX 提供只读查看。浏览器经同源反向代理访问文档服务，服务端通过短期票据回源；账号、文件权限、就绪状态和文件完整性继续校验。
- DOCX、图片与 ONLYOFFICE 预览使用右侧非模态面板。桌面宽屏下会话区域收窄、仍可操作，关闭后恢复；窄屏下预览占满屏幕。切换或关闭时清理图片临时地址和 ONLYOFFICE 实例，并避免旧请求覆盖新预览。

## 验证与限制

- 定向测试覆盖图片、DOCX 内容预览、ONLYOFFICE 只读配置、票据签名和文件权限；真实浏览器测试验证右侧定位、原页面操作、关闭恢复及窄屏布局。
- 隔离 PostgreSQL 与 HTTP 测试验证文件归属、用户隔离、停用或失效文件及回源票据。相关 Lint、前端静态资源和增量开发规范检查通过。
- 默认内容预览来自 Document IR，分页、字体和图片可能与实际 DOCX 不同；当前图片以占位说明显示。ONLYOFFICE 路径为只读查看，不提供编辑或保存回写。
- 开发环境未连接生产 ONLYOFFICE。真实文档服务、代理、JWT、容器网络和目标浏览器仍需现场联调；未运行全量回归、构建安装包或部署服务器。

环境参数、代理设置及现场验收见 [ONLYOFFICE 文档预览说明](../deployment/ONLYOFFICE文档预览.md)。v0.7.78 多表关联的真实查询和 v0.7.76 多节点恢复的既有限制继续适用。
