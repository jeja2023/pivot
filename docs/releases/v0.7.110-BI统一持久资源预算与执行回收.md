# v0.7.110 — BI 统一持久资源预算与执行回收

对应建设方案第 13.3、21.1—21.2 节。本次完成统一执行预算这一项功能，后续容量、恢复和上线证据继续分别记录。

## 行为

全部模型执行类型、后台 SQL 与原有重型分析复用 analysis_query_jobs 和 analysis_runtime_slots，不增加独立任务队列。数据库调度锁内检查全局与用户配额，按用户最近执行时间和等待老化调度；批处理最多占一个槽位，交互仍有执行机会。

进程内信号量保留为第二道保护。异步上下文使嵌套计算只取得一个持久槽位；执行主体不一致的嵌套调用拒绝。续租同时更新任务和槽位，使用数据库时间避免应用时间精度差异。

取消先登记意图，监督器中断活跃连接；确认退出后释放容量。同机进程失联时检查进程归属和存活状态，不因租约到期直接复用容量。其他主机、未知执行者或仍存活的进程保持占槽，交由受控隔离处理。

过期排队检查落下 incomplete 报告、刷新失败信息和审计，不能被当作发布证据。
