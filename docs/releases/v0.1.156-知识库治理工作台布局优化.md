# Pivot v0.1.156 发布记录：知识库治理工作台布局优化

发布日期：2026-09-20  
版本来源：[CHANGELOG.md](../../CHANGELOG.md) 顶部版本标题；已同步至 `package.json`、`package-lock.json` 与 README。

## 发布目标

本版本优化知识库页面的信息层级，不改变知识资产、索引、引用、局域网来源、权限或 PostgreSQL 主库行为。核心原则是：**资料管理留在首页，检索与治理按需进入工作台。**

## 页面布局调整

- 首页保留专题库/标签筛选、刷新和上传、内容/检索/批量操作、统计摘要、紧凑质量告警、文档表格、分页和行级详情；文档列表获得更多可用高度。
- 原本固定在资料表格下方的“知识使用与治理”区域移除，不再使首页在首屏出现第二个大型工作区。
- 工具栏新增“知识使用与治理”入口，打开独立的大尺寸弹窗工作台，默认进入“搜索问答”。
- 质量诊断仅展示可操作的告警摘要；点击后直接进入“知识内容”治理 Tab，避免统计行被异常文档名称、重复文档清单和说明文本撑开。

## 治理工作台交互

治理工作台保留原有所有能力和服务接口，并在一个独立 Tab 容器中提供：

| Tab | 用途 |
| --- | --- |
| 搜索问答 | 在验证状态、来源类型、更新时间范围内检索证据或生成带引用回答。 |
| 知识内容 | 维护文章、版本、审核、发布、验证、评论、纠错和归档。 |
| 局域网来源 | 创建和管理目录、内网 HTTP/API、只读数据库来源，查看同步记录并执行受控同步。 |
| 索引任务 | 查看持久化索引任务、阶段、重试次数、失败原因和更新时间。 |
| 质量评测 | 管理黄金问题集、运行评测、查看指标、比较运行结果和定位知识缺口。 |

- 各 Tab 只在打开或切换至该 Tab 时加载数据，避免首页打开时同时请求所有治理数据。
- 支持标准 Tab 语义及左右方向键、Home、End 键切换；关闭按钮、Esc 与遮罩点击均可关闭，并将焦点返回打开入口。
- 弹窗内容区独立滚动，避免长检索结果、来源列表或评测记录拉长资料首页；窄屏下自动改为全高窄边距布局，筛选和操作纵向排列。
