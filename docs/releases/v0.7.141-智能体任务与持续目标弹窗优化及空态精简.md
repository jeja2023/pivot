# v0.7.141：智能体任务与持续目标弹窗优化及空态精简

日期：2026-11-09。承接[v0.7.140](v0.7.140-持续目标模型绑定与运行校验修复.md)，本版对智能体工作台任务新建面板、持续目标配置弹窗以及自动化目标空白态的视觉布局与交互层级进行专项优化，提升宽屏使用体验与界面整洁度。

## 优化与变更

1. **新建任务面板尺寸与排版放大**：
   - 原 760px 宽度对于包含任务标题、多行目标、常用预设、模型选择及高级设置 3 列网格的复杂表单较为局促，导致长文本策略选项（如“成本升级（置信不足时升级）”）及标签出现紧凑换行或截断。
   - `.agent-task-editor-modal` 宽度调大至 `min(980px, calc(100vw - 36px))`，最大高度增至 `min(900px, calc(100dvh - 36px))`；
   - 弹窗头部、表单主体与底部内边距水平增宽至 20px，高级设置 3 列网格每列获得约 300px 的舒适排版空间；
   - 任务目标输入框（`textarea.agent-goal-input`）最小高度提升至 132px，便于编辑 5 行以上的目标描述；
   - 模型选择容器最大宽度放宽至 480px，适配较长模型名称与多项能力标签展示。

2. **自动化目标无任务空白态精简**：
   - 自动目标页面卡片右上角已提供常驻的“新建自动目标”主操作按钮，英雄空白卡片中间的“+ 新建自动化目标”按钮形成冗余；
   - 移除列表无目标时（`goalEmptyHero`）中间多余的“+ 新建自动化目标”按钮，保留右上角主入口与下方的“推荐场景快速创建”快捷卡片（每日晨间项目巡检、每周部门数据周报、数据更新监控告警），界面结构更简洁清晰。

3. **新建持续目标弹窗加宽与消除垂直滚动条**：
   - 持续目标配置弹窗（`.agent-goal-modal-dialog`）原固定宽度为 600px，高度上因目标描述文本框继承 132px 高度且各个表单项独占多行，在常规桌面屏幕（如 900px 高度视口）下会撑出右侧垂直滚动条；
   - 宽度调整为 `min(840px, calc(100vw - 36px))`，让双列/三列布局获得充裕展开空间，下拉框选项与提示说明完整展示；
   - 布局压缩与网格重组：将“目标类型 / 触发方式 / 每日执行时间”整合为自适应三列网格，“执行模型”与“模型策略”并排双列，“时区 / 结果投递渠道 / 结果保留天数”并排三列；
   - 目标描述输入框高度收敛为 56px，弹窗头部、表单主体与底部内边距及间距适度紧凑化，总高度压缩至约 540px，在主流桌面视口内一屏完整展示，彻底消除了右侧垂直滚动条。

## 使用与升级

- 样式已通过 `node scripts/build_chat_css.js` 统一编译并压缩至 `client/chat/chat.workspace.agent.css`，刷新页面或重新载入智能体工作台即可生效。
- 移动端与小屏幕（<=720px）保持原有流式单列响应式布局，不影响小屏设备操作体验。
- 本次改动纯属前端样式布局与空态模板精简，不涉及数据结构、数据库迁移或后端接口变更。
