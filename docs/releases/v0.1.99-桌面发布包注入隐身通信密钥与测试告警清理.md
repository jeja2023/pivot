# v0.1.99 发布记录：桌面发布包注入隐身通信密钥与测试告警清理

## 变更

- 桌面打包前从 `PIVOT_DISTRIBUTION_STEALTH_SECRET`、`PIVOT_STEALTH_SECRET` 或根目录 `.env` 读取 stealthSecret。
- 仅将 secret 注入构建中的 `config.json`，打包完成后恢复仓库原始配置；仓库不保存真实 secret。
- 新安装客户端可直接连接启用隐身模式的服务端，并可继续使用同站 `/downloads/` 自动更新。
- 服务端重置 stealthSecret 后，重新打包并发布新版本即可让客户端升级切换到新密钥。
- 优化系统监控页面知识库（RAG）面板样式：列表容器添加弹性伸缩与独立纵向滚动，固定延时趋势图高度，解决面板高度受限时趋势图遮挡指标数据行的问题。
- 加固 PostgreSQL 共享白名单查询：弃用非 PostgreSQL 原生函数 `instr` 与 `LIKE` 模糊匹配，采用 `strpos` 精确匹配逻辑，防止特殊字符（如 `%`、`_`）意外通配并确保高并发稳定运行。
- 清理 `tests/desktop-delivery.test.js` 中 8 个未使用变量和参数 warning。

## 发布要求

构建前必须提供有效密钥，例如：

```powershell
$env:PIVOT_DISTRIBUTION_STEALTH_SECRET = $env:PIVOT_STEALTH_SECRET
npm run dist:win
```

构建后确认安装包中的 `resources/config.json` 包含 secret，且工作区根目录 `config.json` 已恢复为不含 secret 的版本。
