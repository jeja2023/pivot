# v0.1.198 知识库综合页表格自适应分页与核验中文化

## 1. 版本背景

在知识库综合页（Wiki 工作台）的页面详情查看视图中，由于原始依据来源列表（`data.sources`）直接全量渲染上百条数据记录且各列使用了固定绝对像素宽度，导致出现了两个体验问题：
1. **水平滚动条与列宽截断**：固定列宽总和超出右侧弹窗容器宽度，产生水平滚动条，且最右侧“核验状态”列被挤压截断；
2. **内外部双重垂直滚动条**：表格内部有 `max-height` 滚动，同时外层页面整体高度超出弹窗，出现两层并排垂直滚动条；
3. **核验状态英文泄露与文字不全**：服务端写入的 `auto_checked` 状态缺少前端中文枚举映射，导致直接回退展示为原始英文 `auto_checked`，且因列宽过窄被截断为 `auto_check`。

本版本针对上述问题进行了针对性重构与修复，全面优化弹窗表格布局、分页交互和多语言状态标签。

---

## 2. 核心改进点

### 2.1 引入标准工作区分页组件并消除双重垂直滚动条
- 在知识库综合页详情视图（`.is-detail-mode`）中接入系统标准的 `renderWorkspacePagination` 分页器；
- 原始依据来源每页固定展示 6 条记录，表格高度稳定保持在约 210px，支持“首页/上一页/下一页/末页”切换与总页数统计；
- 表格内部移除内部独立垂直滚动条（`overflow-y: hidden; max-height: none;`）；
- 紧凑优化详情头部导航、页面摘要与正文预览框高度，使得在标准桌面视口下整个详情视图高度（约 430px）完全容纳在弹窗可用高度内，外层与内层垂直滚动条同时消除。

### 2.2 表格列宽自适应重构与杜绝横向滚动条
- 表格严格采用 `table-layout: fixed; width: 100%;` 百分比自适应分配列宽：
  - `序号`：固定 `42px`，居中对齐；
  - `来源资料 / 文档`：百分比 `26%`，文本超长自动省略（text-overflow: ellipsis）并附带原生 tooltip title；
  - `版本`：固定 `48px`，居中标签；
  - `章节 / 区块路径`：`auto`，自适应占用剩余空间；
  - `引用性质`：固定 `84px`，居中标签；
  - `核验状态`：固定 `88px`，居中标签。
- 表格容器及外层面板配置 `overflow-x: hidden; width: 100%;`，彻底杜绝任何分辨率下的横向滚动条。

### 2.3 来源核验状态全中文化与语义化色彩
- 补齐前端 `verifiedStatusLabels` 字典映射，彻底杜绝原始英文字符串直接显示：
  - `auto_checked` → **`自动核验`**
  - `human_verified` → **`人工核验`**
  - `verified` → **`已核验`**
  - `unverified` → **`未核验`**
  - `pending` → **`待确认`**
  - `conflict` → **`存疑冲突`**
  - `invalid` → **`已失效`**
  - `expired` → **`已过期`**
- 对应标签赋予 `tag-success` 语义化浅绿色彩，与“支持依据”保持视觉一致；
- 拓宽后的 88px 列宽确保 4 字符中文徽标完整居中展示，留白充足无截断。
