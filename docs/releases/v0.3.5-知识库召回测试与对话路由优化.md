# v0.3.5 - 知识库召回测试与对话路由优化

**发布日期**：2026-10-15  
**版本类型**：补丁版本  
**兼容性**：向后兼容；无需数据库迁移。未配置 Embedding 服务的开发、离线或内网环境可直接使用关键词检索降级路径。

## 1. 发布目标

本次更新聚焦知识库“召回测试 → 带入聊天”的真实工作链路：让测试结果更易判断、让用户主动选择的资料确实进入下一轮回答，并消除生产截图中暴露的内部检索词元和低置信候选噪音。

## 2. 召回测试体验

### 2.1 每次打开均为新测试

- 删除弹窗中的历史调试记录区域。
- 每次打开自动清空上次的测试问题和结果，恢复为空状态提示。
- 测试范围、标签和默认检索参数仍由当前知识库状态加载，不影响专题库筛选。

这样可以避免历史问题、过期结果或不同范围的记录让当前测试产生误判。

### 2.2 检索词不再泄露内部编码

RAG 为了让 PostgreSQL 全文检索匹配下划线、路径符号等字符，会生成类似 `zsym5fz` 的内部索引词元。该类词元继续保留在服务端检索链路中，但不会再显示在召回测试界面。

界面改为展示用户可读的检索词，例如法规名称、业务词和版本号，并继续用这些词高亮原文片段。

### 2.3 结果与诊断分层

- 默认结果仅显示达到阈值或实际会进入聊天上下文的资料。
- 零分、低置信度或未通过引用门槛的候选不再混入可用资料列表。
- “查看检索诊断”保留初筛数量、关键词降级、融合权重、队列状态和隐藏候选数量，供管理员排查。
- 文案区分“可引用资料”“待核验资料”和“没有达到引用门槛”，避免将候选误认为回答依据。

## 3. 从测试结果进入聊天

点击“带着资料去聊天”时，系统会执行以下受控行为：

1. 将测试问题带回聊天输入框。
2. 将当前专题库与标签范围同步到聊天检索范围。
3. 为下一条待发送消息建立一次性 `forceRag` 路由覆盖。
4. 服务端将这视为用户显式请求知识库：即使问题是“总结这份材料”等通常可能不触发检索的问法，也会执行知识库检索。
5. 发送完成后覆盖自动清除；之后的普通消息继续使用智能自适应路由。

该流程不会扩大用户权限。专题库、标签和共享资料仍由既有 ACL 在检索层二次校验。

## 4. Embedding 未配置时的行为

未配置 Embedding HTTP 服务时：

- 文档仍可建立关键词检索投影并处于 `lexical_ready` 状态。
- 召回测试、专题库/标签范围、引用门槛和聊天知识库上下文仍可工作。
- 系统在诊断中标示“关键词降级检索”；不会将缺少 Embedding 配置视为应用故障。
- 语义相似度、向量召回和重排序增强不会启用；配置服务并重建向量后即可恢复增强能力。

## 5. 交互韧性

召回测试入口原本依赖设置脚本按需加载。本版将打开和关闭操作收敛为知识库工作台自身可处理的路径：设置脚本尚未就绪时仍可打开、关闭和重置弹窗；脚本加载完成后继续复用相同的操作入口。

## 6. 验证

- RAG 安全与关键词降级回归：136 项通过。
- 聊天安全与工作台契约回归：155 项通过。
- 自适应路由、内部检索词展示和一次性知识库请求定向回归通过。
- 知识库浏览器冒烟测试通过。
- JavaScript 语法、安全 HTML 和 E2E 冒烟脚手架检查通过。

## 7. 部署说明

直接部署 v0.3.5 并重启服务即可，无需数据库迁移或新增环境变量。版本号由 `CHANGELOG.md` 顶部条目驱动；静态资源 URL 会使用 `v0.3.5` 缓存标识，浏览器会拉取更新后的知识库脚本与样式。
