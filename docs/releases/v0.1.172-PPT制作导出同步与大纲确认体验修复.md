# v0.1.172 发布记录：PPT 制作导出、同步与大纲确认体验修复

发布日期：2026-09-24

## 发布摘要

本版本修复 PPT 制作应用中已经生成的 PPTX、PNG 在受控下载阶段仍显示失败的问题，并将 AI 大纲确认页从内部 JSON 文本编辑改造成面向普通用户的结构化表单。同步操作同时补齐了保存中、本地未保存修改及远端无变化时的状态反馈。

## 主要变更

### 1. PPTX 与 PNG 导出下载恢复

- 定位到导出请求实际已成功生成 Rendition，但交付文件名安全白名单未登记 `pptx`、`png`，下载路由随后抛出“不支持的交付格式”并返回 500；
- 将 `pptx`、`png` 纳入共享交付扩展名映射，浏览器下载与本机交付继续沿用统一的路径穿越、危险字符、保留设备名和扩展名强制保护；
- 导出按钮会在执行期间防止重复点击，下载令牌、导出产物和响应状态异常时会给出可读错误，不再误显示“已保存”。

### 2. 导出内容与选项一致性

- 导出流程会等待当前编辑保存请求完成，保证产物使用最新已确认的文稿内容；
- 导出 API 传递页面比例设置，16:9 与 4:3 会按用户选择实际生成；
- 将不改变文稿 IR 的渲染选项纳入确定性渲染配置：PPTX 是否包含演讲者备注、PNG 当前页及 PNG 清晰度均不会复用到不匹配的历史文件；
- 文件名继续由服务端安全生成，客户端文件名也会清理 Windows 非法字符。

### 3. 协作同步状态完善

- 手动同步会在本地修改尚未保存时征求确认，保存进行中的修改会等待完成后再读取远端版本；
- 即使远端版本号没有变化，用户主动同步也会明确得到“已经是最新版本”的反馈；
- 本地编辑、自动保存和远端刷新使用修订序列控制，避免保存响应覆盖保存期间产生的新修改。

### 4. 面向普通用户的大纲确认页

- 移除原有的 `presentation-outline-editor` JSON 文本框；
- 新确认页展示并允许编辑：演示标题、章节名称、页面标题、页面目标、页面版式与每行一条的核心要点；
- 保留 AI 返回的章节层级、建议版式、来源引用、待确认项和提示，但不向用户暴露内部字段；
- 点击“生成页面”时从结构化表单收集并校验必填内容，再组装服务端所需的大纲对象；标题或要点为空时给出具体页面提示，不再出现“无效 JSON 格式”。

## 兼容性与升级

- 无数据库迁移、无新增环境变量，也不会修改既有演示文稿内容；
- 远程模式只需部署服务端与静态前端资源并重启 Pivot 服务。已安装的远程桌面客户端会加载服务端页面，不需要仅为本版本重新打包；
- 使用离线客户端内置服务的场景，需要将本版本代码重新打包后发布。

## 验证记录

- PPT 工作台专项测试通过：文稿渲染、PPTX/PDF/PNG 输出、导出选项、契约与交付缓存均通过；
- 路径安全回归验证 PPTX、PNG 文件名经过安全清理后可正常生成；
- 大纲确认页浏览器交互验证：不显示 JSON 编辑器，用户编辑后的标题和核心要点会作为结构化大纲提交；
- 弹窗视觉验证：桌面视口下确认页高度受限、内容区可滚动、操作区固定，无元素重叠。
