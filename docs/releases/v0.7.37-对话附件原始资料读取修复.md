# v0.7.37 对话附件原始资料读取修复

发布日期：2026-10-23。版本类型：对话任务资料读取可靠性修复。

## 问题与修复

读取长附件时，模型有时会把正文中的数字或引用里的数字当作消息编号传给 `chat.read_source`。此前系统把任何不属于当前任务来源集合的编号都解释为原始消息或会话已删除，造成工具步骤失败；任务可能在后续重试或断点续跑后完成，但执行过程仍留下误导性错误。

现在只允许读取当前任务的原始用户消息，以及用户控制消息明确登记的后续补充消息。模型传入无效或未授权的编号时，读取器回退到当前任务原始用户消息并说明回退结果；它不能借此读取其他会话内容。原始消息或会话已删除、或明确登记的补充来源已删除时，系统仍拒绝读取。
