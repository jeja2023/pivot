# Pivot v0.1.142 发布记录：工作流编排产品级可用性复核

## 版本概览

- **版本号**：v0.1.142
- **发布日期**：2026-09-18
- **核心定位**：以画布、节点配置、运行前校验与受控资源选择为主线，完成一轮工作流产品可用性复核和改进。

## 本次改进

- 空画布提供“从任务开始、查询数据、统计图模板”三个可操作起步路径。
- 画布会直接标记缺少配置的节点；节点 Inspector 同时展示可读的问题和修复方向，预览/当前版/发布版运行会在创建任务前拦截不可运行配置。
- 编辑期校验新增常见业务规则：分组字段与指标字段组合、条件比较值、浏览器点击目标、输入参数名、数值/数组范围、重复运行参数与重复交付名称。
- 报表查询可在选定授权文件后读取工作表和字段候选；工作表、字段列表和筛选字段不再要求手写。对比报表只显示两份文件的共同工作表。
- HTTP 节点优先从受控凭据库选择凭据引用，不暴露密钥正文；保留旧环境变量引用的兼容入口。
- 条件判断统一中文选项，并只在需要时显示比较值；工作流输出按默认结果、表格或文件产物展示对应配置。运行参数默认值会随文本、数字、布尔、对象和数组类型切换相应控件。
- 图表分组字段、智能体交接的发现/证据/风险/待确认项改为可视化字段或逐条标签配置。
- 受控通知取消手填平台：平台由所选渠道绑定自动确定，服务端仍以绑定平台为准。

## 验证

- DAG 编排、节点专用控件、数据分组、报表工具、通知和循环 Worker 定向测试通过。
- `node --check` 覆盖本次新增/修改的 DAG 前端模块通过。
- 架构治理对本次工作流大文件通过；全仓治理仍受同一工作区已有的聊天工作区和知识库大文件改动影响，未在本次修改中调整其职责边界。
