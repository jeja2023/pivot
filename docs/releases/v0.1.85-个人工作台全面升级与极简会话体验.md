# v0.1.85 发布记录：个人工作台全面升级与极简会话体验

发布日期：2026-09-06

## 一、更新背景

随着 Pivot (智枢) 系统在智能体编排、知识库检索与专业垂直微应用矩阵（公文写作、数据分析、法规查询等）上的持续拓展，原先以单一大模型对话为主轴的交互结构逐渐显露瓶颈：
1. **主中枢缺失与分散**：用户登录后缺乏统一聚合待办任务、自动化状态、历史工作流与高频业务工具的一级全景工作台；
2. **二级页面关闭导航断层**：以往系统将底层对话页面（`chat`）作为硬编码兜底，导致用户从工作台打开具体微应用或设置面板后，点击关闭会被直接“踢回”大模型对话页面，必须反复手动切回工作台；
3. **会话侧栏臃肿挤压视野**：对话界面的左侧边栏堆叠了大量一级导航工具按钮及底部的控制按钮，使真正核心的“历史会话列表”被压缩在狭小的中间区域，破坏了沉浸式交互质感。

针对上述痛点，v0.1.85 严格遵循系统经典翠绿/薄荷绿主题色彩规范，开展了系统层级的“**个人工作台中枢确立、工作区生命周期闭环与纯粹极简会话侧栏**”全面重构。

---

## 二、核心变更与技术实现

### 1. 个人工作台（Personal Workbench）全面重构与默认主入口确立
- **确立系统默认主中枢**：将个人工作台（`personal`）确立为系统登录及初次访问的默认一级入口，登录后直接呈现全局信息中枢，无需手动点击切换；
- **后端聚合服务与持久化接口**：
  - 新增 `server/services/personal-workbench.js` 服务，统一聚合用户待办（Agent 运行与待审批）、持续自动化目标、最近会话与高频工作记录；
  - 在 `server/routes/agent-control-plane.js` 扩展 `GET /api/agent-control-plane/personal-workbench` 与 `PUT /api/agent-control-plane/personal-shortcuts` 接口，支持用户偏好快捷方式的安全隔离持久化；
- **前端工作台组件与视图架构**：
  - 新增 `client/chat/personal-workbench.js`、`client/chat/partials/workspaces/personal.html` 与 `client/chat/styles/workspaces/personal.css`；
  - 核心展示 **3 栏 KPI 统计与趋势指标**（需要我处理、自动化运行中、本周已完成成果）与 **4 大业务看板**（待办中心、持续自动化、继续工作、常用入口）；
- **错位互补业务入口设计**：
  - 彻底解决常用入口与左侧导航栏的职能重合问题，将工作台常用入口精准映射至高频「垂直业务微应用」（公文写作、数据分析、法规查询、文字识别、PDF 工具及自定义扩展）；
- **Hero 胶囊问候横幅与顶部优化**：
  - 移除横幅内右下角重复的操作按钮，将横幅高度压薄为 ~60px 的轻量问候胶囊，释放约 100px 纵向黄金视野；
  - 顶部动态日期规范化升级为带有当前年份的格式（如 `今天是2026年 9 月 5 日，星期六`）；
  - 移除搜索栏多余的麦克风图标以及与左下角重复的用户名头像，右侧常驻统一全局搜索胶囊。

### 2. 工作区来源追踪与关闭返回导航闭环（`returnFromWorkspace`）
- **来源根工作区智能感知**：
  - 在 `client/chat/app-workspaces.js` 引入 `RETURN_WORKSPACE_STORAGE_KEY` 缓存机制与 `returnFromWorkspace` 判定函数；
  - 当用户处于根工作区（`personal` 个人工作台 或 `chat` 对话）时，系统自动感知并记录来源根上下文；
- **全系统二级工作区关闭重构**：
  - 升级应用中心（`apps-workbench-rag.js`）、管理设置（`admin.js`）、智能体与自动化（`agents.js` / `agent-workflows.js`）、知识库（`rag-documents.js`）、工具库（`mcp-workbench-form.js`）及使用手册的关闭按钮；
  - 关闭操作统一调用 `window.Pivot.legacy.returnFromWorkspace()`；从工作台点进任何微应用/二级页面，关闭后精准返回个人工作台，彻底根除“跳回对话页”的体验断层。

### 3. 会话侧栏纯粹极简重构（对标 ChatGPT / Claude 高级感）
- **会话侧栏去除 4 个重复业务按钮**：
  - 从对话界面（`chat`）左侧栏移除冗余常驻的 `应用`、`知识库`、`工具库`、`自动化` 4 个按钮；
  - 顶部仅保留核心极简操作：**`[ 🏠 返回工作台 ]`**（随时一键返回中枢）与 **`[ 🔍 搜索会话 ]`**（快速拉起会话搜索）；
- **清除右侧多余快捷键徽标**：
  - 响应视觉纯净诉求，彻底移除搜索按钮右侧的 `⌘ K` 方框徽标（`.sidebar-kbd`），保持界面整洁干练；
- **去除侧栏底部冗余区块**：
  - 将原侧边栏底部的 `.sidebar-footer`（包含 `用户名/角色徽标`、`帮助`、`设置`、`退出`）从可视区域完全隐藏；
  - 退出登录、系统设置与个人信息集中收归至 **个人工作台左侧导航轨底部（rail）**，分工明确、操作直观；
- **历史会话列表一贯到底**：
  - 累计为历史会话列表（`#session-list`）夺回 **~250px 的纵向展示空间**，列表直通侧栏底部，单屏可多浏览 6~8 条会话记录，彻底摆脱拥挤滚动感。

### 4. 架构治理、影子兼容与全流程测试验证
- **DOM 影子容器向后兼容**：
  - 被精简的 4 个工作区按钮与底部管理按钮在 DOM 层完整保留于隐藏容器中，100% 保持系统既有模块事件绑定、静态资产扫描（`check_chat_assets.js`）与底层自动化测试兼容；
- **严格架构红线治理**：
  - [app-workspaces.js](file:///e:/pivot/client/chat/app-workspaces.js) 严控代码行数，降至 963 行（完全符合 $\le 1000$ 行单文件门禁）；
  - 全量 SVG 图标与 HTML 注入严格使用 `PivotSafeHtml`，零裸 HTML 注入风险；
- **新增单元测试与全量检验**：
  - 新增 `tests/personal-workbench.test.js`，针对常用入口白名单过滤、主模板接入、来源工作区持久化与返回导航进行全面覆盖；
  - ESLint 检查 0 错误 0 告警，架构治理与全量核心测试全部绿灯通过。
