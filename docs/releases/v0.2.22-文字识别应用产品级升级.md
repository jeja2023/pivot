# v0.2.22 文字识别应用产品级升级

发布日期：2026-10-13

## 交付内容

- **完整页覆盖与预检**：OCR 在创建任务前检查真实页数、文件类型、页范围和有效配额；任务记录原文件页数、计划页数、已处理页数、失败页和未选页。超出页数预算时明确拒绝或要求指定范围，不再无提示截断。
- **可靠任务与恢复**：OCR 页按持久任务处理，单页失败形成部分完成结果；支持只重试失败页并保留已完成页、已有人工修订与历史输出。任务增加 worker 租约所有者与执行 epoch，降低多实例恢复时迟到状态覆盖的风险。
- **可信复核与版本化输出**：机器原文、人工修订、页内容版本和坐标对齐状态分开保存。保存复核使用乐观版本校验，防止多窗口覆盖。修订后的 TXT、Markdown、JSON、HTML、DOCX 与 Excel 生成新内容版本；旧输出明确标为旧版本。导出请求会冻结当时的页面/文字块快照，异步生成后可轮询状态并在重启后恢复；全文修订导致坐标失效时，会阻止生成伪精确的可搜索 PDF。
- **中文可搜索 PDF 与结构化结果**：可搜索 PDF 复用 CJK 字体和不可见文字层，保留原页视觉尺寸。OCR HTTP 契约保留未知置信度、阅读顺序、模型/质量信息和表格单元格结果；结构化表格可导出为 Excel，并防止公式注入。
- **混合 PDF 与问题复核**：共享文本提取改为按页判断，原生文本页保留原文、扫描页才 OCR。低置信度、未知置信度、空结果和日期异常形成页级待核问题；工作区可导航全部文字块，不再只显示前 120 项。
- **高效输入与业务衔接**：支持批量上传最多 20 份文件、浏览器粘贴图片、批次逐项状态、任务详情覆盖摘要、字段候选提取（文号、日期、发布单位、金额）及知识库/法规库的来源回执。业务分发以“任务、内容版本、目标与参数摘要”去重并记录状态；公文材料未打开时不再把正文写入浏览器本地存储。
- **区域与协作治理**：复核工作区支持在原图框选区域后生成独立 OCR 候选，不自动覆盖人工文本；任务所有者可向同单位可用用户分派复核，受指派用户仅能读写被分派任务；纠错反馈要求材料使用授权，并在管理员审核通过后才进入可用样本状态。
- **本机快速输入**：桌面客户端复用既有“当前前台授权窗口”截图确认通道；用户可将截图送入 OCR。网页端仍采用粘贴/上传，不会后台截屏。
- **质量与长文档读取**：新增 60 份、206 页可重复 OCR 黄金夹具和 CER/关键字段/阅读顺序评估器；新增分页页块接口和带任务、修订、页码来源的聊天上下文，避免长文档只能整体取回或失去来源。
- **国产格式基础支持**：已支持安全读取文本型 OFD 包中的页面内容并导出；扫描型 OFD 不会伪装为可识别，仍需经外部 OCR 服务的实际渲染能力和目标平台样本验收后启用。
- **安全与治理**：密码继续只保存在短期加密秘密存储；OCR 专用路由在读取、导出、预览、复核和分发前限定 `ocr_app` 作用域。新增能力接口、类型化 OCR 配置、输出内容版本、覆盖率监控和页面修订/批次迁移。

## 数据迁移

新增 `202610130003_ocr_product_upgrade`，扩展文档任务、页面和文字块的覆盖率、版本、对齐与执行租约字段，并新增页面修订和 OCR 批次表；新增 `202610130004_ocr_async_exports_and_distributions`，持久化固定版本的异步导出快照及幂等分发记录。部署前按既有流程备份 PostgreSQL；应用启动后自动执行迁移。旧 OCR 任务继续可读，缺乏历史原始页数的记录会保留已有状态而不会被伪造为完整覆盖。

## 已知边界

- Pivot 继续只通过 HTTP 调用独立 OCR 服务，不随客户端打包具体 OCR 模型。复杂表格、公式和手写是否可用由服务端能力契约决定；区域重识别已作为受控候选能力提供。
- 字段提取返回的是带页码的候选，不代替人工核验，也不会自动修改正式公文或法规数据。
- 浏览器粘贴图片可直接创建 OCR 任务；受控桌面截图与组织协作复核复用既有授权能力。受控目录监听和 OFD 专项解析仍须以组织部署的本机连接器/解析服务和实际格式样本验收后启用。
