# Pivot v0.1.144 发布记录：对话入口默认智能自适应

## 发布概要

本版本把自适应路由从可选输入区开关收敛为普通会话的默认行为。用户无需先决定是否使用知识库或工具库，只需描述目标；系统在现有权限与安全策略内判断是否检索资料、是否建议工具候选。

## 界面变化

- 移除输入区“智能自适应、知识库、工具”三个菜单项及其二级配置面板；
- “+”菜单仅保留“选择文件”和“选择文件夹”，附件仍要求当前模型支持视觉或文档分析；
- 输入框提示可使用“@”精确指定知识库或工具；
- 工具尚未授权时，回答中的路由摘要会提供“启用工具库”操作；完成明确授权后需重新发送问题。

## 保留的控制与安全边界

- 前端默认发送自适应路由请求，但服务端总开关、分项开关、影子模式及降级策略继续生效；
- “@”选择仍受知识库可见范围、MCP Capability、会话授权与已保存工具白名单限制；
- 工具发现只产生候选，不能直接执行；真实调用仍需用户授权、执行策略、审批、网络预检及本机确认（如适用）；
- 既有手动工具白名单不会被移除或放宽；为保证“@”指定、历史恢复与 RAG 数据加载，聊天页保留不展示的兼容状态承载。

## 验证

- 更新聊天输入菜单静态回归和浏览器冒烟用例，覆盖默认自适应、旧菜单不存在、附件菜单仅有两项及布局边界；
- 运行聊天路由、输入菜单、安全 MCP 与安全聊天回归，以及项目检查门禁。
