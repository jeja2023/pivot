# v0.2.13 法规解释分类与联合发布机构

发布日期：2026-10-12

## 概述

本版本修正法规导入中“法律解释”和“司法解释”的术语口径，并补齐多个机关联合发布法规文件的录入、批量维护和检索体验。

## 变更内容

### 1. 解释类型口径修正

- 新增“法律解释（人大常委会）”快速预设，自动填写：法规层级“法律解释”、分类“法律解释”、发布机构“全国人民代表大会常务委员会”、适用范围“全国”。
- 保留“司法解释（最高法）”“司法解释（最高检）”，并新增“司法解释（两高联合）”预设，自动填写共同发布机构“最高人民法院、最高人民检察院”。
- 快速预设区明确提示：全国人大常委会的法律解释与最高法、最高检的司法解释属于不同口径，避免导入时误归类。

### 2. 多机构联合发布支持

- “发布机构”字段在新建、编辑、批量修改中明确标注“可多个”。
- 支持使用顿号、中文/英文逗号或分号输入多个机构；保存时会去除重复项并统一规范为顿号分隔。
- 目录筛选、条文检索、问答上下文和导出仍使用同一发布机构字段，因此按任一共同发布机构名称均可命中相应法规。

## 法律口径说明

全国人民代表大会常务委员会行使法律解释权；最高人民法院、最高人民检察院分别就审判、检察工作中具体应用法律的问题作出司法解释。两高可共同发布司法解释。相关条目仍应由管理员结合正式标题、发布机关和原始来源人工核验后入库。

## 验证

- 浏览器回归验证“法律解释（人大常委会）”和“两高联合司法解释”预设会同步填写层级、分类、发布机构和适用范围。
- 服务回归验证多个发布机构去重、顿号规范化，以及按任一发布机构检索命中。
- 法规/RAG 集成回归通过；前端资源、迁移索引、文本完整性、开发规范与差异格式检查通过。
