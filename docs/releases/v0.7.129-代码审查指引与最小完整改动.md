# v0.7.129：代码审查指引与最小完整改动

日期：2026-11-08。

## 新能力

- “创建 / 导入技能”增加中文“代码变更审查”和“代码仓库审计”模板，不上传文件即可预览固定指引，并沿用个人草稿、验证、发布和运行上下文。
- 工具限于当前账号已授权的本机工作区只读连接器，保留原有确认与审批。服务端校验模板和工具，发布前重新核对目录；缺少连接器时显示可操作提示。
- 模板仅供显式选取，排除关键词自动匹配；不会成为普通聊天、PPT 或 BI 的全局行为规则。审查只交付有证据的中文报告，明确未读及未验证范围。
- 完善 `AGENTS.md` 与开发规范：先理解调用链和需求，复用现有实现，完成最小有效改动与测试，保留安全、兼容、审计和恢复，不以代码行数评价完整性。
- 增加四类历史问题的对照计划，以及 `npm run compare:code-review` 运行记录汇总工具。按模型比较质量、回归、Token、工具调用及耗时，严格区分夹具与真实测量。

## 使用与部署

更新服务端与前端资源后，在“技能 → 创建 / 导入技能”选择模板。先通过既有桌面连接器连接并授权目标工作区，核对工具后预览、确认添加，再在审查任务中显式选择技能。可使用现有技能暂停和版本管理撤销后续使用，不会删除历史报告。

无需数据库迁移、新依赖或额外环境配置。模板随 `server/skills/` 分发，原始 MIT 许可保留在 `docs/licenses/PONYTAIL-MIT.txt`。固定上游 Ponytail 5.3.3 / `96608e078b2d5ea607c5c3b8b5a54d1c1fba6846`；未引入其宿主 hooks、全局模式或统计面板。
