# v0.7.54 扫描件定位补充与 WebDAV 范围保护

发布日期：2026-10-28

## 改动

- 为旧扫描 PDF 提供“补充定位”入口。每轮最多重新识别 10 个已有文字但缺少坐标的页面，成功后写入原文件哈希对应的 OCR 缓存并重建索引；失败时保留原有缓存文字和其他页面。OCR 服务未返回可用坐标时仍可能无法高亮。
- WebDAV 每个目录必须返回该目录自身成功的集合属性，才能被认为扫描完整；空响应、权限失败、目录缺失或范围不完整不会触发删除同步。
- 同步游标记录目录范围指纹。第一次同步或地址、递归设置、深度、文件上限、凭据引用变化时，禁止按旧范围执行删除；新的范围完成扫描后，后续完整扫描才进入既有删除保护。超出当前目录或深度的历史资料不会作为缺失项自动归档。扫描失败不会更新该指纹。

## 验证与限制

隔离 PostgreSQL 和模拟 OCR/WebDAV 测试覆盖缓存隔离、失败保留、范围变化和空目录响应；浏览器回归覆盖补充定位入口。生产 OCR 及 WebDAV 产品尚未验收；更换凭据引用会触发范围保护，但同一凭据引用的权限变化不会被指纹识别。管理员仍须核对源端账号的访问范围。

无新增数据库迁移，依赖 v0.7.53 的 `202610280004_knowledge_ocr_location`。本版本不会自动重新识别全部历史扫描件；使用者可逐次发起补充。扫描页坐标来自 OCR 服务，其内容及坐标质量仍需业务抽检。

生产语料黄金集、实际容量测试、真实备份恢复和具体企业平台连接器依旧需要目标数据或独立环境，不能以模拟测试替代。
