# v0.7.55 智能体 SLO 历史脱敏数据兼容修复

发布日期：2026-10-28

上下文压缩事件的 `inputTokensBefore` 和 `inputTokensAfter` 过去被通用敏感字段规则误识别为令牌并写成“[已脱敏]”，监控查询直接转换为 PostgreSQL bigint 时会报错，导致周期性运行 SLO 监视失败。

本次在压缩事件写入时，仅对明确列出的计数字段保留有限非负整数；其他字段仍按原规则脱敏。读取历史事件时先校验格式，再转换并聚合有效的前后计数对；对历史脱敏、缺失和异常数据记录不可用样本数量。硬字段丢失也按有效布尔样本统计，界面在无样本时显示“暂无数据”。历史脱敏数字无法从事件中恢复，不做猜测或回填。

无需数据库迁移或修改历史数据。更新并重启服务、重新加载页面后生效；已存在的缺失计数不会参与节省率，新事件会逐步积累可用样本。长期记忆向量列兼容问题已在 v0.7.56 单独修复。
