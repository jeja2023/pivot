# Pivot v0.7.190 发布说明

2026-11-20 · 原稿编辑器下拉框优化与工作台工具栏精简

## 主要变更

- **优化「原稿编辑与离线视频」中的「已有原稿」选择体验。**
  - 字段头部新增原稿数量徽标与「刷新」按钮，便于在导入或归档后实时同步历史原稿列表。
  - 规范下拉选项展示格式为「《文稿标题》 · v版本号（更新时间）」，无历史原稿时展示明确空状态引导并置灰禁用，防止误触。
  - 选中已有原稿后，下拉框下方即时渲染结构化预览卡片，展示标题、版本徽标与更新时间，内置「清空选择」与带二次确认的「归档移除」快捷操作。
  - 联动「打开原稿」按钮状态（未选择时置灰禁用，选中后点亮为主按钮），支持下拉框双击或按 Enter 键快捷打开；「打开当前工作台文稿」按钮动态悬停提示当前打开的文稿名称。
  - 完整适配深色模式并重新构建应用工作区样式包，同时移除界面提示文案中的表情符号。
- **精简「我的演示文稿」顶部工具栏按钮视觉。**
  - 移除「AI 自由设计」「模板库」「更多创建」「刷新」按钮名称前方的图标，保持与「完整制作记录」一致的简洁纯文本风格（保留「更多创建」右侧下拉展开箭头）。
- **同步架构治理字节基线。**
  - 收紧 `client/chat/apps-workbench-presentations.js` 在 `scripts/governance_baseline.json` 中的字节基线，保证治理门禁通过。

## 升级与兼容

- 本版仅更新 Pivot 主应用前端与发布文档，无需重建独立执行服务镜像，无数据库迁移。
