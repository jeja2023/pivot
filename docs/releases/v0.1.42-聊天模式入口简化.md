# v0.1.42 版本发布记录

**发布日期**：2026-08-24  
**版本主题**：聊天模式入口简化

---

## 一、交互调整

- 当前模式从“+”菜单移到聊天输入框加号右侧，始终显示“普通”或“Agent”。
- 点击模式名称打开紧凑选择面板，可在“普通回答”和“Agent 执行”之间切换。
- 当前选择继续保存在浏览器本地，发送下一条消息时沿用当前模式。
- 管理员禁用 Agent 执行模式时，Agent 选项显示禁用状态并说明原因；普通模式仍可用。

## 二、菜单收口

“+”菜单现在只负责附件、知识库和工具配置，回答模式不再重复出现在菜单内部，减少操作层级和视觉噪声。

## 三、验证

- 聊天模式选择器静态契约测试通过。
- 设置页契约测试：3/3 通过。
- Agent SSE、聊天桥接、预算契约：通过。
- ESLint、语法、文本完整性、架构边界和 Raw SQL 检查通过。

本版本无需数据库迁移。
