# Pivot v0.7.182 发布说明

2026-11-20 · PPT 模板预览中文字体修复

Linux 主应用镜像原本已包含 Noto Sans SC，但图片渲染器无法通过 Fontconfig 找到它。在缺少其他中文字体时，预览中的汉字会显示为十六进制码位方框。新版主镜像在构建时注册随包字体、生成缓存，并以非特权运行账号检查匹配结果。模板库里的 PPT Master 风格示例与内置模板版式都使用这条渲染路径。

启用源码版本 v0.7.182。生产部署使用包含修复的 Pivot 主应用镜像。已配套部署上游 v6.10.0 的环境可继续使用 `ppt-master:6.10.0-pivot0.7.181`。本次修复无需数据库迁移。[主应用离线部署](../生产环境离线部署.md) · [PPT Master 独立服务部署](../deployment/PPTMaster独立服务部署与更新.md)

升版前，在 Linux/amd64 的只读容器中，用 v0.7.181 主应用底座制作并验证了字体修复镜像 `pivot:0.7.181-ppt-preview-fontfix`。14 种 PPT Master 风格示例和两个内置封面完成离线渲染，其中「主题演讲」「培训讲解」和「政企正式」的中文显示经人工查看确认。将该归档重新导入后，「主题演讲」生成的 PNG 与已验收文件逐字节一致。18 项镜像契约测试通过。

现有离线归档按实际构建标识保留为 v0.7.181 字体修复版。本次升版完成源码和发布文档同步。完整 v0.7.182 主应用镜像构建和生产部署均待完成。
