# v0.1.76 发布记录：可用工具弹窗加宽与桌面端连接器限流降噪优化

发布日期：2026-09-04

## 一、可用工具模态弹窗宽度加宽与网格重构

### 1. 弹窗容器加宽与多列排版
- **弹窗宽度扩展**：将 `.mcp-tools-modal` 弹窗宽度由原本局促的 `min(720px, calc(100vw - 32px))` 加宽至 **`min(1040px, calc(100vw - 32px))`**。
- **3 列自适应卡片展示**：配合内部 `.mcp-tools-grid`（`minmax(300px, 1fr)`）卡片流，常规桌面屏幕下工具卡片由原本的双列扩展为**舒适的 3 列并行展示**，大幅降低纵向滚动距离，各类工具（本机数据库、报表文件、浏览器自动化等）一览无余，同时在较窄屏幕下平滑回退至双列/单列。
- **架构治理基线达标**：严格控制前端逻辑文件 [`client/chat/mcp-workbench-main.js`](file:///e:/pivot/client/chat/mcp-workbench-main.js) 的代码行数（维持在 1462 行 $\le$ 1463 行基线），通过大文件治理门禁。

## 二、桌面端本机连接器轮询策略优化与空闲待机

### 1. 心跳与任务认领解耦
- **心跳低频上报**：在 [`desktop/local-mcp-connector.js`](file:///e:/pivot/desktop/local-mcp-connector.js) 中，将原本每次轮询（3秒）全量发起挑战、心跳并写入数据库的逻辑解耦；心跳（`heartbeat`）调整为 **45 秒** 上报一次（当用户在本机授权中心变更配置时，仍通过 `sync()` 立即同步）。
- **按需任务拉取**：在未授权任何本机工具（`active === false`）时，连接器自动进入 **20 秒** 待机周期，不再发起 `claim` 任务认领；仅在存在已授权工具时才以 **5 秒** 间隔拉取任务，大幅减轻网络与数据库开销。
- **智能错误退避**：当遭遇网络故障、服务端重启或偶发错误时，停止 3 秒急促重试，采用递增退避机制（`10s -> 20s -> 40s -> 最大 60s`），待恢复成功后自动重置回正常频率。
- **可测试性重构**：允许通过选项注入 `identity` 依赖，便于在纯 Node.js 测试环境中完整模拟并验证连接器生命周期。

## 三、服务端设备挑战限流解耦

### 1. 专用设备限流器
- **独立限流隔离**：在 [`server/app.js`](file:///e:/pivot/server/app.js) 中新增 `deviceChallengeLimiter`（上限 **180 次/分钟**，支持依据设备 ID `device_${deviceId}` 隔离限制）。
- **移出通用自动化限流桶**：在 [`server/routes/agent-delivery.js`](file:///e:/pivot/server/routes/agent-delivery.js) 中，将 `/api/agents/local-devices/challenge` 从原先每分钟仅允许 30 次的 `automationLimiter` 中剥离，彻底消除正常设备安全验签触发 `[状态: 429]` 告警的误伤问题。

## 四、服务端控制台高频请求日志降噪

### 1. 内部心跳与任务轮询静默
- **补齐新版内部轮询路径**：在 [`server/logger.js`](file:///e:/pivot/server/logger.js) 中定义 `HIGH_FREQUENCY_BACKGROUND_URLS`，覆盖 `/api/mcp/local-device/connector/heartbeat`、`/api/mcp/local-device/connector/tasks/claim`、`/api/agents/local-devices/challenge` 及 `/api/agents/deliveries/claim`。
- **成功请求降噪**：对 HTTP 200/201 成功的心跳与任务轮询请求在控制台静默（或设为 trace），不再向终端频繁输出 `INFO: POST ...`，恢复终端清爽；对 4xx/5xx 异常依然保持告警输出。
