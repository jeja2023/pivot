# v0.7.22 工作流画布模式聚焦与交互体验升级

日期：2026-10-21。

### 1. 安全彻底清理步骤编排模式
- **架构聚焦画布模式（Canvas Mode）**：
  - 经确认步骤模式与画布视图共用同一套底层 DAG 流程定义，彻底移除步骤模式专用入口、界面与控制逻辑。
  - 清理步骤卡片、分栏、步骤抽屉、分组折叠以及 `.workflow-view-steps`、`.workflow-product-view-switch` 模式切换等相关死代码与专用样式。
  - 重新编译并压缩客户端样式包（`chat.workspace.agent.css` 等），避免残留无用样式。
- **保留并无缝接入画布的核心共用能力**：
  - **草稿保存失败与冲突恢复**：保留挂载于画布顶部工具栏下方的 `#workflow-product-feedback`，完整支持保存失败重试、差异对比、载入服务器草稿、另存草稿副本与本地导出功能。
  - **运行参数表单**：保留挂载于画布主面板的 `#workflow-product-run-form`，支持线上发布版本参数校验、多类型输入（文本、数值、布尔、日期、文件、JSON 数组与对象）、文件上传及历史参数复用。
- **测试套件清理与适配**：
  - 更新并适配 `tests/workflow-product-foundations.test.js`、`tests/workflow-product-client-state.test.js` 及 `tests/e2e/workflow-product.spec.js`，移除对步骤模式选择器断言，聚焦画布原生交互。

### 2. 工作流结果弹窗与历史运行优化
- **历史运行列表展示**：
  - 时间显示统一增加完整年份（`YYYY-MM-DD HH:mm:ss`），文本单行不折行。
  - 状态标识全面剔除 Emoji 图标，更换为标准化矢量 SVG 图标（已完成打勾、运行中转圈、告警等）。
  - 下拉选择框与“历史运行”标签文本及图标精准水平垂直居中对齐。
- **弹窗操作与交互规范**：
  - 右上角关闭按钮统一采用红边红字 `.workspace-modal-close` 规范，清除弹窗右下角多余关闭按钮。
  - 修复“将已完成的节点结果用于调试”按钮事件绑定，支持直接复用历史完成节点的输出数据作为当前编排的 mock 调试数据。

### 3. 工作流列表与历史版本弹窗优化
- **列表操作列交互**：
  - 收藏按钮移除多余 Emoji 图标并转为清晰文字按钮，统一调整按钮顺序为 `[编排]` → `[运行]`（已发布） → `[收藏/已收藏]` → `[更多 ▾]`。
  - 操作列采用左对齐，修复展开的下拉菜单被表格 `overflow: hidden` 截断的问题，并支持窗口底部自动向上弹出（`.is-dropup`）。
- **历史版本弹窗重构**：
  - 统一将弹窗宽度提升至 920px，统一使用右上角红边关闭按钮。
  - 规范版本号徽章显示，卡片清晰展示节点数与完整时间戳；采用两行分组操作按钮，折叠展示版本 Diff 差异及发布影响清单，全面适配深色模式高对比度。

### 4. 环境配置规范对齐
- 梳理 `.env` 文件尾部配置项，与 `.env.example` 模板完成配置项同步与注释对齐。
