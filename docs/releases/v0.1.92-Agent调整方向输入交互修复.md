## 修复内容

“调整方向”按钮此前直接调用浏览器原生 `window.prompt()`。Electron 和受控浏览器环境不支持该 API，因此点击按钮后会显示 `prompt() is not supported`，无法发送新的执行方向。

本版本改为使用 Pivot 已有的应用内 `showInputPrompt` 弹窗：

- 显示中文标题和说明；
- 支持输入、取消和确认；
- 空内容会进行中文必填提示；
- 支持占位示例和更宽的输入区域；
- 聊天 Agent 与任务详情使用同一套实现；
- 输入模块未加载时显示中文错误提示。
