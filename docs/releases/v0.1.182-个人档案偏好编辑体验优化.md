# v0.1.182 个人档案偏好编辑体验优化

发布日期：2026-09-26

发布范围：自动化工作台中的“技能与助手 → 个人档案”，覆盖工作习惯、常见任务和常用工具的编辑体验、工具建议、响应式布局和回归验证。

## 本次交付

### 标签式偏好管理

- 工作习惯、常见任务和常用工具不再要求用户维护多行文本框；每一项以独立标签展示，已配置内容可以快速扫描、逐项移除。
- 输入内容后按 `Enter`，或点击输入框右侧添加按钮，即可将一项偏好加入对应列表。
- 工作习惯和常见任务提供常用建议，例如“先给结论”“列出假设与风险”“待办整理”“项目汇报”。点击建议即可加入，不需要复制示例文本。
- 每类偏好最多保留 24 项，界面实时显示数量，避免无上限堆积导致运行上下文失焦。

### 常用工具建议与权限边界

- 常用工具区域从当前账号可见的 `/agents/tools` 目录加载建议项，显示工具中文名称和稳定工具标识，支持通过输入框搜索选择。
- 已保存但当前目录中不再可见的历史工具标识继续原样显示和保存，以兼容既有个人档案；它们不会因此变为可执行工具。
- 个人档案中的工具偏好只作为运行建议和受限上下文。它不会增加账户工具权限、绕过工具白名单、审批、租约或本机确认。

### 布局与可访问性

- 桌面宽度下，三个偏好区并排展示；空标签列表按实际内容高度占位，工具建议收敛为三项，减少无内容时的纵向留白。
- 在 1100px 以下自动切换为单列；标签、输入、添加按钮和建议项可以换行，不产生覆盖或水平溢出。
- 标签删除、添加按钮和建议项都使用标准按钮语义、可访问名称和键盘 Enter 操作；未知或空输入不会写入档案。

### 数据兼容性

- 服务端档案契约保持不变，继续读写 `workHabits`、`frequentTools` 和 `commonTasks` 三个数组字段。
- 历史换行或逗号分隔的值在前端加载时归一化为标签；保存仍提交同一数组结构，不需要数据库迁移。
- 偏好编辑逻辑从 `agent-harness.js` 拆分到独立的 `agent-profile-preferences.js`，主 Harness 未新增职责，满足大文件治理约束。

## 发布边界

- 该版本只改变个人档案的编辑界面，不改变 Agent 运行时对偏好字段的权限和安全解释。
- 当前可用工具目录随账号权限、系统配置和本机连接器状态变化；“常用工具”不是授权清单。实际调用仍由任务工具策略、审批、网络策略和本机确认决定。
