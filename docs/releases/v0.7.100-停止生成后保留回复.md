# v0.7.100 停止生成后保留回复

日期：2026-11-06。源码基线：v0.7.99。

## 原因与修复

站内会话恢复已经保留当前页面的流式消息，但普通回复此前主要在模型正常结束时保存。用户停止会取消原连接，服务端不进入正常结束分支；本页虽然仍有部分正文，刷新或读取历史后仍可能消失。

本次在服务器公开 SSE 输出之后保留正文，并在连接提前关闭时保存一条中止回复，添加未完成标记和 `route_metadata.generation` 状态。停止保存与原有完成保存使用同一确认，正常完成先开始时保留完整答案，中止先开始时迟到结束不能再次插入或覆盖。原有会话轮次唯一索引继续防止同一轮重复助手消息。

中止保存只包含真正通过公开输出链路的内容。等待知识核验的隐藏正文、工具参数、路由元数据及临时语音不进入该记录；空回复也不额外生成一条空白答案。不从未完成答案提取长期记忆，不为中止记录另调模型生成标题。

## 验证范围

单元测试覆盖已输出正文保留、停止/结束竞争、空记录与临时语音排除、协议元数据排除和监听释放。真实应用浏览器测试覆盖两会话同时生成、停止其中一条后即时保留、另条继续、切回恢复以及刷新后读取已保存的部分正文且没有重复气泡。

测试位于 `tests/chat-response-retention.test.js` 与 `tests/e2e/chat-generation-navigation.spec.js`，本次日志位于 `output/chat-interrupted-*.log`。本次不包含远程生产环境部署。

隔离 PostgreSQL 的 171 项相关回归全部通过，零失败、零跳过，覆盖聊天路由、完整流快照、空回复、流生命周期和中止保存。完整应用的跨会话浏览器用例通过，并明确断言停止回复已经写入数据库、刷新后恢复正文和未完成标记且仅有一个气泡；最终日志为 `output/chat-interrupted-regression.log` 与 `output/chat-interrupted-browser-final.log`，截图为 `output/chat-generations/stopped-session-after-reload.png`。

`npm run check`、`npm run lint`、`npm run typecheck`、开发规范、测试位置、文本和差异空白检查通过。此次未运行全项目 `npm test`。

## 升级与限制

同步更新服务端代码和客户端静态文件、重启服务并刷新客户端，无新增依赖或数据库迁移。需要服务端能够观察到连接关闭并成功写入数据库；进程突然崩溃、主机掉电或数据库不可用前尚未保存的正文不在恢复保证内。未完成标记不表示答案已经核验完整。
