# v0.1.200 知识图谱查询浮层与知识库综合页交互优化

发布日期：2026-10-10

## 概要

本版本重点优化知识图谱（Knowledge Graph）与知识库综合页（Knowledge Wiki）的交互视觉与排版体验。彻底解决了知识图谱路径查询内容以全宽通栏硬嵌入页面导致的工作区挤压与大屏超长拉伸问题，并优化了知识库综合页来源列表去重、分页扩容与正文排版。

## 核心变更

### 1. 知识图谱路径查询悬浮化与卡片重构
- **由嵌入通栏改为悬浮面板（Popover Card）**：将原本嵌入在顶栏与三栏工作区之间的全宽通栏重构为右上角绝对定位浮层（`position: absolute; right: 18px; top: 122px; width: min(520px, calc(100vw - 36px));`）。
- **解除画布垂直挤压**：彻底消除此前因展开查询结果导致关系地图（Canvas）、实体列表与关系明细纵向可用高度被大幅压缩的问题，保证核心工作区高度完整。
- **避免大屏超宽拉伸**：解决 1920px 宽屏下源实体、关系标签与目标实体被拉伸至近 1900 像素导致的严重空隙与视觉失真。
- **面板头部控制与快速关闭**：
  - 新增专用面板头部栏，包含搜索图标、标题“图谱路径查询”、实体数与路径数统计角标（如 `实体 2 · 路径 1`）；
  - 提供右上角关闭按钮（`×`），并支持按下 `Esc` 键快捷关闭或清空查询时自动收起。
- **实体标签与关系流动卡片**：
  - 匹配实体采用胶囊标签（Chip）样式，标注实体类型（如 `概念`、`系统`），支持 hover 动效与缩放微交互；
  - 关系路径设计为可视化流向卡片（Flow Card）：清晰展示 `[源实体] ➔ [关系类型] ➔ [目标实体]`，底部展示文档来源与置信度；
  - 暂无匹配路径时展示友好空状态提示。
- **画布联动居中定位**：点击查询结果中的实体标签或路径端点，直接调用图谱选择逻辑定位到对应节点并居中展示，右侧同步加载其关系明细。

### 2. 知识库综合页（Wiki）交互与排版优化
- **来源列表操作按钮去重**：移除综合页查看来源列表视图底部重复放置的“‹ 返回页面列表”与“发布此页面”冗余按钮，保留顶部统一操作，收敛交互视觉焦点。
- **来源列表分页扩容**：将来源列表每页展示条数由 6 条提升至 10 条，减少频繁翻页，提升信息密度。
- **正文预览区域扩容与靠左排版**：
  - 调大来源页面的“综合页正文”预览高度（`min-height: 84px; max-height: 150px;`）；
  - 将居中对齐纠正为左对齐（`text-align: left`），符合知识正文的阅读体验。
- **弹窗尺寸自适应与消除双重滚动条**：
  - 将 `.knowledge-wiki-modal` 独立解耦为 `min(1200px, 94vw) × min(760px, 90vh)`；
  - 消除弹窗内外部双重垂直滚动条与页面外部滚动条。

### 3. 前端工程与规范保障
- 样式重新打包编译并压缩至 `client/chat/chat.workspace.knowledge.css`。
- 窄屏（≤ 900px）自动适配吸底显示，避免与多行折叠顶栏遮挡。
- 更新直接 SQL 基线门禁并全量通过所有单元测试、契约测试与代码规范校验。
