# v0.7.66 个人技能单文件导入流程简化

发布日期：2026-10-29

## 更新内容

- 在“自动化 → Agent 控制台 → 技能与助手 → 技能”中，用户可选择单个 Markdown 文件、填写名称并选择当前账号可用工具。服务端转换工作指引并生成技能配置，预览展示完整内容、工具、能力、风险和未沿用的原文件字段。
- 用户确认后，界面依次调用现有草稿创建、验证与个人发布接口；不绕过工具权限、审批、供应链检查或发布门禁。所选工具、授权或待审阅内容变化后需重新核对。
- 验证或发布失败时草稿保留；创建或发布响应不确定时先核对已有记录，不重复提交。已验证草稿在技能列表中保留正确状态和发布入口。
- 原文件的脚本、附件、依赖和外部路径不会自动导入或执行；预览明确提示用户检查。原有手动 `SKILL.md` 配方和签名技能包入口移至“高级”，团队与组织共享仍遵循现有授权和签名规则。

## 验证与限制

- `npm run check` 和 `npm run lint` 通过；隔离 PostgreSQL 的技能治理相关专项 48 项通过，新增导入转换与失败恢复专项通过。
- 隔离数据库的浏览器回归覆盖文件选择、预览、无权工具拒绝、验证、个人发布、技能目录以及桌面和窄屏布局。未运行完整全量测试，也未进行生产环境验收。
- 当前简化入口仅转换一个文本文件，不能自动处理多文件技能或迁移可执行脚本；实际技能质量及其依赖的业务工具仍需在目标环境试运行。若创建或发布结果无法确认，请先在技能列表核对，避免重复操作。

## 更新方式

更新服务端并重新加载页面；桌面客户端使用对应版本构建。本次没有新增数据库迁移、必需环境变量或第三方依赖。
