# v0.1.74 发布记录：个人自主进化与本机浏览器会话访问闭环

发布日期：2026-09-02

## 一、个人自主进化与组织受控共享

### 1. 个人学习闭环

- 新增持久化 `agent_learning_jobs` 队列：支持来源任务去重、每用户每日限额、失败退避、锁超时恢复和审计摘要；学习失败不会阻断原任务结果。
- 成功的多步骤只读任务、失败恢复成功、用户修正和显式“记住这个方法”均可触发学习；敏感来源、敏感 Trace、评测运行、非安全工具路径和提示注入式指令会被跳过或拒绝。
- 学习结果只能创建既有的长期记忆、真实 Skill 版本或真实工作流草稿；不会直接修改 Pivot 代码、权限策略、审计规则、网络基线、凭据或租户配置。
- 已启用个人 Skill 会在相似任务中自动匹配，运行记录保存真实 release/version 信息，最终结果会标记“已使用个人经验”。

### 2. 个人与组织边界

- “我的经验”支持确认、编辑、暂停、恢复、撤销、自动归档和申请组织共享；关闭自动学习会同时停止新的自动学习、自动启用与自动匹配。
- 申请组织共享不复制个人 Skill 原始指令、标题、描述、对话、记忆、文件路径或工具输入；系统生成脱敏的独立候选 Skill/工作流制品，并只附加聚合效果、置信度和最小证据摘要。
- 组织候选遵循：**同租户管理员审批 → 真实验证 → 组织签名 → 10% 灰度发布 → 既有质量监控、熔断和回滚**。候选状态未达到门禁时，任何通用发布接口都不能直接发布。

### 3. 日常控制台

- Agent 控制台的日常入口统一为“个人档案、记忆与隐私、经验沉淀、技能管理”。
- “记忆与隐私”新增“我的记忆”轻量面板，显示活跃/暂停计数、近期使用、来源类型和内容摘要，并支持编辑、暂停、恢复和删除。
- 完整搜索、批量治理、导出与合并仍保留在“长期记忆”中心，避免在 Agent 控制台复制复杂后台。

## 二、本机浏览器直接会话访问

### 1. 授权与同步

1. 使用桌面客户端进入“工具库 → 我的电脑 → 管理授权”。
2. 选择“授权本机浏览器自动化”，填写精确 Origin（每行一个，例如 `http://10.12.0.20:3000`），再选择浏览器程序。
3. 授权保存后桌面连接器立即用设备签名同步浏览器、设备和 Origin；同步失败或桌面端过旧会给出明确提示，避免页面显示已授权而生产服务没有白名单。

### 2. 在普通会话中访问

1. 在输入区打开“工具”。如处于手动工具模式，勾选 `mcp.0.browser.*`，或切换为“模型自动选择”。
2. 直接写明允许站点的完整 URL，例如：`打开 http://10.12.0.20:3000/portal`。
3. 系统只在用户明确请求打开、访问、读取、点击或截图该 URL 时向模型暴露并路由本机浏览器工具；不会因普通聊天自行启动浏览器。
4. 当仅有一个已授权设备/浏览器时自动选择；多个设备时模型根据受控 Schema 选择。服务端会再次校验设备、浏览器、Origin 和端口。

### 3. 安全确认

| 操作 | 桌面端确认 | 说明 |
| --- | --- | --- |
| `browser.open` | 是 | 在隔离浏览器中打开页面，可由用户自行完成登录。 |
| `browser.inspect` | 是 | 回传正文前确认，避免把不应共享的页面内容带回会话。 |
| `browser.click` | 是 | 点击前确认，防止触发未知副作用。 |
| `browser.screenshot` | 是 | 截图回传前确认，并限制为 1 MB。 |

浏览器始终使用 Pivot 独立 Profile，禁止下载，不能读取日常浏览器 Cookie、Storage、密码、历史记录或扩展。未授权 Origin、设备、浏览器或不符合 URL/端口策略的访问会 fail-closed。
