# Pivot v0.1.151 发布记录：筛选行节点筛选条件输入区域重构优化

## 发布概要

本版本对工作流中「筛选表格行（data.filter_rows）」节点的「筛选条件（filters）」参数输入区域进行了深度重构与体验升级，解决了此前由于表单控件类型混杂导致的排版错位、高度失衡、无意义占位符以及上游字段选填不便等痛点。

| 优化维度 | 优化前 | 优化后 |
| --- | --- | --- |
| 控件排版 | 38px 单行 input 与 70px 多行 textarea 混排，带拉伸角标且严重错位 | 统一为 36px 等高单行输入框，与删除按钮居中等高对齐 |
| 引导标识 | 无任何列标签 | 新增清晰表头：`筛选字段`、`匹配值 / 引用变量`、`操作` |
| 新增条件 | 点击强制生成 `field_1`、`field_2` 假数据，需手动回删 | 生成干净空行，提示「选择或输入字段名」并自动聚焦输入框 |
| 上游字段选填 | 仅隐藏在原生 datalist 候选中，不可直观浏览 | 自动展示「可选上游字段」快捷芯片标签，一键填入或新增条件 |
| 空状态与变量联动 | 删除全部后无清晰提示；空列表时无法直接插入变量 | 呈现轻量空状态提示；列表为空时点击变量自动新建行并插入 |
| 代码与样式治理 | 向导文件超 1000 行红线 | 控制器独立解耦至 special-fields，样式遵循 CSS 变量规范 |

## 使用方式

1. 在 DAG 编辑器中添加或点击「筛选数据行（筛选表格行）」节点。
2. 打开「配置节点参数」弹窗，在「筛选条件」区域：
   - 可直接点击「可选上游字段」中的字段标签（如 `+ 部门`、`+ 状态`），快速创建针对该字段的筛选规则。
   - 也可点击「+ 添加筛选条件」手动输入字段名与期望匹配的值（或在右侧「变量引用」面板中点击插入上游结果变量）。
   - 可在下方的「匹配方式」参数中按需切换为「包含匹配（contains）」或「精确匹配（exact）」。
3. 点击「应用到画布」即可保存节点配置。

## 兼容性

- 参数 Schema 保持不变：`filters` 仍为键值对象结构 `{ [fieldName]: expectedValue }`，完全兼容已有的工作流执行、导入导出与后端内置工具调用。
- 原报表查询（reports.query_table）等同样包含 `filters` 参数的节点同步享受表头与等高单行输入体验。
