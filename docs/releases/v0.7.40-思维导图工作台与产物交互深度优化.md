# v0.7.40 思维导图工作台与产物交互深度优化

发布日期：2026-10-25。版本类型：思维导图大纲折叠与沉浸式画布、节点自适应与汉字光学对齐、单行流线型工具栏排版、渲染产物全网格数据表格与修订批注交互重构。

本版本重点解决用户在思维导图工作台、导图图形排版、交付产物表格及修订批注等核心交互中的视觉与使用体验问题：
1. **大纲编排折叠展开与沉浸式画布**：支持分支逐级折叠展开、隐藏计数徽标、全局一键折叠，以及画布侧栏整栏隐藏；消除画布内部多余的白底投影卡片图层；
2. **导图节点尺寸阶梯自适应与文字光学垂直居中**：通过中英文测宽实现节点宽高与列间距阶梯自适应，根主题文字全面居中，中文字符加入 `+1.8px` 字体光学垂直修正量，彻底解决文字视觉偏上问题；
3. **顶部工具栏单行流式排版与水平对齐**：控制栏锁定 `flex-wrap: nowrap` 单行 48px 排布，所有控件统一度量衡为 28px 高度，剔除配色下拉框继承的全局表单底部外边距，解决“商务靛蓝”下拉框浮动跑位问题；
4. **渲染产物全网格数据表格**：产物列表全面升级为含序号列、全网格边框、全列靠左对齐的专业数据表格，完整展示 64 位 SHA-256 内容指纹并支持全选；
5. **修订批注表单标准流卡片排版**：解除底部残留的网格挤压规则，规范为全宽单行位置输入、多行意见文本域与右对齐主按钮的垂直标准卡片流；
6. **全局样式统一与接口容错加固**：弹窗右上角关闭按钮统一样式接入系统红字红框规范，修复公文比对模块缺失的限流中间件引用。
