# v0.1.179 长期记忆产品化改造

发布日期：2026-09-26  
发布范围：长期记忆生命周期、隐私撤回、跨入口上下文、召回排序、评测与可解释治理。

## 本次交付

- **跨入口上下文一致性**：普通聊天、聊天转 Agent、直接 Agent、流式执行和渠道入口使用统一的长期记忆正文契约；修复对象被串化为 `[object Object]` 的桥接缺陷，并避免聊天桥接与统一上下文重复注入同一记忆块。
- **写入门禁与撤回**：长期记忆总开关、用户策略、类别限制和确认要求统一进入写入决策。策略存储故障时自动写入失败关闭；显式“记住”仍须通过敏感与指令内容检查，但不被“关闭自动捕获”误伤。
- **并发安全遗忘**：用户级记忆修订号与数据库行锁覆盖入队、抽取和提交写入。关闭记忆、删除会话、删除来源消息或擦除个人数据后，排队任务取消，在途任务也无法用旧修订号写回。
- **来源与抑制**：新增来源证据记录。删除来源时，只有无剩余证据的自动/学习记忆被撤回；用户“忘记”会保存不含正文的指纹和来源抑制，避免同一来源的改写候选重新出现。用户显式再次记住可解除抑制。
- **低信任注入**：检测凭据、标识信息、提示注入、隐形字符和要求绕过规则的内容。长期记忆作为不可信参考资料进入用户上下文，静态系统提示明确禁止其修改系统规则、工具权限或安全边界。
- **事实版本与作用域**：新增用户、项目、会话和全局范围；会话历史片段默认只在来源会话可用。人工纠正创建新版本并停用旧版本，保留来源审计；支持有效开始时间、过期时间、向量状态和来源声明者。
- **独立候选召回**：移除按重要度预取前 200 条的限制。词法与 pgvector 语义候选独立获取并 RRF 融合；中文 ILIKE 命中以确定性词法分数补偿 pg_trgm 的零分边界；最终须满足最低相关性门槛。
- **向量恢复与生命周期**：embedding 失败时记忆以词法状态保存。后台维护器补齐向量、记录维度，并在阈值达到后建立局部 HNSW 索引；自动归档过期和长期未使用、低价值的历史片段。
- **用户控制和解释**：记忆中心支持待确认候选、范围、生效/失效时间、来源证据、真实使用事件和评测用例管理。自然语言“忘记”会写入抑制记录；删除单条来源消息会同时取消相关排队抽取任务。
- **评测与灰度**：新增用户隔离的评测用例、运行及结果持久化接口，提供 100 条脱敏多轮基准。Recall@8 以最终实际注入集合计算，运行结果记录检索 p50/p95 和预计注入 token；模型抽取用量进入既有模型用量账本。`PIVOT_LONG_TERM_MEMORY_SHADOW_MODE=true` 时记录旧版/新版候选差异，不改变实际回答。
- **数据导出与擦除**：导出会自动分页并标注完整性；普通忘记保留受限抑制项，明确的个人数据擦除则删除记忆正文、来源、使用事件、评测、抑制项和抽取任务。

1. `202609260001_long_term_memory_productization`
2. `202609260002_long_term_memory_evaluations`
3. `202609260003_long_term_memory_embedding_recovery`
4. `202609260004_long_term_memory_search_index`
5. `202609260005_long_term_memory_validity_window`
6. `202609260006_long_term_memory_evidence_excerpts`

升级前按既有 PostgreSQL 运维规范完成备份。迁移只增加字段、索引与新表，并回填安全默认值；不会重写历史正文。向量恢复与 HNSW 索引在后台低优先级执行，向量服务不可用时保留词法检索，不阻塞对话。

## 配置与灰度

- `PIVOT_LONG_TERM_MEMORY_SHADOW_MODE=false`：默认关闭。开启时比较旧版与新版候选并记录事件，不影响回答。
- `LONG_TERM_MEMORY_MIN_RELEVANCE=0.08`：最终注入的最低融合相关性。
- `LONG_TERM_MEMORY_LOW_VALUE_ARCHIVE_DAYS=180`：低重要度、低置信度且长期未使用历史片段的自动归档天数。

首次上线建议保持影子模式至少覆盖一个完整业务周期，按用户或租户收集评测结果后再扩大新版排序范围。长期记忆总开关可立即停止新写入和新注入；不需要回滚数据库迁移即可进入只读/词法降级状态。

## 试点评测

版本库提供 [长期记忆脱敏评测集](../agent-experience/long-term-memory-evaluation-cases.json)，含 100 条多轮样例，覆盖偏好、事实、临时信息、纠正、冲突、无候选、敏感信息、来源撤销、注入和作用域。该文件不会自动导入任何用户账号。

部署负责人应在独立测试账号中创建与样例相符的记忆和评测用例，再在记忆中心运行评测。发布门槛：

- Recall@8 达到或优于旧版基线，目标不低于 85%；
- 错误/无关注入率不高于 5%，越权、删除后重建和注入成功均为 0；
- 用户纠正后下一次新请求不使用旧值；
- 报告模型、数据集版本、样本量、时间窗、p50/p95 延迟、token 增量和抽取成本；
- 真实试点用户评分与备份/保留期证明需要由部署方留档，本地回归不替代该证据。
