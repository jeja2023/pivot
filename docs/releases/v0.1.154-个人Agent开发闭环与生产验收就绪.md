# Pivot v0.1.154 发布记录：个人 Agent 开发闭环与生产验收就绪

## 发布概要

v0.1.154 完成《[Pivot达到Hermes个人Agent体验改造与落地方案](../../Pivot达到Hermes个人Agent体验改造与落地方案.md)》中所有可在代码库、本地 PostgreSQL 集成环境和自动化测试中完成的开发任务。本版本不将真实外部账号联调或真实用户评价伪装为本地测试结果；它们被明确保留为生产部署验收。

## 本次收口内容

- **低门槛入口**：个人工作台新增直接开始、后台 Agent 区分说明、四步可跳过/可恢复的首次引导和不采集正文的体验漏斗事件。
- **连续记忆**：聊天支持“记住 / 忘记 / 更正”候选确认；运行详情展示记忆命中理由。历史会话检索可按会话和 ISO 时间范围收窄，并返回受 ACL 保护的来源引用。
- **学习与 Skill**：自动学习仅从多步骤成功或恢复成功启动；用户纠正仍可显式触发。用户可从明确选中的已完成 Run 生成只含已登记工具/能力的个人 Skill 草稿，原始提示词、工具输入/输出和外部标识不会写入草稿。
- **目标与交付**：持续目标支持测试运行、签名草案的白名单展示级覆盖项、模型/能力/时区/保留期/渠道快照；Run 成功和渠道送达状态分离，支持死信和人工重投。
- **双向渠道**：Gateway 支持签名、时间窗、配对、幂等、撤销、加密回复目标、安全内联图片/常见文档附件、已配对身份审批和用户显式跨渠道会话接续。平台外部附件 URL 不进入工具执行面。
- **协作与治理**：运行详情展示协作任务组状态并可进入子任务；修复 DAG 顶层追踪上下文引用；将新增职责拆分为独立模块，继续满足大文件、死导出、SQL、架构和安全门禁。
