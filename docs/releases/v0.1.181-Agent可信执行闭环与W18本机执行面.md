发布日期：2026-09-26

发布范围：Agent 运行时、任务验收、恢复与协作、浏览器会话、模型质量治理、产物批注、个人体验、本机 Git 工作区、Windows UI Automation 和设备端实时语音。

## 本次交付

### 1. 可信执行与可恢复任务

- **统一完成契约**：任务创建、执行、完成页和评测统一使用 `TaskContract`、约束修订和 `VerificationReport`。运行完成不再只代表模型停止，而是区分已验证完成、部分完成、待补充输入和失败。
- **持久控制与协作**：运行中调整、回复、暂停、恢复和子任务协作均通过持久化命令账本领取、应用和确认。命令按来源消息与修订去重，过期领取可回收，不会因服务重启静默丢失。
- **检查点输出恢复**：检查点只保留结构化 envelope；大输出写入内容寻址存储并以摘要、归属和 schema 版本校验后恢复。缺失引用明确报告恢复失败，不用截断结果伪造完成。
- **副作用故障语义**：外部写操作记录 `prepared`、`dispatched`、`confirmed` 或 `uncertain`。不确定状态要求查询回执或重新人工处置，恢复流程不会自动重复副作用。
- **工作状态与证据**：运行保留已完成工作、未完成项、决策、开放问题、约束和证据引用。网页、检索、工具和产物来源均可以被任务验收、结果页和后续修订使用。

### 2. 浏览器、协作与质量治理

- **可恢复浏览器会话**：授权浏览器页面以会话、标签、导航修订和租约管理，支持跨步骤连续操作和过期回收；可视/DOM 操作保持受控下载、网络和页面边界。
- **受治理子任务**：委派、批量子任务、等待、消息和取消受父任务预算、并发、能力、工具白名单和审批快照约束；父任务取消会传递至活动子任务。
- **业务评测与验收**：评测批次、独立验收器、质量画像和回归门禁持久化。成功率与业务验收通过率分离，空样本不会显示为 100%。
- **质量约束路由**：模型按任务类型、已验证能力、样本量、质量下限、成本和时延选择。`auto-quality` 不在缺少最小样本时猜测模型能力。
- **技能和共享工具治理**：技能自动激活需要冻结评测门槛；共享工具使用跨实例 PostgreSQL 租约限流；渐进发现只开放描述后的受治理工具，批处理仅允许已描述、无副作用且幂等的读取。

### 3. 目标、产物与个人体验

- **目标与监控**：任务、监控和达成型目标具有明确状态、静默通知、变化摘要、失败熔断和 missed-run 处理语义；无变化的监控不生成打扰性通知。
- **产物闭环**：产物版本、CAS rendition、批注、处理状态、修订和交付回执统一关联，用户可在任务详情中查看验收、证据和交付状态。
- **个人工作台与详情**：个人入口和任务详情补齐任务状态、验收结论、证据、运行诊断、目标和受控反馈；移动布局、键盘操作和首用引导均进入回归契约。

### 4. W18：受授权 Git 工作区

- **受限工作区操作**：`workspace.inspect/read/search/patch` 仅作用于用户显式授权的 Git 根目录。读、搜和写均解析物理路径，拒绝符号链接、Windows junction、路径穿越、`.git` 路径和非文本扩展名。
- **搜索与写入安全**：ripgrep 搜索改用 `--regexp <query> -- <path>`，查询内容不可能作为 `rg` 选项或预处理器命令执行。修改前后均检查内容摘要，陈旧内容在打开确认框前或确认后再次校验时会被拒绝。
- **隔离工作树**：创建工作树后将名称、分支与相对路径写入本机授权登记；后续读写、测试、提交、推送和 PR 只能指定 Pivot 已登记的工作树。登记失败会回滚刚创建的工作树。
- **依赖、测试与交付**：`install`、`test` 仅在固定摘要的 Capability Worker 中执行，未配置或未启用 Worker 时拒绝。Git 命令移除外部配置、钩子和高风险环境变量；推送只使用验证过的 HTTPS/SSH 远程；PR 仅允许已授权 `github.com` 远程、当前分支和 GitHub CLI。

### 5. W18：Windows 原生桌面控制

- **窗口绑定**：每项操作在确认后验证当前前台窗口的完整标题和进程名，前台切换、目标不可见、禁用或只读均拒绝继续。
- **可访问性最小动作**：只支持 inspect、窗口截图、Invoke 点击、非密码可编辑字段的 Value 输入和等待控件出现；不使用坐标点击、任意键盘模拟或屏幕全局操作。
- **截图隐私边界**：截图使用 `PrintWindow` 渲染目标窗口内容，前后复核前台句柄，不再通过 `CopyFromScreen` 捕获其他窗口、通知或密码管理器覆盖层。PowerShell 驱动只接收最小 Windows 环境和类型化请求，输出上限为 2 MB。

### 6. W18：设备端实时语音

- **仅设备端能力**：必须同时满足浏览器可确认 `SpeechRecognition.processLocally` 和可用 `localService` TTS 声音；无法确认时不申请麦克风、不创建可用语音会话。
- **并发与生命周期**：启动过程单飞，重复点击不会产生多套识别器或遗留媒体轨道；支持句子级播报、用户插话取消播报、页面卸载释放轨道、会话心跳和服务端 TTL 过期回收。
- **不保留识别文本**：语音轮次使用服务端活动会话作为能力绑定，识别文本仅发送到当前模型请求。临时语音请求禁用 Agent、MCP、RAG 和重新生成，不写入 `messages`、长期记忆、标题、Agent 元数据或独立转写记录；服务器只保留会话状态、轮次数和打断计数。

## 发布边界与部署验收

- 本地 Git、推送、PR、Worker、Windows UI Automation 和浏览器设备端语音均为**可配置、可拒绝的可选能力**。缺少对应授权、认证镜像、前台窗口、GitHub CLI 凭据或浏览器能力时，系统必须拒绝执行，而不是退回到宿主 Shell、屏幕坐标控制或云端语音识别。
- 浏览器设备端识别不等同于每一种浏览器和操作系统都支持该功能。部署方应在目标浏览器上核验 `processLocally`、本地语音包、麦克风授权和页签/卸载场景。
- 本地回归不替代生产模型质量、真实组织数据、受控应用可访问性、远程仓库权限、Worker 镜像供应链、发布包签名和真实用户业务验收。部署前应使用目标凭据与冻结输入完成记录化验收。
