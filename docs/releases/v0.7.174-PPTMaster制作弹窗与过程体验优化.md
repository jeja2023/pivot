# Pivot v0.7.174 发布说明

2026-11-18 · PPT Master 制作弹窗与过程体验优化

## 交互与布局优化

### 1. 「完整演示制作」配置弹窗精简与单屏适配

- **统一底栏与状态收敛**：移除正文底端与页脚重复展示的引擎状态卡片及提示文案，将 `#presentation-master-engine-state`（就绪指示与兜底切换入口）、「查看最近制作」、「查看进行中的制作」及「开始制作」整合至同一底部操作栏，并在操作栏上方就近展示提交前校验错误提示。
- **层次对比与双栏平衡**：主体画布使用 `var(--bg-side)` 与 `var(--surface)` 混色底板衬托卡片边界与标题图标底衬；右栏「补充文字材料（可选）」自适应拉伸以与左栏底端齐平，「目标页数（1至40）」建议胶囊右对齐；精简「文稿名称」「目标受众」占位示例避免常见桌面视口下文本截断，并收紧垂直间距使 `1366×768` 视口一屏完整呈现。

### 2. 独立「完整制作过程」弹窗与退出交互去重

- **过程独立弹窗化**：点击「开始制作」「查看最近制作」或「查看进行中的制作」时立即弹出独立对话框「完整制作过程」，将底层配置弹窗设为 `aria-hidden` 与 `inert`；关闭或按 `Esc` 后清理轮询/准备状态、阻断迟到响应回填并恢复触发焦点。
- **去除重复退出入口**：移除过程弹窗底部与右上角「关闭」功能重复的「返回配置」按钮，保留右上角统一「关闭」入口及底部后台运行提示。

### 3. 过程操作按钮、确认区与「每轮模型用量明细」弹窗

- **状态栏与「停止制作」**：任务状态徽章与标题在左侧并排组合，区分为运行/完成（主色）、人工确认（琥珀色预警）、失败（危险红）与取消/过期（中性灰）；「停止制作」改为带方形停止图标的语义化危险轮廓按钮（`.btn-danger-outline`），修正状态卡片原先错用 `.presentation-evidence-card` 导致的深色背景与按钮文字颜色覆写。
- **每轮用量独立弹窗**：将「查看每轮模型用量」由长篇内嵌折叠列表改为按钮触发的「每轮模型用量明细」独立弹窗（支持轮询期间实时更新与逐层 `Esc`/焦点恢复），采用等宽数字与紧凑字号（`0.74rem`–`0.78rem`）分条展示调用轮次、输入/输出/累计令牌及上下文收敛分布。
- **人工确认与逐页核对清单**：人工确认区域升级为带琥珀色左强调边框与阶段徽章的 `.presentation-master-review-panel`，收敛方案上下文与提问字号；「确认并继续」「提交答复并继续」与「提交修改意见」补充图标及输入联动状态（填写修改意见时自动高亮「提交修改意见」）；逐页核对清单采用带编号徽章的独立页面卡片、正文断言与弱化引文三级字号配色体系。

### 4. 失败横幅与「从检查点恢复」面板

- 失败提示与等宽错误代码整合至 `.presentation-master-error-banner`；
- 原散落的检查点说明、三列续跑参数（累计预算、执行轮次、制作模型）及被横向拉满的「从检查点继续」按钮合并为「从检查点恢复」一体式面板，在 `PPT_MASTER_BUDGET_EXHAUSTED` 场景内联高亮预算提醒与输入框，并将「从检查点继续」升级为靠右对齐的主操作按钮（窄屏自动等宽铺开）。
