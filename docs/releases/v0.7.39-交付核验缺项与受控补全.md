# v0.7.39 交付核验缺项与受控补全

发布日期：2026-10-23。版本类型：Agent 交付核验可诊断性与内部补全修复。

## 问题与修复

独立语义核验要求 `coveredDeliverables` 逐字匹配任务合同中的交付项。若核验模型识别出内容但使用了不同表述，原逻辑会判定未通过，却可能不返回具体 `missing` 项；Agent 随后直接进入“任务等待补充”，界面只显示“交付内容尚未通过核验”。

现在核验器会把合同中未被逐字覆盖的交付项加入缺项清单，并将这些缺项传回执行规划器。仍有执行轮次、Token 和工具预算时，Agent 最多在原任务中进行两轮受控补全，优先使用已读取资料与观察；核验不可用、来源撤回、预算不足或没有具体修复项时仍等待处理。修复提示要求不得臆造事实或重复执行已有外部副作用。
