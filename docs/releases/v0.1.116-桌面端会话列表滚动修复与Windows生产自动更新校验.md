# 智枢 Pivot v0.1.116 发布记录

## 概述

**发布版本**：v0.1.116  
**发布日期**：2026-09-10  
**关注领域**：桌面会话列表滚动修复、Windows 生产自动更新校验与代码签名门禁、前端全局变量架构治理

---

## 核心修复与优化

### 1. 桌面端会话历史列表滚动修复与原生交互保障

- **原生滚轮分发桥接**：Windows Electron 客户端在某些窗口与合成层层叠状态下，Chromium 合成器未将滚轮事件有效分派至 DOM，导致会话列表无法通过鼠标滚轮上下滚动。主进程在 `before-mouse-event` 阶段截获 `mouseWheel`，经由受信 IPC（`pivot-desktop:session-list-wheel`）将滚动增量直接传递至渲染层进行平滑偏移。
- **作用域与手势安全保护**：渲染层通过受信 IPC 同步当前会话列表在屏幕视口中的实时几何包围盒及可滚动状态；仅当鼠标悬停在可滚动的会话列表区域内、且无可见弹窗遮罩、无 Ctrl/Meta 缩放按键时才接管滚轮，防止干扰其他界面元素与缩放手势。
- **双重兜底与可见滚动条**：桌面端预加载脚本恢复会话列表细窄可拖拽滚动条样式，用户除鼠标滚轮外亦可直接按住滑块拖拽浏览历史；保留网页端原有 DOM `wheel` 兜底，实现桌面客户端与浏览器端一致的平滑浏览体验。

### 2. Windows 客户端生产自动更新与签名校验门禁

- **真实代码签名门禁**：修复此前更新逻辑未能严格绑定 Windows 真实签名的问题。Windows 正式构建启用 `forceCodeSigning`，仅接受 Electron Builder 能够识别的 PFX 证书文件（`WIN_CSC_LINK`/`CSC_LINK`）或受信任企业代码签名证书（`PIVOT_WINDOWS_CERTIFICATE_SHA1`/`PIVOT_WINDOWS_CERTIFICATE_SUBJECT`），拒绝未受信任的开发机自签名隐式兜底生产发布。
- **发布产物签名验证管道**：新增 `scripts/verify_windows_update_artifacts.js`，在安装包和 `Pivot.exe` 复制到更新下载目录前，采用与 `electron-updater` 同款的 PowerShell Authenticode 验签算法校验其签名有效性及发布者主题名称（Subject CN）。任一产物签名异常均直接熔断发布流程，杜绝产生损坏或无法静默升级的更新包。
- **同源内网更新支持**：生产环境支持通过受控内网 HTTP 协议（如 `http://50.64.150.51:9006/downloads/`）分发升级包，但前提必须完成目标客户端互信的 Windows 代码签名，确保客户端自动覆盖安装的安全合规性与稳定性。

### 3. 全局变量规范治理与模块收敛

- **规范违规消除**：修复 `client/chat/agent-run-detail.js` 中的未命名空间化 `window.Pivot` 访问（原 `window.Pivot = window.Pivot || {};`），接入全局命名空间模块体系 `window.Pivot?.exposeModule?.('agent.runDisclosure', ...)`。
- **Legacy 存量压降**：避免将新方法写入 `window.Pivot.legacy`，将工作流运行详情相关披露状态函数规范暴露至 `Pivot.modules['agent.runDisclosure']`，使 `check:window-globals` 扫描通过，存量 legacy 别名指标降至 274 项（低于 276 上限）。
- **ESLint 零错误保障**：清理桌面预加载脚本与单测中的多余变量声明，全面通过 `npm run lint` 与 `npm run check`。
