# v0.7.89 对话附件展示与多格式文档预览全面优化

日期：2026-11-04。本版本记录工作区改动；更新版本号不表示已经构建、部署或完成生产验收。开发基线为 v0.7.88。

## 行为变化

### 1. 对话附件卡片统一规格与消息气泡紧凑化
- **附件卡片统一为紧凑规格**：DOCX、PDF、XLSX、TXT、MD、图片等全类型附件在消息气泡中统一以 `200px × 36px` 卡片呈现。移除冗余的文件类型图标，采用单色文本徽标（`DOCX`、`PDF`、`XLS`、`TXT`、`MD`、`IMG` 等）直观标识格式；超长文件名单行省略号截断（`text-overflow: ellipsis`）并提供原生 `title` 提示；移除“点击下载/预览”等多余文字。
- **图片附件卡片化**：图片附件不再在用户消息气泡中内联平铺展开大图，而是与文档一致采用统一卡片展示，点击卡片直接唤起全屏大图预览。
- **气泡宽度与双列排布**：限制用户气泡最大宽度为 `min(85%, 480px)`，附件卡片容器限制为 `416px`，多个附件自动呈规整的双列瀑布流排列，彻底解决大屏下气泡横向过度拉伸的问题。

### 2. 审计落款与内部参考文档标记彻底清理
- **多重分隔符截断修复**：修复当用户上传自含 `---` 分隔线的 Markdown 或审计文档时，非贪婪正则提前终止导致正文末尾泄露的问题。改用前瞻断言匹配整个参考块。
- **审计落款专项清理**：在前端消息渲染管道中针对 `本审计包由 Pivot 自动化控制面于...生成，受控于平台访问审计。` 增加专项过滤，彻底杜绝该底注文本在用户消息气泡中显示。

### 3. 多格式附件预览弹窗体验升级
- **预览弹窗尺寸扩容**：将预览弹窗外壳尺寸从 `1040px × 800px` 扩大为 `min(1320px, 95vw) × min(920px, 92vh)`，文档正文纸张宽度上限扩充为 `900px`，大幅改善大屏与常规屏幕下的阅读视野。
- **彻底消除弹窗外侧垂直滚动条**：将外层内容容器 `.attachment-preview-content` 设为 `overflow: hidden`，所有格式附件弹窗均无外侧冗余滚动条：
  - **PDF 预览**：由内嵌浏览器 PDF 插件自身进行内部页面翻页与纵向滚动；
  - **Word (DOC/DOCX) 预览**：消除内外双滚动条，由内部文档容器（`.attachment-preview-doc-wrapper`）承载平滑滚动；
  - **图片预览**：设置 `box-sizing: border-box` 与 `max-width/max-height: 100%`，自适应居中完整呈现，无任何滚动条；
  - **TXT / Markdown / Excel 预览**：由内部各自的文本或工作表容器内部滚动，弹窗外侧干净无轨道。
- **TXT & Markdown 白底模式**：去除深色黑底（`#0f172a`），统一为舒适的白底纸张样式（`#ffffff`）与深灰文字（`#1e293b`），Markdown 自动排版呈现，支持深色模式自适应。
- **Word 预览排版优化**：背景采用高对比度浅灰纸张衬底，正文采用仿宋、小标宋标题与纸张阴影，保留段落缩进与落款排布。
- **PDF 在线预览修复**：
  - 修复前端安全净化 `PivotSafeHtml.setHtml` 默认剔除 `<iframe>` 导致 PDF 预览区域空白的问题，改用原生 DOM 节点挂载；
  - 修复后端 `/uploads` 静态流未查 `file_name` 导致的 `path.basename(undefined)` 500 报错，显式注入 `Content-Type: application/pdf` 与 `inline` 响应头，确保浏览器原生 PDF 插件秒开。
- **下载交互直达**：弹窗右上角“新标签打开”按钮更换为“下载”按钮，点击即可直接下载原附件文件。
