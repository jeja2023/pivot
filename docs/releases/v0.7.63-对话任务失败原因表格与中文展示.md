# v0.7.63 对话任务失败原因表格与中文展示

发布日期：2026-10-29

## 更新内容

- 在“设置 → 系统监控 → 对话质量”增加对话任务执行失败原因汇总，使用统一数据表格展示序号、失败原因和数量，提供加载、空数据和请求失败提示，并可通过“刷新指标”重新加载。
- 将已识别的交付核验原因显示为“任务交付未通过核验”；未记录或未知原因显示中文提示，悬停可查看原始代码。结果按照数量降序排列。
- 决策维护报告的原因明细增加事件类型，页面仅统计对话任务的执行失败，不把用户反馈或部分完成结果混入。
- 页面按执行失败发生时间统计最近 30 天；这与巡检日志按决策记录创建时间统计的口径不同，数量可能不一致。报告最多返回 500 组结果，达到上限时可能不完整。

## 验证与更新

工程检查和相关代码 lint 通过；7 项监控专项测试通过。使用隔离 PostgreSQL 的浏览器测试验证了表头、中文原因、序号、空状态、请求失败与刷新，以及桌面和窄屏布局。未运行完整全量测试，也未进行生产环境验收。

更新服务端并重新加载页面；桌面客户端使用对应版本构建。本次无需新增数据库迁移、必需环境变量或第三方依赖。
