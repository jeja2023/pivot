# v0.7.2 语音入口与临时对话链路修复

输入框中的“语音输入”和“实时语音”均已接线，但此前存在启动状态和上下文缺陷，不能以按钮存在或请求成功认定真实可用。

- 语音输入：设备端识别后填入草稿，用户可编辑再发送；统一检查本地能力，避免默认浏览器识别可能使用远程服务却标注为本地。
- 实时语音：本地识别后自动向当前文本模型提问，再通过本地声音朗读。等待识别器实际启动才进入活动状态，再次点击正确停止；模型原生音频服务仍未接入。
- 临时文本与连续上下文显式加入本轮模型请求。临时历史仅保存在浏览器内存、限四轮，关闭后清空；不进入聊天、长期记忆和持久化任务快照。
- 修复中间结果、第二轮状态、会话切换、草稿覆盖及资源释放；朗读时暂停识别避免回声，朗读结束恢复聆听。
- 支持情况取决于 HTTPS/可信本地地址、麦克风授权、设备端识别语言包、本地朗读声音和可用文本模型。不能保证所有浏览器或桌面运行时均支持。

证据与限制见 [语音链路验收报告](../reports/语音入口深度检查与修复验收报告_2026-10-19.md)。刷新页面加载新客户端；服务重启后加载服务端修复。无需新增数据库迁移。

工程检查与 ESLint 通过；全量回归 1967 项、最终语音相关回归 19 项、启动补充回归 8 项、浏览器端到端 1 项通过。浏览器语音设备和模型为测试替身，未执行真人录音。本机 Windows 当前枚举的输入设备为 0，仍需设备就绪后完成实际验收。
