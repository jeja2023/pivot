# v0.1.104 发布记录：工作区样式与交互热修复

发布日期：2026-09-09

## 修复内容

- 工作区专属 CSS 继续按需下载，但不再阻塞模板挂载和交互脚本初始化。桌面端升级期间若 HTML、JavaScript 与 CSS 短暂处于不同缓存版本，用户仍可操作关闭、切换和刷新等控件。
- 新增共享表格基础样式包，统一提供表格容器边框、表头底色、单元格边框、文本截断和固定列布局。知识库的文档表格不再依赖设置页专属样式。
- CSS 样式加载失败时会在控制台记录告警，同时让功能入口继续完成；下次打开对应工作区时可重新尝试加载。

## 验证

- `npm run check`：通过；
- 工作区按需加载 E2E：通过；
- E2E 验证应用中心、知识库、工具库和系统设置的关闭控件均未被透明层覆盖；
- 知识库表格验证 `table-layout: fixed`、表头底色和边框计算样式均已生效。
