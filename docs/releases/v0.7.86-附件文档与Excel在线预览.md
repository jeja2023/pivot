# v0.7.86 附件文档与 Excel 在线预览

日期：2026-11-03。本版本记录工作区改动；更新版本号不表示已经构建、部署或完成生产验收。开发基线为 v0.7.85。

## 行为变化

- **Word / PPT 附件 ONLYOFFICE 在线预览**：配置 ONLYOFFICE 后，用户在对话或附件列表中点击 Word（`.docx` / `.doc`）及 PPT（`.pptx` / `.ppt`）文件，直接在弹窗中通过 ONLYOFFICE Docs 打开在线只读视图，完整呈现排版与样式；弹窗关闭时自动注销并清理编辑器实例，避免资源与 WebSocket 泄漏。
- **Excel 附件双轨预览支持（ONLYOFFICE + 内置多 Sheet 表格视图）**：
  - 配置 ONLYOFFICE 时，Excel 附件优先由 ONLYOFFICE 电子表格（`cell`）渲染，提供最接近原生 Excel 的网格浏览与公式视觉展示。
  - 未配置 ONLYOFFICE 或处于纯内网极简部署时，系统无缝回退至内置轻量化解析引擎（基于 `@e965/xlsx`），在客户端直接以交互式多工作表标签页（Sheet Tab）切换呈现二维表格，并带有行列序号与深色主题自适应支持。
- **文档提取文本回退保护**：当未接入 ONLYOFFICE 服务时，Word 附件自动回退至已有的服务端抽取文本纯文本预览，并带有清晰引导说明，确保在任何网络环境下均不阻断用户查看文档内容。
- **多租户安全与只读票据鉴权加固**：
  - 附件预览配置接口（`POST /api/attachments/preview-config`）严格校验附件所有权（仅本人或超级管理员有权请求）。
  - ONLYOFFICE 回源拉取路由（`GET /api/attachments/onlyoffice/file`）使用专用且隔离的数字签名票据（`purpose: 'onlyoffice-attachment-read'`），具备 300 秒短生命周期、用户有效性与令牌版本校验，并加固路径穿越与物理文件存在性防护，杜绝任何越权下载隐患。

## 验证与限制

- 单元测试（`tests/onlyoffice-preview.test.js`）与集成测试（`tests/attachment-office-preview-integration.test.js`）全数通过，覆盖 Word/Excel/PPT 的 ONLYOFFICE 配置生成、票据生命周期签发与验签、Excel 本地多工作表数据提取、无权用户 403 阻断及非法回源票据校验。
- 文本完整性与架构边界检查通过。未运行全量端到端或生产环境部署联调。
