# v0.1.180 长期记忆验收收口与评测体验升级

发布日期：2026-09-26
发布范围：长期记忆撤回竞争、来源可追溯、作用域写入隔离、评测指标、评测工作台与本地验收证据。

## 本次交付

- **撤回竞争收口**：单条记忆遗忘和来源撤销均推进用户级记忆修订号；删除单条来源消息会取消相关排队抽取任务，已启动的旧修订任务不能在撤回后提交。
- **真实遗忘语义**：自然语言“忘记”执行软删除并保存不含正文的抑制指纹和来源抑制，不再只把记录暂停，从而阻止同来源自动候选重建。
- **写入作用域隔离**：相同 `fact_key` 只在相同用户、项目或会话范围内参与去重、合并或版本替代；跨范围合并会明确拒绝，避免项目事实串用。
- **逐候选来源证据**：模型抽取候选必须给出实际用户消息 ID 和可验证摘录；缺少来源绑定的模型断言不会自动入库。来源查看可返回消息、声明者、来源类型和证据摘录。
- **评测按实际注入计算**：Recall@8、禁止命中和无关注入评测改为基于最终进入上下文的记忆集合，不以候选列表代替实际注入。每次评测运行持久化检索 p50/p95、平均延迟和预计注入 token。
- **抽取成本可观测**：结构化模型抽取会将提供方实际 token 用量或本地估算写入既有模型用量账本，供部署方按模型价格、时间窗和样本量生成成本报告。
- **评测工作台体验**：记忆中心的检索评测调整为独立弹窗，新增运行指标、历史运行、空状态与编辑取消状态；全部样式使用主题变量和生成样式包，不引入内联样式或硬编码配色。
