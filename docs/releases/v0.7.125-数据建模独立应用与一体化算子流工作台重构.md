# v0.7.125 — 数据建模独立应用与一体化算子流工作台重构

日期：2026-11-07。上一版本：v0.7.124。

针对可视化拖拽数据建模在画布视野、步骤割裂、常驻面板拥挤、宽表节点圆点密集、缺少内置算子/函数/自定义 SQL 以及缺少节点间运行预览等问题，完成端到端重构与能力补齐。

## 主要改进

- **应用中心独立入口与全宽沉浸布局**：在应用中心新增与「数据分析」并列的独立应用「数据建模」，进入后自动隐藏左侧数据分析子菜单栏，释放 100% 全宽沉浸式画布工作区；两边保留一键互跳并自动恢复原分析子页签。
- **取消人工四步分段，统一为一体化画布工作台**：移除原「1 表与关联 → 2 维度与指标 → 3 检查与依赖 → 4 试算与分析」分段导航条、常驻就绪横幅、右侧固定属性栏与底部冗长关联表，仅保留左侧可一键收起的组件栏，最大化画布操作范围。
- **右侧按需滑出配置抽屉**：点击任意画布节点或顶栏「维度与指标」「检查」「试算与分析」时按需从右侧展开配置抽屉，点击空白画布、按 `Esc` 或点击「关闭」即可收起；抽屉与画布工具栏、底部预览面板采用自适应网格协同排布，互不遮挡。
- **紧凑单圆点节点卡片与宽表字段检索**：将画布节点统一为固定尺寸（`224 × 76`）紧凑卡片，仅展示类型徽标、标题与单行摘要，不在卡片内逐行铺开字段列表；每个节点左侧至多保留 1 个输入端点、右侧仅保留 1 个输出端点。单圆点发起表关联时优先按同名业务列与维度主键智能推荐键对；宽表字段收归右侧抽屉，支持实时搜索过滤与一键设为维度/指标。
- **内置算子库、分类函数与只读自定义 SQL**：左侧组件栏新增 **数据输入、多表关联、数据筛选、函数计算、分组聚合、字段清洗、上下合并、自定义 SQL** 共 8 类可拖拽或点击串联的 DuckDB 算子，抽屉内置 **数学、文本、日期、条件与转换** 4 大类共 24 个函数模板与上游字段胶囊一键插入。执行前校验数据集及列级权限并锁定 `enable_external_access = false`，支持将任意算子节点输出一键物化保存为受治理标准数据集；算子流程图随草稿节点配置保存，不改变已发布正式版本的语义哈希。
- **节点到节点实时流转数据预览**：画布底部新增可折叠实时运行预览面板，展示完整上游流转链路步骤胶囊（点击可即时切换对比上下游任一节点输出）、输入输出行数变化（如 `上游 X 行 → 输出 Y 行`）、字段类型、执行耗时与抽样明细。
- **配置对齐与文档同步**：对齐 `.env` 与 `.env.example` 的数据建模配置项说明，同步更新《使用帮助》与设计规范文档。
