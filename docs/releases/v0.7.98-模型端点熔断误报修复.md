# v0.7.98 模型端点熔断误报修复

日期：2026-11-06。源码基线：v0.7.97。

## 问题与结果

共享端点运行时此前把调用层传来的所有异常都计为失败。后台意图判断取消、用户取消、排队拒绝和已经熔断的准入拒绝也可能被计入，连续三次便触发默认 60 秒保护。新的拒绝又会被记为失败，刷新冷却期并把包含“上次错误”的整段提示写回根因，形成“上次错误：上次错误：canceled”。这不证明模型本身发生故障。

本次在共享运行时排除正常取消、调用方已中止、本地队列与准入错误，并让后台调用只有在取得端点许可后才记录失败。聊天流在用户离开后直接结束；应用中心、公文写作和 OpenAI 兼容入口传递各自的取消信号。

熔断拒绝不再增加失败计数、覆盖根因或刷新冷却期。已熔断期间在途请求的真实失败仍会记录，但不会反复续期。上游超时、连接故障及错误响应仍保留原有保护；成功请求恢复端点状态。提示文本只保留一层“上次错误”。

- 验证排队前取消、持有许可时的调用方截止、普通取消消息，以及没有标准取消码但信号已取消的情况。
