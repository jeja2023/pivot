# v0.7.23 审计时序修复与智能体工作流交互治理

日期：2026-10-21。

### 1. 安全审计日志时序与 IP 缺失彻底修复
- **根因治理与全链路防御**：
  - 排查并修复 RAG 知识库文档上传、全量/增量重建索引、向量模型连接测试、重排序模型测试等 25 项操作写入审计日志时的时序错乱问题。
  - **业务源头修复**：在 `server/routes/rag.js` 的 `auditRagAction` 中，将漏传的 `ip` 字段更正为标准 `ipAddress`，并补全 `timestamp: getBeijingTimestamp()`。
  - **异步队列底层防护**：在 `server/services/db-write-queue.js` 中增加智能防御，自动将 `ip` / `clientIp` 归一化为 `ipAddress`；当任何调用方遗漏时间戳时，自动缺省补齐当前北京时间，彻底杜绝显式写入 SQL `NULL` 覆盖表字段默认值的情况。
  - **存量历史数据回填迁移**：新增并执行版本化数据库迁移 `202610210001_audit_logs_timestamp_repair`，利用连续自增主键 `id` 上下文，对历史存量中 `timestamp IS NULL` 的记录平滑回填真实邻近时间戳与客户端 IP，使历史日志全部归位至正确时序。
  - **测试验证**：在 `tests/security-db-write-queue.test.js` 增加针对队列入参归一化与缺省补全的单元断言，全量通过。

### 2. 工作流详情页操作栏布局与视觉体验升级
- **右侧操作按钮重构与层级明确**：
  - 梳理工作流编排顶部详情栏右侧的操作按钮，清晰区分主要行动与辅助功能：
    - 主操作区：`[保存草稿]`、`[测试运行]`、`[发布版本]`，采用鲜明视觉反馈与主色重点强调。
    - 辅助操作区：`[历史版本]`、`[运行记录]`、`[调试数据]`，采用紧凑次要按钮风格。
  - **样式与排版微调**：
    - 规范控件高度（32px/28px）、内边距（padding）、标准圆角（radius-sm 6px）与行高。
    - 解决右侧操作栏在不同屏幕分辨率下可能产生的折行与留白挤压问题。
    - 完整适配深色模式（Dark Mode），提供柔和的 hover 态与点击交互微动效。

### 3. 任务、工作流与智能体控制台架构与导航去歧义
- **三者概念与入口厘清**：
