# v0.7.101 对话文档生成 PPT 全链路补齐

日期：2026-11-06。

## 改动

- 新增 `presentation.create` 和 `presentation.export` 任务工具，复用已有 PPT 工作台的源稿、模板、质量检查与导出服务，生成包含全部页面的可编辑 PPTX，并挂载到当前任务结果。
- 新增 `diagram.render_svg`，从完整 SVG 源码生成 SVG/PNG，内部完成受控素材登记；导出现有 PPT 的单页 SVG/PNG 无需用户提供图片引用。
- 明确通用文档渲染与 PPT、SVG 生成的职责，补充工具搜索词、输入契约、任务规划和语义路由指导，避免反复调用错误工具。
- PPTX 任务增加真实格式验收，只有大纲或单页 SVG 时不能宣告完整交付；普通 PPT 附件分析不因此要求新建 PPTX。
- 任务标题去除上传地址、系统路径和拼接材料正文，保留业务描述与附件名称；同时处理新任务和历史读取。
- 增加数据库迁移，使演示文稿导出记录支持 SVG，保留历史导出数据。

## 使用与边界

在会话中上传材料并要求生成完整 PPT，任务会读取材料、规划全部页面、生成源稿、逐页检查并交付 PPTX。源稿可到“应用 → PPT 制作”继续修改。当前提供七类内容布局、表格、图表和讲稿备注，每份最多 60 页。

SVG/PNG 导出表示指定单页或单独图形；PPTX/PDF 导出包含全部页面。生成指导已内置，无需用户另装技能或配置额外工具服务器。复杂视觉创作、素材搜索及整稿图片打包属于后续增强范围。

完整规划见 [对话文档生成 PPT 任务方案](../design/对话文档生成PPT任务方案.md)。
