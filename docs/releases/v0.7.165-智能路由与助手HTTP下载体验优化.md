# v0.7.165 智能路由与助手 HTTP 下载体验优化

日期：2026-11-16。启用源码版本 v0.7.165，归档 v0.7.164 之后完成的路由能力误判、SVG、超时诊断及独立助手 HTTP 和下载入口改动。已发布的早期功能记录、验证批次和构建制品保留各自真实版本。

## 对话路由与 SVG

- 移除聊天及 OpenAI 兼容接口按实时检索、图片、视频或语音关键词提前结束回复的固定检查。语义判断使用用户本轮实际文字及交付要求；附件正文、文件名、引用和代码是资料，不自动转为操作授权。
- 分析、翻译、解释或编写提示词继续按文字目标回答；确实要求执行时才检查所需工具。部分能力缺失应说明具体限制并完成其余可做内容，不虚构实时事实、执行或交付结果。
- 明确 SVG 可由文本模型直接编写。聊天展示输出完整 `svg` 代码块，沿用预览和代码文件下载；明确要求独立下载文件时使用 `viz.render` 与现有 `diagram.render_svg`。路由、聊天、OpenAI 兼容接口及默认任务规划共享指引，修正过宽的“不要用代码画图”规则。
- 用户另行要求的媒体生成仍需实际工具，真实数据仍须有来源；SVG 脚本、事件和外部资源等安全校验保留。管理员已发布的自定义规划核心不会被源码更新覆盖，应按现有治理流程同步相关 SVG 指引。

## 超时处理与诊断

- 可选上下文、专用模型查询和经验读取为有效判断收尾预留时间，不再因可选读取卡住而将已验证判断转为超时。令牌用量先进入统一计量队列，路由不等待非计费的供应方校准审计；带运行预算的 Agent 仍等待原有完整记账及预算核验。
- 增加 `PIVOT_CHAT_INTENT_MODEL_ID`，默认 `0` 沿用当前模型；可指定当前账号有权访问、凭据有效且输入窗口足够的低延迟模型专门理解意图。不可用或窗口不足时沿用当前模型，不裁剪授权上下文来迁就窗口；按实际调用模型检查日额度和计量，回答及任务执行模型仍用用户选择。
- 总时限 `PIVOT_CHAT_INTENT_TIMEOUT_MS` 默认仍为 `30000`，包含上下文、排队与上游调用，可设范围 `1000`–`120000`。本版本没有提高并发或将总时限自动延长。用户取消、超时及迟到结果隔离继续生效，失败后不启动未确认操作。
- 结构化诊断保留失败阶段、模型排队、上游响应等数值耗时；系统监控“24小时决策错误明细”显示已记录的阶段及排队/上游时间。仅记录白名单诊断元数据，旧记录缺失信息不补造。意图策略版本为 `chat-intent-v8`，默认规划核心为 `planner-core-v3`。

## 独立助手远程 HTTP 与下载

- 远程 HTTP 配对在发送配对信息前弹出原生确认，显示完整服务 Origin 和明文传输说明，默认取消。取消保留原连接，确认仅随当前连接加密保存，恢复须匹配原地址；不跟随重定向或静默从 HTTPS 降级。
- 持续显示“HTTP 明文直连”，不增加主界面高度。账号与浏览器绑定、设备签名、一次性挑战、应用窗口校验和逐次本机确认保留。HTTP 仍不具备 TLS 的传输保护，不能把签名和本机确认视为链路加密。
- 每台需要被操作的 Windows 电脑安装一次助手，同机换账号重新配对和授权；仅使用聊天或服务器功能的用户无需安装。助手由用户电脑执行，本服务端不代替用户电脑。
- “工具库 → 本机授权中心”顶部增加下载、版本和安装说明；登录页“下载客户端与本机助手”窗口区分完整客户端和助手。未发布、缺包或清单无效时不提供失效链接，开发包显示“开发验证版（未签名）”。
- 新增 `npm run publish:local-helper`，从独立构建记录校验安装包并发布至持久化 `downloads/local-helper/`，同名不同内容拒绝覆盖。该目录与清单不随主镜像或 Git 自动交付，不混用完整客户端的 `latest.yml`，也不新增自动升级机制。

5. 完整 Pivot 桌面客户端无需为远程页面或独立助手改动重新打包；PPT Master 独立服务无需因本版本更新。需要构建与源码版本一致的后续助手时，使用原构建和签名流程重新生成，再按实际版本发布。
