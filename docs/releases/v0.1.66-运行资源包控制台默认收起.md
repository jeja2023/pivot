# v0.1.66 发布记录：运行资源包控制台默认收起

发布日期：2026-09-01

## 决策

运行资源包目前可以从内网地址下载、验证 SHA-256 并缓存，但尚未绑定到 Chromium、Python 或数据引擎的实际启用、版本切换和回滚。因此它暂不构成可用的日常业务能力。

为避免增加普通用户和管理员的操作复杂度，控制台默认收起，不建议使用或手工同步资源包。

## 变更

- Agent“能力与治理”不再显示“运行资源包”标签，也不会在进入页面时加载资源包列表。
- `GET /api/agents/runtime-packs` 与同步接口在默认状态下拒绝访问。
- 下载、内网来源白名单、大小限制和 SHA-256 校验逻辑保留，未来可用作离线运行依赖更新中心的安全基础。

## 内部临时开放

仅在内部排障或试验时，在部署环境设置：

```dotenv
PIVOT_RUNTIME_PACKS_CONSOLE_ENABLED=true
```

并以系统最高管理员身份登录，控制台才会显示。该开关不等于启用新的浏览器、Python 或数据引擎版本；在真正实现“安装后启用、切换、健康检查、回滚”前，不应把它用于生产更新。

## 验证

- Harness 管理入口契约覆盖默认隐藏和系统最高管理员开关。
- `npm run check`、`npm run lint` 通过。
