# v0.3.8 - 系统公告全局居中与历史查阅升级

> **发布日期**：2026-10-16  
> **升级类型**：交互体验优化、系统通知居中展示与历史公告查阅能力  
> **兼容性**：向后兼容；无破坏性改动

## 版本概述

本版本重点针对系统公告“顶部展示不明显”、“长内容显示不完整”、“关闭后无法再次查阅历史公告”以及“弹窗关闭按钮重复”等体验问题进行了全链路产品化升级。新版公告实现了屏幕正中模态呈现、内容自适应滚动、右上角按钮精简收敛、工作台与侧边栏常驻公告中心以及历史公告随时调出复查的完整闭环。

---

## 一、系统公告全局居中与自适应排版

1. **屏幕正中模态呈现**：
   - 彻底改变原顶部贴顶狭窄小横幅（`top: 14px; left: 50%`）的形式，升级为屏幕正中自适应模态弹窗（`.announcement-banner-dialog`）；
   - 配备全屏毛玻璃暗色遮罩背景（`backdrop-filter: blur(4px); background: rgba(15, 23, 42, 0.45);`），使重要通知在工作界面中更聚焦、更清晰。
2. **长文本内容完整展示与平滑滚动**：
   - 彻底消除旧版写死 40px 高度限制与单行截断，支持正文长文本自适应纵向平滑滚动（`max-height: min(48vh, 380px); overflow-y: auto; white-space: pre-wrap;`）；
   - 完整保留多段落换行、序号标号与格式排版，确保复杂公告通告阅读顺畅。
3. **视觉层级与优先级指示**：
   - 弹窗顶部配备对应优先级彩色指示条（普通科技蓝 / 重要暖琥珀 / 紧急警示红）；
   - 配备类型微徽章（系统/维护/安全/功能等）与格式化发布时间；
   - 根除旧版双层弹窗重叠冲突与遮挡问题。

---

## 二、公告弹窗按钮精简与操作收敛

1. **去除右上角冗余关闭按钮**：
   - 彻底移除弹窗右上角重复的 `×` 关闭按钮，消除与右下角“关闭”按钮的认知困惑与视觉繁杂；
   - 弹窗头部仅保留类型标签与发布时间，整体视觉更为纯粹规整。
2. **规范化底部操作与遮罩交互**：
   - 手动查阅详情时，底部提供明确的“关闭”按钮（若公告有强确认要求则展示“我已知晓并确认”）；
   - 新发布自动弹窗时，底部规范提供“不再提示”与“我知道了”（或“我已知晓并确认”强确认）；
   - 支持点击背景毛玻璃遮罩快捷退出弹窗，操作自然流畅。

---

## 三、常驻公告中心与历史公告二次查阅

1. **常驻入口与未读红点**：
   - 在个人工作台顶部操作区（搜索框左侧）与对话侧边栏均配备常驻“公告中心”入口；
   - 实时呈现未读徽标红点，确保用户不会错过任何系统动态。
2. **多维分类 Tabs 与快速标读**：
   - 公告中心面板支持“全部 / 未读 / 历史已读”分类 Tabs 过滤；
   - 顶部提供“全部已读”快捷操作按钮，方便用户一键整理通知。
3. **后端历史接口与全生命周期检索**：
   - 后端新增 `/api/announcements/history` 接口，并在 `/active` 接口中支持 `includeDismissed=true` 参数；
   - 允许用户在关闭或确认公告后，依然能够检索包含已关闭在内的历史全量公告。
4. **详情随时重新唤出**：
   - 历史列表中卡片具备明确的已读/未读状态与优先级边框；
   - 用户点击卡片或点击“查看详情”按钮，即可随时在屏幕正中重新唤出完整大字号公告弹窗，实现公告历史的永久可追溯与随时复查。

3. **工程质量保障**：
   - 全量通过 ESLint、开发规范门禁（`check:standards:changed`）、文本完整性门禁（`check:text`）及死导出门禁检查。
