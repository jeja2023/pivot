# v0.7.143 数据分析至汇报 PPT 与任务交付体验升级

日期：2026-11-09。当前为源码工作区交付，未提交、部署或构建安装包。

## 用户可见变化

- 在“数据分析 → 图表生成”完成图表后，可点击“生成汇报 PPT”。服务端读取当前账号的固定图表快照，创建并打开已保存的可编辑汇报：封面、结论与统计范围、原生图表、全部展示数据的分页明细。可以继续编辑、刷新恢复并下载 PPTX。
- Agent 可通过 `presentation.from_analysis` 使用同一转换链，复用现有版式检查、PPTX 内容核验和结果文件挂载。转换不额外调用生成模型，不自动写入本机；真实模型是否能准确选用该工具尚须单独评测。
- 重试相同创建请求会复用已创建文稿；重命名后的文稿仍可从原请求重新打开。等待重复请求时释放数据库连接，并保留有限等待和取消。
- 对话任务优先展示核验缺口与结果文件。业务信息缺失、核验超时/不可用和交付缺口分别表达；部分完成、取消及缺少核验不能显示为完整核验成功。
- 数据库连接暂不可用时，认证层和刷新入口返回503，浏览器保留Cookie与当前会话，服务恢复后可重试。真正无效、过期或重放的刷新令牌继续返回401并撤销会话；接口故障不再被当成凭证失效。

## 数据与兼容边界

快照保留数据集和来源版本、生成时间、统计口径、排序、分类上限、导入截断与范围未知说明。源数据行数与当前展示分类分开表达，不将类别排序描述成时间趋势。无效值不转换为零，图表不再额外截断到六位小数；舍入的文字摘要标记近似值。源稿、历史版本、投屏与下载读取会复核当前数据和字段权限；数据变化时要求重新生成，保存不能移除原来源绑定。已下载文件不在服务端撤权的控制范围内。

当前接入标准数据集图表：柱形、折线、面积、饼图；最多80个分类、11个数值序列，饼图仅一个序列、最多20个分类。长图表按每页20个分类、明细按每页8行完整分页。旧图表缺少来源版本时需重新生成；复杂图类型和正式 BI 模型运行结果尚未接入此快捷入口，不做静默转换。生成内容以图表描述和统计范围为主，不推断业务原因或未来走势。

修复了当前 PPT 导出库要求字符串讲稿、旧调用却传数组的兼容问题，避免多行备注触发真实 PPTX 内容核验失败。普通文稿、现有导出格式和备注开关保留。
