# v0.7.94 基础能力可靠性与分析准确性优化

日期：2026-11-05。开发基线为 v0.7.93 / `c7d44364`。

本次围绕已有功能的保存、恢复、统计、权限、运行状态与资源管理展开，沿用现有数据分析、任务、文件和草稿机制。

## 使用变化

### 编辑与恢复

- PPT 返回文稿库或切换文稿时等待在途保存，再保存期间新增的修改。保存失败停留编辑器，内容保持可见；点击保存状态可重试，恢复网络后重试未冲突的修改。
- 协作者版本冲突会明确提示，保留本地正文；主动同步仍需用户决定是否放弃本地修改。关闭有未确认修改或在途保存的页面时给出提示。
- 工作流草稿只查当前账号的本机记录，不回退搜索其他账号。账号切换后，旧保存响应和恢复按钮不再作用于新账号。
- 思维导图本机草稿遇到数据库被旧窗口阻塞、事务中止或版本升级，会提示手动保存、导出或重新打开，避免无限等待。

### 数据分析

- 画像、SQL 数值物化、图表、透视、指标、计算字段、物化聚合和跨表汇总使用相同的数值转换：例如 `￥1,200.50` 为 `1200.5`，`25%` 为 `0.25`；空值、无效文本、NaN 和 Infinity 不计为有效数值。原始数据不重写，编号等字段仍可保留原始文本。
- 新计算字段可继续引用已有计算字段。空查询也保留查询实际输出的字段名。
- 切换数据集、模型或仪表盘后，迟到的旧请求不覆盖当前选择；清空页签、关闭预览后也不会重新显示旧结果。
- 切换数据集立即清空旧查询和透视表格。总览工具栏在同一页签保持稳定，避免初始化刷新替换已选择的上传控件；普通导入和增量导入的客户端期限为五分钟。
- 后台查询在页面可见且处于查询页时继续轮询，一次请求结束后才安排下一次；离开、隐藏或切换数据集时停止相关轮询。
- 已有跨数据集模型支持修改信息、删除模型、编辑和删除关联；关系删除会校验剩余图结构，有下游依赖时先调整依赖。保存冲突时拒绝覆盖并保留输入。
- 关联检查显示匹配率、左右重复键数量及关联后行数。基数不符、未匹配、一对多扩行会明确提示；跨表汇总继续按关联后的记录计算，须核对业务口径。
- 模型边界仍为左关联/内关联、最多八条有效关系、从已有表连接新的右表，不支持环路；跨表汇总继续为一个分组字段和一个汇总值。

### 后台状态与权限

- 后台查询使用数据库执行代次及心跳，执行器中断后可重新领取过期任务。旧执行器不能覆盖新结果或把取消的任务重新放回队列。
- 查询输出严格遵守行数上限；截断标志与预览范围分别记录。任务完成和产物登记位于同一事务，失败或失去执行权时清理未登记文件。
- 后台查询与仪表盘快照核对来源版本；字段权限收紧、来源更新或撤权后，旧预览不可继续读取。仪表盘列表不携带快照正文。旧记录缺少来源版本时提示重新运行或刷新。
- 分析视图、指标、模型与仪表盘先过滤可见范围再分页，避免其他用户的大量新资产把本人资产挤出列表。
- 共享摘要过滤受限字段画像；所有字段均不可访问时明确拒绝查询和导出，不回退读取全列。分区字段值和物化结果也检查当前字段权限；来源版本变化后的物化预览提示重新刷新。
- 仪表盘刷新和计划记录区分成功、部分完成和失败，不把逐项失败记为整次成功。

### 文件与运行资源

- Excel 导入线程有五分钟默认期限，失败或取消时等待线程退出后再清理，避免继续写入已经回收的目录。
- 上传文件孤儿对账在引用查询失败时保留文件。删除前再次查询引用、检查实际目录和文件身份，跳过目录链接及已变化文件；扫描游标保证后面的文件可以被逐批检查。
- qpdf 操作返回前复核租约连接，失效后不发布成功结果并保留目录供受控巡检；浏览器失去执行权后保留失效状态，阻止旧会话重新执行。
- HTTP 指标、看门狗和交付观察共用响应结束监听；SSE 停止时取消背压等待并释放监听。替换数据分析图表时释放旧实例。

## 数据库与兼容

新增幂等迁移 `202611050001_analysis_query_reliability`：为 `analysis_query_jobs` 增加来源版本、结果行数和截断标记，并补充执行中任务的过期查询索引。

- 不重写源数据集或已有业务文档，不新增项目依赖。
- 旧查询任务的来源版本默认为零；旧结果需要重新创建查询后查看。旧仪表盘快照由所有者刷新以补齐来源版本。
- 接口保留原模型和关系创建路径；新客户端带上版本条件。更新后应刷新浏览器，桌面客户端需使用重新构建的版本。
- 模型删除为软删除，源数据集保留；关联删除只删除配置。使用恢复备份前仍应核对应用和数据库版本。
