# Pivot v0.7.176 发布说明

2026-11-18 · PPT Master 逐页核验与修复

## 逐页核验与重做

- 交付核验按 PPTX 实际放映顺序报告全部未通过页面，列出应有的标题、关键数据、图表值及已有来源引用。已成功导出的待核验草稿仍可按权限下载。
- 有源页映射的任务可以勾选未通过的页面，填写修改意见并选择“仅修复所选页面”。修复绑定草稿摘要，只允许写入选中的源稿。新导出会检查未选页及其依赖资源，并按原批准清单复核整份 PPTX。
- “重新生成整份”在确认后使用原设置与仍可读取的授权材料创建新任务，独立计算用量。新任务可返回查看原任务和仍在保留期内的草稿。[使用帮助](../../使用帮助.md#31-ppt-制作)

## 升级

源码版本为 v0.7.176，独立镜像为 `ppt-master:6.8.0`，服务协议为 1。无新增数据库迁移、第三方依赖或必填配置。

按页修复同时依赖新版主应用和支持 `pageRepair: 1` 的独立镜像。已有检查点绑定原引擎身份，换镜像前先处理在途和待恢复任务，并保留数据卷。带页数错误、缺失源页映射或使用旧引擎的任务，应根据现有入口续跑、保存草稿或用原资料重新生成。[独立服务更新说明](../deployment/PPTMaster独立服务部署与更新.md)
