# v0.1.70 发布记录：管理后台全局参数页面布局紧凑化与按钮交互规范化

发布日期：2026-09-01

## 概述

本次发布对系统设置管理后台「全局参数」页面进行了全方位的布局排版优化与按钮交互规范化，修复了专属样式未接入导致的退化与右侧留白问题，并严格对齐管理后台通用的设计标准。

## 核心优化

### 1. 样式入口修复与加载链路打通
- 在 `client/chat/chat.css` 中正式引入 `client/chat/styles/admin/admin-global-params.css`。
- 彻底解决管理后台在对话主视图中未加载专属样式、卡片退化为 760px 单列且右侧大面积留白的问题。

### 2. 页面标题结构标准化
- 移除自定义独立毛玻璃外框与大图标，恢复管理后台通用的 `.settings-page-head` 标准标题结构。
- 标题文字、说明文案及右侧「就绪状态 / 刷新 / 保存参数」操作组与「模型配置」、「工具策略」、「公告管理」等其他页面严格对齐一致。

### 3. 页面布局深度紧凑化
- **卡片网格间距**：网格间距收敛为 10px，卡片内边距调整为 `10px 12px`。
- **图标与头部高度**：卡片图标盒缩小为 `26px x 26px`，卡片标题与说明文案行高更加紧凑。
- **表单控件与度量**：输入框高度统一至 28px，字段间距调整为 5-6px，信息密度适中、视觉平衡舒展。
- **响应式排版**：宽屏 3 列、中屏 2 列、移动端 1 列自适应布局。

### 4. 专属按钮交互与颜色规范化
- **「生成并启用新密钥」按钮**：统一使用平台标准的翡翠绿主操作样式（`#10b981 / #059669`）。
- **「加密保存并启用」按钮**：移除黑色配色，调整为规范的白色次级操作按钮（`#ffffff` 底色，`#cbd5e1` 边框，悬浮微灰高亮）。

- 全量自动化测试套件通过（777 项测试无回退）。
- 浏览器端已完成桌面视口、响应式与明暗主题视觉回归。
