# v0.1.175 发布记录：AI 页面 JSON 兼容解析与自动修复重试

发布日期：2026-09-24

## 问题背景

生产日志出现 `POST /api/apps/presentations/ai/slides` 返回 422，错误为“AI 返回的演示文稿 JSON 无效”。这是模型在生成页面时返回了不完全符合严格 JSON 语法的内容，失败发生在页面结构解析之前，因此表格、图表 Schema 容错尚未执行。

## 修复内容

### 本地兼容解析

- 从模型回答中提取第一个完整 JSON 对象，允许对象前后出现简短说明；
- 自动移除 Markdown JSON 代码围栏；
- 在不改变字符串语义的前提下处理尾随逗号；
- 将 JSON 字符串内的原始换行、回车、制表符等控制字符转义为合法 JSON；
- 大纲、生成页面、续写、单页改写和内容检查共用该兼容解析逻辑。

### 一次自动修复重试

- 若本地兼容解析仍无法得到对象，服务端把原始模型回答作为输入，要求同一模型只修复 JSON 语法并返回完整对象；
- 自动修复最多执行一次，避免无限重试和不可控模型消耗；
- 修复回答仍按原始页面解析、表格/图表容错、来源过滤和 PPT IR Schema 校验处理；不会新增事实、数据、来源、外部链接或素材。

### 用户反馈与审计

- 重试成功时用户继续获得正常的 AI 大纲、页面或检查结果；
- 重试失败时返回清晰中文提示，说明系统已经自动修复一次但仍无法完成，建议重新生成；
- 修复调用保留独立审计来源，便于区分初次生成和 JSON 修复调用。

## 验证记录

- 新增代码围栏、对象外说明、尾随逗号和字符串原始换行的解析回归；
- 验证大纲、页面、续写、改写和内容检查均启用 `retryMalformedJson`；
- 通过 PPT 工作台专项测试、表格/图表故障矩阵、ESLint、全量 JavaScript 语法检查、死导出门禁、文本完整性和增量开发规范检查。

## 部署说明

- 无数据库迁移、无新增环境变量；
- 远程模式必须部署 v0.1.175 服务端与静态资源并重启服务。仅刷新仍连接旧版本服务的客户端不会解决该 422；
- 离线桌面包内置服务时，需要重新打包该版本后分发。
