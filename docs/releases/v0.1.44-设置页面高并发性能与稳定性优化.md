# v0.1.44 版本发布记录

## 概述

**Pivot（智枢）v0.1.44** 重点针对系统在生产环境中长时间运行后，管理员与用户访问设置页面出现卡死、加载超时的问题进行了全链路深度排查与根因修复。本次更新消除了全表大子查询物化瓶颈、增加了服务端多级内存短缓存与并发削峰、将目录统计异步化（SWR）、补充关键复合索引，并彻底修复了前端 ResizeObserver 回流重绘死循环与后台监控定时器泄漏。

---

## 核心变更

### 1. 消除大表全量子查询物化与慢查询优化
- **双表标量子查询直接求和**：在 `/stats/ops-summary` 与 `/stats/monitor-summary` 等统计接口中，彻底移除通过 `UNION ALL` 投影全部明细行（数十万至数百万行）并在外层做 `SUM(token_count)` 的重开销子查询，改为直接跨 `messages` 与 `model_usage_events` 执行单行标量子查询快速求和；
- **消除数据库瞬时连接池枯竭**：将全表扫描和无谓的大对象物化开销降低至亚毫秒级，彻底消除由于单次重统计占满 PostgreSQL 10 个连接导致的超时崩溃。

### 2. 服务端多级短缓存与并发削峰机制
- **运维与趋势指标短缓存**：为 `/stats/ops-summary`（8 秒）、`/stats/trend`（15 秒）引入内存短缓存；在配置变动时精准失效；
- **模型端点解析缓存**：为 `summarizeModelEndpoints` 添加 30 秒缓存，避免管理员面板高频轮询时重复触发 DNS/网络异步解析延迟。

### 3. 存储目录大小统计非阻塞异步化 (SWR)
- **Stale-While-Revalidate 机制**：在 `server/services/dir-size-cache.js` 中重构目录尺寸统计逻辑，默认 TTL 延长至 5 分钟；缓存过期时优先立即返回上一轮已知尺寸，并在后台异步触发文件遍历，彻底杜绝同步 `fs.stat` 阻塞 Node.js 事件循环与 HTTP 响应。

### 4. 关键复合索引加速
- **数据库复合索引补充**：在 `server/db/schema/base.js` 中为 `messages` 和 `audit_logs` 补充高频查询索引：
  - `idx_messages_user_created` (`user_id, created_at`)
  - `idx_messages_user_deleted` (`user_id, deleted_at`)
  - `idx_audit_logs_timestamp_user` (`timestamp, user_id`)
  - `idx_audit_logs_user_timestamp` (`user_id, timestamp`)

### 5. 修复前端 ResizeObserver 回流重绘死循环
- **视口容器监听与尺寸防抖**：在 `client/chat/app-workspaces.js` 中，将 `settingsWorkspaceScaleObserver` 的观察目标由内部画板 `canvas` 改为外部视口容器 `content`，并在回调中增加尺寸变化差值（`> 1px`）防抖判断，彻底解决修改 `canvas.style` 触发无限 `requestAnimationFrame` 回流重绘、导致浏览器主线程跑满卡死的问题。

### 6. 前端监控定时器生命周期与后台泄漏治理
- **定时器清理与可见性校验**：在 `client/chat/stats-monitor.js` 中提供 `clearMonitorRefreshTimer` 方法（通过 `Pivot.exposeModule` 注册），并在 `client/chat/admin.js` 关闭设置弹窗或切换至其他非监控标签页时及时销毁定时器；在定时器触发前增加工作区及标签页可见性双重校验，杜绝后台隐蔽轮询与请求堆叠。

### 7. 前端空指针安全防护
- **用户信息可选链防护**：在 `client/chat/models.js` 与 `client/chat/users.js` 中为当前用户对象访问补充 `currentUser?.id` 可选链防护。

## 涉及主要文件

- `server/routes/admin-stats.js`：轻量 Token 标量子查询、ops-summary / trend 内存短缓存与模型端点解析缓存；
- `server/services/dir-size-cache.js`：SWR 异步后台遍历机制与缓存延展；
- `server/db/schema/base.js`：补充消息表与审计日志表复合索引；
- `client/chat/app-workspaces.js`：设置画板缩放 ResizeObserver 目标修正与防抖；
- `client/chat/stats-monitor.js`：监控定时器清理接口与可见性防护；
- `client/chat/admin.js`：切换标签页及关闭弹窗时的定时器主动清理；
- `client/chat/models.js` & `client/chat/users.js`：用户对象可选链防护。
