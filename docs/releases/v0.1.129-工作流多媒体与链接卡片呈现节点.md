# Pivot v0.1.129 发布记录：工作流多媒体与链接卡片呈现节点

## 版本概览

- **版本号**：v0.1.129
- **发布日期**：2026-09-10
- **核心定位**：在“嵌入页面”之外补齐工作流结果呈现节点，让工作流可以直接交付图片、视频、音频和安全链接卡片。

## 新增节点

### 嵌入图片

节点标识：`workflow.embed_image`

- 支持同源路径或 HTTP/HTTPS 图片地址；
- 支持替代文本；
- 支持最大宽度和最大高度限制，避免大图撑破结果面板；
- 使用懒加载和等比展示。

### 嵌入视频

节点标识：`workflow.embed_video`

- 支持同源路径或 HTTP/HTTPS 视频地址；
- 支持标题和播放器高度；
- 使用原生视频控件；
- 默认不自动播放，避免任务结果打开后产生意外声音或流量消耗。

### 嵌入音频

节点标识：`workflow.embed_audio`

- 支持同源路径或 HTTP/HTTPS 音频地址；
- 支持音频标题；
- 使用原生音频控件并默认不自动播放。

### 链接卡片

节点标识：`workflow.link_card`

- 支持标题、说明和目标地址；
- 结果以卡片形式展示；
- 使用 `noopener noreferrer` 在新窗口打开，不改变当前工作流页面。

## 与嵌入页面节点的关系

本版本与 v0.1.128 的“嵌入页面”节点共同组成“呈现与交付”节点组：

| 节点 | 适用场景 |
| --- | --- |
| 嵌入页面 | 展示同源工作台或受信页面 |
| 嵌入图片 | 展示图像、截图、生成图片或附件预览 |
| 嵌入视频 | 展示培训视频、演示视频或处理结果视频 |
| 嵌入音频 | 展示语音转写对应的音频或播报结果 |
| 链接卡片 | 引导用户打开外部系统、报告或下载页面 |

## 安全与兼容

- 所有地址统一拒绝 `javascript:`、`data:`、`file:` 和协议相对地址；
- 地址包含用户名或密码时拒绝执行，避免凭据进入页面资源地址；
- 服务端仅生成结构化呈现描述，不主动抓取图片、视频、音频或链接内容；
- 图片和媒体资源加入 CSP 的 `img-src` / `media-src` 白名单，页面仍可能受目标站点自身跨域、资源权限或防盗链策略影响；
- 视频和音频不自动播放，链接卡片始终新窗口打开。
