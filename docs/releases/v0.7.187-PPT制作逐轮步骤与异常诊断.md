# Pivot v0.7.187 发布说明

2026-11-20 · PPT Master 逐轮步骤与异常诊断

本版完善 PPT Master「完整制作过程」和「每轮模型用量明细」的过程可见性，解决每轮每步只显示令牌数、无法看出执行工作和出错原因的问题。本版在 [v0.7.186](v0.7.186-PPT制作链路与过程回顾.md) 基础上仅更新 Pivot 主应用。后续界面优化见 [v0.7.188](v0.7.188-PPT制作过程弹窗优化与管理员记录默认视图.md)。

## 主要变更

| 范围 | 当前行为 |
| --- | --- |
| 服务端逐轮工作与异常采集 | 在 `observations.js` 新增脱敏动作摘要与轮次诊断（`summarizeTurnAction`、`summarizeExecutedTurn`、`recordTurnDiagnostic`、`usageDiagnosticsView`）。在 `driver.js` 中实时记录模型输出校验重试、引文核对重试（含待核对项数与首项页码位置）、阶段确认（方向/最终清单页数/模板）、动作批次执行、工具失败（退出码/错误码及同批未执行项数）、重复读取停滞及交付回读转自动修页。 |
| 历史检查点自动回填 | `tasks.js` 输出 `usageDiagnostics` 时，对升级前已保存、未含 `turnSummary` 的旧检查点，自动按步骤从 `state.messages` 回填当轮执行动作、同步骤重试及异常状态，无需重跑即可排查历史任务。 |
| 脱敏与边界保护 | 仅展示受控的标准相对路径、白名单工具子命令、分页偏移、退出码和标准错误代码；不展示自定义项目根目录名、文档正文或工具原始堆栈。 |
| 前端过程面板与明细弹窗 | 「每轮模型用量明细」每轮卡片新增状态徽标（已写入推进、读取与检查、提交确认、动作修正重试、工具未通过、重复无进展、自动修页、导出交付、执行异常）、**本轮工作**行与**异常诊断**行。「完整制作过程」主面板同步展示**本步工作**与**轮次异常记录**摘要。 |

## 升级与兼容

- 本版只需更新 Pivot 主应用镜像或服务进程，无需重建 `ppt-master:6.10.0-pivot0.7.186`（或兼容的 v6.10.0）独立执行镜像，也无需执行数据库迁移。
- 已有生产检查点和历史失败记录在主应用更新后即可直接打开「完整制作过程」和「每轮模型用量明细」查看逐轮工作和异常诊断。[部署说明](../deployment/PPTMaster独立服务部署与更新.md#v07187-逐轮步骤与异常诊断) · [用户操作](../../使用帮助.md)
