# v0.1.168 发布记录：PPT 制作应用产品级验收收口与导出治理增强

发布日期：2026-09-23

版本号：v0.1.168

## 发布结论

本版本完成 PPT 制作应用在文稿库筛选、AI 创建参数、页面高级编辑、质量治理和导出可配置性方面的验收收口。演示文稿继续以受控 PPT IR 为唯一事实源，所有素材、渲染和下载仍沿用 Artifact → CAS → Rendition → Delivery 链路。

## 用户可用能力

- 文稿库可按标题/正文、模板、状态、创建者、更新时间、标签和收藏组合筛选。
- AI 创建可明确时长、语言、图表需求、来源保留、必含内容和禁止内容；系统仍只将材料作为事实来源。
- 编辑器支持多选、复制粘贴、组合、对齐与分布，表格行列增删，图片替换与裁剪位置调整。
- 质量检查覆盖文本溢出、占位符、对比度、遮挡、敏感信息、字体回退、图片清晰度、来源引用与数据来源。
- 导出可选择 16:9/4:3、备注、页码、来源标记、PNG 质量和字体策略；4:3 PPTX 已使用 LAYOUT_4x3 生成。

## 数据库升级

新增迁移 202609230003_presentation_quality_metadata：

- presentation_assets 新增 pixel_width、pixel_height；
- 新增按租户和更新时间的文稿索引；
- 既有素材不会暴露对象存储路径，尺寸仅用于质量检查与界面提示。

## 验证记录

- 所有本次变更的 JavaScript 已完成语法解析；
- 浏览器实测新筛选、AI 创建字段、高级编辑工具和导出选项均可加载，未发现控制台错误；
- 内存渲染验证通过：16:9/4:3 的 PPTX、PDF、PNG 均生成有效文件头；
- PPTX 备注开关、来源标记、字体回退及高质量 PNG 均已验证；
- 新增质量规则可识别来源、字体、图片分辨率和数据来源问题。

## 升级步骤

1. 按既有流程备份 PostgreSQL 数据库。
2. 部署 v0.1.168 代码并重启 Pivot 服务，使迁移与运行时版本生效。
3. 打开 PPT 制作应用，确认底部版本提示为 v0.1.168。
4. 在安装 PowerPoint、WPS 或 LibreOffice 的目标机执行 npm run verify:presentation:office，并按脚本指引完成真实打开、编辑、保存、重开验收。

## 固定边界

- 不执行 VBA、宏、ActiveX 或任何 Office 二进制对象。
- 不承诺复杂第三方 PPTX 的母版、SmartArt、嵌入对象、动画时间轴或媒体逐字节无损还原。
- 未安装 Office 客户端时，只能完成 OOXML 与受控渲染验证，不能将真实 Office 兼容性记作通过。
