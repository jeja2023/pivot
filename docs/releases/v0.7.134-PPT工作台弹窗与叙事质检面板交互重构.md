# v0.7.134：PPT工作台弹窗与叙事质检面板交互重构

日期：2026-11-08。

本版本针对 PPT 制作全链路的弹窗体验、应用中心入口布局、质检与叙事结构面板交互完成全面规范化重构：

### 1. 应用中心与文稿库操作入口收敛

- **应用可用性开关**：应用中心应用卡片的可用性控制升级为现代药丸滑块（Switch）置于卡片顶部右上角，移除繁琐的“全局可见”文字说明，与系统其他设置开关交互保持一致。
- **制作顶部操作合并**：原先散落在顶部过多的“使用单位模板”、“沿用原稿设计”、“模板库”、“原稿编辑与离线视频”等平铺按钮，收敛合并为“模板库”与“更多方式”两组下拉菜单，主界面聚焦于“AI 自由设计”核心主流程与“从 Agent 产物创建”、“空白创建”等辅助入口。

### 2. 弹窗布局规范统一与视口自适应

- **AI 自由设计弹窗自适应**：调整弹窗视口尺寸（`width: min(860px, 94vw)`，`max-height: min(88vh, 800px)`）与表单间距，彻底消除默认垂直滚动条；“阅读方式”（现场演示 / 阅读材料）按规范从创建弹窗隐藏（采用标准推荐行为），仅在侧栏高级结构面板中按需保留。
- **从 Agent 产物创建弹窗**：重构表单网格间距，移除右上角与底部“取消”功能重复的多余关闭按钮，聚焦于来源产物选择与模板匹配。
- **弹窗关闭按钮全局统一**：“浏览全部模板库 / 使用单位模板”、“原稿编辑与离线视频”及“沿用原稿设计”弹窗右上角的关闭按钮统一采用红字红框全局标准样式（`.btn-secondary.workspace-modal-close`），保持全站视觉语言统一。

### 3. 质量与合规检查面板优化

- **解决按钮折行与视觉层级**：将原先挤压在标题行右侧导致严重折行（“立即体/检”、“交付检/查”）的按钮独立下沉为双列专区操作栏（`.presentation-issues-actions`）。“立即体检”升级为主操作翡翠绿盾牌按钮，“交付检查”升级为精致白底卡片次操作按钮，配备专属矢量图标与悬浮微动效，严格保证不折行。
- **消除空容器幽灵虚线框**：修复任务状态容器 `<div id="presentation-production-task-status">` 空内容时残留的绿色虚线框，增加 `:empty { display: none !important; }`，并将质检空状态从 26px padding 的粗糙大框精简为紧凑信息条。
- **标题行空间释放**：“质量与合规检查”标题与副标题独占首行完整宽度，阅读舒适不拥挤。

### 4. 逐页叙事结构面板深度重构

- **流转指示胶囊栏**：将原先大面积绿色虚线框 `上一页：...；下一页：...` 改造为一体化紧凑流转指示胶囊栏（`[上页: 开篇] ➔ [当前 P1] ➔ [下页: 业务进展]`），直观展示当前页在整篇文稿叙事脉络中的承接定位。
- **模块卡片化与 2 列紧凑网格**：
  - **整稿目标折叠卡**：折叠头集成靶心图标与受众/模式胶囊，展开时显示受控表单，合拢时保持轻量。
  - **本页叙事定位卡**：“本页职责”与“本页核心结论”优化输入框字号与提示文案；“故事线阶段”与“信息关系”、“与下页衔接”与“讲解时长”均改为双列并排（`presentation-story-grid-2`），纵向滚动高度压缩超 45%。
  - **AI 故事线调整卡**：采用微渐变科技感底色卡片，范围与模型双列并排，搭配醒目的“按故事线调整”主按钮。
  - **全稿叙事脉络列表**：列表项集成 `P1/P2...` 页码徽章与叙事阶段分类彩色轻胶囊，激活页高亮显示。
- **深色模式适配**：完整支持暗色主题下的卡片背景、输入框轮廓、文字对比度与标签颜色。

验证范围：自动化资产校验、开发规范门禁、安全 HTML 检查及 46 项 Node 单元与集成测试全部通过。当前改动未部署生产，未构建安装包。
