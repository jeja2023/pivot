- **版本号**：v0.1.122
- **发布日期**：2026-09-10
- **核心定位**：CI / 运行时自动注入环境变量白名单登记，打通 `check:env-example` 与全量静态代码门禁。

---

## 变更背景与根因分析

在 v0.1.121 引入 `isHeadlessEnvironment()` 以适配 CI 无头浏览器环境后，CI 中的代码质量门禁步骤（`npm run check:env-example` / `scripts/check_env_example.js`）触发报错：
```
环境变量模板检查失败：4 个 server/desktop 变量未声明。
 - CI
 - DISPLAY
 - HEADLESS
 - WAYLAND_DISPLAY
```

### 根本原因

`scripts/check_env_example.js` 会扫描 `server/` 与 `desktop/` 下所有 `process.env.[A-Z0-9_]+` 变量，并要求这些变量必须在 `.env.example` 中声明，或者登记在 `scripts/env_example_ignored.json`（运行时/系统自动注入环境变量白名单）中。
`CI`、`DISPLAY`、`HEADLESS` 与 `WAYLAND_DISPLAY` 属于 CI 流水线、操作系统窗口管理会话或临时测试开关，不属于用户在 `.env` 中填写的业务配置参数，因此需要依法登记到 `env_example_ignored.json`。

---

## 核心改进

1. **运行时环境变量白名单登记**（`scripts/env_example_ignored.json`）：
   - 登记 `CI`：CI/CD 流水线自动注入的环境变量，用于运行环境识别。
   - 登记 `DISPLAY`：Linux X11 显示服务环境变量，由系统或桌面会话自动注入。
   - 登记 `HEADLESS`：自动化测试或无头运行模式开关，非持久业务配置。
   - 登记 `WAYLAND_DISPLAY`：Linux Wayland 显示服务环境变量，由系统或桌面会话自动注入。
2. **全门禁校验打通**：
   - `scripts/check_env_example.js` 检查通过（293 个模板声明，11 个运行时自动变量已登记）。
   - `npm run check` 包含 22 项全量门禁测试一次性通过。
