# v0.1.178 发布记录：外部 PPTX 模板导入与复用产品化

发布日期：2026-09-25

## 发布摘要

本版本将原有“受限主题提取”升级为可审核、可版本化、可复用的外部 PPTX 模板能力。管理员能够预检已有 PPTX，查看转换后的母版、布局、槽位、素材和兼容性报告；审核发布后，用户可将模板用于空白创建、AI 生成、材料转 PPT、重新套版和新增页面。

目标不是承诺任意第三方 PowerPoint 文件无损往返编辑。系统只转换经过受控映射的主题、母版、布局、素材和常见动画；无法安全表达的对象会明确显示在兼容性报告中，并按“可编辑”或“外观优先”策略处理。

## 主要变更

### PPTX 解析与安全

- 使用结构化 XML 和 OOXML `_rels` 关系文件解析 `presentation → master → layout → theme/media`，支持多母版、多布局、主题颜色、字体、页面比例、占位符几何和背景/装饰素材；
- 修复主题色读取缺陷，颜色不再因正则转义问题落入 Pivot 默认值；
- 限制上传体积、ZIP 条目数、解压体积、压缩比与 XML 大小，拒绝路径穿越、重复路径、DTD/实体和非法外部关系；
- 外部 URL 不会被下载。宏、ActiveX、嵌入对象、媒体、Office 原生图表及不可映射对象仅生成兼容性报告，不会在服务器或浏览器执行；
- PPTX 解析运行于受限 Worker：Worker 不持有数据库或网络访问能力，设置内存上限与 30 秒超时。

### 模板模型与治理

- 模板定义升级为 v2，新增母版、布局、占位符、装饰层、默认转场、槽位动画、受控素材引用和导入报告；旧版 Pivot 模板包仍可读取；
- 新增 `presentation_template_versions`，模板更新、重新解析或下架不会改变历史文稿绑定的模板版本；
- 原始 PPTX/模板 JSON 存入 CAS，模板版本记录来源对象、导入模式和兼容性报告。管理员可下载来源文件或基于来源重新解析为新版本；
- 导入任务持久化到 `presentation_template_import_jobs`。接口返回任务 ID，客户端轮询状态；仅排队状态可以取消，解析状态将原子完成或失败；
- 提交审核和审核通过前会检查阻断项、母版关联、受控素材访问及文本/背景对比度。

### 编辑、AI 与导出

- 模板预检会显示转换后的布局缩略预览、母版/布局/素材数量及逐项兼容性报告；
- “优先可编辑”让可转换的简单装饰保持可编辑；“优先还原外观”锁定装饰层，避免误改；
- 空白创建、材料转 PPT、AI 创建、AI 续写、AI 改写和复制文稿均携带模板 ID、版本和摘要；AI 按所选模板的布局/槽位工作，不再静默回退到内置模板；
- 新增页面与“重新套版”会应用母版背景、装饰层、文本/图片/表格/图表槽位、文本样式、默认转场和可映射入场动画；
- 浏览器预览与 PPTX 输出支持受控的 `fade`、`zoom`、`wipe`、`fly` 入场动画及常见页面转场。导出 PPTX 使用 PowerPoint 可识别的动画时间线和稳定对象名；
- 主编辑器、模板工作流、模板服务和素材服务完成职责拆分，继续通过既有 CAS、Artifact、Rendition 与 Delivery 链路交付。

## 数据库迁移

本版本新增以下迁移，应用服务启动后自动执行：

| 迁移 | 作用 |
|---|---|
| `202609250001_presentation_template_versions` | 保存不可变模板定义、版本摘要和导入报告 |
| `202609250002_presentation_template_source_metadata` | 为已存在的模板版本补齐源文件与导入参数元数据 |
| `202609250003_presentation_template_import_jobs` | 保存可轮询、可取消的模板导入任务和结果 |

## 部署说明

1. 按既有运维规范备份 PostgreSQL。
2. 部署服务端和静态资源，重启 Pivot 服务以应用三个模板相关迁移。
3. 使用管理员账号导入一份已授权的企业 PPTX，先检查缩略预览、字体替代、素材授权和兼容性报告。
4. 修复阻断项后提交审核并发布。普通用户只能使用其权限范围内已发布的模板。
5. 在目标 PowerPoint/WPS 版本中执行打开、编辑、另存、重开和 PDF 导出矩阵验证，尤其检查品牌字体、背景图、简单入场动画和转场。

## 兼容性边界

- 不支持 `.ppt`、`.potx`、`.pptm` 作为模板导入输入；
- 不执行 VBA、宏、ActiveX、OLE 或任意第三方嵌入对象；
- 不承诺 SmartArt、复杂母版、复杂动画时间轴、触发器、媒体联动和第三方 Office 对象无损转换；
- 缺失字体会保留字体替代风险提示，不能以文本字体名称替代实际授权字体文件；
- 历史文稿保留创建时模板版本，更新或下架模板仅影响后续新建/选择，不改写既有文稿。
