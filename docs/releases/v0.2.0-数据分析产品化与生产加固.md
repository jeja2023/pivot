# v0.2.0 数据分析产品化与生产加固

发布日期：2026-10-10

## 交付范围

### 数据分析工作台

- 字段治理：显示名、逻辑类型、单位、日期格式、业务定义、指标/维度角色、敏感级别与版本修订。
- 计算字段：仅接受字段占位符、数字、四则运算及白名单函数；可预览，生成派生数据集，保留来源、表达式、依赖和版本。
- 分析资产：查询、透视、图表可保存、共享、复跑；资产固定数据集版本与配置快照。
- 图表：新增散点、堆叠柱、漏斗、热力、箱线、双轴；保留原有柱状、折线、面积、饼图。
- 协作：仪表盘、多项目快照、受控共享、计划刷新与阈值告警。
- 语义层：业务指标口径（字段、聚合、单位、有效期、共享范围）与跨数据集模型关系（Join 类型、基数、键质量）。
- 规模化基础：异步查询任务提供队列、取消、超时、退避重试、受控 Parquet 结果和预览；任务不改变同步查询的安全边界。

### 安全与治理

- 数据集共享只读；修改、删除、清洗、计算字段和共享设置仅限所有者。
- 对共享数据集，`confidential` / `restricted` 字段不会进入前端预览、查询临时表、图表、比对或导出。
- 所有跨数据集关联在运行前检查两个数据集和关联字段的可见性，禁止借数据模型绕过 ACL。
- 异步查询继续复用只读 SQL 校验、文件访问关键字封锁、超时与受控输出目录。

## 新配置

| 配置 | 默认值 | 说明 |
| --- | ---: | --- |
| `DATA_ANALYSIS_REFRESH_INTERVAL_MS` | 60000 | 仪表盘刷新与告警调度轮询间隔。 |
| `DATA_ANALYSIS_ASYNC_QUERY_POLL_INTERVAL_MS` | 3000 | 异步查询 Worker 领取任务间隔。 |
| `DATA_ANALYSIS_ASYNC_QUERY_MAX_ROWS` | 200000 | 单个异步查询可物化的最大结果行数。 |
| `DATA_ANALYSIS_ASYNC_QUERY_TIMEOUT_MS` | 300000 | 单个异步查询的 DuckDB 超时。 |

不要把同步导入、透视或查询上限直接抬高来处理大数据。超过当前单机工作台范围时，应使用异步查询、聚合、分区 Parquet 或专用 OLAP 服务。
