# v0.7.33 演示文稿多色卡片排版重构与离线办公增强

发布日期：2026-10-23。版本类型：功能升级、设计范式重构与架构治理。

本版本重点参考前沿 GPT/NotebookLM/Opus 实践与根目录《数智侦查项目阶段性汇报.pptx》，对 PPT 演示文稿工作台进行深度重构，打破单色死板束缚，建立权威高对比标题、中性副标、深灰正文与多功能序列卡片的现代信息架构，并完成全工作区大文件治理和离线办公增强。

版本号已在源码中启用，不表示已经提交 Git、推送版本标签、更新生产服务或重新发布客户端安装包。

## 1. 具体变更

| 范围 | 本版行为 |
| --- | --- |
| **视觉配色系统** | 告别“一个主题全盘一种纯色”：确立高对比标题（深青/深石板）、中性副标（石板灰）和护眼正文（`#344054`，行高 1.8~1.95）；卡片容器引入 6 色功能色板 (`cardPalette`)，由科技蓝、青绿、翡翠绿、暖金、数智紫、珊瑚红自动按序分配 |
| **卡片与排版自适应** | 三栏卡片（`three-card`）与双栏容器（`two-column`）卡片顶条与标题自动映射对应功能色彩；封面页（`cover`）支持主标、副标、二级说明三层纵向展开，搭配加宽徽章与底部元数据消除虚空 |
| **前台排版与对齐** | 修复 Flex 纵向对齐导致的文字中心漂移脱离左侧强调条 Bug，显式赋予 `flexDirection: column` 与精准 `alignItems`，保证无论单行或多行均与左边框稳健对齐 |
| **全格式保真渲染** | 统一 PPT IR 经 `presentation-renderer.js` 输出真实 PPTX、PDF 和 PNG 时，多色卡片强调条、圆角卡片边框、高反差总结横幅与文字样式均保持严格一致 |
| **Emoji 矢量 SVG 替代** | 演示全链路彻底剔除 Unicode Emoji（💡、🎯、✦、★、🔊、▶、📎、☑、□），构建前后端同构的 SVG 矢量图标库，支持暖金灯泡、珊瑚红靶心、闪烁星芒、收藏五星及对勾方框的高保真矢量输出，无操作系统字形割裂 |
| **版式与信息密度增强** | 吸收 GPT 汇报样例文稿设计，封面页新增 5 阶段汇报议程卡片胶囊与多色卡片条；复选清单升级为矢量方框与对勾；建议与成效模块重构为带图标呼应盒（Callout Box），全面提升版面专业度与沉浸感 |
| **架构治理与代码解耦** | 将 Smart Reflow 及布局层叠加逻辑从 `presentation-template-service.js` 独立拆至 `server/services/presentations/presentation-template-reflow.js`（缩减至 892 行）；客户端布局切换抽离至 `client/chat/apps-workbench-presentations-templates.js`（缩减至 945 行与 989 行），全部满足不超过 1000 行治理门禁 |
| **门禁与死导出清理** | 全面通过死导出门禁 (`check:dead-exports`)、文本完整性 (`check:text`)、治理指标 (`check:governance`) 与静态资产校验 |
| **Agent 工具引用恢复** | 在授权目录快照中刷新过期引用并返回完整契约，清除旧执行引用；修复内置工具 `releaseId: null` 拒绝问题与白名单误拦截 |
| **离线办公增强集成** | 交付统一中文离线朗读代理队列、公文 DOCX 精细字符修订比较、同源动态 OA 抓取与可编辑交互脑图产物 |
