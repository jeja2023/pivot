# v0.1.101 发布记录：用户管理多维检索与工程规范增强

发布日期：2026-09-09

## 版本摘要

本版本主要聚焦于用户管理模块的高可用多维检索治理、账号状态与注销逻辑规范化、前端交互与事件防重、数据库模式隔离稳定性加固，以及工程代码门禁和 CI 流水线的智能化体验提升。

## 主要变更

### 1. 用户管理多维检索与状态治理
- **多条件组合筛选工具栏**：
  - 新增用户名 / 显示名关键字模糊搜索（不区分大小写匹配 `username` 与 `nickname`）；
  - 新增所属单位模糊搜索（基于 PostgreSQL `ILIKE` 进行安全参数化匹配）；
  - 新增角色层级过滤，精准支持系统管理员（内置 admin 账号）、普通管理员（manager）与普通用户（user）；
  - 规范账号状态筛选，提供清晰的 5 档选项：`全部状态（正常）`、`启用`、`禁用`、`已删除`、`全部状态（含已删除）`。
- **状态徽标与注销用户安全治理**：
  - 采用统一的企业级自适应状态徽标，启用（绿色）、禁用（橙黄色）、已删除（红色）状态清晰易辨；
  - 针对软删除（已注销）用户，安全隐藏“编辑”与“重置密码”按钮，避免向后端发起非法修改请求；同时明确展示“已注销”占位状态，保留具备审计权限时的“记录”审计入口；
  - 列表筛选与 CSV 导出条件完全同步，确保导出数据“所见即所导”。
- **前端交互与防重加固**：
  - 彻底消除查询与重置按钮因全局静态动作与局部绑定并存导致的多重重复执行与网络竞态；
  - 下拉选择框支持切换即时联动，输入框支持 Enter 键回车查询，提供一键重置筛选表单并重载列表能力。

### 2. 数据库模式隔离与服务稳定性
- **PostgreSQL 独立 Schema 隔离加固**：
  - 优化模式版本检测机制，确保隔离环境下的迁移标记精准匹配，杜绝意外回退至 `public` 模式；
  - 增强迁移标记检查与版本化迁移自动执行保障。
- **系统维护任务独立超时**：
  - 为 `ANALYZE` 等维护任务配置独立超时时间，防止因大规模表统计信息收集耗时拖累在线业务 SQL 全局超时；
  - 控制台日志输出统一规范为东八区北京时间格式，避免时区格式解析混淆。

### 3. 前端工程化解耦与组件规范
- **模块职责清晰分离**：
  - 抽取独立的设置工作区延迟事件注册模块（`admin-settings-events.js`）与自适应缩放模块（`workspace-settings-scale.js`）；
  - 抽取独立的 MCP 工作台动作处理器（`mcp-workbench-actions.js`），优化前端模块维护性；
  - 保持样式收敛至受控的单一 `chat.bundle.css`，杜绝内联样式与裸写颜色代码，全面复用系统主题变量。

### 4. 规范门禁检查与 CI 流水线增强
- **智能 Diff 范围识别**：
  - 增量门禁检查脚本升级：PR 流水线自动寻找目标分支的 `merge-base` 作为基准范围，普通推送场景智能回退至前一次提交，消除跨分支误报；
  - 优化日志文案与代码语法误报检测，准确区分调用实参前缀与用户界面展示文案；
  - 自动化构建产物样式包智能跳过颜色检测，源码严格执行主题变量门禁。
