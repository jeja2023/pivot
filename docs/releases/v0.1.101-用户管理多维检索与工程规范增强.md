# v0.1.101 发布记录：用户管理多维检索与工程规范增强

发布日期：2026-09-09

## 版本摘要

本版本主要聚焦于用户管理模块的高可用多维检索治理、账号状态与注销逻辑规范化、前端交互与事件防重、数据库模式隔离稳定性加固，以及工程代码门禁和 CI 流水线的智能化体验提升。

## 主要变更

### 1. 用户、用量与附件多维检索治理与规范统一
- **用户管理多维组合筛选**：
  - 新增用户名 / 显示名关键字模糊搜索（不区分大小写匹配 `username` 与 `nickname`）；
  - 新增所属单位模糊搜索（基于 PostgreSQL `ILIKE` 进行安全参数化匹配）；
  - 新增角色层级过滤，精准支持系统管理员（内置 admin 账号）、普通管理员（manager）与普通用户（user）；
  - 简化筛选结构：移除前端冗余的状态下拉筛选框，精简前后端交互链路。
- **用量统计与用量明细多维查询**：
  - 用量统计支持用户（模糊）、模型（模糊）与起止日期范围筛选，并支持一键重置；
  - 用量明细支持用户、模型、调用角色（提问/回答/系统/工具/智能体/向量/API 等）与起止日期范围筛选；
  - 导出 CSV 均自动携带当前筛选参数，保持“所见即所导”。
- **附件库多维检索与权限隔离**：
  - 支持文件名模糊搜索、文件类型分类（图片/文档/压缩包/代码数据）、关联会话检索；
  - 严格限定仅系统管理员可见并使用“上传用户”筛选框，普通用户仅展示并检索个人附件，杜绝界面信息冗余与越权风险。
- **筛选栏控件与表格视觉规范全局统一**：
  - 全局统一所有筛选栏输入框、下拉框、日期框为 `32px` 紧凑标准高度、`5px 9px` 内边距与 `0.78rem` 统一字号；
  - 用户表、用量统计表、用量明细表、附件表单元格行高统一设置为 `36px`，附件操作列按钮统一样式为 `22px` 规范尺寸，彻底杜绝单元格行高被撑大或换行错位。
- **显式点击查询机制与事件委托重构**：
  - 移除输入文本与按键时的自动查询，改为严格点击“查询”按钮时才进行实际查询，杜绝输入干扰；
  - 将各页面的查询、重置及列表操作按钮统一重构为全局 `document` 级别的点击事件委托（Event Delegation），彻底解决设置工作区在懒加载（Lazy Workspace）模式下初次直接绑定丢失导致的点击无反应问题。

### 2. 数据库模式隔离与服务稳定性
- **PostgreSQL 独立 Schema 隔离加固**：
  - 优化模式版本检测机制，确保隔离环境下的迁移标记精准匹配，杜绝意外回退至 `public` 模式；
  - 增强迁移标记检查与版本化迁移自动执行保障。
- **系统维护任务独立超时**：
  - 为 `ANALYZE` 等维护任务配置独立超时时间，防止因大规模表统计信息收集耗时拖累在线业务 SQL 全局超时；
  - 控制台日志输出统一规范为东八区北京时间格式，避免时区格式解析混淆。

### 3. 前端工程化解耦与组件规范
- **模块职责清晰分离**：
  - 抽取独立的设置工作区延迟事件注册模块（`admin-settings-events.js`）与自适应缩放模块（`workspace-settings-scale.js`）；
  - 抽取独立的 MCP 工作台动作处理器（`mcp-workbench-actions.js`），优化前端模块维护性；
  - 保持样式收敛至受控的单一 `chat.bundle.css`，杜绝内联样式与裸写颜色代码，全面复用系统主题变量。

### 4. 规范门禁检查与 CI 流水线增强
- **智能 Diff 范围识别**：
  - 增量门禁检查脚本升级：PR 流水线自动寻找目标分支的 `merge-base` 作为基准范围，普通推送场景智能回退至前一次提交，消除跨分支误报；
  - 优化日志文案与代码语法误报检测，准确区分调用实参前缀与用户界面展示文案；
  - 自动化构建产物样式包智能跳过颜色检测，源码严格执行主题变量门禁。

### 5. 桌面客户端内网 HTTP 自动更新、动态推导、自动化签名与用户信息展示修复
- **放开内网 HTTP 自动更新限制**：
  - 修改 `desktop/update-policy.js`、`desktop/config.js` 与 `scripts/desktop_distribution_config.js`，彻底移除仅允许 HTTPS 更新源的硬编码限制，支持在纯内网无证书离线环境（如 `http://50.64.150.51:9006`）中正常执行客户端检查与静默升级。
- **自动更新同源动态推导机制**：
  - 更新源配置支持相对路径动态推导（`url: ""` + `path: "/downloads/"`）。客户端启动或用户在客户端修改服务器连接配置时，自动基于生效的 `remoteUrl` 计算更新地址并加入同源来源白名单，未来服务器 IP/端口变更无需重新分发客户端。
- **自动化代码签名与构建流程**：
  - 新增 `scripts/desktop_auto_sign_profile.js`，自动在 Windows 本地证书库中检测或静默创建 `CN=Pivot Local Dev` 代码签名证书，自动生成默认受控分发配置，规范绑定 Electron Builder 26 的 `win.signtoolOptions.publisherName` 签名结构，一键运行 `npm run dist:win` 即可完成完整打包。
- **标题栏控制按钮透明化**：
  - 修改 `desktop/main.js`，将 `titleBarOverlay.color` 设为透明（`rgba(0, 0, 0, 0)`），使 Windows 原生最小化/最大化/关闭按钮与登录页渐变背景及工作区自然融合。
- **用户个人信息注册时间展示修复**：
  - 修复 `server/auth.js` 在 `/api/auth/me` 与 `/api/auth/login` 响应中遗漏返回 `created_at` 字段导致所有用户注册时间均显示为“系统初始用户”的缺陷；前端在 `client/chat/personal-workbench.js` 中接入 `formatDateToCN` 规范化时间格式展示。

### 6. 第三方 API Key 有效期自定义与永久有效支持
- **后端支持多种有效期限与永久有效**：
  - 修改 `server/routes/auth.js` 的 `POST /auth/keys`，扩展接收 `expiresInDays` 参数。支持预设天数（30、90、180、365 天）、永久有效（`expiresInDays: 'never'`，`expires_at = null`）以及 1~3650 天范围内的自定义有效天数；
  - 严格校验自定义天数范围，防止非法的负数或极大数值；
  - 审计日志记录完整密钥有效期信息，响应结果返回精确的 `expires_at`。
- **前端交互与密钥列表可视化完善**：
  - 在新建密钥弹窗中增加“有效期限”选择下拉列表及“自定义有效天数”动态输入项；
  - 密钥创建成功即时呈现具体的到期时间或“永久有效”状态；
  - API 接入管理列表中新增“有效期至”数据列，依据剩余时间展示“永久有效”、“余 X 天”、“1 天内到期”预警或“已过期”状态，鼠标悬停可查看精准到秒的时间戳。
