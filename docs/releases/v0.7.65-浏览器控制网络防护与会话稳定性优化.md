# v0.7.65 浏览器控制网络防护与会话稳定性优化

发布日期：2026-10-29

## 更新内容

- 受控浏览器通过本地出站代理按授权站点和端口检查页面及后台工作线程的连接，并校验和固定解析地址；WebSocket 另行执行授权校验。安全防护无法初始化时，浏览器会话启动失败。
- 等待操作可等待目标出现、隐藏或移除，并按指定时间超时；水平滚动传入垂直位移零时不再误触发向下滚动。
- Agent 浏览器会话绑定创建任务，跨任务复用或当前任务网络策略变化时会拒绝并要求创建新会话；原有租约、写操作恢复和防重放机制继续生效。
- 桌面本机浏览器的同一隔离配置正在执行时，重复操作会提示稍后重试；完成、取消及异常时释放本机占用。
- 更新工具描述与使用帮助：默认使用页面元素定位，视觉坐标定位仅为可选扩展钩子，当前生产执行链没有接入真实视觉定位器。浏览器专项测试加入 Agent 质量门禁。

## 验证与限制

- `npm run check` 和 `npm run lint` 通过。隔离 PostgreSQL 和本机 Chromium 的浏览器专项 36 项通过；追加变更后会话专项 12 项通过。
- 本机可见 Chromium 与 Microsoft Edge 的打开、读取、点击、截图、取消确认和同一配置并发保护测试通过；页面与后台工作线程的授权及未授权 WebSocket、后台 HTTP 请求经过本机测试。
- 测试中使用本地站点和隔离数据库，部分网络测试为本地夹具启用测试例外；这些结果不能代替生产环境验收。Firefox、Linux 桌面、真实业务站点、网络隔离及故障恢复演练仍需在目标环境完成；未运行完整全量测试套件。
- 受控浏览器禁用 WebRTC，Chromium 禁用 QUIC，依赖这些能力的网站可能受到影响。代理不替代主机或容器网络隔离，具体排查参见 [运维手册](../agent-experience/operations-runbook.md)。

## 更新方式

更新服务端并重启；本机浏览器能力需使用包含相应更改的桌面客户端构建。无需新增数据库迁移、必需环境变量或第三方依赖；任务网络策略发生变化时请创建新浏览器会话。
