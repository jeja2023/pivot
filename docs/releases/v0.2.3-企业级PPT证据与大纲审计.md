# v0.2.3 企业级 PPT 证据与大纲审计

发布日期：2026-10-11

## 功能交付

本版本将 PPT 工作台的材料、大纲和后续 AI 编辑串成可审计闭环。

- **证据持久化**：用户粘贴或上传的材料在进入页面生成前，由服务端标准化为来源标识、标题、类型、定位、SHA-256 内容指纹和最多 2,400 字的受控摘录。摘录用于后续生成上下文，不保存整份上传材料到演示文稿 IR。
- **后续 AI 有据可依**：AI 改写当前页和继续生成页面会从当前文稿的来源摘录重建材料上下文。AI 内容检查同样可读取已保存的来源证据，避免初稿生成后只剩来源标题。
- **大纲确认可回放**：用户确认大纲并生成页面时，服务端将规范化大纲、确认方式、服务器确认时间、确认用户标识和大纲摘要哈希写入首个版本。后续保存保留已有记录，外部请求不能借文稿 JSON 伪造确认信息。
- **编辑器可见性**：右侧新增“证据”面板，展示已确认大纲的章节和页面数量，以及每项来源的定位、页面引用次数、内容指纹和摘录。
- **画布可读性**：默认缩放提升至 100%，并提供 110% 手动缩放。缩放下拉框会在每次渲染时同步实际画布比例。编辑区缩小上下留白，宽屏下可更充分显示页面，较小屏幕仍可通过滚动查看。
- **质量提示**：若页面引用的历史来源未保存定位、摘要或摘录，质量检查给出信息级提示，提醒补充原始材料后再作正式核验。
- **数据分析导航一致性**：修正“字段治理”“分析资产”“仪表盘”误套用操作按钮样式的问题；这些入口现与其他侧边导航项等宽、左对齐，并使用统一的交互状态。
- **数据分析标题语义**：为字段治理、分析资产和仪表盘补齐独立的顶部标题与功能说明，避免它们被错误呈现为“数据总览”。

## 兼容性

- 历史文稿无需迁移，缺少证据字段的来源仍可打开、编辑和导出。
- 模板、品牌锁定、数据图表、原生 PPTX/PDF/PNG 导出、版本恢复和协作权限保持原有行为。
- 新字段存储在结构化演示文稿 IR 与既有版本快照中，不新增业务数据库表或迁移步骤。

## 验证

- `npm run check` 通过，包括架构、迁移、索引、秘密、HTML 安全、异步数据库调用和语法等工程门禁。
- PPT 工作台、模板导入、协作和 PostgreSQL 集成专项回归共 48 项通过。
