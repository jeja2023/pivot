# v0.1.169 发布记录：精准知识检索与受控工具访问改造

发布日期：2026-09-23

## 发布摘要

本版本围绕“相关内容优先、无可靠结果不乱答、工具不乱调、目录不越权”完成对话检索、知识库、工具调用和本机文件访问链路的收口改造。

## 主要变更

### 1. 结构化任务状态

- 新增结构化任务状态对象，记录当前问题、检索 query、目标、约束、实体、证据需求、知识库范围和工具意图。
- RAG 和工具规划使用当前任务状态中的 `currentQuestion` / `retrievalQuery`，不再把完整聊天记录直接作为检索 query 或工具规划输入。
- 任务状态写入 WorldState 和上下文快照，保留 hash、审计和窗口演进信息。
- 完整聊天历史仍可用于最终回答上下文，但不会直接驱动知识库召回或工具候选发现。

### 2. 知识库精准检索

- 保留并统一元数据过滤：专题库、标签、验证状态、生命周期、来源类型、责任单位、更新时间和访问权限。
- 使用向量召回、FTS 词法召回和图谱候选进行混合融合，并通过 RRF/MMR 控制相关性和结果多样性。
- 新增确定性 rerank，综合问题词覆盖、短语命中、标题命中、稠密分和融合分。
- 新增引用可信度门控和低置信度拒答；结果分数过低、引用可信度不足或候选高度并列时不注入知识库上下文。
- 对需要制度、政策、依据、知识库或引用的任务，在没有可靠命中时注入明确拒答指令，禁止模型使用常识补答或伪造引用。
- RAG 缓存键纳入 rerank 和引用可信度阈值，避免调参后命中旧结果。

新增配置：

- `RAG_RERANK_THRESHOLD`：rerank 最低分，默认 `0.30`。
- `RAG_CITATION_CONFIDENCE_THRESHOLD`：引用可信度最低分，默认 `0.42`。

### 3. 工具和本机文件访问治理

- 正常路由和路由异常回退均限制工具候选数量，并按本机文件、浏览器、数据查询等任务意图优先排序。
- MCP Planner 实际入口增加候选硬上限，减少无关工具暴露和误调用概率。
- 工具输入 Schema 默认严格拒绝未声明字段；对明确声明的动态 Map（如 `fields`、`headers`、`sections`）保留合法动态键能力。
- 报表工具补充路径、字段、数组数量、过滤条件和未知字段限制。
- 本机报表文件只接受授权目录白名单内的相对候选路径，拒绝绝对路径、盘符、路径穿越、NTFS ADS 和符号链接越权。
- 工具策略阶段提前校验报表路径，校验失败不会进入文件读取执行器。
- 保留设备显式选择、设备签名、桌面连接器 Grant、授权目录和治理启停校验。
- 路由异常时仍走候选展示和用户授权流程，不会因为回退而直接执行工具。

## 兼容性与升级说明

- 本版本无新增数据库迁移。
- 现有知识库文档、工具目录、桌面设备注册和本机授权无需重新建立。
- 建议升级后检查以下环境变量：
  - `RAG_RERANK_THRESHOLD`
  - `RAG_CITATION_CONFIDENCE_THRESHOLD`
  - `PIVOT_CHAT_ROUTE_MAX_TOOL_CANDIDATES`
- 如需更换 Embedding 或 rerank 阈值，建议先使用知识库召回调试接口观察拒答比例，再逐步调整。
- 本机目录能力仍必须通过桌面端授权；服务端不会接受模型直接传入的任意绝对路径。
