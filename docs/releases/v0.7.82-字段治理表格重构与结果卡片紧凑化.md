# v0.7.82 字段治理表格重构与结果卡片紧凑化

日期：2026-11-01。本记录描述工作区的版本更新和开发成果；版本号更新不代表安装包或服务器已经更新。

## 修改内容

- **字段治理数据表格深度排版与完整性重构**：
  - 第一列“字段”代码与源名称重构为单行内联容器（`.data-analysis-gov-field-cell`），彻底消除“c_1 时间”折行导致行高异常撑大（由 57px 降至紧凑的 42px）的问题。
  - 全局消除表格内所有 `input` 和 `select` 继承自 `.form-input` 的 15px `margin-bottom` 冗余底边距，使所有输入控件严格垂直居中对齐。
  - “角色”列宽度拓宽至 160px 并设定标签 `flex-shrink: 0; white-space: nowrap;` 不可压缩，确保“维度”与“指标”两个复选框及文字完整展示绝不截断。
  - “单位/日期格式”列宽度拓宽至 240px，双输入弹性容器（`.data-analysis-governance-dual-input`）对半均分宽度（单输入框宽度达 108px），“单位”和“日期格式”占位符完整呈现。
  - 表格设定 1150px 最小安全宽度，在小屏和笔记本 125%/150% 缩放下通过表格横向滚动包裹层（`overflow-x: auto !important`）自适应滑动，杜绝列内容被强行挤压省略。
- **会话结果文件区域横向流式紧凑布局**：
  - 将会话任务生成的结果文件区域（`.chat-task-artifacts`）由原先纵向三行卡片堆叠重构为单行横向流式布局（`[文件图标] 标题 [格式徽章] 大小 · 版本 · 状态  [操作按钮]`）。
  - 条目最小高度由 84px+ 精简至 38px，垂直占用空间缩减 50% 以上，长会话阅读视野大幅提升，并支持移动端自适应平滑折行。
- **桌面客户端原生窗口控制按钮避让**：
  - 针对 Electron 桌面端（`body.pivot-desktop-runtime`）无边框窗口右上角原生标题栏（最小化/最大化/关闭按钮，高 30px）的悬浮层级，右侧预览抽屉（`.chat-result-preview`）与遮罩容器顶部自动下移 30px（`top: 30px; height: calc(100vh - 30px)`），消除右上角“下载”和“关闭预览”按钮与系统窗口控件的重叠遮挡。
