# v0.7.45 思维导图编辑器 XMind 布局与交互样式全面重构

## 概述

按照业界标杆 XMind 的经典现代布局与视觉设计规范，对应用中心思维导图可视化编辑器进行全方位的重构改造。彻底告别此前多行杂乱按钮、死板三栏堆叠与原始表单控件的陈旧布局，呈现出沉浸式、专业级、现代化的全新导图创作体验。

---

## 核心重构与优化特性

### 1. 顶部专业级工具栏（XMind Top Bar）
- **左侧文档与视图控制**：
  - `< 导图列表` 简洁返回按键，平滑回退导图总览管理页；
  - 紧邻返回按键右侧的独立 `[ ◨ 大纲 ]` 侧边栏抽屉开关按钮，与最右侧 `[ ◧ 格式 ]` 形成规范的左右对称面板控制体系；彻底精简移除原具有误导性的互斥伪切换“思维导图”按钮；
  - 垂直细分割线清晰隔离视图控制与文档信息区；
  - 内联文档标题输入框，支持点击直接重命名，与根节点文字、大纲树双向实时同步；
  - 动态状态胶囊（保存状态、协同/权限角色）。
- **居中经典胶囊操作栏**：
  - 依据 XMind 快捷操作习惯定制的中心悬浮/吸顶工具栏：
    - `子主题`（Insert Child Node / Tab）
    - `同级主题`（Insert Sibling Node / Enter）
    - `联系`（Relations）
    - `概要`（Summaries）
    - `删除`（Delete / Backspace）
    - `撤销` / `重做`（Undo / Redo）
    - `一键折叠` / `一键展开`（修复原按钮动作未绑定缺陷；深度重构接入 SimpleMindMap 原生 `UNEXPAND_ALL` / `EXPAND_ALL` 引擎命令，实现平滑收折子分支并保留视口缩放比，折叠状态实时持久化并纳入撤销重做历史）
  - 全量采用统一规范的 15px 线性矢量 SVG 图标与平滑悬停微动效。
- **右侧沉浸式操作区**：
  - 一键演说模式、实时多人协作、历史版本快照；
  - 导出下拉菜单（整合原生 JSON、PNG 标清/高清、SVG、Markdown、XMind、FreeMind、OPML 多格式一键导出与状态提示）；
  - 主色加固的“保存”主按键；
  - 格式检查器折叠开关（`[ ◧ 格式 ]`），灵活释放全屏画布空间。

### 2. 沉浸式画布与浮动状态底栏（Canvas & Floating Footer）
- **全视口自适应无限画布**：
  - 导图画布采用微渐变点状网格背景，支持手势平移、滚轮缩放与节点拖拽排布；
  - 优化层级与全屏自适应布局，消除原有容器滚动条抖动与边距浪费。
- **浮动控制底栏（XMind Floating Footer）**：
  - 左侧：工作簿/画布选项卡（`画布 1`），精简去除与顶部重复的画布左下角大纲按钮；
  - 右侧：主题节点统计（`主题: X`）、鹰眼导航缩略图切换、缩放比例调控微调组（`[-] 100% [+]`，点击百分比重置视口）、以及视口最佳适应按键（`⛶`）。

### 3. 右侧专业级格式属性检查器（XMind Inspector）
- **分段式 Tab 控制**：
  - `[ 样式 ]` 与 `[ 画布 ]` 双 Tab 快速切换，严格还原 XMind 属性面板布局。
- **节点样式（Style Pane）**：
  - 节点选中状态指示条与结构切换下拉菜单；
  - 节点形状可视化选择器（圆角矩形、直角矩形、椭圆、圆形、胶囊等）；
  - 填充色与边框色：原生复选框与定制色块吸管选择器无缝嵌入，支持边框粗细与虚线样式；全量色块（填充色块、边框色块、分支连线色块）统一右对齐至同一垂直基准线，清除外层 `form-input` 默认底部边距实现色块与前置输入框/下拉框完美垂直居中对齐，边框行重排为 `[实线▾] [宽度] [色块]`，色块规格提升为与控件等高的 28×28px 规范圆角方块，未勾选时呈现平滑半透明禁用过渡；边距 `×` 乘号放大至 14px 并垂直居中；
  - 内边距（X / Y）微调输入；
  - 文本排版工具栏：
    - 字体族下拉选择、字号像素微调下拉框；
    - `B` 加粗、`I` 斜体、`S` 删除线微型按键组；
    - 文本色彩色块快速选择器；
    - 左对齐、居中对齐、右对齐排版微按键组；
  - 节点文字多行编辑框（回车/失焦实时更新画布与大纲）；
  - 分支连线色彩与线宽实时调优；
  - 备注与超链接收折式面板；
  - 底部快速动作组：一键应用修改、AI 智能扩展分支、AI 智能总结分支。
- **画布全局属性（Canvas Pane）**：
  - 全局色彩主题与样式切换；
  - 主题库与自定义主题包导入导出；
  - 自动保存、本地草稿持久化开关、另存为个人模板、另存副本及数据来源刷新。

### 4. 优雅可折叠的大纲抽屉侧边栏与原地内联编辑（Collapsible Outline & In-place Inline Edit）
- 左侧大纲树支持跟随节点选定自适应滚动；
- 能够通过顶部视图切换器、底部快捷按钮或大纲面板自身的关闭按钮平滑滑入滑出。
- **废除冗长弹窗，支持大纲原地内联编辑**：彻底精简移除原“编辑节点大纲”的长列表弹窗及面板顶部冗余的“编辑”按钮；全面升级为在大纲树上直接选中编辑：
  - **双击修改**：双击大纲中任一节点文字即可立即切换为内联输入框（`.xmind-outline-input`）快速修改名称。
  - **悬浮微图标**：鼠标悬停于大纲节点时展现精致的编辑铅笔图标，点击即可原地编辑。
  - **键盘快捷操作**：在大纲活动节点上按下 `Enter` 或 `F2` 即可直接激活编辑模式；编辑时按 `Enter` 或失焦（blur）自动提交保存，按 `Esc` 退出并还原。
  - **全链路响应联动**：修改后自动触发数据归一化与 `state.editor.update()`，同步画布图形重绘、纳入撤销/重做（Undo/Redo）历史记录、联动右侧属性检查器，若修改根节点则同步刷新顶部标题。

### 5. AI 扩展分支与 AI 总结弹窗布局及样式全面升级（AI Branch Dialogs）
- **告别原始裸露表单**：全面接入 Pivot 现代弹窗设计系统（`.mm-modal-form.mm-ai-modal`），具有统一规范的圆角边框、柔和背景与精美阴影。
- **去除突兀的红色关闭按钮**：弹窗自动隐藏右上角生硬的红色“关闭”按钮（`hideClose: true` 并通过 CSS 选择器严格加固），底部规范化为“取消”与“生成预览”双按钮操作区，支持 `Ctrl + Enter` 快捷提交与空要求智能推导。
- **引入目标分支上下文卡片（.mm-target-branch-card）**：显式展示当前操作的目标分支名称、层级标签（L1/L2 等）与状态徽标，消除用户对操作范围的疑惑。
- **精细化提示与状态机制**：定制扩充与总结各自的副标题、输入提示语、文本域容器、AI 提示条（`.mm-ai-notice`）与动态加载状态条（`.mm-status-bar`）。
- **专业级结果预览与应用机制（.mm-ai-preview-modal）**：结构化 Markdown 树形大纲展示，提供“返回重试”与“应用到原分支 / 应用到节点备注”确认应用机制。

### 6. 管理关联线、管理概要与历史版本弹窗全面重构（Relations, Summaries & Versions Dialogs）
- **管理关联线（.mm-relations-modal）**：
  - 顶部分组卡片（`.mm-section-card`）承载创建表单：起点与终点节点采用双列栅格（`.mm-form-grid-2`）排布，说明输入框与等高的主色“+ 添加关联”按钮单行内联组合。
  - 已建关联清单接入带吸顶表头的专用滚动表格（`.mm-modal-table-wrap`），以徽标加箭头形式（`[起点] → [终点]`）清晰展示逻辑流向；提供友好的虚线空状态卡片（`.mm-empty-box`）。
- **管理概要（.mm-summaries-modal）**：
  - 父主题节点下拉菜单自动标注已有子分支总数；起始与结束分支序号采用两列数字微调输入框，与概要文字输入、添加按键结构化排布。
  - 已建概要清单由原先杂乱的原生列表升级为规范化表格，呈现所属父节点徽标、分支跨度胶囊、概要文本与删除操作，同样提供空状态插画。
- **历史版本（.mm-versions-modal）**：
  - 顶部新增“当前版本”状态栏（包含绿色版本徽标、版本号、快照总数）。
  - 版本表格中当前活跃版本呈现绿色高亮胶囊与“当前版本”不可重入标签；历史快照提供带回滚图标的“↺ 恢复”操作按键。
  - 分页栏升级为双侧排布的页码指示与标准翻页按钮，底部提供稳定保存机制提示。
- **关闭按钮与交互规范**：管理关联线、管理概要与历史版本三个弹窗遵循平台全局统一规范，在弹窗右上角呈现经典的红色边框与红色字体关闭按钮，底部移除重复关闭按键并保留提示文案；弹窗宽度适度放宽至 `640px`，桌面端视效开阔舒展。
