# Pivot v0.7.175 发布说明

2026-11-18 · PPT Master 自动修复与待核验草稿

## 失败恢复

- `PPT_MASTER_ACTION_INVALID` 的引文问题现在指出具体页、数据项和来源。宿主从授权材料定位有限原文片段，最多自动查证并修复三次。修订清单仍须核验和确认。
- 连续三轮读取或检查无有效进展时，任务最多自动调整两次，优先复用现有材料、工具结果和源稿。仍无法推进时保留检查点，显示 `PPT_MASTER_NO_PROGRESS`。手动继续携带上次失败原因，保留累计用量、预算和执行权限。
- 已批准项目导出有效 PPTX 后，若交付内容与清单不符，任务可保留待核验草稿。下载时检查任务归属、来源访问权及文件摘要。正式文件和项目源包在交付核验通过后登记。[使用帮助](../../使用帮助.md)

## 独立服务与升级顺序

源码版本为 v0.7.175。独立服务使用上游 6.8.0 和 `ppt-master:6.8.0` 标签，服务协议为 1。本轮无新增数据库迁移、第三方依赖或必填配置。

1. 更新主应用后，可先保留原引擎处理在途与待恢复任务。当前可用的检查点继续绑定原引擎身份。
2. 启用待核验草稿时，在处理完原引擎上的任务后导入本次离线包，核对归档摘要和镜像标识，再更新独立服务。保留连接配置和服务数据卷。[独立服务更新说明](../deployment/PPTMaster独立服务部署与更新.md)
3. 使用代表性材料进行新任务验收，确认引文修复、待核验草稿与正式交付状态可区分。
