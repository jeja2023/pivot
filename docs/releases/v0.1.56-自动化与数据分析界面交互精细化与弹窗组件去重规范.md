# Pivot v0.1.56 发布记录

**发布日期**：2026-08-27

---

## 概述

Pivot v0.1.56 聚焦于**自动化中心（任务、工作流与 Agent 控制台）与数据分析应用的界面交互精细化、弹窗交互组件去重规范、以及全局表格行高与按钮尺寸标准化**。本次更新全面梳理了多个工作区的按钮对齐与弹窗关闭逻辑，重构了新建任务模板的交互心智，彻底消除了表格单元格行高突变与数据错行问题，带来更加严谨、紧凑且现代化的交互体验。

---

## 主要更新内容

### 1. 自动化中心与 Agent 控制台布局与对齐优化

- **任务页面按钮布局重构**：
  - 将「新建任务」按钮移动至「删除审计」按钮左侧；当非 Admin 管理员用户登录（无删除审计权限）时，按钮依然自然靠右对齐，操作动线更加合理。
- **工作流页面工具栏对齐重构**：
  - 将工作流搜索框调整至工具栏最左侧，将「新建工作流」与「新建计划」按钮移至右侧操作区，采用 `space-between` 两端对齐，消除原有中间留白与操作分散问题。
  - 工作流资产列表严格对齐发布状态：未发布工作流不再展示「计划」按钮，仅对已发布工作流展示计划入口，杜绝未发布版本的误调度。
- **Agent 控制台按钮去噪与去重**：
  - 移除了顶部标题栏中多余的「新建持续目标」重复按钮；
  - 去除下方持续目标面板按钮名称前的装饰性加号，名称统一规范为「新建持续目标」。

### 2. 评测集与新建任务弹窗去重与紧凑化

- **新建评测集弹窗体验升级**：
  - 去除右上角关闭按钮，与右下角「取消」按钮去重；
  - 紧凑化表单内边距与用例卡片间距，默认无用例状态下自适应高度且不出现垂直滚动条，添加新用例后按需展示滚动条。
- **质量与可靠性大屏左右双栏对称重构**：
  - 彻底解决原本大屏布局松散、大卡片过度拉伸的问题，重构为左右平衡对称双栏布局（左侧评测中心概览与详情，右侧运维指标、工具可靠性与反馈闭环）。
- **新建任务模板交互重构（按钮 + 独立弹窗）**：
  - 移除了原常驻在新建任务表单顶部、挤占表单垂直空间的内嵌模板卡片条（`.agent-task-composer-templates-bar`）；
  - 将「常用模板」按钮唯一定位于新建任务模态框底部操作栏左侧（与「保存为模板」并列）；
  - 新增独立的 **「常用任务模板」弹窗**（`#agent-template-modal`），采用自适应卡片栅格展示所有已保存模板，点击模板直接自动回填任务目标并关闭弹窗。
- **弹窗关闭按钮去重规范**：
  - **新建任务弹窗**：去除右上角「关闭」按钮，与右下角「取消」按钮去重，统一由「取消」按钮关闭；
  - **常用任务模板弹窗**：去除右下角多余的「关闭」按钮，统一由右上角标准「关闭」按钮关闭。

### 3. 数据分析数据总览表格全局标准化

- **数据大小单行不换行与状态标签展示**：
  - 移除了数据大小单元格内行数/列数与范围标签之间的 `<br>` 换行符，将列宽扩展至 180px 并应用 `white-space: nowrap`，使数据规模与范围状态在同一行紧凑呈现。
- **严格保证 7 列完整对齐**：
  - 补齐并严格校验表格 7 列数据（序号、数据集名称、原始文件名、数据大小、文件类型、导入时间、操作），修复列错位问题。
- **行高与操作按钮高度全局统一**：
  - 表格行高显式设定为系统全局工作区统一标准 `38px`（`min-height: 38px; padding: 6px 8px; box-sizing: border-box; vertical-align: middle;`）；
  - 操作栏按钮统一定义为全局紧凑标准 `24px`（`min-height: 24px; padding: 0 8px; font-size: 0.68rem; line-height: 1;`），杜绝按钮撑高表格行；
  - 对数据集名称与文件名开启单行溢出省略（`text-overflow: ellipsis`）并补充原生 `title` 浮动气泡提示。

### 4. 自动化测试与契约保证

- **自动化契约测试全面覆盖**：`tests/automation-page-contract.test.js` 扩展至 13 项全自动化契约测试，覆盖未发布工作流无计划按钮、弹窗关闭按钮去重、左右双栏大屏结构、独立模板弹窗、表格 7 列对齐与 38px/24px 统一尺寸断言；
- **核心测试与安全回归全绿**：`tests/security-agent.test.js` 58 项安全与工作流测试全量通过；
- **治理规范**：`npm run lint` 与 `npm run check` 零警告、零报错。
