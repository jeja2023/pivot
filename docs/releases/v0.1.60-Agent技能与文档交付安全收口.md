# v0.1.60 发布记录：Agent 技能与文档交付安全收口

发布日期：2026-09-01

## 已完成

### 技能治理

- `SKILL.md` 成为前端创建个人 Skill 草稿的唯一入口，支持严格 Frontmatter 校验、预览和版本化保存。
- 技能治理页支持查看版本差异、能力/工具扩权提示、创建后续草稿和管理 Release ACL。
- 发布解析、技能目录与运行时 PEP 统一执行租户、团队成员、Release ACL、灰度和工具能力校验。
- 签名信封以内容摘要、密钥标识和签名形态为不可变键复用，后续导入不能覆盖已验证版本引用的签名记录。

### 文档与交付

- 文档统一由 Document IR 渲染为不可变 Artifact Rendition；公文工作台会在导出前自动沉淀独立 Artifact。
- 二进制 CAS 支持租户隔离、流式读写、引用计数与保留期；下载前复算实际内容摘要，拒绝同长度篡改。
- 支持 DOCX、XLSX、HTML、Markdown 和具备 CJK 字体自检的 PDF 渲染；字体缺失或摘要不符时 PDF 能力 fail-closed。
- Web 下载使用一次性令牌；桌面本机保存要求用户意图、指定设备、目录授权和设备密钥证明四项同时成立。

### 桌面连接器

- 文档交付设备使用密钥对、nonce 签名、claim token、原子写入和本地已写清单。
- 原本依赖进程内 Map 的只读本机 MCP 桥接已替换为持久化桌面连接器：任务、租约、领取凭据和结果均保存到 PostgreSQL。
- 网页不再上报自报设备 ID 或目录授权；桌面主进程直接使用设备私钥完成连接器 heartbeat、领取和结果回传。
- 本机 SQLite 与报表目录工具必须显式携带 `deviceId`，不会再由服务端隐式挑选一台设备。

### 可执行 Capability Package

- 增加 Docker 隔离执行框架，默认关闭。
- 只接受不可变 `image@sha256`、平台固定入口命令和受限资源配置。
- 运行容器默认禁网、只读根文件系统、无 GPU、无业务凭据，并限制 CPU、内存、进程数、临时空间、输入输出和执行时间。

## 运维操作

### PEP 当前运行模式

当前生产环境没有存量 Skill，已直接配置为：

```dotenv
PIVOT_AGENT_PEP_MODE=enforce
```

后续如需迁移历史技能，可在隔离环境中使用 `shadow` 评估影响；生产环境继续维持默认拒绝。

### Capability Worker 启用条件

必须先由运维提供经审计的内网镜像，例如：

```text
registry.example.internal/pivot/capability-runner-python:1.0@sha256:<64位摘要>
```

同时登记固定入口命令、CPU/内存/超时/输出上限。未完成这些准备前，保持：

```dotenv
PIVOT_CAPABILITY_WORKER_ENABLED=false
```

### Windows 桌面客户端封包状态

Windows 安装包已通过 `npm run dist:win` 成功生成。发布文件位于 `downloads/`：

- `Pivot Setup 0.1.60.exe`
- `Pivot Setup 0.1.60.exe.blockmap`
- `latest.yml`
- `SHA256SUMS-windows-x64.txt`
