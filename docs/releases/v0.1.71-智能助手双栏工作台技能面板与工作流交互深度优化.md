# v0.1.71 发布记录：智能助手双栏工作台、技能编辑面板与工作流交互深度优化

## 概览

Pivot `v0.1.71` 聚焦于 Agent 控制台与工作流管理界面的排版、空间利用率与交互一致性体验优化。主要涵盖：
1. **「我的智能助手」双栏工作台重构**：将个人档案与记忆治理重构为并排双栏结构，移除多余占位并消除页面顶部大块空白，操作状态反馈全面升级为 Toast；
2. **「技能」管理面板深度优化**：扩充代码编辑区（`SKILL.md`）高度至 `410px`，调整左右栏黄金比例为 `0.75:1.25`，强制文本域 100% 满宽填充，完美填补底部空白且保障 100% 首屏展示、绝不触发垂直滚动条；
3. **Tab 切换组件样式统一**：「运行质量」与「技能与助手」子 Tab 导航栏增加 `align-self: flex-start` 紧凑包裹，统一 26px 高度、内边距、圆角与选中态微交互规范；
4. **「工作流」页面交互收敛**：移除顶部操作栏中冗余的「新建计划」按钮，将计划任务创建统一收敛至数据表操作列。

## 详细变更

### 1. 「我的智能助手」双栏工作台与空白消除
- **独立双栏工作台网格**：引入 `.agent-assistant-workbench-grid` 独立容器包裹左侧「个人档案设置」与右侧「记忆与隐私治理」，在大屏下并排展示，彻底消除了由于隐藏子面板导致的 CSS Grid 占位空白问题。
- **状态反馈 Toast 化**：移除底部常驻的状态提示横幅占位，所有策略保存与修改统一通过全局 `showToast` 弹窗即时反馈。

### 2. 「技能」管理面板高度与排版优化
- **代码编辑体验提升**：`#agent-harness-skill-manifest` 编辑区高度扩充至 `410px`（支持纵向自由拖拽），可完整查看和编辑 YAML Frontmatter 与工作指引。
- **满宽横向拉伸**：修复 `<textarea>` 默认宽度受限导致的居左挤压与右侧空旷问题，强制 100% 满宽适配。
- **左右黄金比例分配**：调整左右栏为 `minmax(280px, 0.75fr)` 与 `minmax(0, 1.25fr)`，让列表更紧凑、编辑器更宽敞。
- **无滚动条视口约束**：总高度收敛在 ~800px 左右，在 900px+ 桌面视口下无需滚动即可完整呈现。

### 3. Tab 导航组件规范对齐
- **紧凑包裹**：为 `.agent-cp-quality-tabs` 与 `.agent-harness-nav-tabs` 配置 `align-self: flex-start`，彻底消除拉伸至 100% 产生的多余灰色背景槽。
- **规范对齐**：统一按钮高度为 `26px`、内边距为 `3px`、圆角为 `8px / 6px`、字体为 `0.74rem`，并统一翡翠绿激活态配色。

### 4. 工作流（DAG）页面操作收敛
- **移除顶部冗余按钮**：移除了工作流资产列表顶部的「新建计划」按钮。
- **明确上下文关联**：计划创建统一收敛至各工作流数据行的「计划」操作按钮，确保每次创建计划都能明确绑定对应工作流。
