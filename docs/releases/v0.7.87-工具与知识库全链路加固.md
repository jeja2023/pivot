# v0.7.87 工具与知识库全链路加固

日期：2026-11-04。开发与功能验证基线为 v0.7.86 / `2ef5ebd9` 上的工作区改动。本次将这些改造归入 v0.7.87，并同步更新日志与项目版本；版本号更新不代表已经构建、部署或完成生产验收。

## 用户可见变化

- 再次复查工具和知识调用链路，修复批量知识来源传递、单项读取失败丢失其他结果、在途读取提前返回、流式完成快照、来源撤权及授权失效恢复等边界。组合契约和工具引用版本同时补齐校验。见[深度复查记录](../reports/工具与知识库全链路深度复查-20261104.md)。

- 纯输入契约错误单独作为参数问题处理，显示尚未执行、字段问题和当前契约，交回模型有限修正；不再误提示申请权限放行，也不挤占业务工具连续失败额度。权限和审批仍须完整通过，持续无进展仍有界收尾。见[输入契约修复记录](../reports/工具输入契约修复与任务连续性-20261104.md)。

- 工具引用缺失或连续搜索失败后，停止无效循环并生成能力受限答复；概念/写作可先用模型知识，文件任务可先给文本草稿，内部事实和外部操作结果不能伪造。详情改为核心首屏优先、完整诊断按需，并增加超时、重试及关闭/切换保护。改造后的链路 287 项通过，详情见[专项记录](../reports/工具失败答复收尾与任务详情加载-20261104.md)。

- 智能体轮次改为分级单段预算与累计预算，默认聊天档位为 6/6、30/60 和 50/120；自动续跑要求实际新进展并保留跨恢复累计消耗，对话卡及诊断分别显示两种计数。收尾预留和旧任务兼容详见[轮次预算改造记录](../reports/智能体分级轮次与累计预算改造-20261104.md)，对应专项回归与此前 248 项验证分开记录。

轮次预算改造后的完整链路回归为 275 项通过（151 单元、75 隔离数据库、45 恢复/网络、4 浏览器），无失败或跳过，验证前后源码指纹一致；项目检查、Lint 和类型检查通过。该结果仍属于本地与隔离验证，不改变下文真实服务及生产未验收的状态。

- 基于知识库和图谱的任务保留可复核来源。工作流、子工作流、逐项处理及复用结果在继续执行和交付前检查资料范围与版本；无法确认时提示重新选择资料。
- 来源变化或访问失效后，相关历史消息、任务结果、上下文和审计读取隐藏旧内容，相关文件不可继续预览或下载。会话分支保留来源关系，失效来源不能通过复制分支继续使用。缺少必要来源信息的旧记录采用保守处理，需要重新检索；已经交付到客户端的内容不能远程撤回。
- 操作目标、参数、工具版本或连接授权变化时，需要查看新请求并重新确认。旧操作授权缺少版本与连接绑定时也需重新确认；来源或审批阻断不自动重试。
- 知识库文档详情显示处理页数、完整或部分覆盖、未处理页、失败页及索引版本；片段可用不代表全文处理完成。
- 质量面板显示自己的调用样本、成功率分母、业务失败、超时、拒绝、耗时分位及文件阶段计数。调用成功、内容核验通过、下载响应完成和文件已保存到本机分别确认。

## 工具与开发接口

- `knowledge.graph.query` 与 `rag.search` 复用 `knowledgeSourceVersion: 1`，包括文档、版本、片段、引用键、内容摘要、字符定位与覆盖状态；图谱关系依据摘要需对应当前原文。旧关系缺少摘要或来源已变更时不作为可引用结果返回。
- DAG 派生输出通过来源信封持久化，运行时解包保留原输出类型；缓存命中、恢复、跨运行复用、子工作流和逐项调用均传递来源。普通会话在路由元数据保存来源，后续回答及压缩摘要继承，分支复制保留该关系。
- 新增 `pivotArtifact.kind = document`：接受受控文档结构，格式为 `docx`、`pdf`、`xlsx`、`html`、`md`，复用现有渲染、产物归属和下载接口。
- 新增 `pivotArtifact.kind = file`：原始文件仅接受 `png`、`svg`、`wav`，需提供匹配的 `mimeType`、`encoding: base64`、`content` 和 `sha256`；解码后上限 8 MiB，并检查图片/音频结构、图片尺寸及 SVG 外部资源。文件归属与调用标识由服务端上下文确定，不能提交任意路径或外部 URL 代替内容。Word/PDF/Excel 等第三方原始二进制不在此契约中。
- 原有 `audit`、`diagram` 契约继续使用，`tools.execute` 嵌套调用的文件登记不重复执行。文件摘要、内容核验和交付状态分别保留，文件存在不冒充内容正确。
- 新增用户级统计 `GET /api/agents/quality/tool-chain`，并接入现有质量面板；按入口、模型、工具及契约摘要分组，返回样本数、分母、业务失败、超时、拒绝、P50/P95、Token/成本及独立交付阶段。指标仅统计已记录样本，生产告警阈值未自动设置。
- 工具调用事件修复 INSERT 占位符缺失，并增加发现、知识与文件阶段原因码；预览和下载记录响应完成/失败，不能据响应完成推断客户端本机保存完成。
- 审计导出省略工具 SQL、输入参数和工具正文，保留运行状态、结果摘要与来源标识；补充 Bearer、连接串和 URL 查询参数脱敏。来源失效后不通过导出恢复旧内容。

## 评测与恢复工具

```powershell
node scripts/verify_tool_knowledge_chain.js --isolated-postgres --report output/tool-knowledge-chain/v0.7.87.json
```

该命令使用本机 PostgreSQL 的独立临时实例，不使用当前业务库；完成后停止实例并清理隔离目录与 schema。Windows 自动寻找已安装 PostgreSQL，其他位置可用 `--pg-bin` 指定 `bin` 目录。显式配置独立 `TEST_DATABASE_URL` 时，也可分别运行 `--unit --browser`、`--integration --recovery`。报告记录 Node/平台、源码指纹及通过、失败、跳过计数；验证期间源码变化会使检查失败。

`scripts/benchmark_tool_discovery.js` 评估经授权目录快照的候选排序；当前 1001 项合成目录、2 个反例的首位正确率由 0.5 到 1，结果只代表该合成样本的排序，不代表真实模型选择正确率。`scripts/benchmark_knowledge.js` 增加 Recall@5、MRR、无答案和引用标注指标及样本数，未提供事实支持标注时保持未评估。

无答案指标检查没有返回引用，引用指标检查返回引用键与标注键的对应，不代替拒答正文与事实支持评审；标注者信息也不能代替双人独立复核。具体字段见[知识库验收手册](../deployment/知识库生产验收与恢复演练.md)。

## 升级与兼容

本次不新增数据库迁移、生产依赖或必需环境变量，继续使用现有 PostgreSQL、工具服务及文档渲染配置。部署时按既有维护流程备份，更新主程序并重启，重新加载页面；桌面安装包需重新构建后才具有新的客户端版本。

升级后注意旧审批重新确认及旧来源无法定位的提示。回退前先停止任务恢复与调度，在隔离环境确认旧版本对新增来源信封的读取兼容性；不要删除来源元数据、关闭授权/审批或出站检查来恢复运行。已发生的外部操作需单独核对，应用回退不会撤销副作用。
