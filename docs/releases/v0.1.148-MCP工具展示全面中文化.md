# Pivot v0.1.148 发布记录：MCP 工具展示全面中文化

## 发布概要

本版本统一 MCP 工具在聊天 `@` 选择器、工具库详情、智能路由摘要和智能体目录中的展示语言。用户默认看到可理解的中文名称和说明；技术标识仅在详情中按需展开。

## 中文化范围

- 数据库：列出数据表、查看表结构、执行只读 SQL、分组统计；
- 报表与文件：查找报表文件、读取报表摘要、查询表格数据、对比数据文件；
- 数据、文档、格式和图表：筛选数据行、分组汇总、提取文档大纲、转换 JSON、生成图表等；
- 本机浏览器：打开本机浏览器、读取本机网页、点击网页元素、截取本机网页；
- 外部 MCP：已知工具使用系统中文词典；未知英文标识提供可读中文兜底，并允许所有者/管理员维护正式中文名称和说明。

## 功能兼容性

中文化只作用于展示、搜索别名和语义目录描述，以下内容保持不变：

- 工具原始 `name` 与完整 `fullName`；
- 输入/输出 Schema、参数名称和工具白名单；
- Capability 治理、授权、审批、网络预检和实际执行；
- MCP 调用日志、审计记录、路由覆盖和历史数据。

用户可以使用中文名称、英文原名、短名称或完整内部标识搜索；工具详情的“技术标识”折叠区仍可用于排障。

## 外部工具维护

外部工具服务所有者或管理员可在“工具库 → 工具 → 中文名称”中维护展示名称和说明。配置保存在服务配置的展示元数据中，不写入 MCP 工具缓存，也不改变远程工具服务协议。清空后恢复系统默认中文词典或自动兜底。

## 验证

- 中文展示层单元测试与自定义展示持久化测试通过；
- 聊天输入、RAG、MCP、安全聊天专项回归通过；
- 完整 `npm run check` 通过；
- 真实浏览器 E2E 验证英文原始工具标题在 `@` 列表中显示中文标题，且英文原名仍可搜索。
