# v0.7.64 对话任务执行过程折叠与任务面板体验优化

发布日期：2026-10-29

## 更新内容

- **对话任务执行过程默认折叠**：
  - 大模型回复生成后或任务进入终态时，对话气泡中的执行过程 `<details class="chat-task-process">` 默认自动折叠，避免冗长的步骤列表撑满屏幕，将视觉焦点全面聚焦于大模型生成的最终答案。
- **正常完成时操作按钮收纳折叠**：
  - 对于顺利完成且无错误的正常对话任务，操作按钮（`[任务详情]`、`[转为计划]`、`[另存模板]`）统一收纳进折叠层内部，外部卡片收敛为极度纤薄干净的状态条；用户按需展开执行过程时即可在步骤末尾使用相关操作。
- **出错原因外显与过程折叠**：
  - 任务发生执行异常时，红色的出错原因说明卡片与操作按钮（`[继续/重试]`、`[任务详情]`、`[停止任务]`）直接在折叠栏下方醒目外显，执行过程保持折叠状态，用户可自主点击 `<summary>` 手动展开确认出错具体环节；同时屏蔽了失败状态下冗余的“暂无独立核验记录”占位。
- **任务详情面板执行过程默认折叠**：
  - 点击“任务详情”进入的独立弹窗中，执行过程列表默认保持折叠，优先呈现任务目标、完成状态指标、核心耗时与异常统计，避免大弹窗初始加载时长篇步骤列表挤占视线。
- **样式与轻量化排版优化**：
  - 优化完成态与折叠态下的面板内外边距，新增高对比度的错误提示条样式，并重新编译打包聊天样式。
