# Pivot v0.1.146 发布记录：聊天 @ 两级能力搜索

## 发布概要

本版本重构聊天输入框的 `@` 引用选择器。初始状态不再把知识库与工具混合成一个可滚动长列表，而是先让用户选择能力类别，再进行针对性搜索。

## 交互变化

- 输入裸“@”时，只显示“知识库”和“工具”两个入口；
- 选择入口后弹出该类别的紧凑搜索框，输入关键词才显示匹配项；
- 每次最多展示 6 条结果，支持返回类别选择，不因知识库或工具数量增加而拉长初始菜单；
- 用户先输入 `@关键词` 时同样可以先选类别，已有关键词会保留并用于后续搜索。

## 安全与一致性

- 工具目录仅在用户进入“工具”搜索时按需请求；
- 候选继续按用户可见性、Capability 与当前聊天工具白名单过滤；
- 选择工具只写入本轮显式路由候选，不能自动授权或执行；实际调用仍须完成用户确认、审批、网络策略和原有执行预检。

## 验证

- 更新浏览器 E2E：验证裸“@”仅显示两个类别、进入工具搜索后按关键词显示白名单内工具、并能形成正确的工具路由覆盖；
- 执行聊天输入、自适应路由、RAG、MCP 与安全聊天专项回归；
- 执行完整 `npm run check`。
