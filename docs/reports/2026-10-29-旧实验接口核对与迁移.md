# 旧实验接口核对与迁移

核对范围为当前仓库的前端调用、路由接线和自动化测试，不能证明外部集成方没有调用旧接口。旧接口在完成独立适配、授权和行为验证前保持不可用；下列现有能力的参数、响应、权限和生命周期不同，不是逐字段兼容替换。

| 旧实验入口 | 当前已接线能力 | 迁移时需要注意 |
| --- | --- | --- |
| `/api/streaming/*` | `GET /api/events` 为当前用户推送事件；`GET /api/agents/runs/:id/events` 和 `/events/replay` 查询或回放指定任务事件 | 旧会话 ID、事件游标和返回格式与当前任务事件不同，需按用户和任务重新绑定；不得把其他用户事件映射给调用方。 |
| `/api/evaluation/*` | `/api/agents/evaluations/suites`、`/api/agents/evaluations/suites/:id/runs` 等使用现有评测系统 | 旧基准测试包含模拟运行器，不能复用其成功结果作为真实评测证据；评测集、裁判及人工审核需按当前接口处理。 |
| `/api/tools/recommend` 等 | `GET /api/tools/catalog` 和 `POST /api/tools/search` 返回当前用户可访问的工具 | 工具搜索不等于旧推荐算法，评分、反馈及统计不能默认一一对应。 |
| `/api/planning/*` | `POST /api/agents/runs` 创建持久任务；工作流通过 `/api/agents/workflows` 创建及发布 | 旧规划接口依赖模拟模型，任务计划和工作流版本的输入、审批、预算及状态模型均须重新对接。 |
| `/api/orchestration/execute` | 已发布的工作流及 `POST /api/agents/runs` 提供当前受治理的运行入口 | 旧 DSL 解析只用于结构检查，未接入真实执行器；不能把旧 DSL 文本直接当成已批准的工作流执行。 |

若存在外部调用方，迁移前应盘点其接口、身份和数据范围，在隔离环境验证正常、匿名、跨用户、异常及恢复路径，并由业务方确认替代功能；没有验证前不解除安全门禁。
