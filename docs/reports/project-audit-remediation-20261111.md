# 智能路由、智能体与技能十项审查问题修复

日期：2026-11-11；源码版本同步至 0.7.151。本记录对应本次审查的 F01—F10 以及 BI 建模高压调度与锁竞争优化，未发布镜像或安装包。

## 修复范围

| 编号 | 修复结果 | 验证入口 |
| --- | --- | --- |
| F01 决策特征重复归一化丢失 | 原始 taskState 与规范化 requestState 使用同一白名单，重复处理保留任务哈希、能力、证据需求及计数；缺失租户保持 null。 | project-audit-routing：真实提供器、序列化与重复归一化 |
| F02 核验续租和恢复遗漏 | 执行租约状态共用状态机定义，verifying 正常续租；核验阶段确实失去租约或服务退出时保留答案并明确失败，不自动重放业务动作；旧持锁者和旧代次不能结束新任务。 | project-audit-runtime：心跳、真实数据库条件更新、重启恢复 |
| F03 队列跳过启动 Hook | 队列认领后的执行器在模型和业务来源之前运行启动前置检查，按执行代次关联前后置审计；拒绝启动不会自动重试。原直接状态迁移的保护继续保留。 | project-audit-runtime：队列认领、真实执行器及前置拒绝；既有 lifecycle 回归 |
| F04 换模型身份不持久 | 普通/CAS 状态写入允许 chosen_model_id；初次执行、恢复与故障切换同步持久模型和内存身份，备用模型失败也保留实际身份。 | project-audit-runtime：真实写入及质量样本可见性；模型路由回归 |
| F05 学习决策与执行结果断链 | 实际生效的学习决策作为结果主身份，语义判断和影子建议保留独立标识；任务交接与纠正沿用主身份。终态投递使用确定性键；执行失败率仅以实际生效且取得结果的决策为分母，不混入影子或待完成记录。 | project-audit-routing：真实任务反馈、结果去重及制品指标/熔断 |
| F06 去重后水位不推进 | 已接纳批次先于新增运行配额识别，核对目标和版本；去重命中也在当前 claim/version 下提交水位，未确认提交明确报错。 | automation-goal-source-polling：Run 已保存、水位未保存且窗口配额已满 |
| F07 长技能静默截断 | 保留原 256KB 正文上限，移除 12k/16k 截断；创建、验证、发布和运行共用正文容量校验，JSON/流式规划、总结及独立核验接收完整要求。模型容量不足明确失败，不能使用不完整指引声称完成。 | project-audit-skills、agent-provider-sse-harness：尾部规则与上下文不足 |
| F08 目录被历史和他人发布挤占 | 参数化键集分页在 SQL 中先排除他人个人范围，逐页复核当前 ACL、状态和灰度；实际有效条目才消耗名额。搜索可遍历完整目录，详情按名称缩小查询范围并校验完整引用。 | project-audit-skills：超过 400 条私有/灰度历史记录；discovery HTTP/ACL 集成 |
| F09 匹配与执行版本不一致 | 在当前实际可用的发布集合上匹配；将 releaseId/version/digest 绑定到任务创建，再解析时复核版本与显式激活要求，变化返回冲突。相同发布时间按发布 ID 稳定排序。 | project-audit-skills：用途不同的历史版本、灰度回退及选择后变化 |
| F10 技能负反馈率分母错误 | 工具调用与有效用户反馈分别统计；负反馈使用用户反馈样本及独立最小门槛，默认继承原 minSamples；运行时反馈不算用户评价，修改后的反馈按更新时间入窗；迟到的运行时收尾不覆盖用户评价身份与时间。 | project-audit-skills：20/400、无工具、无反馈、小样本与真实反馈查询 |

没有新增依赖或数据库迁移；已有历史记录保持原始身份，不回填无法证明的旧路由特征、模型选择和结果归因。旧核验任务会在运行时停滞恢复中收敛；长技能超出模型容量时需要更换模型或将参考资料移入配套资源。
