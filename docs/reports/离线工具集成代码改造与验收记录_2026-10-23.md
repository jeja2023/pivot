## 3. 镜像与物料

官方 MCP Python SDK 固定 1.26.0，传递依赖全部固定并带分发 SHA-256，基础镜像固定摘要。Linux amd64 镜像 pivot-offline-tools:1.0.0 已构建，最终镜像 ID：

`sha256:5331bae629ecbb09cb6c59f32c24876a9608a67ef1c983a87429c58636e96260`

Kroki 与 Mermaid 固定 0.28.0。Docker 代理不可用时通过官方 Registry API 获取平台清单和镜像层，逐层核验 SHA-256 后本地导入，未修改用户 Docker 配置。只启动独立 pivot-guide-verify 测试项目；其控制与渲染网络均禁外网。真实联调通过后已停止并移除测试容器与网络。

联调实际修正了 tmpfs 字符串编排、Graphviz 固定 XML/DTD 声明、Mermaid HTML 标签及合法动画样式兼容。未通过放行 HTML、脚本或外部资源来解决问题。

[物料导出工具](../../scripts/offline_tools_release.js)交付三个镜像归档、Compose、依赖锁、标准 Python 验证器和 BOM；密钥不包含在公开包中。最终物料摘要结果另附实际运行记录。

最终离线包已保存在本工作区 `artifacts/offline-tools-1.0.0-20261023/`，Node 校验与 Python 标准库校验均已通过，包含 6 个受校验交付文件和 BOM。该目录为本地交付产物，不进入 Git。镜像文件总量约 3.58 GB；移交时应再执行随包 `verify_bundle.py` 并比对可信 BOM。
