## 产品行为与兼容

- 算子流作为数据准备能力，不隐式改变已发布语义哈希。物化完成后提供“基于输出新建正式模型”，再设置粒度、维度和指标并检查发布。
- 节点接口返回 `202 { job }`，通过现有异步查询接口轮询和取消。请求必须携带草稿修订及幂等标识；旧客户端提示刷新，不回退至 API 进程内执行。
- 最近二十条节点任务可在重开后查询。预览沿用七天结果保留策略；物化产物由数据集不可变版本保留。后续字段治理或数据更新不改写旧输出预览。
- 部署需先排空任务，升级迁移、API 与 Worker，完成 `node_flow` 能力预检后启用；不能把新任务交给只理解旧类型的协调器。继续遵守单活与兼容回退合同。
- 未新增依赖、执行配置或私有样式体系。
