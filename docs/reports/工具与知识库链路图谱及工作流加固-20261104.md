## 本批落地

| 方案任务 | 实际变化 | 边界 |
| --- | --- | --- |
| K01、K04 | `knowledge.graph.query` 工具适配到 `knowledgeSourceVersion: 1`，返回文档、版本、片段、引用键、摘要、真实字符范围、索引与覆盖状态；保留关系路径的基本字段。图谱线索与引用原文一起传递。 | 不虚构页码；图谱线索仍需结合原文判断事实支持，未替代业务黄金集和语义评审。 |
| K02、T03 | 图谱在任务、会话和本次选择的交集内读取片段，并重新检查当前引用权限；依据摘要必须对应当前片段。旧关系缺少摘要或依据已改变时不作为可引用结果返回。 | 未更改现有共享规则；原始图谱管理/查询服务未切换到此工具结果契约。 |
| K02 | 顶层 DAG 恢复、跨运行节点复用、缓存命中、下游调度和最终交付检查直接知识节点的来源。范围不符、旧格式、版本变化、来源不可访问或复核失败时阻断。继续及兜底策略不能放行该阻断。 | 本批不是所有子工作流、逐项执行及派生结果的完整证据传递实现。已进入执行的并发工具不会因数据库复核而自动撤回。 |
| T03 | 恢复的知识观察结果纳入最终验收；新执行节点的观察结果保留独立来源清单，持久化步骤保存结构化引用，避免仅保留截断 JSON 文本。来源清单的文档、版本、片段、专题及索引代次参与复核。 | 来源有效不等同于模型答案已通过事实支持检查。 |
| T02、D03 | 增加 `KNOWLEDGE_SOURCE_UNAVAILABLE` 阶段投影；任务详情中的 DAG 知识节点与完整输出接口在读取时复核，失效时隐藏旧正文、名称和完整输出引用。兼容字符串形式的历史结果；待执行节点保持原状态。 | 运行最终答案、普通派生节点、Trace、检查点、审计导出及已生成文件的所有读取路径仍需继续治理。 |

新增业务逻辑分别放在图谱工具结果、DAG 知识校验与状态恢复模块中，主运行文件保持薄接线，没有增加数据库迁移、依赖或配置。工作区原有 `.env.example` 改动保留。

资源门禁发现已提交的 `chat.shell.css` 与现有源样式不同步，按项目构建脚本重新生成该产物并保留；没有手工改动源样式。
