# v0.7.14 Agent 任务执行验收报告

日期：2026-10-20。范围与生效步骤见 [发布记录](../releases/v0.7.14-Agent任务执行与知识问答预算修复.md)。

## 功能回归

版本同步前，按 Agent、聊天、工作流、桌面执行、工具守卫、模型用量及相关安全测试范围选取 149 个测试文件，分为 50、50、49 个文件的三组。每组通过 `scripts/run_node_tests.js` 使用独立 PostgreSQL schema，结果如下：

| 测试组 | 文件数 | 通过 | 失败 | 跳过 |
| --- | ---: | ---: | ---: | ---: |
| 第 1 组 | 50 | 246 | 0 | 0 |
| 第 2 组 | 50 | 304 | 0 | 0 |
| 第 3 组 | 49 | 396 | 0 | 0 |
| 合计 | 149 | 946 | 0 | 0 |

该范围覆盖任务创建、队列与租约、模型调用、工具发现与执行、预算、审批、暂停取消、恢复续跑、协作、工作流、验收与结果回写，不等同于全项目所有测试。

主要新增与补充的回归：

- `tests/agent-execution-edge-cases.test.js`：重试时间保存、迟到异常、零额度、耗尽后的收尾、验收中断及委派修复用量。
- `tests/agent-provider-sse-harness.test.js`：暂停与租约丢失、答案收尾失败、Token 耗尽、检查点工具结果与控制要求恢复。
- `tests/agent-resume-budget.test.js`：并发继续原任务、旧续跑链定位、真实耗尽、消息回写关联及持久化与内存用量一致性。
- `tests/agent-runtime-pause.test.js`：暂停与完成或等待提交并发、父任务停止传播。
- `tests/agent-verification.test.js`、`tests/agent-verification-persistence.test.js`：预检索资料参与规则及语义验收。
- `tests/chat-session-selection.test.js`、`tests/chat-conversation-product.test.js`：重复恢复只保留一张卡片、旧响应失效、无权限后停止查询及旧续跑链过滤。
- `tests/agent-token-policy.test.js`、`tests/agent-auto-continuation.test.js`：知识问答预算、较低管理员限额、累计用量恢复及执行轮次上限。

## 浏览器专项

执行命令：

```powershell
node scripts/run_e2e_tests.js chat-agent-waiting.spec.js --workers=1
```

1 项通过。使用真实 Chromium 页面、登录与会话接口，对任务详情和状态响应进行受控模拟，检查：

1. 等待补充时已有答案、具体缺口与累计输入输出用量可见。
2. 同一任务响应重复三条，且并发触发三次恢复，仍只有一张卡片。
3. 等待输入期间停止轮询，继续后恢复原卡片并显示补充后的结果。

该专项验证任务展示与恢复行为，没有对截图中的真实 Qwen 模型发起端到端负载测试。
