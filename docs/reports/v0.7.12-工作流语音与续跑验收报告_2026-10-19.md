| 长回答漏读、重复读、误报播放失败 | 短段完整播放，补齐最终尾部，重复完成不重读 | 超过 2000 字全文回放、播放事件与看门狗测试 |
| 说退出仍继续对话 | 在聆听、等待、朗读阶段均可结束语音并清理资源 | 退出指令、普通解释问题不误退出、请求与麦克风清理测试 |
| 完成录音丢尾句或第二段 | 先收尾再清理，保留工作线程尾包及排队结果 | 浏览器停止、384 采样尾包、两段排队转写与取消后迟到结果测试 |
| 低音量、自然停顿被漏掉或过早切句 | 调整触发与预录，容忍短停顿 | 低于旧阈值的 PCM 与 800ms 停顿测试；Windows 中文合成音频实际识别验证 |
| 点击继续申请原始总预算而失败 | 在事务内继承实际剩余额度，两层预算同步收紧 | 使用 2048000 总额、1735413 剩余额度精确复现的 PostgreSQL 回归 |
| 真正预算不足显示内部错误 | 返回 409 与业务错误码，保持更小和零额度约束 | 耗尽、预留扣减、更紧总预算、零额度与并发双击测试 |

## 实际运行证据与边界

Windows 测试在内存中合成固定中文语音，运行真实系统识别工作脚本，分别验证自然结束和发送 `finish` 指令两条路径，得到 `started → result → ended`，不打开麦克风、不播放声音。默认与新停顿参数的同一音频对比显示分段从两段合并为一段，但识别错字没有改善，因此没有整体字错率提升的结论。详见 [语音专项报告](语音功能版本对比与优化验收_2026-10-19.md)。

瀑布图浏览器验证使用真实页面脚本及 HTML 安全组件，通过受控接口响应驱动状态变化；不把它描述为生产工作流完整执行验收。390 像素窄屏截图已人工检查，弹窗、状态说明和节点行没有横向溢出。运行查找的兜底范围为最近 100 条个人运行，未匹配时显示说明，不展示伪造状态。

本次完成源码版本及文档升级，未构建安装包、修改生产数据、提交推送 Git 或部署服务。网页与预算修复需更新服务端，Windows 原生语音优化需同时升级桌面客户端；用户实际麦克风、扬声器与生产任务仍需上线后复验。
