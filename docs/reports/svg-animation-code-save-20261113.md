# SVG 声明式动画与代码保存输入修复

日期：2026-11-13。执行时源码版本为 v0.7.157；本次没有重新构建主镜像或桌面安装包，也没有发布生产。

本次修改随后归档于[v0.7.158发布说明](../releases/v0.7.158-SVG声明式动画与代码保存弹窗修复.md)并启用新源码版本；下述功能测试和截图保留执行时的 v0.7.157 身份，不把源码升版当作新制品构建或生产验收。

## 问题与修改

聊天 SVG 预览原先只允许静态图形标签，直接拒绝 `animate`、`animateTransform` 等元素；服务端 SVG 代码保存入口也会拒绝动画。代码文件名与多个本机授权目录的选择调用原生 `window.prompt()`，在 Electron 中报不支持。

- 前后端共用声明式动画属性规则，仅在 SVG 代码预览及受控保存入口启用。支持 `animate`、`animateTransform`、`animateMotion`、内部路径 `mpath` 与安全 `set`，保留现有安全 CSS 关键帧动画；禁止动画修改链接、事件、样式、标识符或命名空间，不加载脚本与外部资源。动画元素最多 256 个，继续受源文本大小、节点和结构限制约束。
- 图形继续作为 Blob 图片加载，不把模型生成的 SVG 节点插入聊天主文档。预览、放大及下载保留受支持动画，生命周期继续释放图片 URL；通用静态图片转换入口仍默认拒绝 SMIL 动画。
- 代码文件名和多授权目录序号选择复用 `showInputPrompt`，不再调用原生 `prompt()`。取消不发起交付；输入完成后仍复查原账号、原代码块和原始内容，再经原有 Artifact、Rendition 与桌面授权交付链保存。
- 手机或普通浏览器没有桌面授权桥时，“保存到本机”明确引导使用下载文件或下载 SVG，不预先创建本机交付产物。

## 实际验证

通过项目隔离 PostgreSQL 测试入口运行六个相关测试文件，共 30 项通过，无失败或跳过：SVG 动画规则、代码语言及格式映射、真实受控接口创建和下载、桌面目录选择、HTML/代码浏览器预览、Mermaid/SVG 浏览器预览。后续对动画与输入弹窗两项浏览器场景复验通过。

浏览器检查覆盖两个时刻动画画面不同、旋转/位移/路径动画及 CSS 动画保留、下载与本机保存、原生 `prompt()` 不可用、取消、多目录、账号变化和桌面/390px 窄屏弹窗。真实接口验证动画 SVG 可按原授权创建并下载；危险属性动画、事件触发、脚本、外链和扩展名伪装继续被拒绝。截图保存在 `output/svg-animation/` 与 `output/code-preview/save-modal-390.png`。

## 边界与部署

只支持受限的声明式动画，不支持 JavaScript 驱动或依赖外部资源的 SVG 交互。预览以图片文档运行，不接受点击等交互式动画触发。手机浏览器的文件去向由浏览器和操作系统决定，“保存到本机授权目录”仍是桌面客户端能力。

预览、输入弹窗及服务端代码文件校验均随服务端代码和静态资源部署；按当前容器交付方式需要重建并部署主镜像，然后刷新客户端页面。没有新增桌面 IPC、数据库迁移、依赖或必填配置，不需要为本次输入弹窗修复单独升级桌面客户端。未完成生产环境部署、真实手机系统文件选择或 Electron 原生磁盘落盘验收，不能把受控浏览器接口验证等同于这些验收。
