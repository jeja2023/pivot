# 聊天任务预算与语音体验验收报告

版本：v0.7.11。日期：2026-10-19。

用户先报告 HTTP 桌面语音的安全地址提示，随后确认更新客户端后识别与实时语音均已正常，要求仅做小幅优化。本次保持原识别与本地朗读链路，增加阶段状态、播放错误提示和句末及时入队，未关闭浏览器安全机制或新增语音服务。

另一问题定位到聊天自动任务固定 60000 Token 累计预算。改用已配置模型窗口的 8 倍、最低 500000、自动最高 10000000；256K 模型为 2097152。正整数部署配置、显式任务预算和既有审批快照继续生效。任务草案启动时累计预算与审批快照一致。单次上下文继续保留输出和安全余量，步骤、超时、风险与审批边界不变。

预算验证覆盖 256K 窗口自动分配 2097152，累计消耗超过旧 60000 后仍可继续，显式小限额继续阻断，正数部署限额优先，自动上限有界，单次模型窗口仍扣除输出预算和安全余量。聊天自动接管保留工具、步骤与审批边界；任务草案启动使用审批快照预算。

语音验证覆盖 HTTP 非安全页面没有浏览器麦克风接口时，桌面原生识别通道仍可用；旧桥缺失和 IPC 不匹配提供升级提示。识别结果、连续两轮问答、朗读、停止与临时会话不落聊天记录均通过。阶段状态、句号末尾及时入队、实际声音语言、朗读失败与资源释放另有定向回归。

窄屏验收发现旧样式压缩器错误拆开 CSS 变量名，导致 collapsed 侧栏的负边距失效。删除该重写并增加构建测试；最终在 1280 与 390 宽度验证状态条可见且宽度正常，截图已人工检查，保存于 output/voice-status-1280.png 和 output/voice-status-390.png。该修复没有改变语音引擎。

浏览器自动化模拟音频/桌面 IPC 事件与本地播放回调，模型交互走真实测试后端。用户本轮已确认更新客户端后的实际识别与实时语音正常；本次未再次调用生产麦克风或扬声器。

完整 Node 测试后仅补充了上述三项构建回归、窄屏样式修复与一处空闲阶段提示，均由定向测试、最终浏览器回归及静态检查覆盖，没有重复扩大后端测试范围。

本次交付为本地代码与文档，未部署生产，未改写生产 .env、模型设置或旧任务。生产应用时需将所用模型的实际上下文窗口配置为 262144，并将 AGENT_TASK_MAX_TOKENS_TOTAL 设为 0/留空以启用自动预算；重启/重建服务后新任务生效。若保留原有正数值，则继续采用该明确累计限额。
