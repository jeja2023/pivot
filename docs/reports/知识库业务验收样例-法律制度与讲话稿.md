# 知识库业务验收样例：法律、制度与讲话稿

本文件使用虚构资料和问题，供建立测试用例与人工标注流程使用，不代表任何真实法律、企业制度或领导讲话，也不能替代生产语料黄金集。导入实际资料后，需由资料所有者填写真实文档、版本和页码，并由另一名业务人员复核。

| 场景 | 测试资料与问题 | 预期检查 |
| --- | --- | --- |
| 法律条款定位 | 虚构《测试条例》第二条：测试资料应记录来源。问“第二条要求什么？” | 命中正确条款，引用真实片段和章节；不补充未规定的义务 |
| 条款不存在 | 虚构条例没有第九条。问“第九条是什么？” | 明确未找到，不把其他条款当成第九条 |
| 制度多版本 | 同一虚构制度两版对办理期限作不同规定 | 只依据当前授权且有效版本回答；历史版本可区分，不能混为现行 |
| 长制度尾部 | 在超过首轮字符预算的文件末尾放置虚构条款 | 首轮显示覆盖不完整；续处理后尾部可检索且前文仍可检索 |
| 扫描 PDF | 混合可复制文字页与扫描页，超过一轮 OCR 预算 | 后部原生页不漏；扫描页分轮处理，失败和遗漏页可见 |
| 讲话稿分节 | 虚构讲话稿含“一、加强基础建设”“二、完善协同机制” | 分段保留标题；后半部分主题和来源能被定位 |
| 讲话稿全文概览 | 在讲话开头和尾部设置不同的虚构主题 | 回答清楚说明覆盖范围；未检索到尾部时不能声称已覆盖全文 |
| 权限隔离 | 用户 A 的私有制度，用户 B 同单位但非所有者 | 列表、检索、原文、引用、Wiki 和对话均不能向 B 返回资料 |
| 删除撤回 | 停用或归档虚构资料及其 Wiki/图谱衍生内容 | 新查询不能继续使用失效来源；历史审计受既有权限约束 |
| 注入与拒答 | 资料包含伪造引用标记，问题缺少可用依据 | 伪造标记不能成为来源；没有依据时服务端拒答 |

建议将真实业务资料至少覆盖法律、企业制度、规范和讲话稿四类，每类分层标记长短文档、OCR、复杂表格、版本变化和无答案问题；分别记录检索召回、引用准确性、答案完整性、拒答与权限结果，并记录每次运行的模型和索引配置。运行、容量和恢复流程见 [生产验收指南](../deployment/知识库生产验收与恢复演练.md)。
