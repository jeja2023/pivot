# v0.7.13 聊天 Markdown 与样式验收报告

日期：2026-10-20。版本：v0.7.13。范围与升级步骤见 [发布记录](../releases/v0.7.13-聊天Markdown渲染与阅读样式修复.md)。

## 问题、行为与证据

| 问题 | 修复后的行为 | 验证方式 |
| --- | --- | --- |
| 中文引号、标点附近残留星号或下划线 | 正确渲染加粗、斜体、嵌套强调与多余空格 | 按用户截图中的法规目录结构复现，并覆盖中文引号、括号、书名号等边界 |
| 流式或最终回复漏写强调闭合符 | 按段落恢复，思考块同步处理 | 逐字符回放、最终结果一致性、跨段落与思考块回归 |
| 链接文字直接显示格式字符 | 内联解析链接文字，保留原始地址和标题 | 格式化链接、带特殊字符地址、代码及公式原文保留测试 |
| 父级列表符号被嵌套任务项隐藏 | 普通父项保留项目符号 | Chromium 检查真实计算样式 |
| 表头对齐失效、长单元格撑宽 | 对齐正确、长文字换行、多列仍能滚动 | 桌面与窄屏检查对齐、单元格行高及末列可访问性 |
| 窄屏代码按钮挤压、引用代码变斜体 | 工具栏分行，按钮完整可点击，代码为正常字形 | 320/390 像素浏览器验证与实际复制操作 |
| 长公式开头被居中裁切 | 首尾均可滚动查看 | 检查公式起始元素和滚动到末端后的边界 |
| 长模型名称或统计溢出、消息按钮越界 | 名称省略、统计换行，窄屏按钮位于气泡内 | 历史、流式、最终和任务统计四条渲染路径验证 |
| 深色回复与表格文字不易辨认 | 使用主题变量，代表性正文对比度不低于 4.5:1 | 深浅主题下计算回复、表头、思考正文及用户表格的颜色对比度 |
| 系统选择减少动态效果后仍持续动画 | 消息入场、思考脉冲与展开过渡关闭 | Chromium 模拟减少动态效果偏好并检查实际样式 |
