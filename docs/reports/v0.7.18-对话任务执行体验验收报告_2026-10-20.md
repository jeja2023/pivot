## 2. 自动化回归

使用 `scripts/run_node_tests.js` 在独立 PostgreSQL schema 执行 142 个 Agent、聊天、产物、本机执行及相关安全测试文件：**767 项通过，0 失败，0 跳过**。

新增专项覆盖：

- `tests/chat-task-feed.test.js`：游标/页大小校验，模型事件与敏感字段过滤，账号与已删除会话隔离，隐藏事件后的游标前进，旧步骤分页，真实文件字节与过期状态，开始/完成/复用/重试/暂存差异。
- `tests/chat-task-state.test.js`：重复和乱序合并，同一操作唯一展示，历史读取不倒退当前状态，等待/终态不受模型流覆盖，断线与未确认结果。
- `tests/chat-task-controls-http.test.js`：真实鉴权与归属，过期审批拒绝、重新申请、旧参数失效，并发点击只保存一份授权，不覆盖同期任务要求；暂停与越权请求。

既有相关回归继续覆盖模型原生流与规划式执行、审批撤销、检查点恢复、暂停取消、续跑链、语义任务接续、预算、外部副作用及下载/本机权限边界。新增实际开始事件和控制路由拆分后，既有契约测试同步定位新的职责模块，没有降低原行为要求。

## 3. 浏览器证据

命令：

```powershell
node scripts/run_e2e_tests.js chat-task-execution.spec.js chat-agent-waiting.spec.js --workers=1
```

**5 项通过**，覆盖：

1. 等待补充保留答案、缺口与用量，重复恢复只有一张卡片，等待期间不持续轮询，继续后复用原任务。
2. 实际工具执行阻塞期间显示执行中；模型参数流结束不会提前显示成功；工具返回后更新同一操作；实际创建文件、下载并核对字节；完成刷新后回看。
3. 审批卡不被迟到模型流覆盖，批准携带当前请求绑定；断线显示未知并保留最后确认状态，恢复后重新读取；重新验收时不显示旧通过结论。
4. 多任务选择，补充和暂停只作用于指定对象；停止文字流不取消任务；历史翻页按原顺序合并，切换会话后迟到响应不写入新会话。
5. 长操作名、错误、审批和文件卡在浅/深主题及 1280/390/320 像素共 **6 组组合** 下无页面、任务过程或状态栏横向溢出，正文对比度达到 4.5:1；启用减少动态效果。

浏览器发现并修复了状态栏继承输入区 `pointer-events: none` 导致按钮无法点击的问题。截图经视觉检查，任务内容在桌面与窄屏可读，暗色任务与状态栏使用全局主题变量。
