## 本轮完成

| 能力 | 实际行为 |
|---|---|
| PDF | 指定历史版本的图形经严格 SVG 清洗、现有 PNG 渲染后进入公共 Document IR/PDF 底座，使用横向 A3 页面适配全图；输出进入原有 CAS/Rendition/一次性下载链 |
| XMind | 导入单画布、含 `content.json` 的现代 XMind；导出可被现代结构解析的 `.xmind` 压缩包，往返验证层级、纯文本备注、关联线、概要与有限颜色；不承诺所有 XMind 专有布局/样式无损 |
| OPML / FreeMind | 导入导出层级、文本、稳定 ID、纯文本备注和受支持链接；FreeMind 另保留基础颜色、字号、折叠与关联线；原生 JSON 仍是完整备份格式 |
| 大纲编辑 | 按稳定节点 ID 修改节点文字，保留结构、样式与关联关系；普通画布继续负责增删和子树拖移 |
| 关联线与概要 | 配置起点、终点和说明，按父节点下连续分支序号添加概要；新增、删除、历史保存/回滚与导出共用规范格式，拒绝重复范围、悬空引用和非法 ID |
| 主题包 | 允许粘贴版本化的名称、中心色、连线色和背景色配置；禁任意 CSS、函数和外部 URL；主题随内容版本保存并包含在原生 JSON 备份中 |
| 导航与演示 | 导航图查看全局、拖动平移、点击适配全图；演示按节点聚焦、左右键或按钮切换并可退出，聚焦期间不写入正文变化 |
| 分支 AI | 基于当前用户有权读取的已保存节点和版本展开子树或总结；先预览，用户确认后添加子节点/写入备注；生成期间原稿变化时拒绝应用，关闭弹窗会取消请求 |
| 数据转图 | 选择本人数据集的已保存分类汇总图表，复用既有查询与字段治理链；预览后另存静态导图，记录实际执行视图的版本、数据集、生成时间和统计口径。共享来源暂不复制，特殊图表结果不满足规范时明确拒绝 |

## 安全与一致性改进

- 公共交付扩展名白名单补齐 SVG、XMind、OPML 和 FreeMind，使“渲染成功”与“实际可下载”一致；没有扩展执行类文件权限。
- XMind 输入限制为 2MiB、128 个归档条目、4MiB 总解压规模，逐条检查路径并对实际解压内容设置流式上限；不落地解压目录，不访问归档中的外部图片或链接。
- OPML/FreeMind 文本限制为 256KiB；拒绝 DTD/实体、非法 XML、超量结构和不支持的富文本节点。解析结果再次经过与手工保存相同的业务 Schema 校验。
- 节点/概要 ID 排除原型属性保留名；备注、颜色、链接、范围与主题包使用明确字段白名单，错误输入不会部分入库。
- 切换导出格式时立即移除上一份文件的下载按钮，避免误下载旧任务；渲染语义版本升级为 `mindmap-1.1.0`，旧语义交付不会被当作新渲染结果复用。
- 高级编辑的撤销重做改用最多 50 个规范文档快照，覆盖主题、布局、结构、文字、关系与概要，避免内核重载清空历史。历史版本持久化仍使用原有版本表，浏览器撤销栈与服务端版本是不同用途。

### 更新方式

在已有导图工作区即可看到新增格式和高级操作。新增 XML 解析器为显式生产依赖，源版本、锁文件和许可治理已更新。普通部署更新依赖与源码并重启服务后生效，本轮不新增数据库表；首版导图迁移仍需按既有启动流程执行。

限制继续保留：每图 120 节点、深度最多六、文本文件 256KiB、原生规范格式版本一。现代 XMind 多画布、旧式 `content.xml`、图片/附件、自由节点与复杂富文本暂拒绝；跨格式只承诺已验证字段。PDF 是适配整图的图像文档，复杂大图建议同时导出 SVG。

尚未包含多人实时协作、复杂富文本/附件、5000 节点流畅编辑和跨应用自动刷新；这些能力涉及权限、内容安全或资源边界的独立改造，没有开放无实现入口。
