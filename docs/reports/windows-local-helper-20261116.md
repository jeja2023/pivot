# Windows 独立助手开发验证

日期：2026-11-16，源码基线 v0.7.162。新增独立 Windows 助手程序、浏览器本机授权中心配对入口、受限签名通道、账号切换和安装构建脚本。

本记录随后归档于[v0.7.164发布说明](../releases/v0.7.164-Windows独立助手与浏览器本机控制.md)。测试、截图和安装包保留实际执行时的 v0.7.162 身份，源码升版不重标旧制品。

## 已实现

- 五分钟一次性配对，服务端仅保存配对码/凭据摘要；助手以 Ed25519 证明本机身份，凭据仅可访问助手专用通道。每次通道调用包含绑定动作和参数摘要的一次性挑战签名。
- 浏览器账号与浏览器设备 Cookie 摘要、页面会话随机证明绑定，后台任务使用服务端写入的独立绑定列，其他浏览器和调用方自报元数据不能选择该助手。浏览器15秒续期，45秒无续期后拒绝新操作，凭据最长8小时；正常退出、重新登录、撤销和重新配对使旧绑定失效。
- 助手在当前 Windows 用户数据目录使用系统安全存储加密持久化设备私钥与凭据。正常退出断开连接并清除状态；异常退出恢复仍受服务端到期和撤销约束。断开并更换账号先停止并等待旧任务，清空应用授权和身份，再以新密钥、新设备身份配对。
- 执行复用现有Windows可访问性驱动，前台窗口标题和进程名必须匹配；仅允许登记的检查、截图、点击、输入和等待。每次本机确认，输入显示拟填写内容；确认后再核验服务端任务租约和本机授权。停止后等待子进程退出，已领取超时动作不自动重放。
- 独立 NSIS 安装、卸载和手动升级；正式构建沿用现有发布签名配置并在缺失时失败。`--unsigned` 生成名称带 Dev 的开发验证包。无需安装Node.js或整个Pivot仓库。
