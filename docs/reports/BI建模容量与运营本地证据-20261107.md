## 环境与夹具

Windows 11 主机，Intel Core i5-10500、十二个逻辑处理器、约十六 GiB 内存；PostgreSQL 18.3，Docker Desktop 的 Linux 容器，Node v24.22.0。该配置与方案参考的三十二 GiB 应用主机和独立十六 GiB 数据库不同，不作为生产支持矩阵认证。

两档均为一张事实表加八张维度表，每表一百二十列，全部通过受控分块摄取创建版本。标准档位事实二十万行、维度合计两万；百万档位事实一百万行、维度合计两百万，输入共 `1619071258` 字节。包含复合粒度和关联键、百分之九十集中键、长字符串、高基数及每九十七条一条未匹配记录。常用查询两个维度、三个基础指标；复杂查询五个维度、十个指标，包含精确去重与派生比率。

每个输入保存 SHA-256、行列数与字节，实际输出依据可独立计算的金额、计数、去重和比率核对。新的执行器进程逐次启动；当前没有查询结果缓存，文件系统缓存未受控，持久结果再次读取另报。
