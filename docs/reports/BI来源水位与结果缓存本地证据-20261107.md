# BI 来源水位与结果缓存本地证据

对应 v0.7.122。原建设方案619条目录保持不变，未降低缓存、源版本、权限或性能合同。

## 授权与缓存

缓存键覆盖当前用户、模型/发布版、语义哈希、来源清单ID及摘要、规范化查询、时区和当前授权向量。先固定并验证来源，再在原持久任务内查找缓存。命中仍有独立运行ID、有效租约和槽位、实际结果与分页文件校验、最终授权/取消复核、引用及审计。权限变化但仍可读时退回重算；撤权、停用或取消先提交时不登记可读结果。损坏文件真实隔离，不以缓存掩盖完整性失败。

结果页面与CSV/XLSX显示原计算时间，来源水位保持原清单。指标有效期只限制新计算；历史结果保留全部结构依赖的当前授权，不因过期失去读取能力，也不能借缓存绕过排队后到期检查。

## 来源业务信息与追加

源版本 manifest_json 保存批次、业务期间、数据截止时间和业务覆盖。所有者补录需当前来源修订，生成新版本并递增来源修订；旧版本、文件及清单不可修改。空截止时间保留原数据时间，治理或描述更新不伪装数据刷新。共享接收者只读，HTTP真正发送前再次授权。

同批次/同期间策略可从真实版本成功形成多来源清单；缺失或不一致均拒绝。增量、部分和未知不能冒充全量，模型须明确声明部分分析。不同来源保留各自截止时间，不制造共同事务快照。

旧追加入口先固定上传原字节和摘要，再生成新CAS合并文件；批次、文件摘要、长度、行数和版本同时记录。无显式批次的旧客户端按文件摘要识别源记录身份，重命名重试也不重复追加；这不宣称消除了上游不同批次内的业务重复。显式使用不同批次代表新的追加意图。最终事务固定当前任务代次/槽位/租约和取消、当前所有权、来源修订、唯一批次、对象引用、数据指针、审计与任务成功，准备后变化或取消不产生版本。
