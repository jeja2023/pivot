# Windows 助手紧凑布局验证

日期：2026-11-16。基于独立助手开发验证版本调整窗口和表单布局，运行协议及授权逻辑沿用原实现。

功能及本记录验证在 v0.7.162 下执行，归档于[v0.7.164发布说明](../releases/v0.7.164-Windows独立助手与浏览器本机控制.md)；安装包和截图不随源码升版更改历史身份。

- 默认窗口由620×680调整为620×620，最小窗口为540×600；移除Electron默认英文菜单。
- 复用全局主题字体、输入框和按钮，正文13px、输入框34px高、按钮32px高，采用横向标签和统一操作行。进程名提供记事本及Office进程建议，仍允许自定义填写。
- 账号行紧凑展示账号和服务地址，完整设备信息可悬停查看；状态文本最多两行并保留完整提示。底部保留关闭与断开说明，不通过隐藏整个页面溢出来遮挡控件。
- 真实Electron分别验证620×620、540×600、760×680，覆盖明暗主题、长账号和长状态文字；核对实际内容区尺寸、页面无横向或纵向溢出、全部按钮可见、菜单隐藏、输入框高度与自定义进程输入。
- 布局及最终打包程序启动2项通过；ESLint、开发规范和文本检查通过。截图位于 `output/local-helper/compact-ui.png`。没有运行全仓测试；混合验证中的原生驱动场景曾因前台窗口不匹配而拒绝，已将原生执行测试与布局测试分开，未改动驱动授权规则。
- 更新后的未签名开发验证安装包位于 `dist-local-helper/build-1794830876049/PivotLocalHelper-Dev-Setup-0.7.162.exe`；本轮验证其启动和页面无溢出，没有重复安装/卸载验收或生产发布。
