# 思维导图应用开发与验收记录

日期：2026-10-25。项目基线：v0.7.42。本次交付对应设计方案的独立应用首版，并增加基础模板和 AI 整图生成；不将另列后续阶段的复杂富文本、图片附件、多人实时协作或大图性能目标计作已完成能力。

后续继续开发已增加格式互通、概要/关系、导航演示、分支 AI 和数据转图，详见[后续能力开发与验收记录](mindmap-extensions-delivery-2026-10-25.md)。本文保留首版时点的范围和验证结果。

## 已实现行为

- 应用中心新增「思维导图」，个人工作台与旧导图产物打开同一文档；刷新恢复当前文档，返回列表、切换应用和退出账号清理画布实例与监听。
- 文档按当前用户分页、搜索和排序；支持空白、工作计划、分析研判、会议纪要模板，以及检查后导入原生 JSON 或受限 Markdown。
- 使用 SimpleMindMap 精确版本 0.14.0-fix.3，裁剪出编辑、拖拽、选择、键盘、搜索、导出等所需插件。支持七种布局值、四套预设主题、大纲定位、增删改、子树拖移、撤销重做、折叠、字号/颜色/形状/字重和纯文本备注。
- 自动保存采用每文档一个在途请求、内容去重、3 秒防抖与 15 秒最大等待；幂等键在网络重试期间保持一致。冲突返回 409，不覆盖其他窗口修改，提供重载和另存副本。限流后延迟重试。
- IndexedDB 草稿按部署来源、账号、文档和基线版本隔离，保留七天、每用户最多二十份。草稿写入串行化，可关闭并清除，退出账号清理。草稿恢复会比较服务端版本；关闭页面仍依赖浏览器本地存储成功，不能承诺所有断电/存储损坏场景零丢失。
- 全量内容快照复用 `agent_artifact_versions`，恢复会生成新版本；旧裸树只在读取时转换，首次写入新快照，不批量重写旧历史。
- JSON、Markdown、SVG、PNG 导出是持久任务，固定源版本。SVG.js 的编辑器元数据经过归一后仍由原有严格清洗器校验；PNG 由已有 Sharp 渲染。输出存 CAS、登记 Rendition，下载沿用当前用户的一次性令牌与审计链。
- AI 通过现有应用模型权限、上下文/配额、用量和取消机制调用；服务端验证结果后展示预览，用户确认后创建新图，不覆盖当前稿件。

## 权限与可靠性

`client/common/mindmap-document.js` 是前后端共享的规范格式与校验实现；服务端再次校验所有写入。正文保存集中在 `server/repositories/mindmaps.js`，用户级请求锁、文档行锁、版本比较、快照写入和版本指针更新在同一事务内完成；重试回放原请求对应的快照，不把后来的其他修改当成自己的保存结果。

应用、新旧保存、Agent 工具与通用产物版本入口统一委托导图服务，或明确拒绝缺少冲突条件的旁路写入；通用产物管理器不能绕过导图保存、恢复、删除和个人访问规则。软删除后拒绝新编辑、快照访问和下载令牌签发，已有下载令牌兑换时也会复查归属及状态。

导出队列按租约认领，进程重启后可恢复过期处理任务；旧租约不能提交。每用户最多同时处理四个任务。不可变交付登记与 CAS 引用计数同事务提交，避免进程在登记后中断导致有效文件被零引用回收。失败可重试，内容保存与交付失败分离。

## 资源和部署

- 新增迁移：`202610250001_mindmap_workbench`，创建保存幂等请求和导出任务表及索引。仍复用既有正文与版本表。服务启动按现有迁移流程应用，未直接操作正在运行的生产数据库。
- `server/bootstrap.js` 注册导出恢复轮询。图形导出需要服务端可用的项目 Chromium 运行环境；缺失时任务返回可理解的失败，文本编辑与 JSON/Markdown 导出不依赖浏览器运行时。
- vendor 资源已构建并纳入源码分发，运行时不联网下载。普通部署直接使用受控资源；开发者使用 `npm run build:mindmap-vendor` 重建，`npm run check:mindmap-vendor` 检查版本、摘要、静态模块和许可。
- 裁剪后的 ESM 约 409KB，gzip 约 117KB，未包含 Quill、KaTeX 或实时协作依赖代码；不开放 `unsafe-eval`。来源、精确依赖及文件摘要在 vendor 的 `provenance.json`，版权/完整许可保存在同目录 `LICENSES.txt` 与 `docs/licenses/`。
- 应用 CSS 已重新构建。部署更新并重启服务后，刷新客户端可看到入口；本次没有重新打包安装程序，也没有替用户重启现有生产服务。

## 明确的产品边界

首版保留 120 节点、根深度零且最大深度六、每节点文本 120 字符、备注 2000 字符、文档 256KiB、每用户 1000 份有效导图、每图 1000 个快照的限制。到达上限时返回明确错误，不静默裁切。5000 节点全展开性能尚不满足流畅创作，未对外开放。

PDF/XMind/OPML/FreeMind、数据转图、复杂主题包、概要/关联线的完整编辑面板、演示、小地图导航 UI、附件和实时协作仍属于方案另列的后续扩展，未做虚假入口。规范文档可以保留受支持的基础关联关系，导入不支持的富文本/图片/附件等内容会拒绝，不悄悄丢弃。
