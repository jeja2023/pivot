## 落实边界

截图中的要求作为本次公文输出规范，并非参考配色。页面和字号强制采用截图值，公文内容中的任意字体/行距覆盖不再改变正式公文版式；报告、表格和备忘录仍使用各自通用样式。

源参数统一放在 `client/common/official-writing-format.js`。客户端只把正文和附件映射为 Document IR；DOCX/PDF 继续使用服务端统一 Renderer，无第二套二进制导出路径。

## 七项逐条证据

1. **页面**：固定 A4，页边距毫米值37/35/27/27；页眉15mm、页脚30mm。DOCX 写入 `linesAndChars` 网格、`linePitch=560`、与28字对应的字符间距，段落 `adjustRightInd`、`snapToGrid` 开启，固定行距560缇。Word 实际显示 LinesPage=22、CharsLine=28。PDF 每页按22行分页、基线间隔28磅，正文第一行因二字缩进容纳26字，续行28字。
2. **标题**：2号（22pt）方正小标宋_GBK，使用原字形、不伪加粗。按词边界和语义连接位置分行，以梯形/菱形排布；提供“标题分行”字段，只允许调整原题换行。过长的手动行在导出前报错，不能溢出版心后仍提示成功。
3. **主送**：3号（16pt）方正仿宋_GBK，标题下一个28磅空行；顶格，回行不缩进，自动使用末尾全角冒号。DOCX 段前560缇、首行缩进为零；PDF 同一段的后续行仍从版心左边开始。
4. **正文与层次**：3号方正仿宋_GBK、首行二字缩进；一级3号方正黑体_GBK、二级3号方正楷体_GBK，三级/四级3号方正仿宋_GBK。识别四种层级并规范序号形态；西文和阿拉伯数字绑定/嵌入 Times New Roman。格式转换不回写和覆盖用户原始正文。
5. **附件**：独立保存附件名称/正文。附件说明第一项前空一行、左空二字，标签全角冒号；多项自动生成半角阿拉伯序号，移除名称末尾标点。DOCX 使用左缩进+悬挂缩进，PDF 分别计算首行/续行位置；长名称续行与名称首字对齐。每份附件从新页开始，标识3号方正黑体顶格、不加冒号，附件页保留全篇页码。
6. **署名成文日期**：日期格式 `YYYY年M月D日`，不补零；日期右空四个字符网格。根据实际日期字体宽度计算中心，署名在上一行围绕该中心排布，较长署名可分行，不写死“右对齐即合规”。DOCX 给署名和日期保留同页关系。
7. **页码**：4号（14pt）宋体、半角数字，`— N —`。DOCX 使用 PAGE 域，全篇同节连续；PDF 在全部主文/附件排完后统一编号。5页样稿分别出现1、2、3、4、5，无附件重新从1开始的情况。

## 字体核验

本机字体目录实际存在下列字体，加载器检查内部名称，不接受仅改文件名的其他字体：

| 字体 | 实际 PostScript 名 |
| --- | --- |
| 方正小标宋_GBK | FZXBSK--GBK1-0 |
| 方正仿宋_GBK | FZFSK--GBK1-0 |
| 方正黑体_GBK | FZHTK--GBK1-0 |
| 方正楷体_GBK | FZKTK--GBK1-0 |
| 宋体 | SimSun |
| Times New Roman | TimesNewRomanPSMT |

PDF 字体资源表包含上述六种原字体。未使用 Noto 子集替代；通用非公文 PDF 的原 CJK 字体路径保留。缺字体时的拒绝行为有独立测试。字体未复制到源码，也未打包分发，部署要求见字体说明。
