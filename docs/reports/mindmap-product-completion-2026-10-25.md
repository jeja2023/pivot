# 思维导图产品功能补全与验收

日期：2026-10-25。接续[首版](mindmap-workbench-delivery-2026-10-25.md)和[扩展能力](mindmap-extensions-delivery-2026-10-25.md)，本记录是当前交付范围的最新说明。所有修改保留在当前工作区，尚未推送、发布安装包或重启现有业务服务。

## 本轮交付

1. **文档组织**：本人/共享范围、收藏及标签筛选，设置按用户隔离，不产生正文版本。标签最多二十个、每个三十二字符。
2. **个人模板**：从当前稿件保存完整结构、主题与备注，个人模板库可使用、删除；重复保存相同名称和内容返回同一模板，最多一百份。
3. **回收站**：所有者查看并恢复已删除稿件。恢复建立新版本并清除旧共享状态和权限，阻止旧客户端覆盖；历史版本配额已满时幂等恢复为新副本，原记录继续留在回收站。
4. **团队共享编辑**：所有者显式授权最多五十个有效账号为查看者或编辑者；只有所有者可共享、回滚、删除和导出原稿。共享接收者可以另存个人副本再导出。企业访问启用时，候选列表、授权和每次读取都限制同一有效组织，成员组织变化或失效立即影响访问。
5. **协作合并**：新增 Yjs 13.6.33，通过固定源构建的同源模块运行。以节点和字段为合并单元，正文、样式、关系、概要与来源经过统一规范校验后写入；协作状态、正文与版本快照同事务提交。删除父节点、循环移动、容量超限等不能安全合并时拒绝写入并提示另存副本，不静默丢失结构。
6. **协作撤销与恢复**：本地撤销只撤销当前客户端修改；远端合并不进本地撤销历史。会话 epoch 在关闭/重新开启协作时改变，旧会话更新被拒；每次同步/写入复查授权，撤权后转为只读，未同步内容可另存个人副本。
7. **链接与交付修复**：节点可维护 HTTP/HTTPS 超链接，安全独立打开；SVG/PDF/PNG 图形交付去除外部跳转包装，保留图标和受控源稿中的链接。导出处理器在登记 Rendition 前再次校验租约，已过期处理器不能生成有效登记。
8. **长流程可靠性**：离开工作区、切换文档或账号时为加载、同步和导出轮询设置序列栅栏，延迟响应不会重启旧会话。自动保存返回前后复查账号/文档，协作模型字段排序固定，避免无意义版本累积。退出账号同时清理本地草稿、画布、大纲、属性、个人模板选项和预览弹窗内容。画布销毁后延迟适配回调不再访问移除的 SVG。

## 协作协议与实际边界

此实现采用 **CRDT + 每两秒同源 HTTP 同步**，复用当前鉴权、连接限制和部署方式，不另起 WebSocket 服务。断网期间保留已打开编辑器的本地状态；恢复网络后按有效授权合并。隐藏标签暂停同步，网络错误和限流退避。它是已验证的多人共同编辑能力，不能据此宣称任意规模、完全离线站点或字符级实时光标协作。

不同字段/不同分支修改可以保留双方结果；同时改同一字段由 Yjs 的确定性合并规则裁决，服务端快照可用于核对与恢复。树结构仍是单父节点模型，不能把所有并发移动自动转换为用户期望的层级。服务端校验失败后不提交 CRDT 状态。

协作上限：规范正文仍为 120 节点、深度六、256KiB；单次更新最多约 384KiB 原始二进制、持久 CRDT 状态最多 2MiB，历史过大后提示另存副本。每份导图最多 1000 个快照；配额可见且不会静默覆盖历史。共享设置按 revision 并发校验，正文保存按行锁/版本或 CRDT 状态合并。

## 数据与部署

新增迁移 `202610250002_mindmap_product`，包括个人组织信息、模板、共享工作区和成员授权表。正文与快照继续复用既有 Agent 产物表；收藏/标签和共享权限不混入内容版本。迁移由项目既有启动流程执行，测试使用本机 PostgreSQL 18.3 的临时 schema，未使用业务数据做夹具。

新增显式生产依赖 Yjs，许可为 MIT；浏览器协作资源和全部依赖许可、文件摘要由 `npm run build:mindmap-vendor` 生成，`check:mindmap-vendor` 同时检查编辑器与协作模块。未引入任意代码求值、公共 CDN 或 P2P 外连。资源已经随代码构建，普通部署不需要运行时下载。

更新时安装锁文件依赖并重启项目服务，启动迁移完成后刷新客户端。没有自动替用户重启正在使用的服务，也没有执行提交或远程发布。
