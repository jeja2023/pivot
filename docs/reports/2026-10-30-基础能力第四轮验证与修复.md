# 基础能力第四轮验证与修复

日期：2026-10-30；对应版本：v0.7.73。使用本机隔离 PostgreSQL、测试服务、合成文件和浏览器；不连接生产业务数据。

## 修复

- 公文编辑区在工作区安全挂载后恢复固定编辑区域的可编辑属性；命名的新公文即使正文为空也会保存。相同文档的保存请求顺序执行，迟到的保存响应只确认它实际发送的快照；删除等待已发出的保存完成，避免文档复活。
- 公文保存使用客户端版本比较；不同窗口的旧版本修改返回冲突，保留本页内容并提示复制，重复提交相同内容仍保持幂等。未携带版本的旧客户端仍保留兼容行为，不能视作具有冲突保护。
- OCR / 文档处理配置先完整校验，在数据库事务提交后刷新缓存并返回；存储错误不再被异步吞掉。
- 文档处理执行使用独立 PostgreSQL 任务锁，任务内数据库调用绑定持锁连接；连接失效后旧执行不能回退到普通连接池继续写入。恢复扫描不抢占仍持锁的执行器，更新版任务按实际租约到期恢复，旧版本任务保留原有保守等待；临时页面与输出采用独立文件名。
- 语音浏览器测试中的合成音频在采集节点建立后播放，并避免对虚拟轨道执行设备驱动约束。
- 浏览器回归的被测服务使用正常异步 PostgreSQL 路径；测试专用登录配额与长数据分析流程时限按整套规模调整。监控页刷新测试等待登录状态恢复后再检查保存的子页，正式环境的限流策略不变。
- 离线备份清单扩展到文档处理、分析、Agent 大对象、运行包及技能目录；临时目录排除，缺失的默认可选目录明确标记，显式指定却不存在的目录报错。旧版清单可校验并提示覆盖范围。
- 文档处理维护任务会分批核对新版任务生成的页面与输出，清理至少 30 天前、任务已终结且没有数据库引用的孤儿文件；清理时持有任务锁并检查等待中的导出。历史命名、通用 `tmp`、原文件和找不到任务归属的文件不自动删除。

## 验证

- 真实浏览器和隔离数据库验证公文空正文保存、保存期间继续编辑、跨窗口冲突、删除期间保存及文本导出；知识库重复导入、删除后的独立检索；PDF 合并、刷新与下载；演示文稿编辑、刷新与 PPTX 导出。
- OCR 通过本机受控 HTTP 服务验证两页识别中一页失败、失败页重试及保留已成功页。模拟服务返回预设结果，此测试不评估真实 OCR 精度。
- `npm run drill:application-restore` 使用随机测试 schema 和独立应用，恢复数据库及受控目录后重新登录，核对会话、附件、数据库运行配置、OCR 配置、分析数据、PDF 输出和 Agent 文件。环境配置和加密密钥不在备份包中；本演练使用测试配置，并不验证真实密钥恢复。
- 针对文档任务持锁和慢 OCR 的真实 PostgreSQL 专项，以及连接器重试、权限和重启相关测试均通过；浏览器下载、中断与租约失效用例在六个低优先级、约半负荷 CPU 工作进程同时运行时各重复三次，共 9 项通过。该有限负载不代表生产容量测试。
- 最终完整浏览器回归 103 项通过、0 失败；备份扩展后的完整 Node 回归 2417 项通过、0 失败、0 跳过，包含隔离 Docker 和 FastMCP 的真实集成。扩展后恢复演练和备份专项通过。外部容器、网络及临时密钥已由测试脚本清理；工程检查、lint 和类型检查通过。
- 双执行进程故障测试强制终止旧执行器的 PostgreSQL 持锁连接，新执行器重领并完成 OCR，迟到的旧结果不能覆盖新页面；同时验证运行中的任务不被重领及旧版本任务保守恢复。该测试覆盖 OCR 结果路径，不代表所有外部服务和文件故障组合均已覆盖。
- 孤儿清理补测实际强制终止隔离执行器、恢复任务并清理过期未登记页面；覆盖已登记引用、任务仍活跃或最近更新、持锁、待导出、未知及历史文件、目录链接、数据库异常和分批扫描。相关 OCR 与 PDF 浏览器路径 2 项通过；随后完整 Node 回归 2422 项通过、0 失败、0 跳过。

## 未完成的边界

- 旧版本执行器不具备新的持锁连接围栏，升级时不应与新版执行器混跑；旧任务仍按保守窗口恢复。历史命名、通用 `tmp` 和缺少任务记录的遗留文件需单独核对，不能由新版自动规则认定为安全可删；未验证所有 PDF 输出和跨进程故障组合。
- 受控浏览器关闭在更高负载和长期运行下仍需稳定性观察；有限次数的负载复测不能证明不会复发。真实 OCR、业务文档样本、生产数据和目标设备验收仍属后续工作。
- 早期完整浏览器回归出现过真实音频超时、数据分析长流程超时、测试登录限流及监控恢复时序问题；经调整测试时序和隔离配置后，相应专项及最终完整回归通过。有限次数的回归不能证明所有设备和负载下不会复发。
