- 更早迭代分别发现 Windows 参数/路径、空 PostgreSQL 目录、密文硬链接临时移除导致 ctime 变化、Linux 私有套接字/溢写目录、忙碌磁盘连接超时等问题；失败日志保留，不改写为通过。Linux 第四/五次已知旧夹具运行被主动停止，不能作为成功证据；第六次恢复及查询完成至 HTTP 入口，但测试配置缺少生产指纹密钥，整项失败。最终夹具在长复制前先验证生产配置，并还原及复用真实托管配置。
