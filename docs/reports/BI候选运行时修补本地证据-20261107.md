# BI 候选运行时修补本地证据

v0.7.123固定DuckDB Node API/绑定1.5.6-r.2；官方[1.5.6维护发布](https://www.duckdb.org/2026/09/28/announcing-duckdb-156)包含正确性、性能及安全维护修补。随后实际原生入口检查发现 Linux 缺失 SQLite 绑定，以及 Windows 普通 Node ABI137绑定不能在 Electron ABI148 下加载。最终依赖差异限于 DuckDB 包组及 SQLite 维护补丁，其余锁文件组件不变；原始失败和修补前制品继续保留。

SQLite 采用官方[12.11.2发布](https://github.com/WiseLibs/better-sqlite3/releases/tag/v12.11.2)补充的 Electron43资产，核心仍为SQLite3.53.2。npm官方注册表对12.11.2返回404，实际锁定[官方源码归档](https://codeload.github.com/WiseLibs/better-sqlite3/tar.gz/refs/tags/v12.11.2)及锁文件SHA-512；归档下载后逐字节核对。Windows Electron148、Windows Node137及Linux Node127资产核对官方GitHub发布API提供的SHA-256，保留来源URL和摘要，不使用未标明版本的第三方二进制。

## 适用性与修补边界

扫描发现的CVE-2026-58139实际针对AWS扩展的凭据读取策略，见[CVE原始记录](https://raw.githubusercontent.com/CVEProject/cvelistV5/main/cves/2026/58xxx/CVE-2026-58139.json)。不能把核心库版本号单独作为适用性结论。正式执行器禁用自动安装/加载及外部访问、锁定配置、无凭据，AWS扩展未安装/加载；实际LOAD aws被拒绝。维护升级仍完成全功能回归，不把扫描不再命中当作唯一证明。

Windows扫描将本项目名称Pivot匹配到2006年的同名PHP产品。原始[CVE-2006-3531记录](https://raw.githubusercontent.com/CVEProject/cvelistV5/main/cves/2006/3xxx/CVE-2006-3531.json)指向includes/editor/insert_image.php和PHP数组认证参数；本候选为Node/Electron项目，不包含该PHP产品。保留原始扫描和逐项组件不适用结论，不加入全局安全白名单。

Debian原生库的二进制CPE版本可能省略发行版回补修订。实际镜像通过dpkg核对文件归属及sourceVersion，再与官方bookworm安全源修补版本逐项比较。尚未解决的所选基线告警保持开放，发行版no-dsa、postponed或低优先级不等于安全通过。Windows签名使用现有自签名链，标准门禁实际拒绝，未改变系统信任设置。
