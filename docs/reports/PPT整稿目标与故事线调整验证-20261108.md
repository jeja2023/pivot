# PPT整稿目标与故事线调整验证

日期：2026-11-08。关联版本：v0.7.132。

## 实际变更

创建表单共用受众、整稿目的、阅读方式与目标时长，标准AI生成结果保存同一份目标。PPT Master的合同、提示、公开任务查询和交付元数据保留目标；制作窗口刷新后能从任务恢复目标，当前未提交的表单修改在同一会话重新打开时保留。

结构化编辑侧栏保持“结构”短名称。整稿目标默认折叠，当前页维护职责、核心结论、阶段、信息关系、与下一页的衔接和讲解时长；前后页标题来自实际页序。续写和改写继续使用整稿目标。

“按故事线调整”先创建后台任务并返回方案，文稿不在生成阶段改变。统一预览弹窗完整换行展示页序、原结构与建议结构、原文字与建议文字；明确确认后保存新版本。范围、已批准页、锁定对象、已有文字、数值和可检出的溢出均在服务端校验。

确认核对当前权限、原版本和内容摘要，最终文稿条件更新还比较原稿JSON，覆盖自动保存不增加版本号的情况。文稿、所有者独立产物及两个版本登记使用同一显式事务，冲突没有部分提交。已提交的确认可重试，未提交的过期应用租约可恢复。最近任务按数据库精细时间排序，避免同秒取消和重建读回旧任务；通用工具任务入口也核对当前文稿可见性，并沿用故事线取消规则。

## 验证范围与限制

逐页调整用于结构化在线编辑器。原稿PPTX继续使用原生对象编辑与完整引擎的既有确认流程，本轮没有把任意PPTX自动转成结构化画布。

数值保护以当前页已有文字和备注为依据，未出现的数值不能由模型自动补入；图表、表格、来源、证据登记和素材保持不变。检查不能替代事实含义核对，也不代表所有字体下的真实Office渲染均通过。方案文字仍须在预览中人工审阅。

本轮未运行全仓全部测试、真实模型质量盲评或新的真实PPT Master容器/Office渲染验收；此前完整引擎证据不作为本轮新增通过项。未修改生产配置、部署生产或构建安装包。
