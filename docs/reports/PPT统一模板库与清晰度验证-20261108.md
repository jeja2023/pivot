# PPT统一模板库与清晰度验证

日期：2026-11-08。关联版本：v0.7.131。

## 问题与修复

截图中的深色封面有白色标题，但编辑画布没有应用保存的幻灯片背景，透出了浅色工作区。形状改由共享SVG绘制后，外层仍保留默认实线边框；切页时异步图片加载还可能覆盖新页的背景。现已使用文稿背景、清空旧图并校验异步图片引用，外层形状不再重复绘制边框。

换主题时原实现提前替换背景和字体，保留了旧文字颜色。现仅在明确换主题时由服务端模板快照一起处理配色，不在普通保存中改写自定义颜色。默认模板内的低对比标签、页脚等另存新版本，保留旧版定义和摘要。

## 模板组织与权限

模板库统一显示三类通用用途、单位/个人、固定PPT Master制作模板和历史主题配色。默认自由设计，无需先挑模板。结构化模板和原稿PPTX的制作方式明确区分，没有把两种格式宣称成可以任意互换。

当前固定发行包登记14类Style制作模板，名称和用途用中文说明；由固定ID映射包内目录，客户端不能提交任意脚本或运行包路径。单位模板沿用租户、个人、单位/部门及发布状态判定，并固定实际来源版本；下架撤权会阻止新制作，历史版本读取不受新目录筛选影响。

## 范围

对比度断言针对明确实色背景及完整包围文字的实色矩形卡片。图片背景、复杂透明或渐变叠加、所有字体和目标Office版本均未获得全面兼容结论；没有对用户原稿进行自动批量改色。当前管理员导入沿用PPTX和Pivot JSON模板合同，PPT Master生成的任意ZIP工作区仍不自动安装或发布；统一目录中上游Style为固定版本的14类已登记模板。真实模型成稿质量盲评不在本轮范围。当前改动保留本地，未部署生产。
