# PPT Master独立服务与标准回退验证

日期：2026-11-08。关联版本：v0.7.135。

## 变更与边界

完整引擎新增独立服务入口和稳定协议1，Pivot通过内网鉴权接口传递输入快照、固定动作并下载文件，主应用的账号权限、模型调用、确认、预算、任务租约、CAS及下载令牌保持原有职责。服务版本和引擎提交由服务自己的完整包校验确认，Pivot按协议与能力检查接入；正在处理的任务固定运行包身份，不跨升级混用。

独立服务不挂载Docker socket或Pivot任务目录，服务端只接受不可猜测任务标识、固定入口和文件类型。输入、输出、动作JSON与日志都有对应限制；重复动作标识只能读取同一请求的完成结果，中断动作不会自动重放。密钥不进入动作进程环境。动作进程通过libseccomp拒绝Internet socket，保留LibreOffice所需本地Unix socket。

服务未配置或不可用时，标准PPT创建、编辑、故事线及导出不调用完整服务。依赖完整引擎的原稿和视频功能明确显示不可用，不把该状态描述为本地原稿引擎已经就绪。

## 已完成验证

- 首批54项Node/PostgreSQL相关回归全部通过，无跳过，包括服务协议/鉴权、取消转发、文件摘要与大小、重定向拒绝、标准可用性提示，以及既有Master、原稿、模板、故事线和直接Docker兼容回归。
- 真实浏览器在配置了不可连接的服务地址时完成标准AI大纲与三页创建、结构编辑、PPTX导出和令牌下载。使用本机确定性模型夹具，不据此判断真实模型设计质量。
- 首次真实服务容器已生成原生PPTX与项目源包，校验文件摘要和实际页面文字；匿名访问被拒绝，跨用户输入不可读取，越界路径被拒绝，动作进程实际不能创建Internet socket。没有挂载Docker socket或共享工作区。首批服务Python五项在该Linux容器内通过。

## 未扩大结论

当前没有部署目标生产服务器，没有运行全仓全部测试、真实模型质量盲评或全面Office/WPS渲染矩阵。服务升级需保持协议1及实际消费能力兼容，任意不兼容的上游版本不能靠替换标签保证兼容。运行中的动作在服务重启时会中断并保留状态，不能称为无中断升级。
