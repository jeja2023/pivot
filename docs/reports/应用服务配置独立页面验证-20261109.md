# 应用服务配置独立页面验证

日期：2026-11-09。关联版本：v0.7.137。

## 变更

设置将OCR、语音识别和PPT Master移至独立“应用服务”页，聊天、向量、重排序和检索策略保留在模型配置。原有配置弹窗、接口、加密存储、连接测试及运行读取继续复用，未迁移配置值、改变服务协议或部署容器。

应用服务页使用现有管理员导航和统一卡片/表单样式，写入与测试仍受服务接口权限保护。独立加载具有请求序列、账号和可见分区检查；切走取消旧加载。目录搜索仅筛选已有卡片，不重置服务配置或密钥状态。

## 验证范围

- 最终30项Node回归通过，无跳过，覆盖设置页面合同、导航和模板组装；模型页仅保留模型/策略，应用服务独立入口及两个延迟/常规事件入口均有检查。
- 最终6项真实浏览器流程通过：模型与应用服务导航分类、三个既有配置弹窗、搜索/空结果、保存后搜索不重置配置、刷新恢复入口、管理员/普通账号边界、关闭后的迟到响应保护、慢加载切走保护，以及PPT和语音配置保存/测试/即时应用/密钥不回显回归。
- 普通账号直接请求应用服务分区会回到可用的模型页；非系统admin管理员可查看服务状态，但不能获得配置按钮，PPT配置接口仍返回403。后端权限和加密保存复用现有实现，未增设旁路。
- 实际查看桌面与390px窄屏截图，宽度不溢出，窄屏可滚动到PPT服务配置按钮并打开弹窗。搜索仅筛选已有卡片，不重新灌入旧配置。
- `npm run check`、定向ESLint、TypeScript与差异空白检查通过。首次导航测试发现懒加载事件入口漏接新标签，已同步常规/延迟两处接线并回归；慢OCR检查不再阻塞卡片展示，地址变化后旧检查结果不会覆盖新状态。
