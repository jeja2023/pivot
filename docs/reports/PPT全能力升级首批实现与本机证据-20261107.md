# PPT 全能力升级：首批实现与本机证据

日期：2026-11-07。本报告记录实际代码和验收结果；全能力目标见 [升级与对标方案](../design/PPT全能力升级与PPTMaster对标方案-2026-11-07.md)。本轮不作“各方面已高于 PPT Master 两个档次”的结论。

本轮改造汇总纳入 [v0.7.126](../releases/v0.7.126-PPT原生能力与技能格式兼容升级.md)。本报告保留执行当时的专项证据和失败边界；版本号登记不使历史证据自动成为完整发布验收。后续底层能力优先按[完整引擎复用方案](../design/PPTMaster整体引擎集成与复用方案-2026-11-07.md)接入。

## 已实现

- 原生形状由 4 类扩展为 187 类。采用固定版本 DrawingML 数据，按实际宽高及调整参数求值；工作台有中文形状目录和几何参数控件。PPTX 保留原生预设与调整值，PDF 保留形状矢量路径。
- 图示支持节点/连接数据，流程、循环、层级和关系图共用计算。循环闭合、层级拒绝循环；原生 PPTX 中连接线附着到对应节点，组合可继续编辑。工作台可改节点和连接。
- 多序列、负数与零值在编辑器、演讲者视图、远程展示、SVG/PNG/PDF 中共用图表场景。表头样式保留；修复原生图表工作簿零值为空的问题；拒绝空数值、非法饼图与超出支持范围的数值。
- 逐页来源不再机械关联全部材料。新增页面职责、核心结论、故事线阶段、信息关系、时长，以及事实/推导/假设/建议。证据片段记录原文、偏移、原文摘要和定位；明确计算可复算。正文、图表数据或讲稿变化使旧论点绑定失效，单纯移动对象不会使内容绑定失效。
- 制作目标及故事线可在工作台编辑。默认适应画布，仍可手动缩放；保存与刷新恢复沿用既有持久化机制。
- 后台质量任务新增交付检查，回读最终 PPTX 的对象身份、文字、单元格、图表缓存/嵌入工作簿、图示连接、资源和备注。报告分别列出事实、版式、原生文件、视觉及 Office 范围，原文片段匹配不表述为事实真实性已经证实。
- 远程展示共用图形运行时，并按公开内容摘要识别自动保存草稿的变化；来源摘录、讲稿和内部论点不进入远程投屏内容。

## 复现

```powershell
node scripts/verify_presentation_studio.js
powershell -NoProfile -NonInteractive -File scripts/verify_ppt_office.ps1 -PresentationPath artifacts/presentation-studio-acceptance/Pivot-PPT-Studio.pptx -OutputDirectory artifacts/presentation-studio-acceptance/office
node scripts/verify_presentation_office_geometry.js
node scripts/benchmark_presentation_rendering.js
node scripts/run_e2e_tests.js tests/e2e/presentation-studio.spec.js
```

原生形状目录可通过 `scripts/build_presentation_shapes.js --source <固定版本源XML> --check` 重建核对。来源、SHA-256、Apache-2.0 与 MIT 声明随 `client/vendor/presentation/` 保留，无运行时网络下载，也未引入完整 Python 依赖包。
