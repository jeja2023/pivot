# 基础能力第一轮验证与修复

日期：2026-10-30；对应版本：v0.7.70。以 v0.7.69 为起点，在本机隔离 PostgreSQL、可控假模型和浏览器环境进行；本记录不等同目标服务器或真实业务模型验收。

## 已修复

1. 上游模型返回 HTTP 成功但没有可显示正文或图表时，不再保存空的成功回复；保存用户消息并给出可重试的空回复错误。聊天请求记录关联该错误，同一请求标识重放时返回原错误，不重复调用模型；新请求仍可继续发送。
2. 上游只返回 HTTP 429 而没有可识别的错误正文时，按限流提示稍后重试；明确的余额/额度不足仍按原有规则优先识别。
