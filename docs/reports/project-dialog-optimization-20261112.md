# 项目空间与模态弹窗深度优化与体验统一报告

日期：2026-11-12（Asia/Shanghai）  
范围：项目空间列表弹窗、新建/编辑项目弹窗、里程碑子模态对话框、CSS 语法与全局样式统一  
测试环境：Node v24.22.0，Playwright 无头 Chromium，PostgreSQL 隔离测试库

---

## 1. 发现的问题与排查根因

1. **模态弹窗层级过重且无呼吸感**：
   - 项目主弹窗与新建项目弹窗原尺寸较紧凑（原 1040px / 780px），且多段字段垂直堆叠导致表单内容严重拥挤。
   - 里程碑字段直接展开在主表单内部，导致表单长度无限膨胀，严重影响填写体验。
2. **Emoji 图标风格与生产环境不一致**：
   - 界面中使用了 `📁`、`📂`、`🎯` 等原生 Emoji 字符，不同操作系统字体回退表现差异大，不符合全局矢量图标标准。
3. **全局样式继承污染与控件错位**：
   - 全局表单基础类 `.form-input` 设置了 `margin-bottom: 15px;` 以及 `font-size: 1.1rem;`。
   - 在项目空间搜索栏中，输入框与下拉框继承了 15px 的底部外边距，而操作按钮（`查询`、`新建项目`）外边距为 0，导致 Flex 居中计算时输入框偏上、按钮偏下，严重失去水平基准。
   - 输入框字体呈现 1.1rem（约 17.6px），相比全局工作台标准字号（0.85rem / 13.6px）明显偏大。
4. **分页控件非标准且空数据展示冗余**：
   - 原项目空间采用简易卡片手写分页（`共 0 个项目 上一页 下一页`），未接入全局统一的工作台居中分页控件规范。
   - 在无数据（0 条项目）时仍常驻显示底部分页栏，占用大面积垂直空间。
5. **CSS 语法错误**：
   - `client/chat/styles/workspaces/shared.css` 中存在一段未定义选择器的孤立属性与多余花括号代码（第 550～553 行），导致编辑器 CSS 语言服务报错 4 项。

---

## 2. 优化方案与工程实现

1. **弹窗尺寸与呼吸感重构**：
   - 项目空间主弹窗（列表与详情）宽度扩至 `min(1180px, calc(100vw - 32px))`，高度扩至 `min(840px, calc(100dvh - 40px))`，内边距增至 `20px 28px`。
   - 新建/编辑项目弹窗重构为「基本信息」、「资料范围与交付物」、「项目里程碑」三大卡片，采用自适应双列网格排版，精确微调控件高度，使新建弹窗在标准视口下无需滚动即可完整呈现全部内容与吸底保存栏。
   - 里程碑编辑/添加解耦为独立子模态弹窗（`.agent-projects-milestone-dialog`），宽度扩至 `min(640px, calc(100vw - 32px))`，最大高度 `min(720px, calc(100dvh - 40px))`，支持 Esc 键与遮罩退出、表单校验、卡片化管理与回填编辑。
2. **全量 SVG 图标替换**：
   - 彻底移除所有 Emoji 字符，在 `client/chat/agent-projects.js` 中使用原生安全的 `svgIcon(paths, size)` 动态构建轻量矢量图形（文件夹图标、空状态图标、里程碑同心靶心图标）。
3. **控件像素级水平对齐与字体规范化**：
   - 在 `client/chat/styles/workspaces/shared.css` 中重置 `#agent-projects-modal` 内的 `.form-input` 基础外边距（`margin: 0; margin-bottom: 0;`），消除 15px 偏移；
   - 统一搜索输入框、状态选择框、查询按钮与新建项目按钮高度为 `34px`（`line-height: 32px; box-sizing: border-box;`），在 Flex 容器中实现严格像素级水平对齐；
   - 统一工作台字号为 `0.85rem`（输入框、选择框）、`0.82rem`（按钮文字、表格表头）、`1.08rem`（弹窗标题）。
4. **接入全局统一分页规范与智能隐藏**：
   - 接入全局工作台统一分页组件 `renderWorkspacePagination`（`[首页] [上一页] 第 X / Y 页 [下一页] [末页]`）；
   - 当项目总数 ≤ 20（包括 0 条项目）时彻底隐藏底部分页条，空状态卡片自适应居中舒展；仅当总数 > 20 时展示标准居中分页条。
5. **修复 CSS 语法错误**：
   - 清理 `client/chat/styles/workspaces/shared.css` 中的孤立样式片段与多余闭合花括号，实现全文件零语法错误。
