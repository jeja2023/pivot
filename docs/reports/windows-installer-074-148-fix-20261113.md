# 0.7.74 升级至 0.7.148 的安装器进程检查修复

日期：2026-11-13。

## 生产反馈与定位

生产旧客户端为 0.7.74，下载 0.7.148 后没有原生安装提示；Pivot 菜单已显示“重启并安装更新／已就绪”，点击后未完成安装。直接运行 0.7.148 安装器提示“无法核对安装目录的运行状态，已停止安装”。

“已就绪”表示旧客户端已经完成下载和验签。直接安装时的提示来自 `desktop/installer-process-guard.nsh`，原实现强依赖 PowerShell 的 CIM 模块和 WMI 查询；模块加载或查询失败就会停止安装。现有错误不能归因于新包中尚未执行的验签代码。

提取历史提交 `a0dc6012` 的 0.7.74 更新器，使用 Windows 实际查询结果验证原 0.7.148 安装器和本次修复安装器，均可通过。签名状态为 1，发布者为 `CN=Pivot Local Dev`。没有回退客户端验签或取消证书指纹校验。

## 修改

- 安装器直接使用 Win32 进程快照和完整映像路径查询，移除 CIM/WMI 与 PowerShell 模块依赖。查询使用有限权限，并支持 32 位 NSIS 安装器读取 64 位客户端路径；接口约束见 [QueryFullProcessImageNameW](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-queryfullprocessimagenamew)。
- 保留安装目录边界、大小写比较和失败阻断；不终止其它目录的同名进程。自动更新通过 `--updated` 交接时最多等待十秒，让旧客户端自然退出。
- 服务端页面分别去重“发现更新”和“下载完成”通知；页面重载后提示已就绪更新，迟到的初始状态不能覆盖新事件。该页面修复需单独随服务端代码部署，不包含在本次沿用的原版 0.7.148 应用载荷中。
