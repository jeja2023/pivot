# 基础能力第二轮验证与修复

日期：2026-10-30；对应版本：v0.7.71。继续第一轮工作，使用本机独立 PostgreSQL、可控 HTTP 服务和浏览器，未连接生产业务数据库或真实模型供应商。

## 修复的问题

1. **上游错误响应**：共用安全 HTTP 封装在未指定状态策略时把 `undefined` 传给 Axios，导致非 2xx 状态可能被当作成功；已恢复默认状态判断，并保留调用方显式策略。真实 HTTP 测试验证 401 失败，GET、POST 和 PUT 默认行为及显式允许策略均有回归。
2. **模型连接测试**：非文本的地址、密钥、名称或来源返回 400，而不是产生内部异常。隔离 HTTP 测试覆盖正常响应和认证失败；连接测试检查的是模型列表接口的连通性，不能替代实际推理测试。
3. **错误流资源释放**：上游错误流长时间不结束时，读取超时后主动关闭流；正常结束和提前关闭均释放监听器。
4. **知识库索引重领**：任务租约被重新领取后，旧执行不能续租、修改任务状态、写入文档失败状态或切换正式索引；索引切换在事务内锁定并核对任务、用户、文档、执行者和领取次数。原文档错误和重建错误更新也绑定同一租约。此修复保护上述关键状态及切换，不声称已对所有外部 OCR、向量服务及跨进程故障组合完成验收。
5. **知识库批量重试**：接口等待异步调度结果，返回实际的待处理和已调度数量；调度失败由接口错误处理，不再提前返回成功和空统计。

## 测试记录

- 使用生成的 TXT、DOCX、XLSX 和文字型 PDF 测试实际解析与中文内容，PDF 原生文字不进入 OCR。
- 在隔离应用中以真实浏览器执行聊天、专题知识问答、知识库上传、PDF 引用与跨用户拒绝、工具库异常恢复及数据分析导入/清洗/图表等 8 项测试，全部通过；模型配置与空回复测试 3 项通过。模型连接使用本机受控 HTTP 测试服务，不代表真实模型供应商。
- 知识库重领、PDF 覆盖率及安全等 149 项专项通过；真实 PostgreSQL 测试验证旧任务被拒绝、新任务仍能切换索引。
- 文本附件通过浏览器上传、抽取并送入受控模型，刷新后可预览；停止生成后可以切换模型继续对话。工作流本地草稿恢复、双窗口冲突和发布版本固定的浏览器测试通过。
- 知识库批量重试使用隔离库中的已上传文档人为设置失败状态，验证接口返回调度数量、重新处理及索引内容恢复；这是对失败状态的模拟，不代表覆盖所有真实故障。
- 最后一次全量 Node 测试两组分别为 1207 通过、2 失败、1 跳过及 1198 通过、0 失败、1 跳过。失败均在受控浏览器测试中，单独复测通过；其中 Windows 临时目录清理已增加重试，浏览器上下文在高负载下关闭超时仍是待排查稳定性风险。随后补充的重试接口修复及浏览器测试未重新运行全量 Node 测试，已运行对应浏览器回归及修改文件 lint。

## 边界与后续

本轮并行启动两组隔离 PostgreSQL 测试时，用例通过但同时清理大量表触发测试库共享锁不足；已核对并顺序清理本次测试 schema，后续数据库测试顺序执行。图片和扫描件的真实 OCR 质量、附件其他类型和异常边界、真实外部连接器及各应用完整路径尚未全部验证；模型供应商、目标操作系统和生产恢复/负载仍需目标环境验收。不将模拟和合成样本视为全部基础能力完成。
