# Pivot Windows App 远程模式部署说明

本桌面包支持“一个安装包 + 外置 config.json”的分发方式。IT 可以给所有用户分发同一个安装器；需要切换生产、测试或 UAT 环境时，只替换 config.json，终端用户无感。

## 分发文件

- `Pivot Setup <version>.exe`：由 `npm run dist:win` 生成的 Windows 安装器。
- `config.json`：真实环境配置文件，安装后放到 `Pivot.exe` 同目录，或通过 `--config <path>` 指定。
- `config.example.json`：配置模板，随包放入 `resources`，仅供复制修改，不会自动作为真实配置加载。

## 配置加载优先级

桌面端按下面顺序查找配置，找到第一份存在的 `config.json` 后停止：

1. 命令行：`Pivot.exe --config C:\Pivot\config.json`
2. 环境变量：`PIVOT_DESKTOP_CONFIG=C:\Pivot\config.json`
3. `Pivot.exe` 同目录下的 `config.json`
4. 安装包 `resources/config.json`

如果以上位置都没有配置文件，应用会进入本地模式默认配置。

## 远程配置示例

`config.example.json` 内容如下，复制成 `config.json` 后按环境修改：

```json
{
  "mode": "remote",
  "environmentName": "Production",
  "remoteUrl": "https://pivot.example.com/",
  "partition": "persist:pivot-production",
  "windowTitle": "Pivot",
  "allowExternalOpen": true,
  "autoUpdate": {
    "enabled": false,
    "url": "https://updates.example.com/pivot/",
    "checkOnStart": true,
    "autoDownload": true,
    "allowPrerelease": false,
    "installOnQuit": true
  }
}
```

## 字段说明

- `mode`：`remote` 连接已有 Pivot 服务；`local` 启动安装包内置的本地服务。
- `environmentName`：显示在窗口标题中，建议填写 `Production`、`UAT`、`Test` 等环境名。
- `remoteUrl`：远程模式必填，只允许 `http` 或 `https` URL。
- `partition`：Electron 会话分区。建议每个环境使用不同值，隔离 Cookie 和缓存。
- `windowTitle`：窗口标题前缀。
- `allowExternalOpen`：为 `true` 时，非当前服务域名的外链会用系统浏览器打开。

## 本地开发测试配置

首发测试包内置 `resources/config.json`，默认使用本地开发服务：

```json
{
  "mode": "remote",
  "environmentName": "Local Dev",
  "remoteUrl": "http://127.0.0.1:3000/",
  "partition": "persist:pivot-local-dev",
  "windowTitle": "Pivot",
  "allowExternalOpen": true,
  "autoUpdate": {
    "enabled": false,
    "url": "http://127.0.0.1:8080/pivot-updates/",
    "checkOnStart": true,
    "autoDownload": true,
    "allowPrerelease": false,
    "installOnQuit": true
  }
}
```

部署到生产环境时，将 `remoteUrl` 改为生产服务器地址；如果启用自动升级，再将 `autoUpdate.enabled` 改为 `true`，并把 `autoUpdate.url` 改为生产更新目录。

## 自动升级配置

`autoUpdate` 控制 App 自动升级，业务服务器地址和升级服务器地址相互独立。

- `enabled`：是否启用自动升级。模板默认 `false`，正式启用时改成 `true`。
- `url`：更新文件所在目录，例如 `https://updates.example.com/pivot/`。只允许 `http` 或 `https`，程序会自动补齐目录末尾的 `/`。
- `checkOnStart`：启动后自动检查更新。
- `autoDownload`：发现新版本后自动下载。
- `allowPrerelease`：是否允许预发布版本。
- `installOnQuit`：下载完成后，退出 App 时自动安装。

下载完成后，App 会提示用户重启并安装更新。生产环境建议配合代码签名证书，降低 Windows SmartScreen 和 UAC 干扰。

## 自动升级发布流程

每次发布新版本时：

1. 修改 `package.json` 版本号，例如 `0.0.137` 改成 `0.0.138`。
2. 执行 `npm run dist:win`。
3. 将下面文件上传到 `autoUpdate.url` 指向的目录：
   - `Pivot Setup <version>.exe`
   - `Pivot Setup <version>.exe.blockmap`
   - `latest.yml`
4. 已安装客户端启动后会检查 `latest.yml`，发现新版本后自动下载并提示安装。

## 换环境方式

从 UAT 切换到生产时，只需要把用户机器上的 `config.json` 替换为生产配置。安装包和应用本体不用重新分发。

## 异常页与重试

远程服务不可达、VPN 未连接或证书/网络异常时，应用会显示内置错误页，页面包含环境名、目标地址和“重试”按钮。用户恢复网络后可直接重试，不会看到原始 Chromium 错误页。

## IT 注意事项

- 生产环境建议使用 HTTPS。
- 确认 `remoteUrl` 和 `autoUpdate.url` 在用户网络或 VPN 下可访问。
- 同一环境保持 `partition` 稳定，便于保留登录状态。
- 测试和生产使用不同 `partition`，避免 Cookie 或缓存串环境。
- 如果使用内网更新源，确保客户端能访问 `latest.yml` 和对应安装包。
