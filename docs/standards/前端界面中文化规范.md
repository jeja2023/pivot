# 前端界面中文化规范

## 目的

所有面向用户展示的界面文案必须使用中文，包括工具目录、工具契约弹窗、提示语、按钮和错误信息。技术标识（工具 name、schema 字段名、原始 JSON）只能出现在“技术标识”、“输入 Schema”等明确标注为技术细节的位置，不得作为标题直接展示。

## 工具标题规则

1. 工具目录对外输出的 `title` 必须是中文。
2. 新增内置或 MCP 工具时，在 `server/services/agent-tool-catalog.js` 的 `KNOWN_MCP_TOOL_TITLES` 或 `TOOL_DISPLAY_TITLES` 中登记中文标题；`TOOL_DISPLAY_TITLES` 用于数据库等通用工具（如 `db.*`）。
3. 未知工具回落时优先使用工具自带中文 `title`，其次使用去前缀技术名，且必须通过 `localizedToolTitle()` 统一处理，禁止在调用点散落英文标题。
4. 前端 `toolDisplayName` 映射与服务端目录保持一致；服务端已提供中文标题时前端原样展示，前端映射仅作为兼容旧数据的兜底。

## 验证方式

- 新增工具后，调用 `GET /api/agent/tools/catalog` 检查返回的 `title` 是否为中文。
- 在工具契约弹窗中确认标题为中文，技术标识仅出现在副标题。
