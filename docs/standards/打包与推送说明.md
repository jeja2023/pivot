# 智枢 (Pivot AI) - 打包与推送脚本中文说明

本说明文档使用简体中文说明项目根目录下两个常用脚本的作用、执行流程和注意事项，方便手动打包或推送代码前快速核对。

---

## 1. 📂 打包成安装包.bat
**存放路径**：[打包成安装包.bat](../../scripts/bat/打包成安装包.bat)  
**主要功能**：一键安装项目依赖并执行 Electron 桌面端打包，生成 `.exe` 安装程序。

### 脚本中文注释与执行逻辑说明：
* `@echo off`：关闭脚本命令的逐行回显，保证控制台界面整洁。
* **Step 1: Install dependencies**：第一步，自动运行 `npm install` 检查并安装项目所需的全部 Node.js 依赖包（如 `electron`，`electron-builder`等）。
* **Step 2: Build and package installer**：第二步，执行编译打包命令 `npm run dist:win`（即调用项目自带的 `scripts/package_desktop.js`），编译生成 Windows 的可执行安装程序。
* **输出路径**：打包成功后，安装包会保存在项目根目录的 `dist-electron-remote` 文件夹中。常见安装文件为 `Pivot Setup 0.0.180.exe`。

---

## 2. 🚀 推送至GitHub.bat
**存放路径**：[推送至GitHub.bat](../../scripts/bat/推送至GitHub.bat)  
**主要功能**：在人工确认后，将本地代码提交并推送至 GitHub 远程仓库的 `main` 分支。

### 脚本中文注释与执行逻辑说明：
* **启动位置检查**：脚本会先切换到项目根目录，避免从其他目录双击时找不到文件。
* **环境检查**：确认当前目录是 Git 仓库，并确认已安装 Node.js。
* **分支检查**：只允许在 `main` 分支执行推送，防止误推到其他分支。
* **文件检查**：展示当前修改，并拦截 `artifacts/`、打包结果、日志、数据库、压缩包等不应上传的文件；如果 `eslint.config.js` 缺失或为空，也会停止执行。
* **提交确认**：有未提交修改时，脚本会询问是否暂存并提交；提交前会展示变更摘要，并要求输入中文提交说明。
* **远程检查**：推送前会先获取远程 `main` 的最新状态；如果本地落后远程，会停止执行，避免覆盖或制造冲突。
* **推送确认**：真正推送前会列出即将上传的提交，并再次要求确认。

---

## 3. 🧹 清理建议
打包或推送任务完成后，您可以随时直接将这两个 `.bat` 脚本以及本说明文档删除，这不会改变您的任何项目核心代码。
