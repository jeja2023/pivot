# Pivot 工具包发布与签名规范

工具包以 `pivot.toolkit.json` 表达发布身份、协议兼容、权限、隐私和供应链信息。完整 JSON Schema 位于 [pivot.toolkit.schema.json](pivot.toolkit.schema.json)。

## 发布流程

1. 创建 Manifest，声明稳定 slug、语义化版本、协议版本、工具名、能力、Scope 与数据分类。
2. 使用组织登记的 RSA 公钥对应私钥，对移除 `signature` 和 `keyId` 后的规范化 Manifest 进行 `RSA-SHA256` 签名。
3. 创建草稿并绑定 MCP 服务；系统验证 Manifest、签名和 Active Catalog Release 中的工具契约。
4. 只有三项验证均通过的版本才会进入待审核状态；管理员可发布、阻断或撤销。

签名和私钥不进入模型上下文、工具 Schema、调用日志或工作流版本。工具版本升级仍须通过 Catalog Release 差异检查；破坏性变更会使依赖工作流进入 stale 状态，重新确认后才可发布。

## 最小示例

```json
{
  "schemaVersion": "1.0",
  "slug": "acme.orders",
  "version": "1.2.3",
  "displayName": "订单工具包",
  "publisher": "Acme",
  "protocol": { "type": "mcp", "versions": ["2025-11-25", "2026-07-28"] },
  "tools": ["orders.search"],
  "requiredCapabilities": ["network.request"],
  "requiredScopes": ["orders.read"],
  "dataClassification": "internal",
  "privacyUrl": "https://acme.example/privacy",
  "keyId": "acme-prod-2026",
  "signature": "base64-signature"
}
```
