# 统信 UOS 桌面操作系统（麒麟 9000 & 龙芯 3A6000）客户端打包指南

本文档介绍如何在 **Ubuntu 打包机环境** 下打压用于 **离线内网统信 UOS 电脑**（**麒麟 9000 / ARM64** 及 **龙芯 3A6000 / LoongArch64**）的 **Pivot 智枢 `.deb` 完整离线安装包**。

---

## 一、 核心机制：离线电脑如何安装运行

`electron-builder` 构建的 `.deb` 安装包为 **Self-Contained 全内置独立安装包**。

- 包内已内嵌：**Electron 运行时** + **Node.js 引擎** + **客户端 UI** + **内置服务逻辑** + **已编译好的 Native C++ 动态库**。
- **离线电脑要求**：麒麟 9000 和 龙芯 3A6000 统信电脑**完全不需要连接互联网**，只需通过 U 盘拷贝 `.deb` 安装包，双击即可完成安装与运行！

---

## 二、 硬件架构与打包命令

| 目标芯片 | 架构名称 | 离线终端类型 | Ubuntu 打包命令 | 产物安装包 |
| :--- | :--- | :--- | :--- | :--- |
| **麒麟 9000 系列** | `arm64` (`aarch64`) | 华为擎云 / MateView 统信桌面电脑 | `npm run dist:arm64` | `Pivot_0.0.261_arm64.deb` |
| **龙芯 3A6000** | `loong64` | 龙芯 3A6000 统信桌面电脑 | `npm run dist:loong64` | `Pivot_0.0.261_loong64.deb` |
| **x86 架构** | `x64` | 标准 x86 统信 / Ubuntu 电脑 | `npm run dist:linux` | `Pivot_0.0.261_amd64.deb` |

## 三、 在 Ubuntu 打包机上操作步骤

在可连网的 Ubuntu 打包机上执行：

```bash
# 1. 安装基础构建工具链
sudo apt update
sudo apt install -y build-essential python3 g++ libvips-dev

# 2. 进入项目根目录
cd pivot

# 3. 安装依赖
npm install

# 4. 执行对应架构的打包命令
# 打包 麒麟 9000 (ARM64) 包：
npm run dist:arm64

# 打包 龙芯 3A6000 (LoongArch64) 包：
npm run dist:loong64
```

---

## 四、 跨 CPU 架构打包（QEMU / Docker 推荐方案）

如果 Ubuntu 打包机是普通 **x86_64 CPU**，要精准编译 **ARM64 (麒麟 9000)** 和 **LoongArch64 (龙芯 3A6000)** 的 C++ 原生动态库 (`better-sqlite3`, `sharp`, `@duckdb/node-api`)，推荐在 Ubuntu 上使用 Docker + QEMU 异构容器：

```bash
# 在 Ubuntu 上开启 QEMU 跨架构支持
docker run --rm --privileged tonistiigi/binfmt --install all

# 使用 ARM64 容器打包 麒麟 9000 离线包：
docker run --rm -v $(pwd):/app -w /app arm64v8/node:20-slim sh -c "npm install && npm run dist:arm64"

# 使用 LoongArch64 容器打包 龙芯 3A6000 离线包：
docker run --rm -v $(pwd):/app -w /app loongson/node:20-slim sh -c "npm install && npm run dist:loong64"
```

## 五、 离线统信电脑安装部署

1. 在 Ubuntu 打包机上打包完成后，在 `downloads/` 目录中找到生成的 `.deb` 文件：
   - `Pivot_0.0.261_arm64.deb`（适用于 麒麟 9000 统信电脑）
   - `Pivot_0.0.261_loong64.deb`（适用于 龙芯 3A6000 统信电脑）
2. 使用 **U 盘 / 安全光盘** 拷贝对应的 `.deb` 安装包至离线统信电脑。
3. 在离线统信电脑上**直接双击 `.deb` 文件**（或终端运行 `sudo dpkg -i Pivot_*.deb`）即可完成安装使用。
