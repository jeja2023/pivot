# PPT 原稿编辑与视频离线部署

日期：2026-11-08。适用版本：v0.7.128。镜像：`ppt-master:6.8.0`，上游固定版本不变，新增原稿适配协议1。

## 离线运行

v0.7.133起可使用[一键离线更新](PPT引擎一键离线更新.md)自动完成镜像导出、签名、导入和生产配置；以下单独构建命令仍用于开发排查。

原稿导入、对象编辑、预览和页面视频均不调用模型、不访问互联网。Pivot负责来源授权、账号、版本、任务和下载；禁网容器负责原生包定点写回、LibreOffice静态渲染、Poppler预览及FFmpeg编码。

在准备环境构建并备齐依赖，再通过离线介质或内网仓库导入生产。任务不执行apt、pip、模型下载或更新。

```powershell
python scripts/build_ppt_master.py --checkout <固定上游仓库> --tag ppt-master:6.8.0
docker image inspect ppt-master:6.8.0 --format '{{json .RepoDigests}}'
docker image save --output ppt-master-6.8.0.tar ppt-master:6.8.0
# 在离线执行节点导入
docker image load --input ppt-master-6.8.0.tar
```

重建后须按[完整引擎部署说明](完整PPT制作引擎部署与验收.md)重新登记固定摘要和正式签名，不能沿用旧镜像摘要或临时测试签名。任务继续使用 `--pull never`、`--network none`、非特权用户、只读根文件系统和独立可写任务目录。

主服务升级创建 `presentation_native_documents` 和 `presentation_native_versions`；源包及预览使用既有CAS。备份恢复必须同时覆盖数据库与CAS文件。

## 原稿编辑

在PPT制作中打开“原稿编辑与离线视频”，上传PPTX，或打开当前工作台文稿。完整制作结果也可直接“在浏览器编辑原生对象”。此工作台以源包为权威，不把原稿重新编译为现有结构化文稿。

| 内容 | 当前操作 | 写回 |
| --- | --- | --- |
| 富文本 | 分段文字、字体、字号、粗体、斜体 | 更新原有分段，保留其余内容和对象身份 |
| Office公式 | 受支持OMML的LaTeX | 固定上游编译器写回Office Math |
| 形状与自由路径 | 位置、尺寸、旋转、纯色/线性渐变、已有调整值、前200个数值控制点 | 原生DrawingML |
| 组合 | 组合本身与组内对象的位置尺寸 | 保留组合，组内使用局部坐标 |
| 原生表格 | 单元格文字，含合并起始格 | 保留样式和合并关系 |
| 分类图表 | 同数量分类/序列的名称和数值 | 同步图表缓存与嵌入Excel工作簿 |
| 图片、SmartArt、OLE等 | 已有位置尺寸，有独立变换时开放 | 内容保持原稿，不执行嵌入程序 |
| 母版、兼容分支、未列出内容 | 保持原稿 | 未修改包条目字节不变 |

图表编辑最多200分类、20序列；散点/气泡/股票/曲面、多级分类、共享图表/工作簿不在当前数据编辑合同内。含宏或ActiveX的原稿明确拒绝。未映射内容保留不等于可任意编辑。

保存生成新版本，要求预期版本与当前版本一致，旧窗口不能覆盖新稿。恢复历史也生成新版本。下载的PPTX可再次导入继续编辑。静态预览由LibreOffice生成；可识别的独立公式在仅用于预览的副本中通过本地数学排版器生成字形，原稿和交付PPTX不替换公式。预览排版器不支持的独立公式会明确停止预览并提示处理，不静默留空；混合文字/公式、字体和其他复杂效果仍可能与PowerPoint不同，交付前应在目标软件复核。

## 页面视频

页面视频支持720p/1080p、24/30帧、直接切页/淡入淡出，以及逐页上传的WAV/MP3/OGG旁白，所有素材均可在局域网准备。

最多40页，每页基础时长0.5至60秒，整稿最多10分钟；旁白可延长停留，延长后仍受上述时长限制。输出H.264/AAC MP4，实际编码后通过ffprobe核对格式、尺寸和时长，大小还受既有产物存储上限限制。

用户必须确认页面视频模式：不播放原生对象动画、嵌入视频或交互链接，不视为原生动画保真导出。原PPTX继续保留这些内容。未上传音频的页面使用静音轨道，不登记为已生成旁白。

任务逐页保存检查点，可停止，可恢复失败可在24小时内继续。完成/取消后清理工作目录，失败检查点保留24小时后由维护任务清理；持久版本和交付文件不依赖临时目录。
